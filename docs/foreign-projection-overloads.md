# 同一 C 函数的多种输入投影

同一个同步 C 入口可以公开不同的逻辑参数表。当前支持：同一 C 描述记录的不同
`c_pack` 形态，以及只读字节片段与单列值数组之间的等价映射。调用仍使用原有
封存 IR 中的投影，生成一次真实的原生调用，没有新增分发函数。

兼容检查比较物理参数位置、C 类型和计数 ABI；数组与片段必须只读。结果、状态
成功码、效果、头文件、存储拥有和其余合同必须相同。回调、区域、固定参数等
尚未纳入这项等价规则，继续拒绝混用。每个投影自身仍须通过完整语义和 IR 校验。

同时修复只含值数组投影的公开 C 头遗漏记录对齐定义的问题。独立的
`xl6_foreign_record_abi.h` 提供对齐常量，避免为一个常量引入完整视图运行时。
对齐数值和已有记录 ABI 均未改变。

`tools/check_foreign_projection_overloads.py` 接受真实编译器与另行构建的 IR 检查器。
本次通过 JIT、独立 AOT、7 个冲突声明负例、8 个既有投影回归，共 20 个进程检查；
IR 驱动在 O0/O2 下分别拒绝 10 项篡改，并确认拒绝时不产生部分 C 或头文件。

证据位于 `F:/xlang-validation/xge-full-20261109/projection-suite-r1/` 和
`ir-gate-r3/`。编译器为语义、IR、Cgen 三个编译单元的诊断替换版本，其他对象和
内嵌资源未整体重建；这证明上述专项行为，不表示已更新或验收正式发布编译器。
完整配套编译器、内嵌 VFS 和 SDK 的构建属于后续集成交付门。
