## 修复内容

普通 C `extern` 返回 `string` 时，物理返回值是借用的零结尾文本指针。
旧 XLIR 将它直接当作拥有字符串，因此静态缓冲、C 字符串常量和参数内部地址
可能被错误释放，或者在语言层使用前被下一次调用覆盖。

本批将转换收敛到调用目标的明确合同：

- `CallTarget.resultConversionAbi = borrowed-string-copy`：真正的 C 字符串返回。
- `direct`：内部函数和已经返回拥有值的编译器运行库桥接。
- lowering 固定该合同；IR 和 Cgen 验证器都校验它，不能遗漏复制或重复复制内部返回。
- `CALL` 的 SSA 结果已完成转换，不允许借用返回跨越参数和接收者清理。
- Cgen 使用 `xrtStrDup(cFunction(...))`，不增加新的字符串实现或临时池。
- 普通调用、具名函数值适配器、native 属性/方法和协议派发保持同一语义。
- async/generator 内部调用使用同一生成路径；非可空 `string` 的 C `NULL` 返回按空串处理。

代码入口：

- `src/ir/xl6_ir.h`：返回转换合同。
- `src/ir/xl6_ir.c`：合同规则、校验及文本/JSON dump。
- `src/ir/xl6_ir_lower.c`：调用目标建立时固定转换。
- `src/cgen/xl6_ir_cgen_type_call.c`：统一直接调用生成。
- `src/cgen/xl6_ir_cgen_dispatch_persistence.c`：协议派发返回转换。
- `src/cgen/xl6_ir_cgen_identity_closure.c`：C 借用字符串的 `const char*` 原型。
- `src/cgen/xl6_ir_cgen_verify_declarations.c`：后端合同校验。

## 验证

新增 `tools/check_xlir_foreign_string_abi.ps1`，已接入语言前端测试套件。
对应 XL/C 样例位于 `test/cases/xlir_foreign_string_abi.xl` 和 `_host.c`。

测试覆盖：

- 同一个静态缓冲连续返回，以及嵌套调用前后内容保持。
- 返回参数地址，并在参数临时字符串释放前复制。
- 空串、C `NULL` 返回、复制后的语言可空字符串。
- 具名 extern 函数经函数值参数调用。
- native 属性、方法、协议派发、临时接收者销毁及实例计数归零。
- async 返回和 generator yield。
- 200 次重复创建、读取、销毁。
- 内部运行库桥接不获得多余复制标记。
- 在 `xlir_function_lower.c` 中篡改内部/外部拥有权合同，验证器必须拒绝。

## 扩展库复测

在同一组 125 个默认 XLIR 用例上复测，每例独立进程，30 秒超时：

| 范围 | 本批通过 | 本批失败 |
| --- | ---: | ---: |
| 重点/第一阶段聚焦用例 | 78 | 28 |
| HTTP/WS 包内用例 | 0 | 19 |
| 合计 | 78 | 47 |

相对原始构建恢复 53 个，原有 25 个通过项没有回退，超时 0。
这些数字是构建间的用例对照，不是完整库验收数量，也不把全部恢复项自动归为同一个根因。
构建包含工作区当时已有的其他修订；本批没有替换或同步开发中的 XRT 快照。

剩余失败按当前外显问题分组：

- 28 项缺失标准库辅助符号，包括 string、time、os、dir 和 extlib error bridge。
- 4 项生成 C 无效，包括 xmail、dotenv 及两个 WS 回环用例。
- 5 项 async/native 返回或挂起 ABI 拒绝。
- 10 项运行时/错误传播/断言失败，需逐项确认根因；完整原始输出在 JSON 中。
