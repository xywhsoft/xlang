# Dict 静态索引与精确键合同

2026-10-11。Dict 静态字面量键、计算键、普通赋值、复合赋值和空值赋值
统一使用精确字符串 SSA 与拥有型 Value 读写。原生 Dict 与现阶段显式 wire
Dict 使用同一驻留索引入口；类字段保留自身独立合同，不与 Dict 混用。
语言 Dict 工厂仍未切换原生载体，直接槽读取、递归导入和恢复继续开发。

## 语言与生成代码

`table["a\0你"]` 与计算键传递完整 `xstrview`，不用 `strlen`，不额外装箱键。
普通非空元素的缺失键产生 checked RANGE，nullable／var 的缺失键返回 null。
安全索引允许空接收者；真实原生游标、BUSY、未经绑定、非法家族或转换失败
不能伪装为安全缺失。原生权限来自驻留所有者和完整准入域，不来自裸指针或
仅相同类型编号。

读取产生独立拥有型 Value，XLIR 显式投影到元素类型并维护临时拥有锚点。
替换或释放源 Dict 后，已读取的字符串仍有效。赋值观察接收者和键，成功与
失败均恰好消费一次输入。错误作用域不能建立时也消费输入并保留首错；后续
析构回调不能替换首错。提交后的清理错误不承诺回滚已提交写入。

Cgen 只输出 `xl6DictValueReadCopyV1`、`xl6DictValueReadOrNullCopyV1`、
`xl6DictValueReadRequiredCopyV1`、`xl6DictValueSetTakeV1` 的声明化调用。
查找、原生鉴权和退役都在驻留运行时，生成代码没有 Dict 算法或类型名追溯。
旧的五种 typed Dict literal 指令被明确拒绝，原来依赖 AST／`dict` 名称的
验证与 lowering 分支已经移除，不再通过这些指令生成失败即 `abort` 的查询。
这不是直接槽性能优化：当前元素仍经拥有型 Value 投影，消除标量装箱属于后续工作。

## 验收

Windows 与 Linux 从冻结源码重建完整编译器，分别编译 293、292 个对象。
严格 O0／O2、实际生成函数、JIT 与按需 AOT 均通过。本批夹具覆盖空键、
内嵌 NUL、UTF-8、前缀键、缺失异常、nullable／safe 索引、char、字符串
快照、复合赋值及空值赋值。实际生成函数另接受真实原生 Dict 输入，逐个
故障点验证 `finally`、调用者输入保留、checked 无诊断失败和内存账本。

两端专项各执行 132 阶段、56 条完整故障前缀，覆盖读取命中／缺失、插入和
替换，直到每条首次无故障命中。实际 XLIR 的 19 次读取、5 次写入接受
509 次篡改测试，包括旧指令注入，全部在 C／头文件输出前拒绝。
5 个独立编译的错误实现对照全部被检测：遗漏原生读取、遗漏原生写入、
截断 NUL 键、吞掉 required 缺失以及边界失败不消费输入。

纯生成模块按生产计划独立链接执行。原生外部测试输入另显式加入三个输入
工厂提供方及 String 类型模块，不把它们算作生产依赖。Linux 原生专项
额外通过 75 阶段、24 条完整故障前缀的 ASan／UBSan；这不覆盖整个共享库
或完整编译器。

动态 Dict、List 索引和 Set 源入口的同源邻近回归通过。驻留目录为
254 个组件、1339 个实际导出，64516 个依赖配对和 13 个错误目录对照
通过。文档索引保留 14 项既有失败；旧文本 guard 不因此记作全仓通过。

入口为 `tools/check_stdlib_dict_exact_index.py`；证据根为 E 盘
`stdlib53-b198-*` 与 Linux `/var/tmp/xlang-stdlib53-b198-*`。早期测试夹具
编译失败和未完成复制导致的构建失败保留，不计作最终通过。
