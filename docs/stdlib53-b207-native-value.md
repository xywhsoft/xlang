# 拥有型原生值的容器传输

SlotMap 键是拥有实例记录的原生值，不能作为普通结构体逐字节复制。
共享存储底座新增明确的拥有型原生记录传输，保留真实 typed 槽与驻留
生命周期；Array、List、Set、Dict 和 SlotMap 不需要复制算法或生成
一个包装类。语言键的直接 ABI、frame 与公开 SlotMap 接线仍待完成。

## 传输和内容能力

新的传输类别独立于普通值、字符串、Value 和 Future。XLIR 与原生层
共享编号，源类型尚不凭“record”或尺寸取得此能力。新传输的驻留准入
数据明确提供类型、内容相等与哈希、空输出判断和失败原子的复制读取。
既有准入 operations 与 policy 结构保持原来的字段布局。

SlotMap 键工厂使用真实驻留类型及精确动态 converter，拥有独立的
准入元数据。空键是合法默认值；增长不需要创建临时 Value。复制读取
只保留实例记录，不分配内容。部分复制和 checked 无诊断失败先撤回
临时拥有权，再交付失败；已占用输出不覆盖。

Array 和 List 使用明确的内容能力比较键，不把“相等”伪装成排序。
键 Set 的真实 typed 存储与擦除入口使用同一内容策略，独立包装的同一
键不重复插入。普通可变对象／容器的引用身份规则没有改变；动态
`set<var>` 的不可变 native-value 能力登记仍待完成。

## 图能力与组件裁剪

原生记录必须提供 TraceSlot。键本身没有通往语言对象或容器的边，
但图解析仍须显式授权实际准入 operations，不能把所有 record 当叶。
未配准入的低层 Array 不取得键的复制读取、内容查找或哈希权限。

键准入工厂登记为独立组件；共用 Sequence、List、Set、Dict 只消费
版本化的数据合同，不硬链接键实现。普通容器不因此选择键投影、
SlotMap 算法或新的标准库公开类型。

## 验收范围

冻结 Windows／Linux 严格 O0／O2 专项各通过 72 阶段、14 组完整分配失败前缀
（86 次运行）和 4 个实际编译错误实现拒绝。覆盖原生插入、独立复制、
空默认值、跨实例键、容器释放后的寿命、精确 NUL Dict 键、封闭键 Set
擦除去重、图策略拒绝、已占用输出与有／无诊断部分复制回滚。
SlotMap 本身也保存真实拥有型键，覆盖双层实例寿命及其创建故障前缀。

双端源码构建分别重新编译 299／298 个源对象。键投影各 60 阶段和
16 次完整故障前缀、SlotMap 各 58 阶段和 32 次完整故障前缀通过；
Linux 三项原生闭包的 O0／O2 ASan／UBSan 均通过。完整目录确认
260 个组件、1381 个实际导出及 67600 个依赖对，13 个损坏目录拒绝
通过。相邻 Dict 真实产品双端各 225 阶段、480 项损坏 IR 拒绝和
666 次完整故障前缀通过，未选择键及其新准入组件。

最终原生值专项证据位于 `E:/xlang-validation/stdlib53-b207-native-win-dev4`
和 `/var/tmp/xlang-stdlib53-b207-native-linux-dev4`；源码构建及相邻回归证据
位于 `E:/xlang-validation/stdlib53-b207-verify-win-dev1` 和
`/var/tmp/xlang-stdlib53-b207-verify-linux-dev1`。最终提交另核对所选
源码与实际编译输入、产物；既有文档和两项静态门禁失败不计为通过。
专项通过不表示公开语言 API、全部 53 个模块或发布门禁完成；不改
XRT 供应库，不提升发布 DLL／SO 或 TCC。
