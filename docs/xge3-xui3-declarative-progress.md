# XGE3 / XUI3 声明式接入实施状态

更新：2026-11-02。当前是编译器基础能力检查点，八项任务尚未全部完成，发布包尚未迁移。

| 项目 | 已落地 | 剩余工作 |
| --- | --- | --- |
| 1. 原生类型 | 精确 C 接收者／参数／返回值、可空、静态继承和别名构造；caller 生命周期声明 | 与受管 owner 的接入归入第 6 项 |
| 2. 原生数据 | 按值 C record、内联固定数组、精确 const 指针、权威头布局检查、同步／异步／生成器读写 | 动态连续数据的安全地址／长度视图及实际绘制接口验收 |
| 3. 工厂 | int 状态／指针输出、部分失败回滚、const 记录地址、函数值适配 | 受管／复合输出、可能失败的参数清理期间的原生结果保护 |
| 4. 回调 | 原生记录／指针 ABI；无捕获 no-raise 函数直接传 C 地址 | 捕获环境＋userdata、注册／替换／销毁和重入、代码驻留及拥有图 |
| 5. 文本 | 保留既有值语义和安全复制路径 | 临时只读借用、长度／NUL 合同、逃逸时物化及成本验证 |
| 6. 生命周期 | caller 视图的显式责任边界 | owner／transfer／context、逃逸视图失效检查、原生销毁观察和并发／重入合同 |
| 7. 效果与生成 | C 生产者与工厂准入分开；静态回调效果检查；平凡直接 C 转发的参数放置 | 受管准备／结果／清理的完整效果合同，以及其余路径的性能核对 |
| 8. 包迁移 | 前轮 XRT 版本／源码对齐保留 | XGE/XUI 完整声明清单、移除旧转发包、宿主 XRT 实例共享、示例和交付验收 |

`@lifetime("caller")` 和 `@c_static_callback` 都是声明作者承担的原生／模块生命周期合同，不能冒充第 6 项的受管安全能力。

Windows 最新完整源码构建为 1,397 个编译单元，输入校验一致。批量入口的 11 组执行全部通过，覆盖 GCC O0/O2、TCC JIT／模块／独立程序，以及数组、工厂、回调的独立 IR 破坏性检查。Linux 已完成 1,396 单元构建与相同基础组验收；最后的别名修复另以同 ABI 单编译单元覆盖方式复测。

同一平凡 getter 的 Windows TCC 代码从 51 字节／15 条指令／48 字节栈降至 32 字节／10 条指令／32 字节栈，与手写 C 指令字节一致。Linux TCC 对照也一致；GCC O2 两者均采用相同尾调用。该结果仅适用于已验证的精确转发形态。

实现与声明语法见 [foreign-declarations.md](foreign-declarations.md)。证据摘要在 `dev/release-materials/provenance/`；当前发布索引和 `release/` 的引擎、SDK、XGE/XUI 产品未由本批更新。
