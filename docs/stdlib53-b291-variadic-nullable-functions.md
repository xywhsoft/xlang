# 可变参数展开与可空方法回调的 IR 合同

反向动态函数适配现在按 IR 中的参数展开合同，把原生 Array 的尾部
转为位置参数，把 Dict 的尾部转为关键字参数。可空函数形参和返回值
也已接入动态方法及绑定方法，使用底层函数的完整签名身份；不新增
语言语法或标准库公开函数。

## 参数展开与拥有清理

`XL6_IrCallableBridge.reverseFrameExpansionAbi` 区分不展开、Array
位置参数快照和 Dict 关键字参数快照。构建器从已解析的函数合同导出
该字段，验证器拒绝错配；Dict 可变参数也携带规范的 var 元素身份。
函数形参的反向子桥接不再把尾部容器装成单个实参。

Array 展开校验原生载体的容器身份、元素身份和物理布局，取得独立
拥有的元素引用，再调用目标函数。Dict 展开校验完整 ANY 准入和布局，
使用原生的独立游标快照；实际 wire OBJECT 使用 checked 游标。
关键字名称按精确字节跨度复制，保留内嵌 NUL，值各自拥有独立引用。
基础值保持值语义，容器和对象引用保持既有身份语义，不做递归深拷贝。

固定参数保持借入合同；构造成功后才一并发布帧和 owner，失败不改变
输出。共有 Finish 先摘除 owner，再逆序释放槽位、键名和快照，保留
首个失败，包括无诊断的 checked 失败。重复 Finish 安全，所有帧视图
在 Finish 后失效。Cgen 只选择 IR 指定的驻留构造函数并登记清理，
不在生成 C 内实现容器遍历、扩容或快照算法。

数组展开、Dict 展开和共有清理按不同提供方选择。仅使用数组可变
参数的独立程序不含 Dict 源文件或 `xl6Dict` 符号。新增三个编译器私有
驻留导出；两个新增组件与现有数组提供方一起参与精确依赖闭包。

## 可空方法回调

动态方法的可空 closure 按非空函数的签名身份匹配；null 是允许的
独立分支，错误签名在进入方法体前拒绝。默认 null、显式 null、
普通调用和绑定方法都走相同合同。可空函数返回值为 null 时返回动态
null，否则按底层签名装箱并清理原生 closure，不为 nullable 外壳
创建不存在的函数入口。
