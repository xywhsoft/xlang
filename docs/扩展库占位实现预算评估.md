# 扩展库占位实现预算评估

本文适用于当前仅有演示性 API、常量表或局部算法的扩展库。预算是新增真实实现代码的
估算，不包含已有实现的迁移、压实、测试、范例或 XRT 修复。

## 评估规则

- 少于或等于 `10000` 行，且可由 XRT/CRT 或轻量自研实现可靠完成：列为首期候选。
- 完整语义需要大型协议栈、成熟算法库、平台 SDK、模型运行时或超过 `10000` 行的新实现：暂缓。
- “名称像某个大库”不构成依据；只按完整 API 承诺与真实后端判断。
- 当前仓库的简化常量查询、格式片段或伪对象实现不等于该同名库可用。

## 当前动作

1. 继续压实已有完整实现，不受新增实现预算限制。
2. 对未来新发现的占位库，按 `10000` 行上限重新评估，并先复用 XRT。
3. 其余库保留 `deferred-large`，官网明确展示暂缓原因，不输出成功范例暗示可用。
