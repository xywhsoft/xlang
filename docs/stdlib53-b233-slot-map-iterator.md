# SlotMap 原生游标与完整键复制

SlotMap 已具备同次键值快照的原生游标，供已批准的键遍历和键值遍历
接入统一 IR。游标持有原生快照，不重新克隆数组、不扫描 wire 容器，
也不将完整键装箱再拆箱。公开 foreach 的 lowering 和投影仍待接通，
此批不表示新的语言循环已可执行。

## 四种最小入口

完整键值入口复用一次源 pin 和一次供应方遍历产生的配对快照。仅键
入口不复制值，仅值入口不复制键，全部丢弃入口只捕获原始计数。每种
入口独立登记和选取依赖，不用运行时分支把所有生产者一起链接进程序。

快照源销毁、clear 或替换不改变已捕获结构；对象和容器值仍按已批准
规则保留引用，不声称深克隆。没有公开的原始槽指针、借用键或新标准库
命名空间。单变量仍表示完整 SlotMapKey，双变量仍表示同次键和值。

完整键从当前原生键行复制到空输出，保留实例身份与 generation。
得到的键拥有独立实例引用，可以在推进或销毁游标之后继续使用。
没有整数槽号降级，也没有键 box 和 unbox 的中间分配。

## 版本和生命周期

原有 ValueIterator V2 record、View 和 NativeOpsV1 布局不变。新配对
snapshot 与 resident ops 使用独立版本；完整键复制通过新的 checked
子接口提供。回调记录为常驻不可变数据，不接受生成代码或模块拥有的
回调 context。

游标分别持有需要的键快照、值快照和当前拥有值，View 只是借用投影，
不重复计为拥有边。推进前释放上一拥有值；EOF、前置读取、错误模式和
失败后的再次使用都有独立状态检查，失败不伪装成 EOF。复制失败保持
空输出并使该游标不可继续推进。

分阶段释放先在 freeze 下断开所有真实边，再在 freeze 外释放退役值。
清理继续执行所有步骤，并保留首个物理错误，包括无法分配诊断的失败。
Finish 可以再次调用，但不会重复释放已退役资源。准入失败的原始错误
先被捕获，不会被后续无效参数或清理错误覆盖。

## 双端验收

Windows 与 Linux 当前源码驱动分别构建 314 和 313 个编译单元。
原生专项每端通过 90 个阶段、O0 和 O2 合计 76 个完整分配失败前缀，
包含失败后的同操作重试。五种传输域包括标量、精确 NUL 和 UTF8
文本、共享引用、Future 和原生键。

专项核对了四种入口的扫描与复制次数、完整代际键、源销毁后使用、
空表、EOF、部分复制和无诊断失败。真实拥有环覆盖游标、两个快照、
重复对象边和当前拥有值，验证终结器失败重试、复活后的 rooted 拒绝
及恢复后的完整释放。提前销毁和两次 Finish 均保持内存平衡。

提前 EOF、错配键行、漏掉键拥有边和复制失败后仍可读取的四种实际坏
实现均被拒绝。Linux ASan 与 UBSan 插桩覆盖这个选定的原生闭包，
不宣称整个运行时或 shipping 产品均已插桩。

四种入口每端独立链接 O0 和 O2 的 8 个程序，执行和 nm 检查通过，
共 161 个阶段。原生实现按生产组件计划选取，没有 MODULE_ALL，也
不链接编译器或发布运行时。仅值和仅计数程序没有键投影、键装箱、
键 schema 工厂或配对生产者。

源码登记核对每端 275 个组件、1427 个实际符号及 13 个坏登记对照。
既有公开 SlotMap 回归每端通过 780 个阶段、610 个完整失败前缀、
49 个调用合同和 499 项 IR 篡改，包含 JIT、模块、独立裁剪和 AOT。
这些公开回归覆盖原有方法与快照，不证明新 foreach 已完成。

写为可验证的 IR 指令，并接通 break、continue、return、finally 和
异常退出的清理。Cgen 只消费已确定的类型、布局、效果和所有权合同。
新循环还须完成语言执行、分配故障、压力和裁剪验收。

WaitQueue、三组标准库与发布总门继续；shipping DLL 与内嵌 VFS 没有
在本批重新验收。XRT 和 xruntime 原生库未修改，未决策功能未扩展，
对象池仍放在最后。专项入口为 `check_stdlib_slot_map_iterator.py` 和
`check_stdlib_slot_map_iterator_pruned.py`，均要求新的证据目录及固定
输入哈希。
