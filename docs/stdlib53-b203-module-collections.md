# 模块图读取能力与字段集合迭代

混合全局容器下的 JSON／XLON 恢复，以及 `for item in object.members`
的直接字段迭代，已在统一 IR 合同中修复。恢复仍逐个认证实际拥有图，
迭代仍取得独立快照，不引入语言引用或参数修饰。本批不新增公开 API，
不代表三组 53 模块或发布动态库已完成整体验收。

## 模块图读取能力

恢复对象的类租约可以到达模块的全部全局存储。仅声明目标 wire
类型的容器提供方，会在目标只有 Dict、其他全局已初始化 List／Set
时拒绝实际 JIT 恢复。IR 恢复根现在声明目标完整存储图与全局存储图
所需的 List／Set／Dict 读取能力；验证器独立重建并比较该合同。

Cgen 只输出同步借入的驻留适配器数组和计数，不生成遍历算法。
运行时先验证计数、指针和非空函数，再在每个节点的 Count／Trace
之前执行精确家族认证；一个家族获准不代表它的子边获准。未知
资源、未认证模块、并发占用与非法计划仍走 checked 拒绝，构造、
克隆和清理回调不在读取围栏内执行。

依赖选择器复用已登记的驻留符号。Dict-only 产品不加入 List／Set
读取适配器；模块全局真正需要的家族才进入能力计划。XRT 实现、
256 个原生组件和 1354 个实际导出均未增加。

## 集合迭代源的生命周期

IR 区分具名借入、拥有型临时值和受管理集合读观察，不再把稳定
来源等同于变量名称。读观察先求值一次，再根据实际 SSA 所有权
保住源：借入结果取得独立拥有者，已有拥有者直接消费。创建快照
后退役临时拥有者，循环体和所有退出边继续使用共用游标清理。

字段仍是可写 lvalue，没有为了迭代而改成 rvalue。临时接收者、
索引接收者和循环体替换／清空字段都不会让已取得的快照失效。
`array<int>` 字段使用同一游标资源合同；静态 Dict 的物理游标调用
改为已存在的原生 Dict 入口，不再把其 HANDLE 当作旧 wire 对象。

## 专项验收

Windows 和 Linux 完整源码分别构建 295 和 294 个对象。专项涵盖
混合全局 JSON／XLON 恢复、共享默认子对象隔离、完整 NUL／UTF-8
键值、五个字段迭代来源，以及 Dict-only 裁剪产品。

- 四个恢复根和五个读观察源；30 项实际 IR 篡改在输出 C／声明头前拒绝。
- 生成 C 确定性、实际 JIT 和独立裁剪 O0／O2 产品通过；六条完整
  分配故障前缀每端 2188 次运行，均到达首次未命中并核对释放账本。
- 实际宿主读取代码另验遗漏能力、空指针／空函数／计数溢出，以及
  未知子边在 Count／Trace 前拒绝；四条宿主故障前缀每端 166 次运行。
- 真正编译的宿主负对照删去 List 读取能力，正常向量在运行时拒绝。
  Dict 导入的旧负对照同步更新为移除目标和模块两条独立能力路径。
- Linux 对所选生成／运行时 O0 闭包和宿主原生闭包执行 ASan／UBSan；
  生成产品 O2 单独严格验证，不宣称整个编译器或发布动态库已 sanitizer 验收。

相邻深复制、Set、Dict 导入及驻留目录回归通过。初轮宿主夹具仍
使用隐含 List 能力的旧组合提供方，初轮 Dict 负对照也仅删去目标
接口；这些初轮报告保留为未通过，最终证据采用修正后的独立报告。

专项证据使用双端 `stdlib53-b203-verify-*-dev2/`；相邻深复制和 Set
在双端 `stdlib53-b203-adjacent-*-dev1/`，修正后的 Dict 导入在双端
`stdlib53-b203-dict-adjacent-*-dev2/`。最终源码和产物证书为双端
`stdlib53-b203-index-*-dev5.json` 及 `stdlib53-b203-products-*-dev5.json`。

全 53 模块和 shipping 总验收继续；本批不是语言所有迭代表达式或
