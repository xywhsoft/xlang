# xlang 0.6.2

产品版本 **0.6.2**，版本代号 **`0x00000602`**（1538），宿主 ABI 保持版本 1。

本次整理发布目录，交付当前已验收的 IDE：首页与历史记录、统一新建和打开入口、工程模板与自定义字段、空白工作空间，以及设置、集成帮助和编辑器交互改进。用户设置、工程、扩展库和 SDK 资源保留。

Windows CLI、DLL、IDE 版本资源、两平台 SDK 和内嵌编译 API 均已更新。编译器沿用已验收的源码与对象，Windows 校验并复用原生对象，Linux 使用相同源码重新以 `-O2` 构建；未将并行开发中的改动混入发布。

针对性验收覆盖两平台版本、C SDK、JIT、AOT、嵌套编译、运行时与交付检查；Windows 另外检查关于窗口、启动、输入、查找、设置、首页和模板。四份核心库的导出符号不变。本次未执行全仓回归，历史验收限制保留在材料中。

更新迭代号为 **ver3**，采用普通更新。Windows 正式更新通道的上线状态及签名、升级和 HTTPS 校验结果，以 [ver3 发布记录](../dev/release-materials/provenance/ide-update-v3-publish-20261109/README.md) 为准；Linux 本次为本地交付。

构建、清理及验收记录见 [0.6.2 交付材料](../dev/release-materials/provenance/release-0.6.2-20261109/README.md)。
