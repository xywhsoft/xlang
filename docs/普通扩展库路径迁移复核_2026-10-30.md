# 普通扩展库路径迁移复核

## 范围

本轮承接仓库根目录调整，只修正普通扩展库的使用路径，未改变库实现、
语言、ABI、运行时或 XRT。活动范围仍为优先级清单中的 100 个唯一包，
不包含独立维护的 X 生态或暂停开发的占位包。

逐包检查 100 份 README、100 份官网详情页源和扩展库总入口，合计
201 份 UTF-8 文档。修改其中 89 份包 README、16 份详情页源及总入口，
共 106 个既有文件。版本名 DEMO6 不等于仍存在 demo6 子目录。

## 路径规则

- 仓库根目录直接包含 tools、test、dev、docs、lib、src、res、release。
- 从仓库根目录执行的命令使用 release/xl.exe、release/extlibs、
  release/examples 等路径；Linux 对应 release/xl。
- 明确从 release 运行时，保留 extlibs、examples 等相对路径。
- 对原 demo6/ 开头、且目标仍存在的 64 处引用去除旧前缀；33 个唯一
  目标均核实存在，并逐段比较实际大小写，避免 Windows 检查掩盖 Linux 差异。
- 同步修正 Markdown、HTML code 标签及裸 cd 命令中的旧工作目录。
  volc.phone 的复现直接注明从仓库根目录执行，不引入目录映射或兼容入口。

历史引用不能机械去前缀：另有 46 处指向 16 个已不在当前源码中的
旧复现文件、报告或临时目录，原文保留，不伪造新链接或恢复旧实现。
总入口已说明其仅是历史现场引用；当前阻断以
[发布验收矩阵](普通扩展库发布验收矩阵_2026-10-28.md)为准。
这些缺失的历史资产不算当前可执行验证入口。

## 实际验证

| 项目 | 结果与边界 |
| --- | --- |
| 活动清单 | 100 个包，100 个唯一名称；只解析逐包 README 链接，不把共享边界表中的复现文件计为包。 |
| 文档编码 | 201 份文档以严格 UTF-8 解码通过。 |
| 路径目标 | 64 处迁移引用、33 个唯一现存目标，存在性和路径大小写全部通过。 |
| Windows | pinyin、hcl、procps 的 C/XL 双语范例，从仓库根目录及 release 各运行一次；六份源码再分别构建、执行独立程序，共 24 个进程检查通过。 |
| Linux | 同一组三包双语范例及两种工作目录，共 24 个进程检查通过；在 /var/tmp 原生文件系统快照中执行，未扩大 DrvFS 性能承诺。 |
| 输出 | 双语、不同工作目录及独立程序输出一致；Windows 只统一行尾。pinyin/procps 另对已有黄金文件，hcl 保留例内全部断言，不只比较双方打印内容。 |
| 官网源 | 16 份受影响详情页在隔离网站目录中生成，逐一与包内源码 SHA256 相等；部分生成不覆盖既有总索引。没有向外部官网部署。 |
| 不变性 | 三个受测包的 Windows 输入树前后不变；Linux 2,482 个源件复制前、复制后、执行后及原工作树复核一致；八个固定发布物/单头库 SHA256 不变。 |

初始探针曾误把 procps C 例假定在公共 examples 目录，实际入口是
release/extlibs/procps/examples/procps_c.c；纠正后重新完成全部检查。
路径检查器也纠正了尾斜杠产生空路径段的误报。这两项属于验证探针问题，
不计作库 BUG 或功能修复。
