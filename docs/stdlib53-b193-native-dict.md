# Dict 原生存储与生命周期底座

Dict 的驻留底座现在复用 XRT `typed_dict`，不建立另一套哈希表、
分配器或动态值存储。文本键按完整字节长度复制，值使用真实 typed
槽位和独立拥有的完整准入域。此批是原生底座验收，尚未切换语言
`dict<T>` 的工厂、方法、擦除、导入或持久化路径；现有语言行为不变。

## 键与值的合同

键允许空内容、内嵌 NUL 和 UTF-8 字节序列，长度是唯一输入边界。
插入复制键；修改或释放输入不会改变已存键。查找与删除平均 O(1)，
迭代使用 XRT 的稳定插入顺序，不用反复按位置查找。

值域由新建的空、已准入 Array witness 提供。Dict 只保留完整的
不可变 policy，不保留 witness、其 storage 或生成模块的回调。
域比较包含容器身份、逻辑元素身份、物理描述、transfer、nullable
规则和完整 policy，不以相同 C 布局替代逻辑域。外来 handle 在
payload 解引用前核对私有操作表。

复制型插入、替换和同域合并复用 XRT 的失败原子操作。浅 clone
创建独立键和 typed 存储；基础值复制内容，引用槽保留相同子对象。
自合并是无操作成功，错误逻辑域在合并前拒绝。

读取的 checked 成功与 found 分开，缺失键是正常结果。拥有型结果槽
必须为空；已有字符串、引用或 Future 会在查找前拒绝，避免输出
替换触发旧对象终结。这里的输出是编译器私有槽，不是语言 byref。

## 快照与退役

游标持有完整独立 typed 快照与不可变域，源 Dict 的清理或释放不
影响快照。正反向遍历都是 O(n)。键与值读出为拥有副本，输出重叠
在复制前拒绝；读取分配失败可以重试当前项，推进失败则保持 sticky
失败，不能伪装 EOF，显式 End 也不能消除失败状态。

图追踪直接枚举真实物理值槽。相同对象在两个键下形成两条拥有边，
自引用不会去重。Future 槽追踪真实控制块，并要求宿主 resolver
独立授权驻留 TraceSlot policy；不把 Future 临时装箱当作拥有节点。

分阶段 Clear 在冻结期只脱离存储，Finish 在排他区外完成销毁。
Finish 无法建立错误边界时保留 detached 存储供重试；普通析构在
边界不可用时仍释放已有资源，并保留首次 checked 错误，不因该错误
直接 abort。私有协议不变量的断言不是可恢复运行时错误的替代路径。

## 验收

`check_stdlib_dict_native.py` 在 Windows 和 Linux 均通过 54 个阶段。
两种优化级各完成 14 条连续分配失败前缀和 60 次逐点资源账本检查，
每平台共 120 次。每次尝试分别检查分配释放、存活字节和调试错误
计数，不以整批净和掩盖中间泄漏。

向量覆盖 NUL 键、输入键修改、完整 int64/uint64 范围、char 拒绝、
nullable string、bytes 准入、相同布局不同规则、外来 payload、
1024 项快照、重复引用、自环、Future、重入、无诊断错误及进入／
清理边界失败。边界故障由 GNU ld 的真实调用包装注入，不等同于
操作系统上下文资源实际耗尽。

四个错误实现均先通过严格编译，再被同一组向量拒绝：NUL 键截断、
跳过元素准入、丢失 policy 等价检查、忽略拥有边。Linux 的实际
所选供应方及驻留闭包通过 ASan/UBSan；整仓编译器与 shipping
库没有据此获得 sanitizer 验收。

源码驱动从隔离的选定源码构建 Windows 289、Linux 288 个编译单元。
新增组件登记为按需 `DICT_NATIVE`，包含 20 个明确归属的私有导出；
原生底座的实际产物不引入 List、Set 或 Array wire 转换提供方。

相邻语言回归双端各通过 Set 239、List 268、DynamicFields 108 个
阶段，包含真实严格 C、JIT、裁剪与各自完整错误前缀。完整驻留目录
双端验证 250 个组件、1313 个实际导出、62500 对组件依赖闭包；
13 个目录损坏对照全部拒绝。这不是三组标准库的总体验收，也不
替代 Dict 尚未实现的语言路径验证。

原生证据位于 `E:/xlang-validation/stdlib53-b193-native-win-dev3-final`
与 `/var/tmp/xlang-stdlib53-b193-native-linux-dev3`。相邻语言与目录
验收位于两平台 `stdlib53-b193-regressions-*-dev3`；提交前重新核对
其输入、产物和选定 index 的一致性。

## 后续语言迁移

剩余工作是明确 Dict 的完整 XLIR 配方，接通原生工厂、静态和 erased
方法、嵌套域、共享图、checked 导入及 JSON/XLON 恢复，并将宿主
拥有图 resolver 接入该原生族后验证实际语言卸载。底座不提供临时
内容 hash/equal 冒充最终语言语义，未实现的结构比较能力明确拒绝。

公开键仍限定为 string，不扩展到任意对象键。Set 的可变对象引用
身份规则保持不变。此批不关闭完整 53 模块任务、资源策略、性能、
发布 DLL/VFS 总验收或任何未决策组，对象池仍在最后。
