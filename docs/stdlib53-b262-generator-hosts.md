# Generator 专用宿主与原生 Array 对象图验收

关闭路由、首错保留、帧借入和拥有图四类专用宿主已在当前统一 IR
合同下完成双端执行。Windows 的 O0/O2 共 203 阶段通过；Linux 的
O0/O2 和所选原生闭包 ASan/UBSan 共 294 阶段通过。此次没有修改生产实现、
公开 API 或语言参数语法，也不代表完整 53 模块或发布产品验收完成。

## 关闭和首错合同

新的测试适配器连接实际生成的 C 与存量宿主驱动，不替换生成器或
原生运行时算法。每个配置执行 900 次源调用和 2700 次重复关闭序列，
检查成功、带诊断失败、无诊断失败，以及未启动、首次暂停和 cleanup
暂停三种状态。消费错误优先于清理错误，已经进入的 finally 只执行
一次；未启动生成器不执行 body。

关闭路由按源夹具的真实循环执行 19 次，逐项比对标记序列、返回值、
嵌套 finally 和 pending 错误。第二次正常 NEXT 可以在关闭前执行
普通 body 标记；关闭本身仍禁止继续执行普通 body。完整运行与关闭
的预期分别检查，避免将合法推进错误地当成关闭行为。

帧借入宿主每个配置执行 3600 次、核对 43301 次平衡分配，覆盖
string 与对象观察、共享更新、自然结束、提前关闭、析构错误及 finally。
存量驱动的循环次数与内存断言均保留。

## 原生 Array 的物理拥有图

Array 和迭代快照各由 Value 外壳及一个原生拥有节点组成。两个原生
拥有节点分别持有重复元素；语言迭代器还拥有当前项投影，View 不再
额外拥有一次。相对已淘汰的 wire cursor 表示，暂停图增加一个节点
和三条边，这是原生快照的真实所有权，不是泄漏或生成器重复持有。

测试不仅更新总数，还使用真实所有权适配器核对拓扑：直接宿主的
Array 与快照共四个 Sequence 节点、六条边，迭代器一节点、两条边；
异步源还创建一个原生单元素共享 Array，因此 Sequence 为六节点、
八条边。直接宿主传入的是 wire Value Array，不能套用异步源的数量。
源值、已转移 item、别名和队列执行根的检查保持独立。

每个配置仍执行 2400 次生成器生命周期、1000 次异步事务、2000 次
真实暂停，拒绝 1800 次运行中检查，并进行 16000 次检查探针和
6600 次实际故障。失败不得修改输出或生成器状态；首错、finally、
分配与释放、存活字节、非法释放及重复释放均继续严格断言。

## 源码和证据边界

四类专用宿主共八个 Windows 配置、十二个 Linux 配置，均使用真实
按需原生供应方。C、头和 IR 重复生成必须逐字节一致；契约测试
使用完整源码核心对象，生成程序与所选原生组件重新编译。生产输入
逐项与完整源码构建比对。拥有布局正向检查使用当前 V2，不将旧 V1
标记当作有效合同。

证据位于 `E:/xlang-validation/stdlib53-b262-hosts-win-dev9` 和
`/var/tmp/xlang-stdlib53-b262-hosts-linux-dev9`；最终选择性源码
快照为 `E:/xlang-validation/stdlib53-b262-source-final1/frozen/demo6`。
最终认证逐项核对已执行输入与该快照，前期删掉计数断言的私有诊断
程序不计入任何通过证据。测试仅驻留运行，不提供卸载许可。

DLL 卸载、跨线程冻结、工作线程及更广对象图 OOM、完整函数覆盖、
新 IR 发布库与内嵌 VFS 重建仍继续。WaitQueue 保持已决策 MPMC 与
`(status, T?)` 拥有接收；CRT 无未决策，XRT 19 个未决策组不变，
对象池仍最后。
