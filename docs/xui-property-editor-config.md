# 属性表格的编辑器配置

`PropertyGrid.setEditorConfig()` 为一个属性配置编辑器。数值编辑器接受最小值、最大值、步长与小数位数。下拉编辑器接受选项标签、值、启用状态、分隔符和图标五列数据。`optionCount=-1` 使用全部数据，要求五列长度相同。非负数量选择各列共有的前缀。设置 `useOptionValue=1` 后，属性使用选项值，其余情况下使用标签。

颜色调色板接受按本机字节序排列的 32 位颜色，输入长度必须是 4 的倍数。日期下限和上限使用 `time` 的底层数值，即从公元 1 年起算的 UTC 毫秒，与 `int64(date)` 的值相同。默认日期范围跨度使用相对毫秒。可分别通过 `useDateMinimum` 和 `useDateMaximum` 启用边界。编辑器还可设置日期格式、文件筛选、操作按钮文字和范围分隔符。

调用在栈上准备一个 C 描述符，直接调用一次原生设置函数。非空选项列需要一次临时记录投影。原生网格复制并拥有选项文字、格式字符串和调色板，调用完成后可以修改原输入。校验或内存分配失败时保留先前配置。`clearEditorConfig()` 恢复该属性的默认配置，`clear()` 释放表格中所有属性的配置。

同进程动态 AOT 对照测试重复替换包含两个选项和一个日期格式的配置。每次调用的 XRT 分配数在两端都是原生 C 3 次、xlang 6 次，释放数与分配数相同。每组 50,000 次取 7 组中位数，Windows 为 111 ms／491 ms，Linux 为 117 ms／447 ms，顺序均为 C／xlang。这组数据涵盖循环和配置替换，用于量化配置入口的转换成本。
