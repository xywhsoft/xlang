# 系统原生接口的真实产品验收

时间、日历、本地转换、时间文本和环境变量的四份原 C 宿主，以及新增的
signal 驻留入口宿主，已通过当前 Windows／Linux 实际运行库和编译库验收。
每端五份宿主以 O0／O2 运行，共二十个正向组合及七项拒绝控制通过。
本批没有修改生产编译器、标准库声明或 XRT 快照。

## 时间与环境变量

四份原宿主保留全部断言，源字节与产品冻结来源逐一比较。时间用例覆盖
完整宽度的日期参数、微秒、负 Unix 时间、日历范围、ISO 周、不可变 DateTime
快照、格式与协议向量、显式偏移和 checked 溢出。成功路径的零分配查询、
既有错误保留以及 tryParse 对输入失败与诊断分配失败的区分继续验证。

环境变量保留 missing 与空串的区分、UTF-8、无终止符输入、内嵌 NUL 和
显式字节前缀、独立拥有结果以及外部非法编码检查。每个配置有四个真实线程
完成 6,000 轮并发操作，核对读取快照完整、线程错误隔离和整体清理。
环境变量修改仅作用于各自测试子进程，不写入用户或系统环境配置。

固定快照仍使用已批准的 Unix 微秒模型，没有同步外部 XRT 的新时间模型。
POSIX 宿主只在自己的进程内设置 `TZ` 并调用 `tzset`，分别验证 New York
的一小时和 Lord Howe 的半小时 fold／gap。Windows 本机仍是无 DST 的
China Standard Time，只证明本地往返等已执行路径，不计作 Windows DST 通过。

## Signal 驻留入口

旧 signal 白盒宿主包含实现文件或使用私有计数／recorder 注入，用于有界
测试无法达到的饱和与精确竞态。它们保留为源码单元证据，不链接到本批
产品消费者，也不通过删除这些断言冒充完成迁移。

新增宿主只调用实际产品入口，INT 仅发送到私有测试进程，且有效 INT 调用
发生在 ignore 或 watch 已安装时。不使用父 PID、控制台广播或关机事件。
真实队列验证事件字段、快照分配失败不消耗待交付项、重试得到同一事件、
消费和幂等关闭、关闭后保存的独立快照仍可读。其他线程的九个可变入口被
StateError 拒绝；同一线程可正常读取，独立事件另有一百次跨线程读取。

每个配置重复完成 32 次真实 once 交付及耗尽，保留事件直至队列和 dispatcher
终结之后。故障循环另验证核心错误及队列构造、snapshot、name 和非法期限。
每条新前缀确认首个与下一个未触发点；不强迫本来不分配的 checked 错误
必须触发 OOM。公开入口测试不替代旧白盒的饱和、溢出和精确 recorder 竞态证明。

32 次 once 交付与故障／退役循环一同位于资源测量区间，不作为预热排除。
比较前置操作完成后的本进程资源基线：Windows 使用
实际进程 handle 数，Linux 枚举自身 FD 并排除枚举目录的 FD。前后相等。
这不是全进程零资源承诺，也没有把逻辑等待提升为 OS join 或镜像卸载保证。

## 故障前缀与完整账本

以下是各平台四种产品／优化组合之和。场景家族数不是模块数；一部分合法
无分配错误没有资源故障点，不能据此前缀数量推导分支覆盖率。

| 平台 | 一次性线程局部逻辑故障场景 | 实际触发点 |
|---|---|---|
| Windows | 212 | 224 |
| Linux | 236 | 212 |

Linux 多出的场景来自两个 POSIX DST 测试。每端新 signal 的 52 条前缀含
第二个未触发确认，四份原宿主保留各自原有的首个未触发确认，不虚构额外执行。

消费者复用完整堆账本观察器：清零前累计真实分配／释放，检查 live 数量和
字节、invalid free、double free、use after free；结束时仍须调试开启、无
未处理错误且整体平衡。实际 reset 被调用一次并原样返回，未拦截库内部调用。
此处不计作语言装箱故障、所有线程同时故障或生产库 sanitizer 验收。

## 编译与拒绝控制

消费者不编入编译器、XRT 或驻留实现对象。头文件来自同次构建，实际导入
核对到选定的 DLL／SO。链接前只查看外部已定义符号，同时识别强定义、弱定义、
只读数据和 PE／COFF 的弱别名，避免把私有 static 参考辅助函数误判为 provider。

每端七项拒绝控制通过：两种产品分别检查资源泄漏、关闭调试和缺失逻辑注入。
前四个程序成功编译后因对应真实断言拒绝；缺失注入的两个程序完成操作，
但被同一故障前缀谓词拒绝。伪造 provider 的独立对象同时含强函数、弱函数及
只读数据，成功编译后被定义检查拒绝，CRLF 对照同样有效。
