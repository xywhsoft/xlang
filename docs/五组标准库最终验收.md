## 中断与复核方式

Windows 的 222 例执行均成功，旧工具在整文件摘要／JSON 封存时遇到内存不足。摘要现按 1 MiB 分块，嵌套报告直接写文件；执行 AST、用例和超时不变。实际 134 MB 文件在验证子进程 64 MiB 地址空间内与独立摘要一致，旧整读被真实拒绝。

Linux 在 WSL 中断后保留原报告。先核对 148 例，再执行剩余 74 例；后续逐文件复核发现其中 3 例的 16 份证据损坏，整例剔除旧证据并实际重跑。最终组成是 148＋71＋3＝222，阶段数仍为 1,198，没有减少人口或把损坏日志算作成功。验证文件分批刷写和独立摘要核对均完成。

完整修复说明见 [原生依赖与独立产物验收](原生依赖与独立产物验收.md) 和 [异步测试合同](异步拥有图测试的忙碌重试.md)。
