# xlang 0.6.1 发布整理

产品版本为 **0.6.1**，版本代号为 **`0x00000601`**（1537）。宿主 C API 的 ABI 仍为版本 1。

本轮在当前已验收的编译器、运行时和 IDE 基础上更新版本标识。Windows CLI、两份 DLL、IDE 的版本资源，以及两平台 SDK 和内嵌编译资源均已同步；没有纳入工作区中尚未提交的语义分析和语言服务开发改动。

验收覆盖 Windows 与 Linux 的版本接口、独立 C SDK 编译链接、JIT、AOT、嵌套编译、字符串嵌入、参数及错误边界，以及 Windows IDE 的关于窗口和启动。嵌套编译与独立程序均验证返回版本代号 1537；四份核心库的导出符号清单保持一致。本轮未执行全仓测试。

发布清理移除了失效编译缓存和未占用的设置锁，并将临时 Linux 映像及本地 Agent 日志归档到 `build/release-0.6.1-20261108/`。运行资源、SDK、扩展库、用户设置和诊断记录保留。

清理和验收工具已适配 `release/win_x64`、`release/linux_x64`。版本检查从统一的产品显示版本派生预期值，同时检查 CLI、DLL、SDK 与 Windows 版本资源，避免继续固定检查 0.6.0。

实际发布产物位于 `release/win_x64/` 和 `release/linux_x64/`。这是本地发布整理；未执行远端发布，更新器的安装迭代号保持独立。

完整记录见 [验收材料](../dev/release-materials/provenance/release-0.6.1-20261108/README.md)。此前的 [0.6.0 发布前检查](prerelease-0.6.0.md) 保持为历史记录。
