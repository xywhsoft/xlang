# 可空原生值的捕获和闭包环境

2026-10-13。拥有型 `SlotMapKey?` 已接通只读闭包捕获、task／then、
Future／await 和生成器传递。存在位和独立拥有的载荷共同保存；来源
函数返回、任务结束或生成器提前退出，不会使已取得的键失效。本批
不新增公开标准库 API，不修改 XRT 算法或单头。

## 捕获配方与环境版本

可空键登记独立的永久捕获配方，精确描述类型、身份和清理动作。
版本化捕获运行时允许已声明可空、可复制、非引用的 optional leaf，
不会将它当作 POD，也不凭相同结构体大小或外国 TypeId 取得能力。
清理先在短暂 mutation 范围内清空整条记录及初始化标记，再退出该
范围释放载荷；包括部分取得但尚未设置存在位的引用。

普通闭包此前没有原生拥有值捕获 ABI，现在统一 IR 提供独立的
copy-native-value 合同和环境版本要求。版本在可达性确定后完成选择，
验证器重新推导并核对。原生键和可空原生键的只读捕获采用 checked
复制，不使用共享裸指针或通用动态装箱代替拥有值。

原生闭包环境采用现有 Capture V2 描述与独立的 Closure V3 入口。
运行时保存实际环境大小、永久原生环境策略和受真实代码 lease 保护
的描述。布局验证、图遍历、回滚与销毁由运行时完成；Cgen 只输出
类型、槽偏移、配方和 checked 状态输送。共享语言 cell 仍使用既有
生命周期。旧闭包、动态方法及 capture-free 入口保持原版本。

可空键的异步捕获及返回复用已有 native Future 和生成器合同。空值
与存在但载荷为空的原生键是不同值，不能根据载荷指针推断存在位。
未使用程序不选择新组件；普通原生键捕获与可空捕获分别登记供应方。

## 双平台验收

Windows 320、Linux 319 个完整源码编译单元通过。专项分别通过
435、471 阶段；严格独立 C 的 O0／O2、实际 JIT、module 与 AOT
均成功，每个优化等级运行 100 次模块生命周期。

调用线程分别执行 334、328 次复制／分配前缀检查，失败后完成清理并
重试，内存数量和字节平衡通过。异步等待的路径随完成时序变化，
两端检查次数可以不同；该注入范围不包含 executor 线程的分配，
不能外推为所有并发时序或工作线程 OOM 已验证。

原生单元每个优化等级检查 1004 次 detach，包括真实独立键、存在的
空键、部分取得载荷、整块／稀疏环境、重复清理、失活毒化槽和环境
大小不匹配时保留目标。跨线程 freeze 探针确认释放不在该 detach 的
mutation 中；健康清理不触发分配。新闭包具有可检查的图 adapter，
环境尺寸拒绝后仍可用正确尺寸重试和释放。

2 个可空词法捕获、3 个 callback 槽和 11 个 await 的 22 项 IR 篡改
均被拒绝。一个真实坏编译器破坏捕获配方；两个真实坏供应方分别
遗漏存在位清空或恢复过时的 record-only 准入，均被测试拒绝。
混合闭包覆盖普通键、可空键、内嵌 NUL 的 UTF-8 字符串和共享整数 cell。

Linux ASan／UBSan 覆盖生成程序、全部 34 个所选供应方和两个测试
宿主。旧 nullable 闭包与 cell 每端 8 个 JIT／module／AOT 阶段通过；
此前默认值／转换／合并回归每端 151 阶段及 54 次分配检查通过。
整批声明／严格 C 检测每端 292 夹具／583 阶段通过，其中保留一个
预期语义拒绝。驻留目录为 281 组件、1449 个精确导出与 13 个拒绝
对照，未使用程序仍只选择原先 3 个供应方。

最终证书核对所选源码、完整编译输入、产物及日志。证据位于
`E:/xlang-validation/stdlib53-b249-*` 和 Linux 的
`/var/tmp/xlang-stdlib53-b249-*`。中途失败运行和诊断部分链接不计入
最终验收；本批未更新或认证 shipping DLL／VFS／SDK。
