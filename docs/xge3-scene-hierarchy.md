# 3D Scene 层级与共享拥有

本批补齐 `xge3d.createScene()` 和 `xge3d.Scene` 的 CPU 基础能力：节点创建／销毁、
父子关系、代际 ID、名称及查找、局部／世界变换、双精度原点和全局位置、可见性、
层掩码、统计及独立共享拥有。需要匹配的 `XGE_ENABLE_3D=1`、
`XGE3D_ENABLE_SCENE=1` SDK，不创建窗口或 GPU 上下文。

新手示例：[scene_hierarchy.xl](../lib/bindings/xge/three_d/examples/scene_hierarchy.xl)。
代码按节点、变换、查找、共享和关闭顺序组织，不加载裸 DLL，也不引入示例专用类。
默认父级用 `Xge3dNode()` 零值表示；节点是带场景 ID／代际的独立值，销毁子树后，
旧 ID 无法访问重新使用的槽。`nodeAt`／`childAt` 越界返回零 ID，沿用原生规则。

## 调用与拥有

业务方法直接声明实际的 `xge3dScene*`／`xge3dNode*` 函数，没有逐方法转发 C 层。
类的通用 `@scope` 声明分配一个栈上指针大小的原生调用记录；policy 只处理调用
保活、checked 释放和拥有图元数据。每次调用在复制借用输出前持有真实原生引用，
最后一个应用拥有引用在调用中释放时，物理销毁等到对应原生 AccessEnd。

`share()` 创建独立原生引用与语言视图。普通语言赋值仍共享同一个视图；对它
`close()` 会使其普通别名失效，独立 share 不受影响。访问和最终原生销毁受创建
线程约束。原生 checked 释放分别报告状态和引用是否已消费，拒绝后保留重试义务。
拥有图使用原生计数、活动调用、准备、可继续 finalize 和完成接口，不伪造叶计数。

`name()` 在调用保活作用域内把借用 C 字符串复制成独立 `string?`，保留 NULL。
`setName` 使用通用 `@c_cstr` 准备有效终止文本并拒绝内嵌 NUL；原生保存一份名字。
`clearName` 通过通用 typed NULL 声明直接调用同一个原生函数。`find` 返回
`(status, node)`，保留 NOT_FOUND 和清零输出；其他状态型方法使用 checked 错误。
矩阵与统计输出是独立记录，`size` 由通用声明初始化。

## 验收

Native：`fb0b60669ace63eea6c6da950aac0ba2f90f4c40`；XRT：
`4641cd2e4da09d8b1a66872cabe085c263d8b5ba`。复用已完整构建的 O2 编译器，
没有替换编译器／SDK 的个别生产目标文件。两个平台各重新构建 hosted/static
原生 SDK，共660个编译单元、零对象复用。

Windows/Linux 各11条原生检查和28条语言构建／运行检查通过，覆盖：

- C O0/O2、真实 hosted/static SDK、共享／活动保活／错误线程／拥有图完整清理，
  OOM 回滚、陈旧节点、变换和四线程创建128个独立场景。
- C11、C++11、C++17 生成头，JIT、动态／静态 EXE，以及范例的相同三种运行路径。
- 动态／静态 DLL/DSO 的实际调用、checked 模块退役和物理卸载。Windows 宿主在
  `FreeLibrary` 前调用既有 `xl_script_runtime_retire_checked`，退役 runtime 的
  OS 线程存储；模块清理本身不等于整个内嵌 runtime 已具备卸载条件。
- 名称快照、内嵌 NUL 拒绝、失败后旧名字保持、空查找状态、语言视图失效、活动
  回调中关闭及抛错、12档构造／交付分配预算。原生全堆回到基线，语言夹具检查
  错误释放计数和 checked 模块退役；不把它描述为整个编译器堆归零证明。

新增夹具使用独立的 `foreign_xge3d_scene.*` 名称。原有 2D Scene 夹具保留原样，
并使用本批 SDK 在两端各补跑一次 JIT 回归，原生场景栈、回调、失效视图和 checked
重试均通过。较早重名候选的源码字节与原始报告保留在外部材料中，没有覆盖历史报告。

源代码审查／重放分别为399／400项。新增公共头仅插入13个拥有接口及说明，
经换行归一化后，其余头文件文本完全不变；只更新4处头依赖指纹，没有改变这些
旧接口的实现或存储合同。重放后的最终候选与运行验收候选逐文件、逐字节一致，
因此无需为这次指纹更新重复运行没有改变的程序。

独立复核还检查了冻结源码、SDK 目标文件／依赖、产物、包、日志和程序哈希。
证据索引：`dev/release-materials/provenance/xge3-scene-hierarchy-20261117.json`。
完整原始资料保留在外部验证目录。

## 实测开销与剩余范围

两个 x64 平台一致：原生旧 Scene 体积672字节，本批兼容体积680字节；拥有对象
追加32字节生命周期记录，总计712字节、一次原生分配。原生 share 不分配新的 Scene 本体。
语言首次创建／share 的实际 XRT 申请量为：

| 验收路径 | 创建分配次数／请求字节 | share 分配次数／请求字节 |
| --- | ---: | ---: |
| JIT、动态 EXE、静态 EXE | 3／1248 | 2／536 |
| 动态与静态共享库内调用 | 2／1184 | 1／472 |

包含原生对象、语言控制和适用的代码保活；不包含底层分配器额外开销或 OS 分配。
语言与原生各1000次暖态查询的 XRT 分配为零。受保护调用仍有访问／错误作用域、
引用与活动计数、拥有变更域操作；名称还存在输入检查、必要的终止缓冲及输出复制。
没有声称这些方法与不受保护的裸 C 调用具有相同 CPU 耗时。

本批不公开裸 `user_data`、存储型加载回调或 GPU 指针。完整渲染、GPU 资源、
模型／动画及它们与 Scene 的共享拥有继续接入；本批也未安装正式 release、IDE
或帮助目录。全量长期目标没有结项。
