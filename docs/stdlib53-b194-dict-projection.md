# Dict 驻留投影与动态值边界

Dict 原生底座补齐不可变驻留转换合同、动态读写、拥有型键快照和
显式单层导入导出。存储仍使用真实 XRT `typed_dict`，不增加第二张
表，也不在 Cgen 增加算法。此批是私有原生边界验收，语言 `dict<T>`
的工厂、方法配方、图消费者和恢复入口尚未切换。

## 转换与准入

转换器是完整、无 Context、生命周期独立于生成模块的驻留声明。
绑定不能替换；克隆和游标保存相同合同。引用槽只使用标准 retained
reference 转换器，保持真实对象身份，不走 XRT 动态值深克隆，也
不修改源子对象的名义类型身份。

XRT 的普通 Value 转换优先处理内建物理类型，自定义转换器只是
fallback。因此 Dict 显式执行声明的驻留转换，再核对完整逻辑域
和物理槽。小型值使用对齐的栈内临时槽，较大或更高对齐值使用
溢出检查后的临时分配。转换、准入和首次 checked 失败均在 XRT
插入提交前检查，不能用一份貌似有效的结果掩盖无诊断失败。

动态读取区分 checked 成功和键存在。take 先完成最终值的投影与
准入，再删除键；投影失败不会损失已存值。读出目标必须是空的
私有拥有槽，避免替换旧结果的终结错误发生在输出发布后。

## 快照与显式导入

正反向游标拥有独立 typed 快照。每次动态推进同时发布拥有型
Value 和独立拥有的精确文本键，支持空键、内嵌 NUL 和 UTF-8。
输出重叠在推进前拒绝；推进、投影或键复制失败后保持 sticky
失败，不能伪装 EOF。这不是 ValueIterator 的借用键扩展接口，
后续语言遍历需要单独接通正确的键生命周期。

wire 导出明确产生一层 `XVALUE_OBJECT`。基础值投影为独立值，
引用子对象保持真实引用；它不代替递归复制或 JSON/XLON 持久化。
导入消费私有、空、已绑定的 seed，成功与失败都消费。完整域和
驻留转换器相同的原生来源使用 XRT 原子 merge；其他原生域先
显式投影，再逐项核对目标域。只接受字符串键 wire object；源
不变，别名、非空 seed、未绑定、BUSY 或无效原生对象都明确拒绝。

## 专项验收

Windows 和 Linux 的原生 gate 各通过 70 个阶段。O0、O2 各完成
23 条连续分配失败前缀、101 次逐点资源账本检查，每平台共 202 次。
八个实际错误实现严格编译后被同一组向量拒绝，包括忽略逻辑写入
准入、物理解码准入、逻辑投影准入及无诊断解码失败后的错误提交。
Linux 的所选原生闭包通过 ASan/UBSan，不等同于整仓 sanitizer。

向量包含完整 uint64、char、nullable string、bytes、外来 handle、
名义域冲突、重入、无诊断失败、源销毁后的正反快照、引用与自环、
同域快速导入和异域 checked 导入。实际产物没有 List、Set、Array
wire 或未使用的 XRT typed_dict Value 包装函数。

隔离源码驱动构建 Windows 289、Linux 288 个编译单元。相邻语言
回归双端各通过 Set 239、List 268、DynamicFields 108 个阶段；
完整驻留目录核对 250 个组件、1327 个真实导出、62500 对依赖闭包，
13 个目录损坏对照拒绝。原有两项文本 guard 的首次失败及文档
索引的 14 项历史诊断不变，不能标成全仓 guard 通过。

证据位于 `E:/xlang-validation/stdlib53-b194-verify-win-dev1` 与
`/var/tmp/xlang-stdlib53-b194-verify-linux-dev1`。提交前重新核对
实际输入、产物与选定 Git index，仅包含本批变更。
