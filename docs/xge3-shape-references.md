# Shape 和 ShapeScene 查询

`parentScene()` 返回父场景，游离节点返回 `null`。`shapeAt(index)` 按场景的子项索引读取图形，索引无效或指向子场景时报告 checked 错误。`childAt(index)` 同时适用于两种子项，返回类型、可空图形和可空子场景。

`maskInfo()` 返回原生蒙版方法、目标类型和两个可空的目标。`clipShapeAt(index)` 返回图形和裁剪模式。`hitTest()` 和 `hitTestEx()` 执行原生场景命中检测，未命中时返回 `null`，后者还接收父变换。

每个非空结果持有独立的原生引用。移除对应子项、清除蒙版或裁剪，或关闭查询的接收者后，结果仍可使用。关闭结果会释放它的引用。图及其查询沿用原生 Shape 的线程约束，同一可变图的访问和释放应在同一线程进行。

底层直接执行原生查询，再为每个非空结果接收一个现有引用。接收失败时释放本次已接收的引用。对象数据和图结构留在原有存储中，语言拥有视图需要自身的控制对象。

## 共享图形和场景

`Shape.share()` 和 `ShapeScene.share()` 取得同一对象的独立拥有引用。任一视图关闭后，另一份视图仍可使用。对共享图形的修改在其他视图中可见。需要独立副本时使用 `clone()`。

两个方法直接调用 XGE 的拥有入口。原生引用计数达到上限时报告 checked 状态错误，原计数保持不变。语言视图分配失败会回滚本次共享引用。同一可变图仍在创建它的线程访问。

Windows 和 Linux 的完整 O2 编译器均通过 JIT、动态和静态 AOT 检查。热 JIT 对照各执行 1,000 轮，每轮共享并关闭一个图形与一个场景。C 循环无 XRT 堆操作，xlang 循环分配并释放 4,000 次，均无重分配。

示例先关闭原场景视图，再使用共享场景执行命中检测。关闭场景后，命中的图形仍由自身的引用保活。 [运行示例](../lib/bindings/xge/examples/shape_references.xl)
