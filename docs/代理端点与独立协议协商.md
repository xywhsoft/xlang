# 代理端点与独立协议协商

本批提供 `NetProxy` 和 `NetProxyHandshake`，复用固定 XRT 的 `net_proxy`、
`net_proxy_handshake`、`net_proxy_socks5`、`net_proxy_http_connect`。后者是独立
sans-I/O 状态机：只处理调用者交付的字节，不连接代理，不解析 DNS，不创建
Socket／Engine／线程。本批不代表 TCP／UDP／Dial 等完整 P3 传输接入完成。

## 不可变代理端点

```xlang
auto proxy = NetProxy(NetProxyType.socks5, "127.0.0.1", 1080)
auto authenticated = net.proxy(NetProxyType.httpConnect,
    "127.0.0.1", 8080, "user", "password", NetProxyAuth.required)
```

`NetProxy(type, host, port, username="", password="", auth=automatic)` 同时提供
bytes 凭据重载；该重载必须显式传入 username、password。host 为完整 UTF-8
控制文本，不接受 NUL；port 为 1—65535。凭据传递完整字节，不附带截断 size，
避免静默改变身份。SOCKS5／HTTP 的具体配置限制由现有 XRT 检查。

| 公开面 | 含义 |
| --- | --- |
| `NetProxyType.socks5`／`httpConnect` | 两种代理协议，不以普通整数替代类型 |
| `NetProxyAuth.automatic`／`none`／`required`／`optional` | 原生认证策略；不静默放宽显式策略 |
| `type`、`authentication`、`port` | 查询独立配置；automatic 查询为归一化后的实际策略 |
| `host()` | 拥有型 string 副本 |
| `username()`、`password()` | 拥有型 bytes 副本，保持精确字节与 NUL |
| `clone()` | 新语言拥有壳，共享原生不可变配置的独立保活引用 |

automatic 在无凭据时归一化为 none，有凭据时归一化为 required；不是“认证失败
自动降级”。析构释放原生引用，原生最终释放清除凭据存储。显式取回的语言凭据
副本是调用者另外持有的数据，不能宣称会随端点一同清除，不应输出至日志。

移除旧普通整数 `net.proxyNone`／`proxySocks5`／`proxyHttpConnect`、裸指针
构造和公开 `nativeHandle()`；不保留尚未发布接口的兼容包袱。旧
`TcpConnectConfig`／Dial 整体迁移尚未完成，其声明不能算作已可用传输能力。

## 独立增量协商

```xlang
auto h = NetProxyHandshake(proxy, "127.0.0.1", 443)
assert h.state == NetProxyHandshakeState.write
auto pending = h.output()
```

构造为 `(NetProxy proxy, string targetHost, int targetPort,
receiveLimit=65536, maxBufferedBytes=67108864)`。原生独立保活 proxy 并复制目标；
targetHost 是完整非空／无 NUL 的控制文本，targetPort 为 1—65535。

两种预算都必须为正：receiveLimit 约束协议接收解析，maxBufferedBytes 约束
语言拥有的全部待消费输入，包括与回复同包到达的应用尾部。前者不能替代后者，
也不限制应用以后的完整传输。协议实际状态和默认解析行为复用固定 XRT。

| 功能 | 接口与合同 |
| --- | --- |
| 状态 | `state`、`step()` 返回 write／read／ready／failed |
| 输出快照 | `output()` 返回第一段待发送数据的独立 bytes；无输出时为 b"" |
| 复用输出 | `outputInto(Buffer, size=-1)` 追加第一段数据，返回实际追加字节数 |
| 确认发送 | `sent(size)` 仅确认实际已经发送的字节数，支持部分写入 |
| 输入 | `append(string|bytes|Buffer, size=-1)`，复制输入 |
| 移动输入 | `appendMove(NetBuffer)` 转移真实拥有块，源清空 |
| 数量 | `buffered`、`maxBufferedBytes` |
| 状态码 | `replyCode()` 返回 `(bool, uint32)`；bool 区分尚无回复码与合法的零 |
| 错误 | `throwIfFailed()` 重新抛出保留的原生错误 |
| 应用尾部 | ready 后 `readRemaining(size=-1)` 返回并消费 bytes；`moveRemaining(NetBuffer)` 转移全部剩余块 |

处理顺序由实际调用者的传输驱动：write 时获取待发输出，传输完成后用真实
写入数量 sent；read 时追加实际收到的数据后 step。拷贝 output 不代表发送，
不能直接以“请求长度”替代实际写入长度。两个输出方法都不消费，也不自动执行
sent。outputInto 追加至已有 Buffer，调用者负责管理该 Buffer 已发送的内容。
一次输出只暴露首个连续段，不承诺囊括未来所有协议消息。

append 与 size 均按字节，-1 为全部，非负数超出输入／可用长度时截断，其他
负数 checked 拒绝。字符串使用双字段 ABI，内嵌 NUL 不截断。appendMove／
moveRemaining 是实际 O(1) 块链移动，不保留源语言对象／调用者池的隐藏引用。
outputInto 在目标预留容量足够时不分配输出，普通 output／readRemaining 则
明确创建拥有副本。

step 仅消费协议部分，ready 后同包的应用尾部保留。readRemaining 完成拥有值
分配才消费输入；分配失败不提前丢数据。moveRemaining 只在 ready 后允许，
已有目标对象无需重新装箱。不能在协商尚未完成时取走回复输入。

协议错误由 step 抛出 checked 异常，同时记录失败状态并保留原生错误；失败后
禁止继续 append。没有虚构 reset：原生协商器不提供复位，需重新构造。析构只
释放资源，不进行 I/O 或补发协议，也不替代调用者观察失败结果。

## SOCKS5 bound 元数据

ready 后 `boundHost()` 返回严格 UTF-8 域名或格式化数字地址的 string 副本；
`boundHostBytes()` 保留原始域名字节，数字地址时为空 bytes。原始域名不满足
UTF-8 时应使用 bytes 方法，不能塞入 string。

`boundFamily()`、`boundPort()` 返回原生元数据；`boundAddress()` 返回独立
拥有的数字 `NetAddress`，域名型 bound 不进行隐式 DNS，checked 报 NotFound。
HTTP CONNECT 没有这类 bound 端点时沿用原生 NotFound，不伪造远端地址。

## 同步、拥有合同与生成代码

配置不可变；协商器可变，同一个实例的重叠／重入操作以一次 CAS checked
拒绝，不在复制／分配期间自旋。调用者如需跨线程组合多个调用，必须显式同步；
输出快照本身独立有效，但 output／发送／sent 整个事务不是多发送者协议。
外部 Buffer 参数同样不能被另一线程同时修改。

两类对象登记独立原生拥有域；协商器拥有输入块与原生状态，原生保活的配置
没有指向语言对象、回调代码或外来池的隐藏拥有边。不可空资源字段必须显式
初始化，不能依靠无实参隐式构造；延迟创建可使用可空类型。

32 个驻留调用合同核对名义枚举、精确宽度、拥有方、错误、效果和非阻塞属性，
状态码复用现有 `(bool,uint32)` 产品 ABI。可能分配或因重叠调用失败的入口不
误标 no-raise。Cgen 只生成声明、直接调用及既有拥有清理，没有输出代理实现体。

10 个新增驻留组件分别按需选择配置、协商、bytes、Buffer、string、地址投影和
拥有域。单独配置不拉入协商；单独协商控制不拉入连续 Buffer。通用协商器按
运行时协议类型选择已有 SOCKS5／HTTP CONNECT 后端，不能声称单协议体裁剪。
这些入口均不拉入 Socket／Engine／Resolver／TLS 或默认异步执行服务。
