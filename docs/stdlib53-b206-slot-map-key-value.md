# SlotMap 键的动态值投影

SlotMap 键具有实例记录与代际槽组成的值语义。原生键的复制、移动和
释放独立于槽表存储；装箱后的两个独立 Value 仍按同一个键比较，而非
包装地址。精确投影与内容键能力已通过冻结双端原生专项。
语言 `SlotMap<T>`、`SlotMapKey`、统一 IR 与擦除后的 Set 接线仍待完成。

## 原生键与装箱

原生键保持双字段结构，不引入裸槽 ID、整数到指针的编码或全局实例
计数器。实例记录只被键保留，不拥有 SlotMap、元素或生成代码。
槽表删除、clear 和代际隔离语义沿用原生底座。

动态投影有固定驻留 converter；编码借用原生键并产生独立 Value，
解码返回一个独立拥有型键。解码仅接受固定语义类型 ID 和真实驻留
handle producer，两者缺一不可。在读取原生指针前认证 producer；
相同类型 ID 的外来 handle 不能借此获得键能力。

原生键复制和解码不分配内容。装箱需要不可变拥有型负载及 Value 壳；
Value 深复制可以共享这个不可变负载，不复制槽表或恢复失效槽。
部分复制、类型绑定及错误边界失败都撤回临时拥有权，保留首错和
无诊断对象的 checked 失败。已占用的键输出拒绝覆盖。

## 相等和哈希

键相等比较实例记录与完整代际槽，不比较包装壳或可移动元素地址。
哈希调用 XRT hash64，输入是两个明确的整数字段，不读取结构体填充。
XRT 另为 boxed Value 哈希加入 tag；两个表示层分别遵守相等键同哈希，
不要求原生哈希与 boxed 哈希数值相同。哈希和实例键都不是持久化 ID。

驻留 typed Set 内容策略只授予相等和哈希，不伪造排序操作。普通 Set
的可变引用身份规则保持不变。公开语言键之前，IR 必须同时接通精确
键类型与擦除路径的不可变值能力；本批不把普通 handle 默认策略当成
键内容策略，也不提前开放一个行为不一致的语言 API。

## 按需组件与验收

原生键生命周期和动态投影分别登记组件。仅保留原生键不需要槽表
算法、装箱或哈希；动态键投影也不依赖 SlotMap 存储算法或 Set 存储。
对象图只观察 Value 叶节点，键没有通往语言对象、容器或代码的边。

严格 O0／O2 专项检查独立包装的相等、哈希一致性、typed Set 内容
能力、真实 converter、零键、跨实例键、容器释放后键寿命、伪造
producer 拒绝、部分复制回滚、首错及完整分配失败前缀。实际编译
错误实现分别省略 producer 认证、改用包装地址相等、省略解码复制
或泄漏失败复制的拥有权。Windows／Linux 的键专项各通过 60 个阶段、
8 组完整故障前缀（16 次运行）和 4 个编译错误实现拒绝；拆分后的
SlotMap 原生回归各通过 58 阶段、14 组完整故障前缀（32 次运行）
和 4 个编译错误实现拒绝。Linux 两项 O0／O2 原生闭包通过 ASan／UBSan。

双端源码驱动分别重新编译 298／297 个源对象。目录确认 259 个组件、
1378 个实际导出和 67081 个依赖对，13 个损坏目录拒绝通过。三种
键组件专用计划均验证存储与投影分离；相邻 Dict 真实产品双端各
225 阶段、480 项损坏 IR 合同拒绝和 666 次完整故障前缀运行通过，
未选择 SlotMap 或键组件。

最终键专项位于 `E:/xlang-validation/stdlib53-b206-key-win-dev3` 和
`/var/tmp/xlang-stdlib53-b206-key-linux-dev3`；槽表回归位于同平台的
`stdlib53-b206-native-*-dev1/map`，完整目录位于
`stdlib53-b206-catalog-*-dev2`，Dict 回归位于
`stdlib53-b206-adjacent-*-dev1/dict`。提交证书另核对最终所选源码和
实际编译输入／产物。文档及两项静态门禁的历史失败保持原状，不记为
全仓通过。

本批不改 XRT 供应库，不更新发布 DLL／SO、TCC 或 VFS，不表示三组
53 模块或全仓门禁完成。语言键的直接 ABI、frame、值投影准入、Set
擦除规则、SlotMap 公开方法和迭代仍是后续必须完成的工作。
