# 数据恢复实例域

日期：2026-10-09。已批准的容器与持久化迁移现区分静态字段配方和
实际初始化的子对象，修正私有恢复事务合并不同默认实例的问题。
XLIR 明确标记字段实例节点；私有原生恢复 API 已实现对应合同，但
生成的语言持久化入口仍使用旧路径，整体 53 模块任务继续。

## 实例身份与静态配方

同一个 ClassField 配方会出现在多个父实例中。若两个父实例的子对象
分别保留默认值 a 和 b，而 wire 输入引用同一个子节点，仅按源 Value
与静态节点索引复用结果，会将这两个实际子对象合并并丢失默认状态。

`FIELD_INSTANCE` 对象节点必须从 IN_PLACE 字段边取得实际初始化的
非空子对象，没有声明工厂，也不能作为根、集合元素或替换字段的目标。
节点的实际类生命周期、名义身份及 runtime tag 在 wire 拒绝和 memo
查找前验证，先前的成功结果不能掩盖第二个父对象中无效的子对象。

memo 的完整键为源 Value、节点索引、实际字段实例。声明工厂及既有
Array 类型链的第三项为空；字段实例使用实际子对象。memo 结果持有
该对象的真实引用，第三项无需另行分配 token 或保留额外引用，查找
和扩容都比较完整键。不同实际子对象保持独立；同一实际子对象在
同一配方下遇到同一源节点时保留别名。一个子对象遇到冲突的 wire
节点或不同配方仍 checked 拒绝，不重复写入已恢复对象。

声明替换和字段原位恢复不能混用一个节点。原私有手写夹具将两者
混用的做法已移除：实际私有子对象只初始化一次，替换对象执行自己
的声明工厂。声明域内的跨字段或集合元素共享继续保留。

XLIR 从规范 ClassField 上下文生成字段实例标记，验证器重新构图比对；
遗漏、伪造或与 nullable 混用的标记均在 C/header 输出前拒绝。
没有 AST 或类型名称查询进入运行时，也没有新增公开标准库 API。

## 语言切换条件

字段实例标记表示需要实际构造能力，并不证明默认对象图是私有的。
类初始化表达式可以返回外部共享对象；仅根是新对象不能授权修改
所有子对象，也不能悄悄调用 clone 绕过资源类的复制能力限制。
完整初始化上下文和别名能力必须在语言切换前闭合。

Cgen 对共享原生恢复事务的接入、开放 DynamicFields、模块 owner 和
List 的完整语言载体仍须协调切换，随后才能移除旧逐类型递归生成。
本批的 C/JIT 是既有路径回归，不是原生计划的语言执行证明，也没有
AOT、shipping DLL/SO/SDK/VFS 或全产品 sanitizer 验收结论。
Set/Dict typed 迁移、SlotMap、WaitQueue/Channel、OrderedMap 公开合同
及 53 模块产品总门继续。CRT 无未决策，19 个 XRT 未决策组不变，
对象池最后；宿主持锁恢复仍使用既有 checked 四接口和手动解锁。
