# 旧字符串生成桥清理

公开 `string.*` 使用精确长度的驻留声明，字符串算法由 XRT 与独立运行时
提供方执行。被这些入口替代的 26 个 `__xrt_string.*` 内部登记退出标准库；
它们不再让 Cgen 生成第二份查询、分配和编辑实现。

## 清理范围

移除旧 emitter、对应的 26 个需求字段、26 个桥接枚举／精确合同／名称标签，
以及 10 份失去引用的参数表。登记数量从 989 降至 963，标准库哈希索引和
XRT 能力矩阵由生成器同步；没有修改 XRT API 或算法。

旧内部入口包括 compare、lastIndexOf、count、hasAny、like、approx、
similarity、isUtf8、lower、upper、trim/ltrim/rtrim、filter、left/right、
charAt、isEmpty/isBlank、remove/removeAt、insert、三种 pad 和 reverse。
公开相似度入口仍是 `string.sim`；charAt 返回 `char`，不是旧的原始指针。

其他库仍引用的内部 byteLen、数字格式化等依赖保留。本批没有借机移除
网络、文件、密码学或其他尚未评估的库，也没有移除语言自身的字符串运算。
字符串近似运算符仍调用 XRT 算法，不依赖被删除的内部标准库函数体。

## 生成与互操作边界

调用退役的内部命名空间成员应在生成前拒绝，不写出 C。显式 C FFI 与标准库
登记分开：当前旧 C 符号保留普通外部声明能力，但编译器不再为其生成函数体。
实现必须由显式互操作方自行提供，不是隐藏的标准库兼容层。

公开入口继续保留 NUL／UTF-8、可选 size、拥有结果、函数值和错误合同。
测试清单分别固定退役名称、参数及旧返回类型；生成后的公共程序必须没有
这 26 个旧名称，真实 IR 中的文本调用必须使用驻留 TEXT_VALUE 合同和原生闭包。

## 验收要求

使用普通构建的真实 CLI／DLL／SO，而不是编译器源码对象或替代提供方。
旧产品对照检查 26 份函数体确曾生成；新产品逐项检查内部命名空间拒绝与
C FFI 不再生成实现，并执行公开功能的源树隔离 JIT、模块、严格 O0／O2 C
及迁移后的独立 AOT。Linux 同时核对真实 SO 的桥接种类和原生产物计划。

首轮构建被登记／能力矩阵守卫拒绝，报告保留原样；同步生成物后使用新快照
重新普通构建。IDE、扩展库及已有 Windows response-template 迁移不纳入
本批，release 产品不提升或覆盖。完整 53 模块完成审计仍继续。

## 实际产品专项结果

两端普通 CLI／DLL／SO 重建成功，Windows 63、Linux 65 个专项阶段通过。
每端 26 个内部成员在写出 C 前拒绝；26 个显式 C FFI 仅生成声明，未生成旧
函数体。旧产品对照确实生成全部 26 个函数体，因此不是只清除了无引用文件。

公开程序覆盖全部 26 项对应能力，以及 NUL／UTF-8、size 截断、拥有结果、
函数值、语言近似运算和仍使用底层格式化依赖的数字格式。源树隔离的 JIT、
模块、迁移后的独立 AOT、O0／O2 保存 C 均通过。Linux 真实 SO 另确认 26 个
旧名称不再属于字符串桥合同，26 个公共文本目标使用 TEXT_VALUE 与驻留闭包。

相同普通构建配置下，与前一生产实现对照，Windows `xlc.dll` 从 13,256,192
降至 13,239,296 字节，Linux `libxlc.so` 从 13,757,032 降至 13,736,552 字节。
这是本机产物差值，不是跨平台固定节省量或运行性能基准。

专项报告位于 `D:/xlang-validation/stdlib53-b336r2-target-win/results.json` 和
`/var/tmp/xlang-stdlib53-b336r2-target-linux/results.json`。首轮守卫失败证据在
对应的 `b336r1-build-*`，保持原样。

## 完整清单与输入一致性

两端 324 项完整产品清单与独立迁移 AOT 清单均通过适用项；产品正例各 315
项，AOT 正例各 314 项。清单分别保留 7／8 项专用宿主要求，并各含一个预期
拒绝和一个平台条件，不把这些项目计为普通程序执行。

Windows／Linux 产品总门分别完成 659／661 个阶段，17／19 个必需子门
全部通过。只有同一产物下独立完成的本批字符串专项在复核后复用，其他子门
重新执行，包括键域 IR 破坏、拥有图、worker 故障与队列并发。Linux 的 325
项绑定发现继续完整覆盖 142 项原生签名、228 项静态签名，无额外或缺失绑定；
这是源码绑定，不是全部运行分支覆盖。

完整证据复算在两端分别核对 19,769／11,451 个唯一输入、产物和日志文件。
总门和 AOT 报告分别在 `D:/xlang-validation/stdlib53-b336r2-products-win`／
`stdlib53-b336r2-aot-win`，以及 `/var/tmp/xlang-stdlib53-b336r2-products-linux`／
`xlang-stdlib53-b336r2-aot-linux`。提交前另逐项核对生产输入与选择索引，
后补的验收脚本／C 观察程序必须有当前报告的哈希证明，不改变冻结生产实现。
