# XUI 范例补全与验收（2026-11-06）

已按当前声明式绑定重写全部 48 个旧范例入口，保留原有 8 个资源／生命周期范例，共 56 个可运行入口。`_support.xl` 提供窗口循环，`all_controls.xl` 通过下拉框切换 47 个场景；切换时先释放菜单／浮动窗口，再销毁旧页面。每份独立范例均有真实控件配置或数据，不恢复旧包装类。

范例源位于 `lib/bindings/xui/examples/`；普通运行包的 `release/<platform>/examples/xui/`、两个平台的 `extlibs/xui/examples/` 及 Windows 可选静态 SDK 均安装相同文件。Windows 可双击 `run_xui_examples.bat`，也可从运行目录执行 `xl.exe run examples/xui/all_controls.xl`。README 提供逐项索引、字体、运行及静态链接说明。

## 必要修正

- 在绑定生成器中登记 21 项直接声明／重载，补充安全数组、描述和输出投影；不增加每方法 C 转发函数。
- Context 内部查询 Proxy 时保留真正的拥有身份，避免缓存 Surface 创建被拒绝；旧 C 借用后端仍使用自己的快照。
- 表格原始列接口借用标题，临时语言数组不能满足该合同。新增原生 `xuiTableViewSetColumnsCopy`／`xuiTableGridSetColumnsCopy`，复制列 ID 和标题；旧借用接口保留原行为。存储在替换、回滚和销毁时维护真实拥有引用，支持重入。
- Accordion 内部分区客户区是依赖父对象的别名。语言声明直接向 AddSection 传 NULL 输出，再按需显式读取客户区，避免用独立工厂回滚规则处理内部对象。
- 两个编译器平台均补入选定 XRT 编译单元需要的三项内嵌 SDK 别名。Windows 只替换两个资源对象；Linux 旧构建未保留链接对象，因此按原冻结源码和 O2 参数重编两个生产配置（2835 个编译单元）。未安装松散的 SDK C 源码。
