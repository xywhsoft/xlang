# ShapeScene 深度优先遍历

`scene.visit(visitor)` 同步访问根场景及其子节点，顺序是先父、后子。回调返回 0 即正常停止，返回其他值继续。回调抛出的语言异常由原调用交付。

`ShapeVisit.kind` 区分图形和场景。`ShapeVisit` 仅在当前回调内有效。从 `node.shape` 或 `node.scene` 取得的非空对象持有独立原生引用，可以保存，并在使用结束后关闭。

遍历期间，原生层保护根场景及其后代的子节点列表。对这些列表执行添加、插入、移除、清空，均返回 checked Busy。读取、嵌套遍历和独立场景的修改仍可执行。遍历遵循原生形状算法的 32 层深度上限。

遍历直接调用一次原生函数，使用已有的同步回调入口。原生层保活根场景，并沿原子节点列表迭代。只读取类型时无需生成节点副本，读取图形或场景时才接收独立拥有引用。

[运行示例](../lib/bindings/xge/examples/shape_traversal.xl) 会输出 `Visited shape 7`，无需初始化绘图设备。
