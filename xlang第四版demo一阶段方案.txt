一、一阶段范围定义
================================================================================

	- 类型系统（原生类型 + var + auto）
	- 变量定义与常量定义
	- 字面量（数字、字符串、布尔、时间、数组、列表、集合、字典）
	- 运算符（算术、比较、逻辑、位运算、赋值）
	- 函数定义（func 关键字、参数、返回值、重载）
	- 流程控制（if/elseif/else、for/in、while/do）
	- 内置函数（print、println、type、len 等）

本阶段排除（后续阶段实现）：
	- class / custom / object / carray
	- namespace / using
	- extern / 外部函数声明
	- 闭包
	- try / catch / finally / throw / Error
	- with 语句
	- async / await / yield（协程）
	- 匿名函数
	- 模块系统（import / export / include）

七、类型转换（构造即转换）
================================================================================

7.1 设计原则
------------
- 类型转换 = 从其他类型构造目标类型
- 由目标类型决定如何接收，无优先级问题
- 编译期重载决议，零运行时开销


7.2 内置类型转换
----------------
int(3.14)           // 截断为 3
float(100)          // 提升为 100.0
string(123)         // 转为 "123"
bool(0)             // 转为 false
bool("")            // 转为 false


7.3 类型名的多重角色
--------------------
int a = 1           // 1. 类型声明
type(a) == int      // 2. 类型字面量
int(3.14)           // 3. 构造函数调用

8.1 基本语法
------------
// 无返回值
func name()
    // body
end

// 有返回值
func name() as int
    return 0
end

// 多返回值
func name() as int, string
    return 0, "ok"
end


8.2 参数
--------
// 带类型参数
func add(int a, int b) as int
    return a + b
end

// 无类型参数（默认 var）
func process(a, b)
    return a + b
end

// 混合
func format(string s, val)
    return s + string(val)
end


8.3 默认参数
------------
func greet(string name, string msg = "Hello")
    println(msg + ", " + name)
end

greet("Tom")            // Hello, Tom
greet("Tom", "Hi")      // Hi, Tom


8.4 可变参数
------------
// 数组可变参数
func sum(...)
    int total = 0
    for v in arg
        total += v
    end
    return total
end

sum(1, 2, 3)            // arg = [1, 2, 3]

// 字典可变参数
func config(***)
    for k, v in arg
        println(k + " = " + string(v))
    end
end

config(name: "test", value: 100)


8.5 函数重载
------------
func add(int a, int b) as int
    return a + b
end

func add(float a, float b) as float
    return a + b
end

func add(string a, string b) as string
    return a + b
end


8.6 多返回值接收
----------------
func divmod(int a, int b) as int, int
    return a / b, a % b
end

auto (q, r) = divmod(17, 5)     // q=3, r=2
int x = divmod(17, 5)           // x=3（只取第一个）


8.7 命名参数
------------
func createPoint(int x, int y, string label = "")
    // ...
end

createPoint(x: 10, y: 20)
createPoint(y: 20, x: 10, label: "P1")

九、流程控制
================================================================================

9.1 条件分支（if）
------------------
// 单行形式
if exp then statement

// 多行形式
if exp
    // code
elseif exp
    // code
else
    // code
end


9.2 迭代循环（for）
-------------------
// 遍历数组
for v in arr
    println(v)
end

// 遍历带索引
for i, v in arr
    println(i, v)
end

// 遍历字典
for k, v in tbl
    println(k, v)
end

// 遍历范围
for i in range(1, 10)
    println(i)
end

for i in range(10, 1)       // 倒序，自动步长 -1
    println(i)
end

for i in range(1, 10, 2)    // 步长 2
    println(i)
end


9.3 条件循环（while / do）
--------------------------
// 前置条件
while exp do
    // code
end

// 后置条件（至少执行一次）
do
    // code
while exp end


9.4 循环控制
------------
break           // 跳出当前循环
break n         // 跳出 n 层循环
continue        // 跳过本轮

十五、编译器实现架构（建议）
================================================================================

15.1 模块划分
-------------
main.c                  主程序入口
src/
    xl_common.h         公共定义（类型、宏）
    xl_token.h          Token 定义
    xl_lexer.h          词法分析器
    xl_ast.h            AST 节点定义
    xl_parser.h         语法分析器
    xl_semantic.h       语义分析器
    xl_codegen.h        代码生成器
    xl_runtime.h        运行时支持
    xl_builtin.h        内置函数


15.2 编译流程
-------------
源代码 (.xl)
    ↓
词法分析 (Lexer)
    ↓ Token 流
语法分析 (Parser)
    ↓ AST
语义分析 (Semantic)
    ↓ 标注后的 AST
代码生成 (Codegen)
    ↓ C 代码
TCC/GCC 编译
    ↓
执行 / 生成可执行文件


15.3 运行模式
-------------
xlang file.xl           TCC 即时运行
xlang -c file.xl        编译为可执行文件
xlang --emit-c file.xl  输出生成的 C 代码
xlang --dump-ast file.xl    打印 AST
xlang --dump-tokens file.xl 打印 Token

================================================================================
附录：与第三版的主要差异
================================================================================

1. 函数关键字：function → func
2. 整数类型名：int8/uint8 → i8/u8
3. 浮点类型名：float32/float64 → f32/f64
4. 时间字面量：#2000-01-01T12:00:00 → #2000-01-01T12:00:00#
5. 移除 meta to / meta from，统一为构造函数 + toXxx() 方法
6. with 语句：with ... as ... → with ... to ...（本阶段不实现）
7. 移除 is 关键字，使用 type(val) == Type 替代
