# XGE Twemoji core SVG data

This generated data set contains the Unicode Emoji 17.0.0
fully-qualified sequences that do not contain a skin-tone modifier, plus the
nine Unicode Emoji components. It contains 1923 SVG files.

Unicode sequence data:
https://www.unicode.org/Public/17.0.0/emoji/emoji-test.txt

Graphics source:
https://github.com/jdecked/twemoji
Twemoji 17.0.3 commit b6b55fef1e8636b540a6d016a4729ca8cdf2e60b

The Twemoji graphics are licensed under CC-BY 4.0. The complete graphics
license is included as LICENSE-GRAPHICS.

Regenerate from the repository root with:
powershell -ExecutionPolicy Bypass -File tools/generate/emoji_pack/prepare_core_svg.ps1
