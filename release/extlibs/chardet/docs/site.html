扩展库 / chardet

chardet

文本处理

基于 XRT 的 Unicode 编码猜测与字节检查。读取普通文本或原始 Buffer，区分 BOM、编码置信等级与 UTF-8 有效性。

文本与原始字节

import chardet

println(chardet.detect("你好"))       // UTF-8
println(chardet.confidence("你好"))   // 90
println(chardet.isAscii("hello"))     // true

五项函数均接受 string 或 Buffer，没有额外可选参数。普通文本直接借用，不先复制成 Buffer；原始文件、网络数据和 UTF-16/32 使用 Buffer。

函数返回值与含义
detect(data) as stringUNKNOWN、UTF-8、UTF-8-BOM、UTF-16LE、UTF-16BE、UTF-32LE、UTF-32BE。
confidence(data) as int0..100 的猜测等级，不是统计概率，也不保证正文有效。
bomSize(data) as intBOM 的字节数：0、2、3、4，不删除或消费输入。
isUtf8(data) as bool整个字节区间是否为合法 UTF-8，检查截断、过长编码、代理项及 Unicode 范围。
isAscii(data) as bool所有字节小于 128，允许 NUL 和控制字符；不是可打印字符检查。

空输入依次得到 UNKNOWN、0、0、true、true。无法识别、非法 UTF-8 都是正常结果，不抛异常。 本库没有 GBK、Shift-JIS 等传统字符集统计识别模型，也不执行转码。

BOM 不等于正文校验

import chardet

Buffer raw = Buffer()
raw.appendByte(239)
raw.appendByte(187)
raw.appendByte(191)
raw.appendByte(255)
println(chardet.detect(raw))    // UTF-8-BOM
println(chardet.bomSize(raw))   // 3
println(chardet.isUtf8(raw))    // false

BOM 优先，置信等级为 100；无 BOM 的 UTF-16/32 使用字节分布和编码合法性启发式，短输入可能不确定。 普通 ASCII 文本当前为 UTF-8/40，合法非 ASCII UTF-8 文本为 UTF-8/90。

编码猜测与字节有效性是独立问题。例如含零字节的 UTF-16 ASCII 文本，也可能同时是合法的 UTF-8/ASCII 字节序列。 应保留原始数据，由应用决定是否接受猜测，不能把猜测直接当成格式验证。

长度、所有权与错误

Buffer 保留真实长度和 NUL 后的字节。当前共享运行库 string.byteLen 对含 NUL 的语言字符串仍有已知截短问题； 此类输入使用 Buffer，语言层缺陷仍在独立用例中跟踪，不作为本库已解决的边界。

原生输入只借用、不修改、不保留；返回名称为静态只读数据，不能释放。xlang 的 string 返回边界复制名称，由语言管理释放。 独立调用可以并发；检测期间不能并发修改输入内存。

C 的空指针加零长度是空输入；空指针加非零长度为 XERR_ARGUMENT，在 xlang 中映射为 ValueError。 原生入口清除旧错误，C 调用者检查 xrtGetError()。原生检测不分配内存，语言返回字符串复制仍可能发生内存分配。

C API

公共头为 extlibs/chardet/include/chardet.h，实现为 chardet_native.c。 依赖 XRT_MODULE_CHARSET_DETECT，不需要另一份字符集检测引擎。

入口合同
xchardet_detect_name_nvoid* 与 size_t 输入，返回借用 const char*。
xchardet_detect_conf_n / xchardet_detect_bom_size_n相同输入，返回 int。
xchardet_is_utf8_n / xchardet_is_ascii_n相同输入，返回 bool。

每项另有 _str 入口，首参数是 const char*，仍显式传 size_t；两组共 10 个 ABI。 一次需要编码、BOM 和置信等级时，C 可直接调用 xrtEncodingGuess(xbytesview)，避免分别探测三次。

双语范例

发行目录运行 xl run examples/extlibs/chardet_basic.xl。 C 对照为 extlibs/chardet/examples/basic.c，需要一同编译 chardet_native.c； 开发仓库也提供 tools/run_extlib_c.ps1 -Package chardet -Source release/extlibs/chardet/examples/basic.c。 两者对照同一份 chardet_basic.expected.txt，覆盖全部五项 API。

验证范围

Linux 独立 C 使用 ASan/UBSan、泄漏检查和 LP64 原型核对。不表示 Linux xlang、32 位/ARM、TSan、 共享字符串 NUL 缺陷或全部平台已经验收。门禁为 tools/check_extlib_chardet.ps1 与 .sh；源码和构建变化后须复验。
