扩展库 / dotenv

dotenv

2026-11-02：修复普通键 export 在等号前含空白时误作前缀；export = worker 与 export=worker 一致，export NAME=value 的前缀语义不变。新增组合语法、限额、失败回滚与逐次内存检查，以及不改环境的双语范例。公开API、ABI、依赖和所有权不变；原M2顶层配置对象退出边界仍是必过正例，未据局部通过签收整包。

解析 UTF-8 .env 文件，独立管理配置，并在需要时显式导入进程环境。

版本 1.0.0 · C / xlang · 无扩展库依赖

快速开始

import dotenv

auto config = dotenv.create()
config.parse("HOST=localhost\nPORT=8080\n")
println(config.get("HOST"))
config.set("PORT", "9090")
println(config.get("PORT"))

输出 localhost 与 9090。解析和设置不会自动修改进程环境；需要时调用 config.apply(overwrite = false)。

安全重载与所有权

examples/reload.xl 与 examples/reload_c.c 使用同一黄金输出：坏配置保留旧值，成功解析整体替换，已保存的文本跨修改和clear继续有效。C查询返回借用，需要跨修改保留时显式调用 xrtStrDup 并以 xrtFree 释放；XLang普通string结果独立持有内容，不能把原生借用结果标成owned。

C对照范例与XLang范例使用不同基名，不作为自动接入的同名C companion；门禁覆盖GCC、C直跑和两种语言的独立EXE，失败保留现场。

接口

入口用途
create()创建空的独立 Config；分配失败时抛错。
parse(text, maxBytes = 4194304)按真实字节长度解析 UTF-8 文本。
load(path, maxBytes = 4194304)从 UTF-8 路径加载文件。
config.parse(text, maxBytes = 4194304)在现有对象上整体替换配置；失败保留旧条目。
config.load(path, maxBytes = 4194304)从文件替换现有对象配置；失败保留旧条目。
get(key, defaultValue = "") / has(key)读取键或检查存在性；空值与不存在有区别。
set(key, value) / clear() / count修改或查看当前对象，不影响其他 Config。
apply(overwrite = false)显式写入进程环境；默认保留已有变量。
errorCode / errorLine / errorText()查询对象最近一次底层失败。

支持 BOM、LF/CRLF、行首 export、注释和单/双引号值；孤立 CR 报格式错误，双引号解析常见转义，不做变量插值。键名遵循 [A-Za-z_][A-Za-z0-9_]*，重复键采用最后一次赋值。键值由 XRT 有序映射保存，查询和解析无需逐项扫描；clear 释放条目及桶容量。create、parse、load 都会拒绝底层创建失败；解析失败不替换已有配置；apply 的多键进程环境修改不提供事务回滚。

配置文本中的 NUL 按真实长度拒绝；键、值和路径含内嵌 NUL 也会在进入 C 字符串接口前被拒绝。XLang 的 maxBytes 必须为正；C 的零限额只允许空输入，非空输入报 LIMIT 且不替换原配置。原生 *Native 成员仅供类内部调用，包外不能自行传入文本长度。文件操作使用 XRT 的 UTF-8 路径接口。C 操作成功后不会遗留上次失败的线程错误；apply 中的内存分配失败保留内存错误并在 xlang 抛 MemoryError。

原样配置与转义

export 本身不是保留键。export = value 写入普通键，export export = value 是前缀加同名键。未加引号的 A=a#b 保留井号，A=a #comment 才把空白后的井号作为注释；A= #comment 是存在的空值。

examples/literal_values.xl 与 literal_values_c.c 对照相同的七行输出：重复键、单引号路径、字面量 ${USER}、井号、空值、双引号制表符及普通export键。XLang使用raw多行字符串保留.env源文本，仅dotenv解释其中的双引号转义。默认不读写文件、不调用apply，不修改或展开宿主环境。

新增C合同夹具按明确输入/预期构造3564种空白、键、前缀、引号、注释、行尾组合，再检查有效/无效输入、限额与OOM的旧值保留和立即恢复；逐次核对七内存指标。它不是完整fuzz，也不宣称与其他dotenv实现具有所有语法兼容性。

C 对照

#include "xrt_dotenv.h"
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char* source = "HOST=localhost\nPORT=8080\n";
    xrtdotenv* config = xrtDotenvCreate();
    if (config == NULL || !xrtDotenvParse(config, source, strlen(source), 4194304u)) {
        xrtDotenvDestroy(config);
        return 1;
    }
    puts(xrtDotenvGet(config, "HOST"));
    if (!xrtDotenvSet(config, "PORT", "9090")) {
        xrtDotenvDestroy(config);
        return 2;
    }
    puts(xrtDotenvGet(config, "PORT"));
    /* 读取的字符串借用自 config，修改或销毁后失效。 */
    xrtDotenvDestroy(config);
    return 0;
}

公共头为 extlibs/dotenv/include/xrt_dotenv.h。C 返回的字符串借用自 Config；xlang 返回的字符串独立持有。失败时使用 xrtDotenvErrorCode、xrtDotenvErrorLine 和 xrtDotenvErrorText。
