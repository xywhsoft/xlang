# 完整图结果顺序与寿命验收

## 范围

本轮没有确认新的产品算法 BUG，也不修改四个生产 C 单元、头文件、
XLang 声明、API/ABI、模块或资源上限。增强的是此前未充分断言的
稳定顺序与完整结果合同，不将新增负控当作产品修复数量。

`test/ordered_records_c.c` 穷举512种三节点有向图（含自环）与64种
四节点前向 DAG。每张图按正向、反向两种输入运行，反向同时反转节点
首次声明顺序并加入重复边，共1152张图、27776次公开调用。
这不是所有四节点有向图或任意规模图的穷尽证明。

名称分为非字母顺序、空串和 NUL 前缀、中文/补充平面、大小写与 NUL
后缀四组。每个返回名字按真实字节长度辨认，不靠 strlen/前缀匹配
把不同节点当成同一个。结果统一输出节点编号，仅用于跨平台确定性对照。

## 独立参照

`test/check_ordered_records.py` 不调用图包，不读取其私有结构或比较器。

- 枚举所有简单路径，以长度与输入边次序选择完整最少边路径；按这些
  路径的层级和次序确定 BFS，而不是再实现一次被测 BFS。
- 非负整数小权重的距离取所有简单路径成本的最小值；次正规数、浮点
  上界等继续由原3072条 Bellman-Ford/float64位模式参照负责。
- 穷举合法拓扑排列，再以每个节点的就绪时刻与最后入边次序检验 FIFO
  入队约束；不复制产品 Kahn 队列。
- 用有向/无向可达关系独立构造强弱分量，核对完整成员及内外层顺序。
- 邻居核对去重后首次出现次序，节点列表按独立 bytes 排序。JSON 比较
  区分布尔和整数，不能利用 Python 的 True == 1 放宽记录类型。

四个错误输出负控分别倒置邻居、倒置 SCC 分量、改选另一条合法等长
路径、改选另一条合法拓扑序。它们仍可能满足旧的成员/合法性断言，
但新完整参照全部拒绝。负控不修改生产源码。

## 所有权与错误

C 夹具先保留同图全部结果，执行完所有查询并释放输入后，才逐项读取
结果；后一次调用不能破坏前面的节点名字、顺序或距离。每张图最终检查
存活数/字节、非法释放、重复释放、上下溢、UAF七项指标。
拓扑环和不可达路径在调用后立即核对 ValueError，其他调用必须无错误。
默认 C 模式检查记录结构、名字完整性、寿命与内存平衡；完整答案由
门禁的记录模式及独立 Python 检查器验证，不能只拿默认 PASS 替代参照。

旧128图 Floyd、218实际分配失败点、四线程1000轮、3072加权记录、
九个实际生成原型以及双语十行范例与 DLL/SO 顺序复用均继续执行。
没有为通过新测试删除旧用例，或改变本包分配失败与异常合同。

## 实测结果

Windows PowerShell5.1默认49阶段，前48项通过，只最后原中央语言数组
输入失败；63个输入/工具指纹不变。Linux原生 `/run` tmpfs 中独立复制
55份文件，49阶段前48项通过，最后同样失败；含 C ASan/UBSan及泄漏
检查，冻结来源与实际工具指纹前后一致。两平台均实际完成新记录的
GCC、TCC运行、独立 C AOT逐字节对照及独立参照；四条普通 AOT与两种
DLL/SO各三轮十行黄金输出也通过。

默认门禁仍真实返回1，而非把最后原语言失败改成预期成功。
Windows最小源 `dev/extlib_blockers/graph_var_array_projection.xl` 本轮再验：
check/build为0，JIT与独立EXE均为1，仍报 `graph edges must be an array`。
不在本包识别编译器私有句柄，不将原数组先序列化成JSON来绕行。
修复建议与本轮复验补入共享 foreign-var 投影记录，整包状态保持 M1。
