扩展库 / volc.phone

volc.phone

火山引擎云手机 ACEP 客户端草案。

当前不可用于生产请求。 XLang 导入链仍被独立维护的 xhttp.client 构造器及成员解析错误阻断；在线请求和整包 AOT 未验收。响应解析分片的 Windows/Linux 离线 JIT/AOT 已通过。

当前源码范围

入口用途与状态
Client / Response请求参数与响应对象草案；当前不可导入运行
raw_call / call_spec定型请求直连 volc.core.request_acep，spec 为显式入口；在线调用未验收
preview_call / preview_spec显式离线签名预览，不发送请求
list_pods / detail_pod / create_pod / wait_task云手机资源与任务入口；未验证真实服务
product_body / pod_body / create_pod_body请求体构造草案；待离线夹具核对

待完成的边界

响应助手使用结构化 JSON，仅按 ResponseMetadata 和 Result 的明确层级读取；离线对象、转义和错误输入已测。定型请求不再把值拼入逐行 spec；预览和请求也不再由 timeout_ms=0 隐式切换。C 对照范例复用 volc.core 的公开定型入口，两平台离线门禁已通过。依赖导入恢复后仍须完成在线 mock、完整双语运行和真实服务验收。

复现命令：在 demo6 目录运行 release/xl.exe check dev/extlib_blockers/volc_phone_import_chain.xl。详细现状和限制见包内 README；示例代码目前仅作草案，不应填入真实密钥运行。
