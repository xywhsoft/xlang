扩展库 / singleinstance

singleinstance

按名称互斥的实例锁；同名进程与同进程的独立包实例不能同时持有。

支持 UTF-8 名称与进程退出自动解锁。2026-11-02 修复清理首因覆盖、关闭失败误作普通争用及 POSIX 无效句柄继续解锁。Windows 43/Linux 45 阶段分别前 42/44 符合，含实际 C 子进程、独立双包实例、三生成原型和每平台八份普通 AOT；最后真实双 XL_Context 仍因 M8 失败，两平台默认门禁均保持红色。深主目录长路径也尚待收口，不签收整包发布级。

API

入口用途
acquire(name) as bool成功为 true；同名进程占用为 false；XLang 名称含 NUL 或其他输入错误抛异常
release()解锁，允许重复调用
isAcquired() as bool查询当前包实例是否持锁

xlang

import singleinstance
if not singleinstance.acquire("my_app") then
    return 1
end
// 应用工作
singleinstance.release()

C 与生命周期

新增 examples/recovery.xl 与 recovery_c.c，展示拒绝重复获取不破坏原锁、finally/显式释放和同名恢复，五种执行形态逐字对照。关闭始终退休文件，若已有锁错误则保留原首因；只有争用且关闭成功才返回 C 的 0。预置失败合同 Windows 72/Linux 108 场景通过，另有真实已预热获取分配故障扫描；不将预置错误数当作真实 OOM 次数或全线程压力认证。

C 头文件 include/singleinstance_native.h；xsi_acquire 用 1/0/-1 区分取得/占用/错误。每个包实例只能持有一个锁；释放脚本上下文前应显式 release()。锁文件保留在用户主目录，不能以文件存在判断是否持锁。已有锁目录若为符号链接或 POSIX 权限过宽，获取锁会报错；Windows 继承 ACL 不做完整审计。完整路径规则与验证范围见包内 README。
