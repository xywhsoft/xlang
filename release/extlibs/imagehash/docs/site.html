扩展库 / imagehash

imagehash

图片相似性指纹。

依赖 stb_image 与 stb_image_resize2，不重复捆绑 stb；UTF-8 路径由 XRT 处理。

2026-10-28：三条完整公开返回链不再复制哈希结果，保留独立图片错误诊断与内存错误。固定 PNG 的 C/XLang 各六组预算、空路径/缺失图片/NUL 反例、双平台默认门禁与双语 JIT/AOT 通过；Linux ASan/UBSan 完整图像链路和普通构建预算分别验收，未关闭 stb 的 sanitizer 保护。仍有一次路径 NUL 针串分配和长度扫描，不称整条操作零开销。

API

接口用途
ahash / dhash / phash生成 64 位图像指纹
hamming计算同类指纹间的位差
valid检验 16 位十六进制格式

范例

import imagehash
string a = imagehash.phash("photo.png")
string b = imagehash.phash("thumbnail.png")
println(imagehash.hamming(a, b))

不是密码学哈希；不同算法的结果不可互比。图片缺失或损坏抛 RuntimeError，内存不足抛 MemoryError；C 接口失败返回 NULL，可查询线程局部诊断与 XRT 内存错误。五个操作入口会清除旧 XRT 错误，普通格式/图片错误不会误报为上次内存故障。当前 Windows/Linux 默认门禁均通过固定图像向量、线程与分配故障、C/XLang 双语输出及核心/分配故障/公开范例独立 EXE；Linux 另通过 C ASan/UBSan。旧共享缺符号仅属历史发布物；-SkipAot 只作 Windows 聚焦快测。C 接口、资源归属及算法范围见包内 README。
