扩展库 / fix

fix

构造并校验 FIX 4.x 文本报文帧，按输入顺序保留字段和重复标签。

版本 1.0.0 · C / xlang · 无扩展库依赖

快速开始

import fix

var fields = [fix.field(35, "D"), fix.field(49, "BUY_SIDE"),
    fix.field(56, "SELL_SIDE")]
string message = fix.build("FIX.4.4", fields)
assert fix.validate(message)
var decoded = fix.parse(message)
println(decoded["fields"][2]["value"])

自动生成 8=BeginString、9=BodyLength 和 10=CheckSum；字段值用 SOH（字节 0x01）分隔。

接口与边界

入口用途
field(tag, value)创建包含 tag/value 的字段对象；8、9、10 为保留标签。
build(beginString, fields)从有序字段数组生成完整报文；保留重复标签。
parse(message)校验并返回包含完整字段数组的对象；格式错误抛 ValueError，超限抛 RangeError。
validate(message)坏帧返回 false；分配失败不是坏帧，在 XLang 中抛 MemoryError。

单帧最多 16 MiB、4096 个应用字段；加上自动生成的 8、9、10，最大合法解析结果有 4099 项。8=BeginString 必须非空；文本值不能含 SOH 或 NUL，XL 传入 C 字符串接口的文本也拒绝内嵌 NUL，避免静默截断。C 的 BeginString、字段文本及 parse 输入均按 16 MiB 限界扫描，超限报告 RANGE；XLang 的 field/build/parse 相应抛 RangeError，validate 对超限输入返回 false。独立字段文本可恰好达到 16 MiB，但完整帧仍须留出头尾字段空间。字段对象的值支持字符串、有符号/无符号整数、浮点和布尔值；无符号整数按十进制完整写出。浮点字段使用点号小数，不受进程区域设置影响。它是帧编解码器，不提供交易会话、序号/重发、场所字典验证或网络连接。

C 对照

#define XRT_MODULE_VALUE_CONTAINER
#include "xrt.h"
#include "fix_native.h"

int main(void)
{
    xvalue* fields = xrtValueArray();
    xvalue* field = xfix_field(35, "D");
    xrtValueArrayAppendTake(fields, &field);
    char* message = xfix_build("FIX.4.4", fields);
    int ok = message && xfix_validate(message);
    xrtFree(message);
    xrtValueRelease(fields);
    return ok ? 0 : 1;
}

C 的报文缓冲用 xrtFree，字段与解析结果用 xrtValueRelease。完整 C/XLang 对照范例位于 release/extlibs/fix/examples/ 和 release/examples/extlibs/fix.xl。C 范例可从发布目录直接运行 ./xl run extlibs/fix/examples/fix_c.c；单文件范例包含原生实现，正式包构建仍将其作为独立源码编译。

此前 Windows 严格 GCC、C 范例单文件 xl run、C/XLang 边界与双语同输出已通过；Linux 同次覆盖 C ASan/UBSan、C 范例单文件运行、中央及包内 XLang 边界、分配失败，以及 C/XLang 范例逐字节对照。两平台还用独立检查器按报文字节重算 9=BodyLength 与 10=CheckSum 并核对字段顺序，不只依赖本包的 validate；包门禁需要 Python 3。最大应用字段数、逗号小数点区域设置，以及四个公开入口的首次分配失败与恢复已有回归。C 的 validate 在内存不足时保留 XRT 内存错误，其他格式错误仍按谓词返回；XLang 的四个入口将分配失败报告为 MemoryError。当前发布版的最小 XLang 用例在将语言数组传给 fix.build 时抛 ValueError：原生入口未收到预期数组类型；独立 EXE 与完整包级门禁仍待共享 foreign var 容器投影修复后复验。旧版 xl6ValueDataSnapshotV1 缺符号不是当前阻断，历史双语通过记录不能签收本版。详情见包内 README 和阻断复现。
