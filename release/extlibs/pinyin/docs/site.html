pinyin

常用汉字的轻量拼音转写。

约 395 个单字固定读音；未收录字符原样保留。不分词、不处理多音字上下文或声调，不适合要求准确读音的全文处理。

API

接口用途
convert(text)将已收录汉字转为带空格的拼音
initials(text)将已收录汉字转为首字母，不额外插入空格

范例

import pinyin
println(pinyin.convert("中国"))   // zhong guo
println(pinyin.initials("中国"))  // zg

输入须为合法 UTF-8，不能包含 NUL。C 函数返回的独立字符串用 xrtFree 释放。当前 Windows/Linux 默认门禁均通过严格 C、Linux ASan/UBSan、语言边界与分配故障，以及中央/边界/分配/公开范例独立 EXE；C 单文件范例 AOT 与 GCC、TCC、XLang 的固定中文输出一致。旧共享链接缺符号不再复现。本包只提供 395 字固定小字表，不做多音字消歧或分词。
