扩展库 / sysinfo

sysinfo

读取 Windows 和 Linux 主机的系统标识、CPU、内存与运行时间。

版本 1.0.0 · C / xlang · 无扩展库依赖

快速开始

import sysinfo

println(sysinfo.osName(), sysinfo.arch())
println(sysinfo.cpuCount())
println(sysinfo.memAvailable())

内存值是瞬时快照，连续调用可能不同；探测失败或 CPU 型号字段只有空白时，文本返回 unknown、数值返回 0。

本模块报告主机信息，不把进程亲和性或容器配额当作整机资源；0可能是真实值，也可能表示探测不可用。Linux解析以完整系统记录为单位，超长行的续块不能冒充新字段，截断目标行也不能隐藏尾部垃圾。

接口

入口用途
osName / osVersion / arch / hostname系统、版本、架构及主机名的 UTF-8 文本。
cpuName / cpuCount处理器名称及全系统在线逻辑处理器数量；Windows 覆盖所有处理器组。
memTotal / memAvailable / memUsagePct物理内存总量、可用字节数及整数使用率百分比；Linux 可用量按 /proc/meminfo 的 MemAvailable 计算，不等同空闲页。探测失败返回 0，不伪报满载。
pageSize / uptime内存页字节数与系统运行秒数。

五个文本查询返回普通 string；原生 XRT 文本由运行时直接接管，不需再次复制。

Windows 版本来自系统 API，主机名和 CPU 名经 Unicode API 转 UTF-8；Linux 的系统标识来自 uname，CPU 名和运行时间读取 /proc。Linux 内核的 CPU 信息字段因架构而异；没有 model name 时返回 unknown，不会以架构名冒充型号。系统返回空文本或非 UTF-8 文本也降级为 unknown。支持范围为 Windows/Linux，不承诺其他平台。

C 对照

#include "xrt.h"
#include "sysinfo_native.h"

int main(void)
{
    char* name = xsysinfo_os_name();
    int ok = name && name[0] != 0;
    xrtFree(name);
    return ok ? 0 : 1;
}

C 字符串结果由调用方用 xrtFree 释放；XLang 包装自动接管。每次公开调用清除之前的 XRT 错误；转换时若内存分配失败，则保留内存错误并返回空结果，不伪装为 unknown。release/extlibs/sysinfo/examples/ 内的 basic 与 metrics 各有 C/XLang 对照：前者展示可稳定比较的主机信息，后者展示会随采样时刻变化的内存和运行时间。

上面的片段需与 sysinfo_native.c 一同构建。包内 examples/sysinfo_c.c 和 examples/metrics_c.c 是自包含完整范例，可直接交给 xl run；不需要另找原生DLL。
