UTF-8 文本、二进制、增量流与事务文件压缩。直接复用宿主 XRT 的 gzip 编解码器和校验，无额外压缩 DLL。

API

函数参数与返回
compress(data)Buffer 或 string 输入，返回 Buffer；level=-1、mtime=0。
decompress(data)Buffer 输入，返回 Buffer；maxRatio=1000。
decompressText(data)解压后按字符串读取；任意二进制内容使用 decompress。
compressFile(source, destination)level、mtime、overwrite=true、输入/输出限额、onProgress=null。
decompressFile(source, destination)overwrite=true、输入/输出限额、maxRatio、onProgress=null。
compressor()gzip.GzipCompressor；level、mtime、输入/输出限额。
decompressor()gzip.GzipDecompressor；输入/输出限额、maxRatio。

maxInput 默认 268435456 字节，maxOutput 默认 536870912 字节，均须为正。 level 为 -1 或 0..9，-1 使用 XRT 默认级别；mtime 为 Unix 秒数 0..4294967295，默认零。 普通字符串按 UTF-8 字节数编码，不把字符数量当作字节长度。

两个导出类均有 valid、inputBytes、outputBytes、finished 只读属性，以及 drain() as Buffer、finish() as Buffer。 压缩器 update 接收 Buffer 或 string，解压器只接收 Buffer。

xlang 范例

import gzip

Buffer packed = gzip.compress("你好，gzip", level = 6)
assert gzip.decompressText(packed) == "你好，gzip"

gzip.GzipCompressor encoder = gzip.compressor()
encoder.update("left")
Buffer output = encoder.drain()
encoder.update("right")
output.append(encoder.finish())
assert gzip.decompressText(output) == "leftright"

以上保留语言应支持的顶层流对象写法；当前JIT可运行，AOT正文断言后仍命中M2退役错误，不用改成局部对象掩盖此问题。

drain 移交当前输出，不强制后端刷新；finish 只交付剩余字节，重复调用返回空 Buffer。 已交付的 Buffer 独立持有。完成后不能继续 update，同一对象需要串行访问。

文件与回调

import gzip

func main(...) as int
    string work = dir.temp(prefix = "xlang-gzip-example-")
    string source = path.join(work, "输入.txt")
    string packed = path.join(work, "output.gz")
    string restored = path.join(work, "restored.txt")
    try
        assert file.writeText(source, "hello gzip")
        assert file.writeText(packed, "keep")
        bool cancelled = false
        try
            gzip.compressFile(source, packed, onProgress = func(int inputBytes,
                int totalBytes, int outputBytes) as bool
                return false
            end)
        catch CancelledError error
            cancelled = true
        end
        assert cancelled and file.readText(packed) == "keep"
        gzip.compressFile(source, packed)
        gzip.decompressFile(packed, restored)
        assert file.readText(restored) == "hello gzip"
    finally
        if file.exists(source) then assert file.delete(source) end
        if file.exists(packed) then assert file.delete(packed) end
        if file.exists(restored) then assert file.delete(restored) end
        assert dir.delete(work)
    end
    return 0
end

回调同步执行，参数均为字节数；总量未知时 totalBytes=0。返回 false 抛 CancelledError， 回调抛出的异常保留原类型与消息。最终通知也可以取消；不能用 inputBytes==totalBytes 判定唯一的最终事件，输入读完之后仍可能有结束输出。

目标目录中建立独占临时文件，处理、最终通知、flush 和 close 全部成功后才替换目标。 常规失败或取消保留原目标并清理临时文件；当前发布物的文件 OOM 专项证据与其他边界见页首。 支持源和目标为同一路径；不覆盖模式区分目标缺失与查询失败。 overwrite=false 禁止覆盖；即使目标在预检后出现，最终提交仍拒绝替换。 源或目标路径含 NUL 时抛 ValueError，不会静默操作前缀文件。 这不承诺断电持久性或多写者事务隔离。

格式、错误与资源边界

  • 支持合法空内容、串联成员、可选头字段和头校验；目前没有读取头元数据的 API。
  • CRC/ISIZE、保留标志错误、截断与尾部垃圾均拒绝；CRC 不是加密认证。
  • 格式和文件错误为 IOError，限额为 RangeError，无效 level 或非正限额为 ValueError， 错误状态为 RuntimeError，分配失败为 MemoryError。不要统一只捕获 CompressionError。
  • maxRatio 为 1..4294967295，按累计输出/已提交压缩输入检查，分块会影响检查时点。 maxOutput 为硬输出限额；这些选项不是 CPU 截止时间、总内存上限或沙箱。
  • 输入参数错误可纠正重试；编解码、限额或 writer 失败后必须新建对象。
  • 借用 reader/writer 的裸流失败前可能已有部分输出；只有文件便捷接口提供失败原子性。

C 接口与双语范例

核心头 include/xrt_gzip.h 提供 OptionsInit、ErrorInit、Compress/Decompress、 Compressor/Decompressor 对象与 CompressStream/DecompressStream。首次包含 XRT 完整头前完成模块选择， 完整清单见 artifact.xrtModules；只链接一份 XRT/xruntime。

C 结果由 xrtBufferDestroy 释放；Finish 不移交 Buffer，DrainBuffer 可多次移交， TakeBuffer 仅在完成后移交一次。流函数借用 Reader/Writer，不关闭它们。 C 进度结构另有 TOTAL_KNOWN、FINAL 标志，支持任意 user 指针。

C 配置 level=-1..9、strategy 为 XRT DEFAULT..FIXED。输入、输出与倍率限制为零时关闭对应限制； OptionsInit 将 tLimits 中不适用的归档/文档字段清零；显式设置这些字段或 iFlags 会报参数错误，不会静默忽略。薄绑定头 include/gzip_native.h 的 25 个实际生成原型接受GCC比对，并以故意错改返回类型验证拒绝。 native文件接口沿用XRT callable；普通C进度由核心流接口提供，两者不是同一ABI。

extlibs/gzip/examples/basic.c 与 examples/extlibs/gzip_basic.xl 使用相同输入与黄金输出；C 范例可从发布目录直接运行 ./xl run extlibs/gzip/examples/basic.c。 单文件路径仅包含所用的包实现，正式构建仍分离编译。examples/extlibs/gzip.xl 覆盖增量、mtime、串联成员和文件回调；文件段使用独占临时目录， 其 JIT 与独立 EXE 在当前双平台门禁均完整运行并输出 gzip example: PASS。
