扩展库 / zstd

zstd

Zstandard 二进制压缩、增量流和文件处理；同时提供 XLang 与 C 接口。

2026-10-26：Windows 默认包门禁及 Python Zstandard 双向标准帧互通通过；Linux C ASan/UBSan、语言 JIT、八条独立 EXE AOT 和 C/JIT/AOT 范例输出对照通过。Windows 从项目根目录直接运行基础范例也通过，旧 VFS 路径及 Linux cstring 阻断不再复现。输出限额抛 RangeError；损坏帧和非法状态抛 CompressionError，分配失败抛 MemoryError。文件回调保留原异常与取消语义。

API

接口用途
compress(data)压缩 Buffer 或 string，返回 Buffer；默认级别 3。
decompress(data)解压 Buffer，返回 Buffer；支持串联帧。
decompressText(data)将解压结果作为文本读取。
compressor() / decompressor()增量 update、drain、finish 和累计字节数。
compressFile() / decompressFile()文件处理、限额、覆盖选项和进度回调；含 NUL 的源/目标路径报 ValueError。

范例

import zstd
Buffer packed = zstd.compress("hello zstd")
assert zstd.decompressText(packed) == "hello zstd"

包内 examples/basic.xl 与 examples/basic_c.c 同输入、同输出；C 范例可直接用 xl run extlibs/zstd/examples/basic_c.c 运行。C 调用方可直接包含 include/xrt_zstd.h，并负责释放返回的 xbuffer。C 流式接口的进度从 Reader 当前读取位置起算；无法同时取得总长和当前位置时不设置 TOTAL_KNOWN。C 编解码入口拒绝选项和资源限制结构的无效版本、长度及保留字段；无效选项不消费输入流。iMaxEntries 限制串联帧数，iMaxItemBytes 限制单帧原文大小；节点数、深度和未知标志不适用。资源限额、所有权及当前验收范围见包内 README。

包级 C 门禁逐点注入 XRT 分配失败，检查一次性编解码的错误与释放平衡；此测试不覆盖上游库的内部 allocator。错误类型负例、中央用例和完整教学范例已进入 Windows/Linux JIT/AOT 门禁。短时门禁不替代 32 位、TSan 或长时间压力验证。
