# demo6/src Source Layout

This directory contains the DEMO6 compiler, CLI, DLL runtime API, and supporting tools.

## Shards

- `lexer`: Flex lexer rules, token model, and lexer API.
- `parser`: Lemon grammar, parser entry points, and generated parser artifacts.
- `ast`: AST nodes, construction helpers, and AST dump.
- `sem`: semantic checks, protocol validation, type registry, and diagnostics.
- `type`: shared type model helpers.
- `ir`: canonical typed/lowered XLIR contract and IR dumps. XLIR owns semantic data and must not retain AST pointers after construction.
- `cgen`: the XLIR-to-C emitter and reusable runtime component emitters. Rule docs must stay aligned with `../cgenrule/README.md`.
- `abi`: ABI dump and callable metadata.
- `package`: package manifest, resolver, and import dependency handling.
- `resource`: Windows-only resource config compiler for version, icon, and manifest output.
- `compile`: compile-unit orchestration and import/stdlib expansion.
- `backend`: build backend and toolchain boundary.
- `stdlib`: default standard-library registration wrappers; prefer XRT-backed functions.
- `api`: public `xl.dll` API implementation.
- `driver`: `xl.exe` CLI dispatch and command implementations.
- `debug`: `xl.exe dbg/dap` language-level debugger adapter and protocol helpers.
- `diag`: diagnostic output.
- `common`: minimal project plumbing; file, time, memory, string, and container work should prefer XRT.

## Generated Files

- `lexer/xl6_lexer_gen.c` and `lexer/xl6_lexer_gen.h` are generated by Flex from `lexer/xl6_lexer.l`.
- `parser/xl6_parser.c`, `parser/xl6_parser.h`, and `parser/xl6_parser.out` are generated by Lemon from `parser/xl6_parser.y`.

Edit `.l` and `.y` sources first, then regenerate generated files through `build.bat`.

## Maintenance Rules

- New `.c` files must be wired into `build.bat`, `build_dll.bat`, or an explicit `#include "*.c"` shard.
- Debugger code is part of `xl.exe`; it must not enter the slim DLL runtime boundary.
- Toolchain paths and default link settings stay centralized in `src/backend/xl6_toolchain.h` and `tools/xl6_toolchain_env.bat`.
- C generator diagnostics must be specific; do not reintroduce generic `code generation error` messages.
- Prefer XRT for file, time, memory, string, container, and synchronization capabilities.
