# dev 工具群当前 BUG 记录

本文件只记录**当前仍未修复**、且已经通过 dev 工具复现确认的 BUG。已修复问题不在这里保留，
三轮问题的原始编号、统一根因、修复边界和验收结果见
[`docs/三轮问题统一修复任务.md`](../../../docs/三轮问题统一修复任务.md)。

## 未修复 BUG

当前为空。

三轮 dev 实测问题以及收口过程中发现的衍生缺陷均已修复，并通过分类套件 `00` 到 `09` 的完整回归。
其中额外闭环的公共边界包括：

- `volc.phone` 的 JSON 整数 token 提取严格遵循数值字段边界，不再把后续字段并入转换文本。
- package/export 内部函数的静态泛型容器参数保持 `xtarray` / `xtlist` / `xtset` / `xtdict` ABI。
- 普通 class 按值形参建立独立 owned copy，调用方字段不会被被调函数修改或释放。
- package 内部可变状态使用模块全局存储，不伪装成无外部实体承接的 C 导出变量。
- 外部变量的读取和赋值统一解析显式 C storage symbol。
- 标准库 DLL 符号守门明确区分允许的 CRT 符号与必须由 XRT/xlang 提供的符号。

## 记录规则

- 设计限制和刻意不支持的写法记录在对应设计文档或本目录 `README.md`，不伪装成 BUG。
- 新 BUG 必须包含最小复现、实际结果、期望结果、影响范围和对应测试套件。
- 修复时处理公共根因和相邻边界，不为单个复现增加兼容分支。
- 修复通过完整回归后，从本文件删除，并把验收事实写入统一任务账本。
