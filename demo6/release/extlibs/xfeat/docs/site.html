扩展库 / xfeat

xfeat

提取局部特征，在目标图片中定位查询图片。

依赖 OpenCV 与 ONNX Runtime；查询与目标 ONNX 模型路径由使用者显式传入，包不分发权重。预处理为 RGB、0–1 归一化和右下补零。

API

接口用途
xfeat.open(queryModel, targetModel)创建推理引擎
xfeat.prepare_query(engine, queryPath)预处理多尺度查询图
xfeat.locate_json(engine, querySet, targetPath)返回位置、内点数和边界框 JSON
xfeat.locate_and_save(engine, querySet, targetPath, outputPath)找到时绘制并保存结果，未找到时保存原图；读图或写盘失败抛 IOError
xfeat.release_query(querySet) / xfeat.close(engine)释放查询集与引擎

范例

import xfeat

point engine = xfeat.open(queryModelPath, targetModelPath)
assert engine != null, xfeat.last_error()
point querySet = xfeat.prepare_query(engine, queryImagePath)
assert querySet != null, xfeat.last_error()
println(xfeat.locate_json(engine, querySet, targetImagePath))
xfeat.release_query(querySet)
xfeat.close(engine)

正常未找到返回包含 "found":false 的 JSON；JSON 序列化失败会抛错，不伪装为空对象。定位器会拒绝宽或高超过目标图一半的框，整图对自身不是正例。包内 examples/live_model.xl 从目标图生成局部查询裁块；examples/live_model_c.c 用公开 C API 做相同的六尺度定位。Windows 门禁覆盖图片保存及失败路径，Linux 门禁覆盖 C 核心和无模型 XLang 调用，暂不验收 Linux OpenCV 桥接。设置 XFEAT_MODEL 后，门禁用包内固定正负图片验证找到与未找到路径，并逐行核对 C/XLang 正例输出；XFEAT_TEST_IMAGE 可覆盖正例图片。另可加 -ParallelLive 做两线程独立定位。模型权重仍由调用者提供；2026-10-26 当前 Windows 门禁已验证真实模型 XLang 独立 EXE 与 C/JIT 同输出及双线程短轮次定位。按 Windows 公开调用层验收；Linux OpenCV 图像桥接与插件内部长期稳定性不在此次签收范围。
