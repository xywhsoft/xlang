扩展库 / hyperloglog

hyperloglog

固定内存的近似去重计数。

复用 XRT 64 位哈希，支持同精度合并、清空及显式二进制长度；估计值不保证精确。

API

成员用途
create(precision = 14)创建 4..18 精度的草图
hyperloglog.HyperLogLog导出草图类型，可用于显式声明和函数签名
add / count加入数据并估计唯一值数量
merge / clear同精度合并与复位
added / precision读取累计写入计数与寄存器精度；重复合并会再次累加源计数，计数在 int64 上限饱和

xlang

import hyperloglog
hyperloglog.HyperLogLog hll = hyperloglog.create()
hll.add("visitor:1")
hll.add("visitor:2")
println(hll.count())

单实例没有并发锁；误差性质、C 接口、测试范围与 AOT 状态见包内 README。

C API 失败后可直接重试，成功调用会清除本线程旧的 XRT 错误。count/added 使用跨平台 int64_t 结果，add 长度仍为 C long long。C 范例可直接 xl run release/extlibs/hyperloglog/examples/hyperloglog_c.c；Windows/Linux 门禁将它与分离编译 C、XLang 范例及固定输出对照，Linux 另含 ASan/UBSan。估计值不是精确基数；完整 AOT 仍受共享符号 xl6ValueDataSnapshotV1 阻断。
