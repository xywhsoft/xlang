扩展库 / toml

toml

解析和生成 TOML，支持 UTF-8 文件、资源配额和四种日期时间值。

版本 1.0.0 · C / xlang · 依赖 _tomlc17

快速开始

import toml

var config = toml.parse("title = \"demo\"\n")
config["released"] = toml.localDate(2026, 7, 16)
string text = toml.stringify(config)
assert toml.dateTimeKind(toml.parse(text)["released"]) == 1

解析结果是可在 C 和 xlang 两侧访问的 XRT 值。根文档写出时必须是字典；文件入口为 load(path) 与 save(path, value)。

解析语法以 TOML 1.0 为目标：内联表不可跨行或带尾逗号，时间须写秒，Unicode 键须加引号；不接受 \xNN 或 \e 转义。

接口

入口用途
parse / load从文本或 UTF-8 路径读入 TOML，返回 var 字典。
stringify / save写出文本或原子保存文件；拒绝无效 UTF-8 键和值。
localDate / localTime创建无时区的日期或时间值。
localDateTime / offsetDateTime创建本地或带偏移的日期时间。
dateTimeKind / isLocalDate / isLocalTime / isLocalDateTime / isOffsetDateTime判断时间类型。
dateTimePart(value, part) / dateTimeText(value)读取时间分量或 TOML 文本表示；part 为 0..7。
errorCode / errorLine / errorColumn / errorOffset查询当前线程最近的 TOML 错误位置；非法 UTF-8 定位首个错误字节，其他语法错误的列号取决于底层解析器。

解析与写出可限制输入、输出、单项、条目、节点和深度；参数 0 使用 XRT 默认值，负数不合法。C 端传入选项结构时须先调用 xrtTomlOptionsInit；结构本身或内嵌资源限额的版本、长度无效会报 ARGUMENT，不会回退到默认限额。深度限额与日期参数进入 C ABI 前进行范围检查，路径不接受内嵌 NUL。日期记录、可变日期对象与格式化共用校验，无效日历值或与类型无关的隐藏字段不会被当成合法日期输出。语法/参数错误为 ValueError，限额为 RangeError，真正的文件或流 IO 失败为 IOError；解析、写出和原子保存过程中的分配失败均报告 MemoryError。

C 选项中内嵌资源限额的保留字段必须为零；非零配置在解析与写出前报告 ARGUMENT。TOML 不使用压缩倍率或资源标志：OptionsInit 将倍率置零，显式设置 iMaxCompressionRatio 或 iFlags 同样报 ARGUMENT，不会静默忽略。

parse(string) 直接传递 UTF-8 数据及字节长度，不另建 XLang Buffer 副本。Reader 同时支持总长度与当前位置查询时，按剩余字节数在读取前拒绝超限；其他 Reader 仍受限额读取约束。正文或注释中的内嵌 NUL 均作为格式错误拒绝。

maxItem 按键和字符串原始 UTF-8 字节数计算，maxEntries 限制每个数组和表，maxNodes/maxDepth 也计入数组表的数组节点。解析和写出使用同一限额口径；刚好到上限可用，超限时 save 不覆盖旧文件。

日期时间支持 6 位秒小数（微秒）。按 TOML 规范，更多小数位会截断而非四舍五入；再次写出只保留微秒，不能用来无损保存纳秒。

日期时间值由本包构造函数创建，以 XRT TypeId 区分于普通表；字段碰巧与日期记录同形的 TOML 表仍按表写回，不会变成日期。深拷贝保留日期身份。

普通有限浮点字面量若溢出 float64，本包报格式错误，不静默转为无穷大；显式 inf/nan 仍可解析。这是本包的数值边界，并非要求所有 TOML 实现采用同一溢出策略。

C 对照

#include "xrt_toml.h"

int main(void)
{
    xrttomlerror error;
    const char source[] = "title = \"demo\"\n";
    xvalue* value = xrtTomlParseMemory(source, sizeof(source) - 1u, NULL, &error);
    if (value == NULL) return 1;
    /* 使用 xrtValueObjectGet 等 XRT 接口读取，完成后释放。 */
    xrtValueRelease(value);
    return 0;
}

公共头为 extlibs/toml/include/xrt_toml.h。xrtTomlParseMemory 返回拥有型 xvalue；xrtTomlStringify 返回拥有型 xbuffer。完整可运行的双语范例为 examples/extlibs/toml.xl 与 examples/extlibs/toml_c.c；两者构造四种日期时间值并检查微秒与偏移。传入目标路径时，使用 TOML 的 save/load 完成文件往返，并由 Python tomllib 独立解析结果。
