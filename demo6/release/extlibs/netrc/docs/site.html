扩展库 / netrc

netrc

解析、修改和保存 UTF-8 netrc 凭据文件，支持 machine、default 和 macdef。

版本 1.0.0 · C / xlang · 无扩展库依赖

快速开始

import netrc

netrc.Netrc config = netrc.parse("machine api.example login alice password sample\n")
var auth = config.authenticators("api.example")
println(auth["login"])

C/XLang 对照范例还展示具名主机、default 回退与 macdef 宏，用 hostNames/macroNames 检查条目，并以 stringify/parse 验证内存往返。固定的未闭合引号示例演示错误码、行列、字节偏移及成功调用后清除诊断。可显式传入目标路径，通过 save/load 保存并读回凭据和宏；密码只参与核对，不写入输出。实际凭据不应写入日志，也不要把 stringify() 的结果直接打印到控制台。

接口

入口用途
parse / load解析文本或从 UTF-8 路径读取。
netrc.Netrc导出的文档类型，可用于变量和参数声明；直接构造要求 hosts、macros 字典。
Netrc.authenticators(host)优先查找指定主机，缺失时返回 default。
Netrc.hosts / macros访问与修改凭据和宏字典。
Netrc.hostNames / macroNames枚举主机与宏名称。
Netrc.stringify / save生成文本或以同目录临时文件替换目标。
errorCode / errorLine / errorColumn / errorOffset读取最近一次原生操作的错误位置；非法 UTF-8 指向首个错误字节，偏移从去掉可选 BOM 后的文本起算；token 间已接受的单独 CR 计作新行，CRLF 只计一行。

C 端包含 extlibs/netrc/include/xrt_netrc.h；文档由调用方用 xrtValueRelease 释放。拥有型 Reader/Writer 在退出时关闭；正文成功但关闭失败时，内存不足报告 MEMORY，其他关闭失败报告 IO；正文已有错误不被关闭故障覆盖。借用型流仍由调用方关闭。Reader 输入限额按当前游标之后的字节计算；无法同时查询总大小和当前位置时由实际限额读取裁决。传入选项结构时须先调用 xrtNetrcOptionsInit；结构或内嵌资源限额的版本、长度无效会报 ARGUMENT，不会回退到默认限额。netrc 不使用深度、压缩比或资源标志；这些字段及保留字段必须保持初始化值，否则报 ARGUMENT。传入 NULL 才使用默认选项。解析结果只存储在当前对象中，本库不会自动读取用户主目录的凭据，也不会自行向网络请求附加认证信息。

文档顶层只接受 hosts 和 macros；主机条目只接受 login、account、password。未知字段或空主机名、空宏名会使 stringify/save 报错，不会写出无法读回的凭据。写出时具名 machine 总在 default 前面，与外部 netrc 读取器的匹配顺序一致。保存失败时原文件保持不变。

单独 CR 与 CRLF 均可结束注释行，不会吞掉后一行的凭据声明；宏正文支持 CRLF 行尾，但行内独立 CR 会报语法错误。解析成功的宏能够写出并再次读回。

验证与边界

powershell -NoProfile -ExecutionPolicy Bypass -File release/extlibs/netrc/test/check.ps1 -SkipAot
bash release/extlibs/netrc/test/check.sh

Windows C/XLang 边界与双语同输出、Linux C ASan/UBSan 和原生文件系统 0600 权限用例通过；Linux 脚本也运行中央与包内 XLang 边界，并将双语范例与黄金输出逐字对照。原生入口的 64 位无符号参数与 XRT 的 uint64 ABI 一致。C/XLang 资源限额中，显式 0 表示不限；省略 XLang 参数使用签名默认上限。parse(string) 直接传入 UTF-8 数据及字节长度，不额外建立 XLang Buffer 副本；原生层先检查输入限额，并完整拒绝内嵌 NUL。负限额会被拒绝；路径或注释（包括 macdef 标题注释）中的 NUL 也会被拒绝。非空 Reader 正常解析。C 的空 writer、空/缺失路径在序列化前报参数错误。流式写入或刷新发生内存错误时报告 MEMORY，普通 I/O 错误报告 IO；保存阶段分配失败也报告 MEMORY 且保持旧文件。POSIX 保存采用同目录私有临时文件并替换；Windows 仍依赖目标目录 ACL。完整 AOT 因主线 xl6ValueDataSnapshotV1 缺符号尚未签收。
