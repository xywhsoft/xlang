扩展库 / css

css

读取 CSS 规则、选择器与声明的轻量语法查询器。

不计算级联、继承、特异性或选择器匹配；不是浏览器样式引擎。XL AOT 当前受共享运行时链接缺符号阻断，尚未完成发布验收。

API

函数用途
get(css, selector, property)读取声明文本；缺失时返回空字符串
countRules / countProps统计规则或指定选择器的属性数量
selectorAt按索引读取规则选择器
validate检查受支持的语法；畸形内容抛 ValueError，嵌套超限抛 RangeError
stripComments去掉注释，保留字符串中的相同文本

get、countRules、countProps、selectorAt 均检查整份样式表的受支持语法；首个匹配之后出现坏规则也会报错。嵌套 at-rule 最多 64 层，第 65 层报告范围错误。引号内未转义 CR/LF/FF 拒绝，反斜杠续行有效。C/XLang 均要求整份样式表及查询名为有效 UTF-8，注释中的非法字节也拒绝；XLang 文本入口另拒绝内嵌 NUL。stripComments 仅处理注释与引号，不替代 validate。

查询名称两侧的注释与空白不参与匹配：a/*x*/ { color/*y*/: red; } 可按 a 和 color 查询；名称中间的注释不合并两个 token。selectorAt 保留原始选择器文本。本包仍是受限查询器，不承诺完整 CSS 语义。

xlang

import css
string sheet = "h1 { color: navy; }"
assert css.get(sheet, "h1", "color") == "navy"
assert css.countRules(sheet) == 1

C

包含 include/css_native.h。计数结果与索引参数使用与 XLang int 一致的 int64_t。文本结果由调用方持有，必须使用 xrtFree；失败时返回 NULL 并保留 XRT 错误。C 范例可直接运行 xl run examples/extlibs/css_c.c。
