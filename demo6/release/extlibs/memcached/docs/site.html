扩展库 / memcached

memcached

长度感知的文本协议与简洁的单命令客户端。

连接由调用方持有。支持 TCP 分包、任意字节值、总超时和失同步连接中止；不含连接池、自动重连、SASL 或二进制协议。

API

函数用途
set(stream, key, data, exptime=0, timeoutMs=5000)写入 string 或 bytes，返回存储状态
get(stream, key, timeoutMs=5000)返回 string、bytes 或 null
del(stream, key, timeoutMs=5000)删除并返回 bool
buildGet / buildSet / buildAdd / buildDelete / buildTouch构造文本协议命令
buildStats / buildFlushAll / buildVersion构造管理命令
frameSize(Buffer) / parseResponse(Buffer)增量识别并解析完整回复

范例

import memcached
Buffer response = Buffer("VALUE key 0 3\r\na\0b\r\nEND\r\n")
var parsed = memcached.parseResponse(response)
assert parsed["items"][0]["data"] == "a\0b"

成对范例：examples/basic.xl 和 examples/basic_c.c；两者展示相同的构造与解析结果。C 侧包含 include/memcached_native.h，返回的命令字符串使用 xrtFree，返回的值使用 xrtValueRelease。
