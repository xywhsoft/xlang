扩展库 / cString

cString

显式 C 字符串互操作：直接调用 CRT 的 strlen。

版本 1.0.0 · 纯 xlang 声明 · 无扩展库依赖

快速开始

import cString

string text = "a\0b"
assert string.byteLen(text) == 3
assert cString.length(text) == 1
assert cString.length("你好") == 6

结果只计算第一个 NUL 之前的字节，不是完整 XLang 字符串长度，也不是 UTF-8 字符数。普通文本使用 string.len；需要完整字节长度使用 string.byteLen。

接口

入口用途
length(text) as c_sizeCRT strlen：第一个 NUL 之前的字节数。

本包没有额外原生封装、状态或资源所有权。它用于需要匹配 C 字符串合同的场合，不适合测量含 NUL 数据缓冲区。

C 对照

#include <string.h>

int main(void)
{
    const char data[] = {'a', '\0', 'b', '\0'};
    return strlen(data) == 1 && sizeof(data) - 1 == 3 ? 0 : 1;
}

完整 C/XLang 对照范例位于 release/extlibs/cString/examples/。
