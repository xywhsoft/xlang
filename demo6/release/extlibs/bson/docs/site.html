扩展库 / bson

bson

在 BSON 文档与 XLang 字典之间转换；C 端可直接操作 XRT xvalue。

版本 3.0.0 · C / xlang · 无扩展库依赖

快速开始

import bson

var wire = bson.encode({"name": "xlang", "count": 7})
var document = bson.decode(wire)
println(document["name"])
println(bson.docLength(wire))

根值必须是字典。原始 BSON 使用 bytes，不使用字符串承载二进制；解码入口只接受 bytes。

接口与边界

入口用途
encode(doc) / decode(data)字典与单个 BSON 文档互转。
concat(a, b) / decodeAll(data)拼接及读取连续文档流；concat 只校验外层 framing，不完整解析，不可信输入需先 decode。
load(path) / save(path, doc)通过 XRT 文件接口读取和原子保存 BSON；读取时执行 64 MiB 限额，写入失败不截断旧文件。
objectId() / oidTime(hex24)生成 24 位十六进制 ID；提取时间并返回 XLang time。
toHex(data) / docLength(data)诊断十六进制和读取文档长度。

支持嵌套字典、连续数组/列表、UTF-8 字符串、bytes（Binary subtype 0）、int32/int64、double、bool、null 和 BSON Date。二进制字段可原样往返。ObjectId 解码为十六进制字符串，再编码不会保留 ObjectId 类型。其余 BSON 特殊类型不在公开模型内。重复键、非连续数组索引、无效 UTF-8、截断及尾随数据报错。单次数据上限 64 MiB；toHex 的输出翻倍，输入最多 32 MiB，超限在分配前拒绝。文档层数上限 64（根文档计一层）；整份文档的字段/数组项合计最多 100 万，连续流 decodeAll 对全部文档累计计数。编解码、concat 和 toHex 的资源超限对应 C XERR_RANGE / XLang RangeError，畸形格式仍报值错误；docLength 对非法输入返回 0。

BSON Date 仅有毫秒精度；微秒时间不能整除 1000 时拒绝编码，不会静默丢精度。超出 XRT 时间范围的 BSON Date 也拒绝解码。

路径和 ObjectId 文本不允许内嵌 NUL；错误不会按截断后的名称读写文件。生成的 ObjectId 使用时间戳及安全随机字节，不承诺顺序递增。

C 对照

#define XRT_MODULE_ALL
#include "xrt.h"
#include "bson_native.h"

int main(void)
{
    xvalue* document = xrtValueObject();
    xvalue* wire = xbson_encode(document);
    xvalue* restored = xbson_decode(wire);
    int ok = restored && xrtValueType(restored) == XVALUE_OBJECT;
    xrtValueRelease(restored);
    xrtValueRelease(wire);
    xrtValueRelease(document);
    return ok ? 0 : 1;
}

C 动态值结果由调用方 xrtValueRelease；失败返回 null 值并设置 XRT 错误。xbson_to_hex 与 xbson_gen_oid 的结果用 xrtFree 释放。双语对照范例在 release/extlibs/bson/examples/，覆盖单文档、连续文档流、HEX、ObjectId 与显式路径的保存/载入；输出有独立预期，保存文件逐字节对照。从发布目录运行 ./xl run extlibs/bson/examples/bson_c.c 即可执行 C 范例。此单文件范例包含原生实现，正式包构建仍独立编译。
