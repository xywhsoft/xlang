扩展库 / jwt

jwt

JWT HS256 签名与紧凑格式读取。

Base64URL、JSON 与 HMAC-SHA256 均复用 XRT；C 和 xlang 共用同一原生实现。

API

函数用途
jwt.encode(payloadJson, secret)签名 JSON 对象 claims，返回 token
jwt.verify(token, secret)校验 HS256 签名、算法及 claims 结构
jwt.decode(token)只读取未经认证的 claims
jwt.header(token)只读取未经认证的头部

xlang

import jwt

auto token = jwt.encode("{\"sub\":\"user42\"}", "demo-secret")
if jwt.verify(token, "demo-secret") then
    println(jwt.decode(token))
end

认证边界：decode 和 header 不验证签名，不能用于授权决策。 verify 不检查 exp、nbf、iss、aud， 应用必须在验签后自行校验业务声明；本包不是完整身份认证中间件。

C 与 xlang 所有权

C 的 xjwt_encode/decode/header 返回调用方拥有的 UTF-8 文本，失败返回 NULL，成功结果须用 xrtFree 释放。xlang 的同名函数返回 cstring，直接接管这份分配，普通局部读取不复制文本。
