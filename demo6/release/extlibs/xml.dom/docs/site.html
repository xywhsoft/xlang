扩展库 / xml.dom

xml.dom

解析、编辑和序列化 XML 文档树。

基于 XRT/Expat；支持元素、文本、注释、属性和父子节点操作。DTD 与外部实体默认拒绝。解析文本按显式字节长度直接传入，不创建整份输入的 Buffer 副本。

API

接口用途
xml.dom.parse / load从文本或文件读取文档
xml.dom.createDocument()创建空文档
Node.child / children / appendChild读取与修改节点树
Node.stringify(...) / save(...)序列化或原子保存文档

范例

import xml.dom
auto document = xml.dom.parse("<root id='one'><child>你好</child></root>")
auto root = document.documentElement
assert root.child(0).textContent == "你好"

节点引用由对象管理；C 调用方按包内 README 释放引用。C 解析接管 Reader 时，关闭失败按底层错误返回 MEMORY 或 IO，不返回未确认关闭的文档树。XLang 显式解析限额必须为正，C 的 XRT 限额配置以 0 表示不限制；写出缩进为 0..16。名称遵循 XML 1.0，写出拒绝无效字符、注释和处理指令；属性空白与文本回车往返保持原值。保存失败不会覆盖已有文件。文本读取与写出使用显式遍历栈，可处理调用方放宽限额后的深树；8192 层解析/读取/序列化、内存故障和限额已有 C 回归。共享 Linux 门禁通过 C ASan/UBSan、三包 XLang 边界及双语范例逐字对照；Windows 标准输出行尾可能不同。完整 AOT 仍受共享运行时缺符号阻断。
