扩展库 / stb_image_write

stb_image_write

从 Buffer 编码 PNG、JPEG、BMP、TGA、HDR，或经 XRT 写入 UTF-8 文件路径。

像素上限 64 MiB，输出上限 128 MiB；编码结果超限报告范围错误，实际分配失败报告内存错误，不返回部分图片。XLang 入口拒绝 C 整数回绕及写盘路径内嵌 NUL；文件写出使用 XRT 原子替换，失败保留已有目标。C/XL 包级测试、Windows GCC 和 Linux ASan/UBSan 已通过；当前普通 Buffer 最小 AOT 仍缺共享运行时符号。

API

函数用途
encodePng / writePngPNG 编码；可指定每行字节步长
encodeJpeg / writeJpegJPEG 编码；质量 1 至 100
encodeBmp / writeBmpBMP 编码
encodeTga / writeTgaTGA 编码
encodeHdr / writeHdrHDR 编码；像素为 float32 通道

xlang

import stb_image
import stb_image_write
stb_image.StbImage image = stb_image.load("photo.png", 4)
Buffer png = stb_image_write.encodePng(image.pixels(),
    image.width(), image.height(), image.channels())

C

包含 include/stb_image_write_native.h。xstbiw_encode 返回调用方用 xrtBufferDestroy 释放的 xbuffer*；像素指针仅借用。详情见包内 README 与 C/XL 对照范例。

Linux 包级门禁 bash release/extlibs/stb_image_write/test/check.sh 同次验证 C ASan/UBSan、XLang 参数与路径边界、64 MiB 输入下的编码输出限额及 C/XLang 范例一致性。完整 AOT 仍受共享运行时缺符号阻断。

Windows 可从 demo6 目录运行 powershell -NoProfile -ExecutionPolicy Bypass -File release/extlibs/stb_image_write/test/check.ps1，联合验证严格 GCC、C/XLang 边界、输出限额专项与双语范例。
