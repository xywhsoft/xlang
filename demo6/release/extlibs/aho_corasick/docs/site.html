扩展库 / aho_corasick

aho_corasick

文本处理

构建一次，多模式同时匹配。稀疏自动机提供排序搜索、即时扫描、跨分块恢复和文本变换；C 接口支持明确长度的二进制视图。

快速开始

import aho_corasick

auto ac = aho_corasick.create(["he", "she", "his", "hers"])
for m in ac.search("ushers")
    println(f"{m.pattern}:{m.start}:{m.endPos}")
end
assert ac.count("ushers") == 3
assert ac.replace("ushers", "*") == "u*"
assert ac.highlight("ushers", "<", ">") == "u<shers>"
assert ac.mask("ushers", "#") == "u#####"

结果为 she:1:4、he:2:4、hers:2:6。 start/endPos 是从零开始的 UTF-8 字节偏移，采用左闭右开区间，不是字符索引。

创建与预算

create(array<string> patterns = [], bool ignoreCase = false,
    int maxPatterns = 0, int maxPatternBytes = 0,
    int maxTotalPatternBytes = 0, int maxNodes = 0,
    int maxMatches = 0, int maxInputBytes = 0,
    int maxOutputBytes = 0) as Automaton

非空模式数组会自动构建；空数组可继续 addPattern/addPatterns 后手动 build。 空模式、重复模式和负数限制会报错；不隐式把数字转换成模式。 ignoreCase 仅折叠 ASCII A-Z，不执行 Unicode 全量大小写折叠。

每项上限为 0 时不限制。输入、模式和输出长度按字节计算；超限报错，不静默截断。 这些限制不是整个进程的内存或 CPU 预算，也不限制用户回调自身的分配。 addPatterns 顺序添加，后续模式失败时保留已添加模式，不提供批量事务。

Automaton 与 Match

接口语义
valid / built / patternCount句柄状态、构建状态和模式数量。
pattern(index)模式的独立字符串，索引从 0 开始。
addPattern(pattern) / addPatterns(patterns) / build()独占构建阶段；成功构建后不可再添加。
search(text) as array<Match>全部重叠匹配，按起点、终点和注册序号升序排列。
searchFirst(text) as Match?上述排序的首项，没有命中返回 null；不创建全部结果数组，但可能扫描全部输入。
contains(text) / count(text)包含判断可以提前结束；计数包含重叠匹配。
scan(text, func(Match) as bool fn)按结束位置即时回调；false 停止，返回是否完整扫描。
scanner()创建可跨分块、可暂停恢复的 Scanner。
replace(text, replacement)合并严格重叠区间后固定替换；相邻区间不合并。
replaceWith(text, func(Match) as string fn)左优先最长非重叠选择，再逐项回调替换，与 replace 的合并规则不同。
mask(text, mask = "*")合并后按 UTF-8 标量数重复 mask，严格检查 UTF-8 和边界。
highlight(text, openTag, closeTag)包裹合并后的区间，不自动转义 HTML。

pattern、replace、replaceWith、mask、highlight 返回带明确字节长度的独立 cstring；含 NUL 的文本也保留完整内容。Match 提供 pattern、start、endPos 和 length；length 也是字节数。search 的起点排序与 scan 的发现顺序不同。

分块与暂停

from aho_corasick import Match

auto stream = ac.scanner()
assert stream.feed("us", func(Match m) as bool => true)
assert not stream.feed("hers", func(Match m) as bool
    println(m.pattern)
    return false
end)
assert stream.resume(func(Match m) as bool
    println(m.pattern)
    return true
end)

Scanner 提供 valid、pending、offset、matchCount，以及 feed、resume、reset。 暂停后先 resume，完成后才能 feed 新分块；偏移是全部分块累计字节数。 它复制当前分块，保存未交付结果；回调异常保留原错误，不重复交付已处理的匹配。 限制错误后的恢复边界见包内 README，不能把重试当成自动回滚。

同一个 Scanner 不支持并发操作，且拒绝回调期间重入 feed/resume/reset。 已构建自动机可以共享，但每个并发扫描应使用独立 Scanner。

C 接口与所有权

核心头为 include/xrt_aho_corasick.h，精确桥接头为 include/aho_corasick_native.h。核心使用 xstrview，支持嵌入 NUL。

#include "xrt_aho_corasick.h"

int main(void)
{
    xrtaho* ac = xrtAhoCreate(NULL);
    bool found = false;
    bool ok = ac && xrtAhoAdd(ac, XRT_STR_LITERAL("fatal"))
        && xrtAhoBuild(ac)
        && xrtAhoContains(ac, XRT_STR_LITERAL("fatal: disk"), &found);
    xrtAhoDestroy(ac);
    return ok && found ? 0 : 1;
}

C 还提供排序/非重叠结果集、计数、首项、统计、资源预检、字节遮盖与增量状态。 文本变换返回独立 xbuffer，由调用方 xrtBufferDestroy 释放；若经 xac_buffer_take_text 移交为带尾零的文本，则改由 xrtFree 释放。结果集与状态由对应 Destroy 释放。

结果集和状态持有自动机引用，可以比调用方自己的自动机引用活得更久。 借用的模式视图要求对应自动机仍存活。XLang 对象由其原生生命周期协议管理， 不得把同一个 C 句柄重复交给拥有型对象接管。

xrtAhoStateFeed 只在调用期间借用输入，返回 COMPLETE、STOPPED 或 ERROR 和已消费字节数。 停止后传入剩余切片；同一结束位置的待发送结果可能使下一次消费量为 0。 C 回调不得释放、重置或重入正在执行的同一状态，嵌套扫描应另建状态。

错误合同

错误写入 XRT 结构化错误域 xlang.extlib.aho_corasick。 XLang 中无效值、重复/空模式与无效 UTF-8 为 ValueError，原生范围/预算为 RangeError， 分配失败为 MemoryError，状态错误为 RuntimeError；pattern(index) 的语言下标预检查是 IndexError。 回调异常不统一改写为 RuntimeError，失败不伪装成空搜索结果。

成对范例

examples/extlibs/aho_corasick_basic.xl 与 extlibs/aho_corasick/examples/basic.c 对照相同输入、顺序和固定输出， 展示查找、计数、替换、高亮、遮盖、跨分块暂停恢复和 ASCII 大小写匹配。 原教学范例 examples/extlibs/aho_corasick.xl 与 examples/extlibs/aho_corasick_c.c 也纳入门禁。
