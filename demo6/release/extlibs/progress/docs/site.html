扩展库 / progress

progress

进度状态与文本渲染。

无自动输出、光标控制或全局结果缓冲；可用于终端、日志、Web 与服务端任务。

API

接口用途
create(total)创建进度对象
advance / set按步进或绝对量更新
setPrefix / setWidth控制单行文本外观；前缀拒绝控制字符、行分隔符、不可见格式符和双向控制符
current / total / percent / done / render查询和渲染

范例

import progress
progress.ProgressBar bar = progress.create(10)
bar.advance(5)
println(bar.render())

不自动写终端；百分比和进度格数按精确整数阈值向下取整，即使总量接近 int64 上限也不提前进位。C 总量、步进和当前值使用与 XLang int 一致的 int64_t ABI。C 操作成功后清除前一次错误，析构不擦除调用方诊断。边界、C 所有权与测试证据见包内 README。

Linux 包级门禁覆盖 C ASan/UBSan、XLang 边界；两平台的 C/XLang 范例各自对照十档进度的固定预期输出。Windows 默认门禁先运行边界 AOT，再要求完整范例 AOT 匹配同一预期；当前完整范例构建因共享 xl6ValueDataSnapshotV1 缺符号失败，未执行到输出对照，不签收发布级。运行命令见包内 README。
