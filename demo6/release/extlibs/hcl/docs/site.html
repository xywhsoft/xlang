扩展库 / hcl

hcl

只读查询 HCL 的属性、块与标签；表达式保留原文。

受限语法查询，不执行 Terraform 表达式，也不解析变量和 provider schema。HCL 正文、属性名和块类型含嵌入 NUL 时会拒绝，不会截断；整份正文须为有效 UTF-8。查询命中后仍会校验后续内容和块体，块及表达式括号最多嵌套 64 层；()、[]、{} 必须按顺序闭合。双引号中的真实换行无效，需使用 \n 转义；非法转义会报错，\u/\U 可解码为 UTF-8，解码结果含 NUL 时拒绝 C 字符串查询。

2026-10-24 当前 Windows 发布物的 C/XLang 边界、线程、分配故障和核心/边界/分配/范例独立 EXE 门禁通过；Linux C ASan/UBSan 与 XLang JIT 双语门禁通过。Linux 独立 EXE 本轮未验收。

HCL 正文最多 8 MiB UTF-8 字节；超过上限时所有查询和 validate 都在解析前报告 RangeError，C 侧报告 XERR_RANGE。属性声明和块头支持 /* ... */ 行内注释，不会把注释两侧的标识符拼接；get 忽略值末尾注释，getRaw 保留原文。

API

函数用途
get / getRaw读取属性文本或原始表达式
getInt / getFloat / getBool读取明确的标量；整数严格解析完整十进制值，浮点固定点号十进制且不受区域设置影响
has / countAttrs查询属性存在性和数量；has 的空属性名报参数错
countBlocks / blockLabel / blockLabelCount / blockLabelAt查询块及标签
validate检查受支持的语法；非法内容抛 ValueError

get、getRaw、blockLabel、blockLabelAt 返回普通 string；运行时直接接管 XRT 分配的原生文本，不重复复制。

xlang

import hcl
string config = "resource \"server\" \"main\" { port = 8080 }"
assert hcl.blockLabelAt(config, "resource", 0, 1) == "main"
assert hcl.getInt(config, "port") == 8080

C

包含 include/hcl_native.h。文本结果由调用方持有，必须使用 xrtFree；失败时返回 NULL 并保留 XRT 错误。C 范例可直接运行 xl run examples/extlibs/hcl_c.c。

2026-10-19：C 回归对固定文档逐字节截断和替换，核对 validate 与属性、原文、块标签和块计数查询的结果及错误状态一致；非法 UTF-8 必须拒绝。Windows 包级 C/XLang 与 Linux C ASan/UBSan、双语对照通过。该矩阵不证明完整 HCL 规范支持。Linux 入口为 bash release/extlibs/hcl/test/check.sh。
