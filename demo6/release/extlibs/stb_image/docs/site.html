扩展库 / stb_image

stb_image

从 UTF-8 路径或内存 Buffer 解码图片。

基于 stb_image 2.30；XRT 负责文件读取，StbImage 自动释放像素内存。输入上限 128 MiB，解码像素上限 256 MiB；XLang 入口拒绝通道数回绕和路径内嵌 NUL。当前 Windows/Linux 的 C/XLang 正例与独立 EXE 已通过；Linux C 边界还通过 ASan/UBSan。但编译器仍允许包外调用私有的原生句柄构造器，这涉及无效句柄释放风险，发布级访问安全尚未签收。

API

函数或类型用途
load / loadf按 XRT UTF-8 路径读取并解码
loadBytes / loadfBytes从 Buffer 解码
StbImage自动析构；宽高、通道、像素大小与像素副本
info / isHdr查询图片元数据和 HDR 标记

xlang

import stb_image
stb_image.StbImage image = stb_image.load("photo.png", 4)
Buffer pixels = image.pixels()

C

包含 include/stb_image_native.h。图像句柄用 xstbi_image_release 释放；元数据 JSON 用 xrtFree 释放。像素指针只在句柄存活期间有效。
