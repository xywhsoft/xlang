扩展库 / redis

redis

RESP2 编解码与简洁的单命令客户端。

按字节长度处理回复，网络命令使用返回 bytes 的 TcpStream.recv；有效 UTF-8 bulk 为 string，其他 bulk 为 bytes。单次命令默认限时 5 秒、最多 64 MiB，两项均可按调用收紧或调整；回复节点最多十万个。不包含连接池、自动重连、Pub/Sub 或流水线调度。当前 Windows 离线包级门禁与独立 EXE、Linux 隔离真服务与独立 EXE 均通过；真实服务的长时耐久性仍需单独验收。

API

函数用途
encode(args)将非空字符串数组编码为 RESP2 命令
encodeBytes(args)将 string/bytes 参数编码为原始 RESP Buffer
decode(reply)解析首条回复并返回 value 与剩余 rest
isComplete(reply)判断首条回复是否完整；畸形输入抛 ValueError
decodeBytes / isCompleteBytes从 bytes 或 Buffer 解析原始 RESP 字节
command(stream, args, timeoutMs=5000, maxReplyBytes=67108864)在已有 TcpStream 上执行单条命令；调用方持有连接，协议失同步时连接会被中止
get / set / del / incr / exists常用命令；get 不存在时返回 null

xlang

import redis
var reply = redis.decode("$5\r\nhello\r\n")
assert reply["value"]["value"] == "hello"
Buffer raw = Buffer.fromHex("24330d0a61ff620d0a")
assert redis.isCompleteBytes(raw)
var binary = redis.decodeBytes(raw)
assert binary["value"]["value"] == Buffer.fromHex("61ff62").toBytes()

C/XLang 成对范例还展示未收齐的原始回复不会被误判为完整帧，完整的非 UTF-8 bulk 值按原始 bytes 回读；两种语言逐行同输出，无需外部 Redis 服务。

超时为 1..2147483647 毫秒，回复上限为 1..67108864 字节；无效参数或编码失败时连接未发送数据，空命令失败后可在同一连接继续发送有效命令。完整 Redis error 回复可继续复用连接。发送失败、超时、超限、畸形或多余回复会中止连接，后续命令需显式重连。decodeBytes 遇非 UTF-8 的剩余回复时，rest 保留为原始 bytes。

C

包含 include/redis_native.h。输入值仅借用；返回的 xvalue* 由调用方使用 xrtValueRelease 释放，xr_encode_bytes 返回的 Buffer 由调用方使用 xrtBufferDestroy 释放。查看包内 README 获取字节长度、错误与容量边界。

真实服务双语示例为 release/examples/extlibs/redis_live.xl 与 redis_live_c.c，都执行 PING、SET、GET、EXISTS、INCR、DEL，并验证键删除后的不存在；C 示例使用增量帧检查器接收分片回复。单独运行默认连接 6379，也可设置 REDIS_LIVE_PORT。包内 test/check_live.sh 使用本次临时端口和进程 ID 校验启动自管理 Redis，不会接管已有服务；在 WSL 中加 --windows-xl 可用当前 Windows 发布版验证真实服务，REDIS_STRESS=1 另跑四连接各 10,000 轮。

验证范围

2026-10-24：当前 Windows 默认门禁通过严格 C、分配故障、线程、XLang 边界和本地 TCP 预检/分包/错误/断线/限额/超时/复用；核心、回环及公开范例的独立 EXE 均已构建运行，C/XLang 范例逐字输出一致。同连接十万次短时 JIT 回环也通过。当前 Windows xl.exe 还在 WSL 自管理 Redis 上通过真实调用、错误恢复、显式重连及四连接各 10,000 轮短时压力。这段是当时的验证记录，数小时稳定性不在签收范围内。

2026-10-25：使用当前 Linux 发布版，在脚本自管理的隔离 Redis 上通过严格 C ASan/UBSan、XLang JIT、核心/预检/回环/连接复用及离线/真服务范例独立 EXE AOT；两份 AOT 范例分别与 C 输出逐字节一致。复杂 TCP AOT 构建门禁保留有界限时和失败阶段诊断。短时真服务验证不等于数小时耐久签收。
