扩展库 / redis

redis

RESP2 编解码与简洁的单命令客户端。

按字节长度处理回复，网络命令使用 recvBytes；有效 UTF-8 bulk 为 string，其他 bulk 为 bytes。单次命令默认限时 5 秒、最多 64 MiB，两项均可按调用收紧或调整；回复节点最多十万个。不包含连接池、自动重连、Pub/Sub 或流水线调度。XL AOT 当前受共享运行时链接缺符号阻断，尚未完成发布验收。

API

函数用途
encode(args)将非空字符串数组编码为 RESP2 命令
encodeBytes(args)将 string/bytes 参数编码为原始 RESP Buffer
decode(reply)解析首条回复并返回 value 与剩余 rest
isComplete(reply)判断首条回复是否完整；畸形输入抛 ValueError
decodeBytes / isCompleteBytes从 Buffer 解析原始 RESP 字节
command(stream, args, timeoutMs=5000, maxReplyBytes=67108864)在已有 TcpStream 上执行单条命令；调用方持有连接，协议失同步时连接会被中止
get / set / del / incr / exists常用命令；get 不存在时返回 null

xlang

import redis
var reply = redis.decode("$5\r\nhello\r\n")
assert reply["value"]["value"] == "hello"

超时为 1..2147483647 毫秒，回复上限为 1..67108864 字节；无效参数或编码失败时连接未发送数据，空命令失败后可在同一连接继续发送有效命令。完整 Redis error 回复可继续复用连接。发送失败、超时、超限、畸形或多余回复会中止连接，后续命令需显式重连。decodeBytes 遇非 UTF-8 的剩余回复时，rest 保留为原始 bytes。

C

包含 include/redis_native.h。输入值仅借用；返回的 xvalue* 由调用方使用 xrtValueRelease 释放，xr_encode_bytes 返回的 Buffer 由调用方使用 xrtBufferDestroy 释放。查看包内 README 获取字节长度、错误与容量边界。

真实服务双语示例为 release/examples/extlibs/redis_live.xl 与 redis_live_c.c，都执行 PING、SET、GET 并清理演示键；单独运行默认连接 6379，也可设置 REDIS_LIVE_PORT。包内 test/check_live.sh 使用本次临时端口和进程 ID 校验启动自管理 Redis，不会接管已有服务。
