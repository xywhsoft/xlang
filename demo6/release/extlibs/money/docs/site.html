扩展库 / money

money

整数金额运算。

精确比例、溢出检查、守恒均分与常见货币展示。

当前 Windows 发布版的 C 算术、主要 XLang 用例与核心 AOT 已通过；完整门禁在故障恢复测试中遇到外来数组与语言数组内容相同却比较为不等的问题，整包发布验收尚未通过。

API

接口用途
add / sub / mul带溢出检查的最小单位整数运算
scale精确整数比例，绝对值四舍五入
split正负金额均分，总和守恒
format / symbol / exponent常见货币展示信息，包括 RUB 的 ₽ 符号
rate近似浮点比例便捷入口

范例

import money
int cents = money.scale(12345, 9, 10)
println(money.format(cents, "USD"))  // $111.11

金额不携带币种；正式财务比例计算优先使用 scale。成对的 C/XLang 订单范例覆盖全部公开入口，rate 只作浮点估算展示。比例允许负分母，按结果符号对绝对值四舍五入。XLang 算术越界抛 RangeError，无效参数抛 ValueError；合法参数的格式化或分摊若内存不足会报内存错误，C/XLang 均有故障及恢复测试。C 成功调用会清除前次失败的线程错误。C 范例可直接用 xl run release/extlibs/money/examples/money.c 运行；Windows 的 test/check.ps1 -SkipAot 验证 C/JIT，默认门禁还构建运行核心与完整范例 AOT。当前默认门禁停在外来数组比较的语言边界，后续 AOT 阶段尚未签收。边界、所有权和验证命令见包内 README。
