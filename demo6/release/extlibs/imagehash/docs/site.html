扩展库 / imagehash

imagehash

图片相似性指纹。

依赖 stb_image 与 stb_image_resize2，不重复捆绑 stb；UTF-8 路径由 XRT 处理。

API

接口用途
ahash / dhash / phash生成 64 位图像指纹
hamming计算同类指纹间的位差
valid检验 16 位十六进制格式

范例

import imagehash
string a = imagehash.phash("photo.png")
string b = imagehash.phash("thumbnail.png")
println(imagehash.hamming(a, b))

不是密码学哈希；不同算法的结果不可互比。图片缺失或损坏抛 RuntimeError，内存不足抛 MemoryError；C 接口失败返回 NULL，可查询线程局部诊断与 XRT 内存错误。五个操作入口会清除旧 XRT 错误，普通格式/图片错误不会误报为上次内存故障。默认 Windows 门禁现检查完整 XLang 范例 AOT，当前仍因共享缺符号失败；-SkipAot 只作聚焦快测。C 接口、资源归属、算法范围与发布验收状态见包内 README。
