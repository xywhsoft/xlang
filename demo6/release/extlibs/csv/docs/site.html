扩展库 / csv

csv

数据格式

基于 XRT 的 UTF-8 CSV/TSV 读写。按行处理大文件，按表头读写字典，显式提交文件输出。

内存表格

import csv

csv.Writer output = csv.create()
output.write(["name", "city"])
output.write(["Alice", "上海"])
Buffer data = output.finish()

csv.DictReader rows = csv.openDict(data)
while rows.next()
    dict<string> row = rows.row()
    println(row["name"] + "|" + row["city"])
end
rows.close()

输出 Alice|上海。open(string) 接受的是文件路径，不是 CSV 文本；文本使用 parse(text)， 原始字节使用 open(Buffer)。全部字段为字符串，不自动猜测数字和日期。

函数与对象

函数返回值与用途
open(Buffer|string path)Reader；Buffer 输入保存快照，文件输入逐行读取。
parse(string text)array<var>，每项是一行字符串数组；整份结果驻留内存。
create() / createFile(string path)Writer；内存或事务文件输出。
stringify(array<array<string>> rows)完整 CSV 字符串。
openDict(Buffer|string path)DictReader；首行为表头，重复名称或数据列数不符抛 CsvError。
createDict(headers, writeHeader=true)DictWriter；headers 为 array<string>，决定列顺序。
createDictFile(path, headers, writeHeader=true)字典行文件写入器；缺失键写空串，多余键抛 CsvError。

Reader 提供 next()、field(index)、row()、close()，及 eof、rowNumber、count 属性。 行号和字段索引从 0 开始，没有当前行时 rowNumber/count 为 -1。field/row 返回独立结果。 DictReader 提供 next/row/close、eof/rowNumber 和表头副本 headers，第一条数据行编号为 1。

Writer/DictWriter 提供 write、close、finish、finishText。finish 取走 Buffer；finishText 直接接管底层缓冲并返回 string，避免再复制整份文本。两者仅限内存模式且只能二选一、取一次。 C 侧的 xcsv_writer_take_text 返回值由调用方使用 xrtFree 释放。最后一行没有换行时， next 可返回 true 而 eof 已为 true；遍历始终使用 while next()。

格式与限额

读选项顺序：delimiter、quote、strict、maxInput、maxOutput、maxField、maxRows、maxFields。 写选项顺序：delimiter、quote、newline、quoteAll、writeBOM，然后是相同的五项限额。 stringify 只接受前五项写格式选项，使用默认限额。可以按名字只传所需选项。

参数默认值与约束
delimiter / quote逗号 / 双引号；均为单个可打印 ASCII，分隔符另允许 TAB，两者不可相同。
stricttrue；false 只放宽引号语法，不允许非法 UTF-8 或 NUL。
newline / quoteAll / writeBOM"lf" / false / false；输出换行另可选 "crlf"。
maxInput268435456；读原始输入字节，写字段 UTF-8 字节累计量。
maxOutput536870912；读解码字段字节，写包含引号/分隔符/BOM/换行的总字节。
maxField16777216；单字段 UTF-8 字节，不是字符数。
maxRows / maxFields1000000 / 10000000；累计行数/字段数，包含表头。
import csv

csv.Writer output = csv.create(delimiter="\t", newline="crlf")
output.write(["甲", "a\tb", ""])
csv.Reader rows = csv.open(output.finish(), delimiter="\t")
assert rows.next()
assert rows.field(1) == "a\tb"
println(rows.count)    // 3
rows.close()

读取支持 LF/CRLF/CR，保留引用字段内部的换行，只跳过开头的 UTF-8 BOM。 单个空字段与零字段空行不同。限额 0 取消该项上限，负数拒绝；这些配额不等于总内存或 CPU 限额。 parse(string) 在复制输入前按 UTF-8 字节数检查 maxInput；大输入应使用流式 open。 不支持多字节分隔符、编码猜测、反斜杠转义方言或 Excel 公式防护。

文件必须显式提交

createFile/createDictFile 使用目标同目录的临时文件，父目录必须已存在。 只有 close 成功才替换目标；未提交析构或失败时保留旧目标，并清理临时文件。 这不承诺断电持久性；文件系统故障可能使清理失败，远程文件系统的原子性不作保证。

发生错误不要继续提交原 Writer。内存结果使用 finish，文件使用 close；析构不是隐式提交。

错误与生命周期

参数非法为 ValueError，限额超出为 RangeError，字段索引越界为 IndexError， 格式/UTF-8/表头错误为 CsvError，关闭后使用等状态错误为 RuntimeError， 分配与读写故障分别为 MemoryError/IOError。错误保留底层原因和 CSV 数据位置。

原始字节中 NUL 不合法，Buffer 输入按真实长度拒绝。语言层的文本、字段、表头、 路径及方言选项在进入 C 字符串接口前拒绝内嵌 NUL；任意二进制输入请使用 Buffer。 同一对象串行使用，不同对象可并发；自定义 IO 回调不得重入操作或销毁当前 CSV 对象。

C API

公共头为 extlibs/csv/include/xrt_csv.h，实现为 manifest 的四个 C 编译单元。 xrtCsvReaderCreate/OpenMemory/OpenFile、Next/EOF/Error、Close/Destroy 负责读取； xrtCsvWriterCreate/CreateMemory/OpenFile、Write、Close/TakeBuffer、Error/Destroy 负责写入。 方言必须通过 xrtCsvDialectInit 初始化；五项有效限额继承 XRT 默认值。 深度、压缩倍率、资源标志及保留字段必须为零，显式设置会在 reader/writer 创建时拒绝。

C OpenMemory 借用内存，必须保持输入有效不变；行字段在下次 Next/Close/Destroy 后失效。 takeOwnership=true 在创建失败时也消费传入流。创建可能返回带错误的非 NULL 对象，需检查 Error()->iCode。 Next=false 需区分 EOF 与错误。内存 Writer 要先 Close 再 TakeBuffer，结果由调用者 xrtBufferDestroy。

C 外部输出流失败后不能回滚已写前缀。C 输入字符串以 NUL 结尾，不保留调用者字段； Destroy(NULL) 安全，文件 Destroy 不自动提交。

双语范例

发行目录：xl run examples/extlibs/csv_basic.xl；xl run examples/extlibs/csv_files.xl。 C 对照位于 extlibs/csv/examples/basic.c 和 files.c，教学范例显式包含 CSV 核心源码， 可直接运行 xl run release/extlibs/csv/examples/basic.c 或 xl run release/extlibs/csv/examples/files.c；正式包仍分别编译四个 C 源。

两组固定输出覆盖表头、Unicode、TSV、严格错误、未提交保留旧文件和提交后读取汇总。基础范例还分别以 XLang stringify 和 C Writer 核对含逗号、引号与中文的完整 CSV 线格式。 C 与 XLang 文件范例都通过 XRT 排他创建临时目录，只操作其中的报表.csv，并在结束时清理；XLang 范例不再写入固定的 build/test 路径，不会覆盖工作目录中的同名文件。
