扩展库 / semver

semver

严格解析 SemVer 2.0.0 版本，比较优先级，并匹配常用依赖范围。

版本 1.0.0 · C / xlang · 无扩展库依赖

当前 Windows 发布物的 C/XLang 边界、分配故障与独立 EXE 门禁通过；Linux C ASan/UBSan 与 XLang JIT 双语门禁通过。Linux 独立 EXE 和可选 node-semver 外部对照本轮未验收。

快速开始

import semver

assert semver.valid("1.2.3+build-5")
assert semver.compare("1.0.0-alpha", "1.0.0") < 0
assert semver.satisfies("1.2.2", "<=1.2.3")

build 元数据不参与版本优先级。valid 要求严格格式；要显式去掉前导 v、V、= 或首尾 ASCII 空白（空格、tab、换行、回车、换页、垂直 tab）时使用 clean。

接口

入口用途
valid / clean严格校验版本，或显式清理常见前缀和首尾 ASCII 空白。
major / minor / patch读取整数分量；非法输入返回 -1。
prerelease / build读取先行版本或 build 元数据；缺失及非法输入返回空字符串。
compare(a, b)返回 -1/0/1；非法版本返回 -2。
satisfies(version, range)匹配常用依赖范围；非法范围返回 false。

范围支持完整/部分版本、x/* 通配、比较运算符、~、^、空格交集、|| 并集及 A - B 区间。比较符与版本号间可有空格/tab，例如 >= 1.2.3 < 2.0.0；区间的 - 两侧可有多个空格/tab。区间还能与同一分支的其他条件取交集，例如 1.2.3 - 2.3.4 >=2.0.0。空范围或只含空格/tab 的范围匹配正式版本；空的 || 分支及只有运算符而无版本号的范围均属非法。需要显式通配时使用 *。prerelease 需要同一主次修订元组的显式 prerelease 比较器才会参与匹配。这是所列语法的实现，不宣称与 node-semver 的全部 API 或宽松解析模式等价。

C 端包含 extlibs/semver/semver_native.h；四个整数结果使用与 XLang int 一致的 int64_t。三个文本入口返回 XRT 堆分配的 char*：C 调用方用 xrtFree 释放，XLang 的 @owned 声明直接接管。九个 C 入口不会带出陈旧 XRT 错误；三个字符串入口分配失败返回 NULL 并保留 XERR_MEMORY，XLang 对应入口抛出 MemoryError。版本分量受非负 64 位整数限制，单个 prerelease/build 字段最长 255 字节，范围文本最长 511 字节；每个 || 分支展开后最多容纳 32 个基础比较器，^、~ 等简写可能占用两个。XLang 输入含内嵌 NUL 时按各接口的失败值返回，不会只检查前缀。

验证与边界

xl run release/extlibs/semver/examples/semver_c.c
powershell -NoProfile -ExecutionPolicy Bypass -File release/extlibs/semver/test/check.ps1
bash release/extlibs/semver/test/check.sh

严格版本与范围解析在格式上限内检查 C 字符串终止符；超限输入不会继续无界扫描。C/XLang 验证了范围长度和元数据字段的恰好上限；C 范例可直接用 xl 单文件运行。完整版本的 <= 按包含式上界处理。2026-10-26 迁移前版本的 Windows/Linux 默认包门禁通过。迁移后的 Windows 严格 C、公共源码驱动 JIT、中央/边界/分配故障/范例的独立 EXE 及黄金输出通过；生成 C 直接保存字符串指针，仅扫描一次长度，不经 takeCstr 包装。现有发布版尚不认识 @owned，新发布构建被 XRT/xruntime 快照一致性校验挡住；新版尚待发布物与 Linux 全门禁复验。本页不把源码驱动结果写作新发布版签收。
