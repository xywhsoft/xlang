扩展库 / semver

semver

严格解析 SemVer 2.0.0 版本，比较优先级，并匹配常用依赖范围。

版本 1.0.0 · C / xlang · 无扩展库依赖

快速开始

import semver

assert semver.valid("1.2.3+build-5")
assert semver.compare("1.0.0-alpha", "1.0.0") < 0
assert semver.satisfies("1.2.2", "<=1.2.3")

build 元数据不参与版本优先级。valid 要求严格格式；要显式去掉前导 v、V、= 或首尾 ASCII 空白（空格、tab、换行、回车、换页、垂直 tab）时使用 clean。

接口

入口用途
valid / clean严格校验版本，或显式清理常见前缀和首尾 ASCII 空白。
major / minor / patch读取整数分量；非法输入返回 -1。
prerelease / build读取先行版本或 build 元数据；缺失及非法输入返回空字符串。
compare(a, b)返回 -1/0/1；非法版本返回 -2。
satisfies(version, range)匹配常用依赖范围；非法范围返回 false。

范围支持完整/部分版本、x/* 通配、比较运算符、~、^、空格交集、|| 并集及 A - B 区间。空范围或只含空格/tab 的范围匹配正式版本；空的 || 分支及只有运算符而无版本号的范围均属非法。需要显式通配时使用 *。prerelease 需要同一主次修订元组的显式 prerelease 比较器才会参与匹配。这是所列语法的实现，不宣称与 node-semver 的全部 API 或宽松解析模式等价。

C 端包含 extlibs/semver/semver_native.h；四个整数结果使用与 XLang int 一致的 int64_t。字符串结果由调用方用 xrtFree 释放。九个 C 入口不会带出陈旧 XRT 错误；三个字符串入口分配失败返回 NULL 并保留 XERR_MEMORY，XLang 对应入口抛出 MemoryError。版本分量受非负 64 位整数限制，单个 prerelease/build 字段最长 255 字节，范围文本最长 511 字节；每个 || 分支展开后最多容纳 32 个基础比较器，^、~ 等简写可能占用两个。XLang 输入含内嵌 NUL 时按各接口的失败值返回，不会只检查前缀。
