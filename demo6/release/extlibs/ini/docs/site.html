扩展库 / ini

ini

读取、修改和写入 UTF-8 INI 配置，保留节与键的顺序、注释和多行值。

版本 1.0.0 · C / xlang · 无扩展库依赖

快速开始

import ini

auto config = ini.parse("[server]\nport = 8080\n")
config.set("server", "port", "9090")
assert config.getInt("server", "port") == 9090
println(config.stringify())

完整的 C/XLang 对照范例还演示 create、save、load：在独占临时目录中保存配置并读回核对，运行结束即清理。Windows 严格 GCC 与 TCC、Linux ASan/UBSan 的输出均和 XLang 对照。

接口

入口用途
create / parse / load创建空配置、解析文本或加载 UTF-8 路径。
Config.get / getOr / getInt / getFloat / getBool读取值并按需转换类型；get 返回可直接用作字符串的拥有型 cstring，getOr 返回普通 string；getInt 严格解析完整十进制值，getFloat 固定点号十进制、不受区域设置影响；失败抛出 ConfigError。
Config.set / remove / removeSection修改键或节。
Config.sectionNames / keys / has / hasSection枚举和查询节、键。
Config.stringify / save生成拥有型 cstring 文本或原子保存到文件；无法无损表示的节名、键名或值会明确报错，不会静默改变数据；写入失败不截断旧文件。
Config.errorCode / errorLine / errorColumn / errorOffset读取最近一次原生操作的错误信息；非法 UTF-8 指向首个错误字节，偏移包含 BOM，首行列号不计 BOM。

可设置大小写敏感、重复键检查、插值和资源限额。${key}、${section.key} 在启用插值时生效。parse(string) 直接传入 UTF-8 数据及字节长度，不另建 XLang Buffer 副本；原生读取器在复制正文前检查输入限额并拒绝内嵌 NUL。set() 可以保留内存值；写出时若值有首尾空白、尾随换行或注释形态的续行等无法无损表示的内容，C 端报 FORMAT，XLang 抛 ConfigError。全局节先于具名节写出。C 端包含 extlibs/ini/include/xrt_ini.h，解析结果由 xrtIniDestroy 释放；xrtIniGet 的结果由调用方用 xrtFree 释放。C 选项须先初始化，顶层与内嵌资源限额的版本和结构长度均会校验，失配报 ARGUMENT。拥有型 Reader/Writer 在退出时关闭；正文成功但关闭失败时报告 IO，借用型流由调用方关闭。

C 配置的顶层及资源限额保留字段必须为零；非零配置在 create/parse 入口报告 ARGUMENT。iMaxEntries 限制所有节的键总数，删除键后恢复额度；不适用的压缩倍率与 iFlags 必须为零，显式设置会报 ARGUMENT。

验证与边界

powershell -NoProfile -ExecutionPolicy Bypass -File release/extlibs/ini/test/check.ps1
bash release/extlibs/ini/test/check.sh

C Reader 的输入限额从当前读取位置计算，不包含已跳过的前缀；只有 Size 而没有 Tell 的 Reader 由实际读取阶段执行限额。
