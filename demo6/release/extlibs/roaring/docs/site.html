扩展库 / roaring

roaring

精确的 uint32 整数集合。

高 16 位分桶，桶内有序数组按密度升级为位图；删除后会回退并收缩，适合 ID 去重。

API

接口用途
roaring.create()创建空集合
add / contains / remove插入、查询、删除整数
count / min / max / clear统计、范围与复用
toArray()生成独立的升序整数数组快照

范例

import roaring
roaring.RoaringBitmap ids = roaring.create()
ids.add(65536)
var ordered = ids.toArray()
println(ordered[0])

范围为 0..4294967295。没有 Roaring 二进制格式互操作或集合并交差；C 接口和验证范围见包内 README。

toArray() 按数值升序返回独立快照；C 接口 xroaring_to_array 的结果由调用方用 xrtValueRelease 释放。C 侧空句柄返回参数错误，与合法空集合或成员未命中区分；成功调用会清除本线程旧的 XRT 错误。创建、插入、删除或快照分配失败抛 MemoryError，原集合不变。

从 demo6 目录可直接运行 xl run release/extlibs/roaring/examples/roaring.c；Windows 包级 test/check.ps1 与 Linux test/check.sh 同时验证单文件 C、分离编译 C 和 XLang 范例的固定输出。当前 Windows 默认门禁的核心与公开范例独立 EXE 均通过；-SkipAot 仅作聚焦检查。Linux 独立 EXE 尚未用新版发布物验收。
