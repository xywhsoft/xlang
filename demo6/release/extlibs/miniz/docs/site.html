扩展库/miniz

miniz

压缩归档
v1.0.0C 混编0 依赖ABI 1

标准 zlib 流压缩，底层复用 XRT 的 deflate/inflate，不重复携带另一套压缩引擎。xlang 层提供二进制安全的 Buffer 一次性、文件级和 update → drain → finish 增量流式接口。

典型场景

嵌入式压缩zlib 兼容轻量集成日志压缩缓存压缩进度回显传输

快速开始

quick_start.xl
import miniz

func main(...) as int
    Buffer packed = miniz.compress("hello miniz")
    println(miniz.decompressText(packed))   // hello miniz

    auto enc = miniz.compressor()
    enc.update("part1 ")
    enc.update("part2")
    enc.finish()
    Buffer blob = enc.drain()

    auto dec = miniz.decompressor()
    dec.update(blob)
    dec.finish()
    println(dec.drain().text())           // part1 part2
    return 0
end

核心特性

  • 标准 zlib 流 — 可与 zlib 工具互通；它不是 gzip 容器
  • 二进制安全 — 原始输出使用 Buffer；decompressText 只接受合法 UTF-8 明文
  • 三种粒度 — 一次性内存、文件级、增量流式（MinizCompressor/MinizDecompressor）
  • 真流式输出 — drain() 随时取走已产出字节
  • 进度回显 — inputBytes/outputBytes 字节计数器
  • 完整性校验 — Adler-32、截断和尾部数据由 XRT 解码器检查
  • 级别 0..10 — 0 不压缩、10 最高压缩率、6 默认平衡
  • 文件原子写 — 临时文件 + 原子重命名

压缩级别常量。0 不压缩、10 压缩率最高、6 为默认平衡点。

一次性 / 文件 / 流式
export func compress(Buffer data, int level = 6, ...) as Buffer export func decompress(Buffer data, ...) as Buffer export func compressFile(...) / decompressFile(...) export func compressor(int level = 6, ...) as MinizCompressor export func decompressor(...) as MinizDecompressor

提供一次性、文件级和增量流式三种接口。流式类提供 update/drain/finish、inputBytes/outputBytes/finished；每次编码只生成一条 zlib 流，解码拒绝第二条拼接流及旧私有容器。

文件接口末尾支持可空 onProgress(inputBytes, totalBytes, outputBytes)。含 NUL 的源/目标路径报 ValueError；返回 false 删除临时输出并抛 CancelledError；回调异常原样传播。C 层对应 xrtprogressproc + void* userData。C 流式接口的进度从 Reader 当前读取位置起算；无法同时取得总长和当前位置时不设置 TOTAL_KNOWN。
C 流式接口借用 Reader/Writer，不接管关闭。读取或 drain 写出失败时，错误结构保留可识别的 XRT 参数、内存、限额、状态、取消或 IO 首因，以及原始代码和消息；未提供详细首因时才按 IO 处理。
level 在工厂和直接原生构造入口都只接受 0..10，越界抛 ValueError。结构化底层错误直接分发：损坏/截断通常为 IOError，限额为 RangeError，分配失败为 MemoryError，不一概改成 CompressionError。

教学范例

完整源文件：examples/extlibs/miniz.xl

1. 一次性 + 流式

miniz.xl
import miniz

Buffer packed = miniz.compress("xlang miniz")
assert miniz.decompressText(packed) == "xlang miniz"
println("引擎版本: ", miniz.version())

auto encoder = miniz.compressor()
Buffer streamPacked = Buffer()
encoder.update("hello ")
streamPacked.append(encoder.drain())
encoder.update("stream")
streamPacked.append(encoder.drain())
encoder.finish()
streamPacked.append(encoder.drain())

auto decoder = miniz.decompressor()
decoder.update(streamPacked)
decoder.finish()
assert decoder.drain().text() == "hello stream"

2. 最高级别 L10

调优
auto tuned = miniz.compressor(miniz.MINIZ_MAX_LEVEL)
tuned.update("tune me")
tuned.finish()
assert miniz.decompress(tuned.drain()).text() == "tune me"

运行范例

终端
cd release
xl.exe run examples\extlibs\miniz.xl

C 对照范例可从 release 目录直接运行：xl.exe run extlibs/miniz/examples/basic.c。正式包仍按清单分离编译原生源码。

包内 extlibs/miniz/examples/streaming.xl 与 streaming_c.c 是完整增量流双语对照：及时 drain、finish 尾部收集、分块解压和计数断言。两份可直接 xl run 或 build，无文件依赖，固定输出为 hello stream 和 12 / 12。

测试覆盖

直接构造器和 C 桥接不接受负级别别名。新增五个非法级别 × 四种入口的 C 负例、0..10 往返、XLang 显式类型/直接构造正反例，以及原生头的两种包含顺序检查。最终 Windows/Linux 默认门禁完整通过；曾遇宿主虚拟内存不足和 WSL 中断，保留现场后按原参数串行复验，不把资源事件当作库功能失败或旧未知风险已修。

2026-10-28 Windows/Linux 默认门禁通过新增 C IO 首因矩阵：四个入口 × 七类错误共 28 组、真实 Writer 扩容 OOM、关闭归属和活动分配恢复。保留严格 GCC、Linux ASan/UBSan、Python zlib 互通、新旧双语 JIT/AOT；Windows 默认模式也完整构建运行中央、进度、文件、分配和完整范例。失败保留原始状态与输入指纹，不把一次通过写成长期压力或所有平台认证。

测试文件：extlibs/miniz/test/file_ops.xl、extlibs/miniz/test/test_miniz.c，以及中央 test/cases/extlib_miniz.xl。C 入口先验证选项和资源限制结构的长度、版本、保留字段及 0..10 级别；条目、节点、深度限额及未知标志不适用于单条 zlib 流，显式设置会报参数错误，不读取文件流输入。

  • 一次性二进制往返（含 NUL / 0xFF）
  • 流式往返 + finished 状态
  • 分块收集 + inputBytes 计数器
  • 最高级别 MINIZ_MAX_LEVEL（L10）往返
  • 级别越界抛 ValueError
  • Python zlib 双向互通、拼接流与尾部数据拒绝
  • 损坏数据抛 IOError
  • 文件级往返 + overwrite 拒绝
  • 文件进度回调、取消清理及限额失败时的既有目标保护
  • C Reader/Writer 二进制流往返与进度回调
  • 一次性编解码的 XRT 分配失败、空输出、释放平衡与恢复；XLang 公开入口须抛 MemoryError
  • 流对象、一次性及文件流入口的选项 ABI 和 -1/11 级别拒绝；0..10 全部可往返

2026-10-26 当前 Windows/Linux x64 包级门禁通过：严格 C、Linux ASan/UBSan、Python 标准库 zlib 双向互通、XLang JIT/AOT，以及 C/XLang 基础范例输出一致。Linux 另覆盖七条独立 EXE AOT 和文件/完整范例 JIT/AOT 对照。旧 Linux cstring、根目录 VFS 与 AOT 缺符号阻断不再复现；32 位、TSan、长时压力及持续模糊测试尚未验收。
