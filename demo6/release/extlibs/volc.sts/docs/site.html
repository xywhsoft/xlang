扩展库 / volc.sts

volc.sts

AssumeRole 请求与离线签名预览。

C 离线签名调用已验证。XLang 导入链、在线请求和响应解析尚未完成发布验收。

API

入口用途
preview_assume_role / preview_assume_role_spec固定输入下离线预览签名，不联网
assume_role / assume_role_trn / assume_role_spec在线请求，未验收
credentials_json / projection_credentials_json解析 Result.Credentials；必需凭据缺失或类型错误会报错，联网请求未验收

示例

import volc.sts
string preview = volc.sts.preview_assume_role("AKID", "SECRET", "123456789", "demo", "demo-session", 900, "20240102T030405Z")

直参入口直接传递字段，角色 TRN 与会话名中的换行会在发送前拒绝；自行编写的 *_spec 声明文本没有值转义。声明中的时长/超时只有省略或留空才取默认值，显式坏数字在签名或发送前拒绝。C 对照见 examples/assume_role.c；Windows 与 Linux 门禁分别为 test/check.ps1 和 test/check.sh，均包含离线响应 JIT/AOT。固定测试凭据不会用于联网请求。响应助手使用标准 JSON 解析，只读取 Result.Credentials；完整 STS 导入仍被独立维护的 xhttp.client 阻断，在线请求尚未验收。详细限制见包内 README。
