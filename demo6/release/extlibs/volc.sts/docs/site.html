扩展库 / volc.sts

volc.sts

AssumeRole 请求与离线签名预览。

C 离线签名调用已验证。XLang 导入链、在线请求和响应解析尚未完成发布验收。

API

入口用途
preview_assume_role / preview_assume_role_spec固定输入下离线预览签名，不联网
assume_role / assume_role_trn / assume_role_spec在线请求，未验收
credentials_json / projection_credentials_json当前以文本切分响应，不适合不可信 JSON

示例

import volc.sts
string preview = volc.sts.preview_assume_role("AKID", "SECRET", "123456789", "demo", "demo-session", 900, "20240102T030405Z")

直参入口直接传递字段，角色 TRN 与会话名中的换行会在发送前拒绝；自行编写的 *_spec 声明文本没有值转义。C 对照见 examples/assume_role.c；Windows 严格 GCC/C 门禁见 test/check.ps1，Linux ASan/UBSan 见 test/check.sh。使用固定测试凭据，不发送请求。XLang 导入仍被独立维护的 xhttp.multipart 阻断；响应助手不是结构化 JSON 解析器。详细限制和待验收项见包内 README。
