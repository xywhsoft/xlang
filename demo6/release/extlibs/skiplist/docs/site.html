扩展库 / skiplist

skiplist

有序字符串键值表。

支持完整长度的键和值、原子覆盖、全量有序键和闭区间遍历。

API

接口用途
skiplist.create()创建有序键值表；分配失败时抛 MemoryError，系统随机源失败时保留 XRT 原错误
set / get / contains / remove管理键值
keys / range按键字节序遍历
count / clear总数与清空

范例

import skiplist
skiplist.SkipList table = skiplist.create()
table.set("a", "first")
table.set("b", "second")
println(table.range("a", "b").length)  // 2

区间两端均包含；每个实例由 XRT 系统随机源独立播种 XRT RNG 层级序列，不回退到可预测固定种子。创建、插入、覆盖、读取及结果遍历的分配故障已用 C/XLang 定向验证，失败的写入保持原值。Windows test/check.ps1 -SkipAot 与 Linux test/check.sh 验证 C 独立模型、包外原生方法访问拒绝、XLang 用例及双语范例固定输出；Linux 另含 ASan/UBSan。Windows 默认门禁还要求核心与公开范例 AOT，目前完整范例受主线共享符号阻断。C 计数返回 int64_t，可在 LP64 平台直接与 XLang int 互通。C 所有权及复杂度见包内 README。
