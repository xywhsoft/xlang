扩展库 / trie

trie

前缀字符串集合。

查找、插入、删除和前缀词数；UTF-8 按字节保存，不做隐式归一化。

当前 Windows 发布物的默认门禁在首个 XLang 用例遇到共享 VFS 缺少 include/xruntime_decl.h；后续语言边界与 AOT 未执行，先前发布物的完整通过记录不能代替本次验收。

API

接口用途
trie.create()创建 Trie 对象；分配失败时抛错
insert / contains / remove管理精确键
startsWith / countPrefix查询前缀
count / clear总词数与清空

范例

import trie
trie.Trie words = trie.create()
words.insert("你好")
words.insert("你们")
println(words.countPrefix("你"))  // 2

C 接口支持明确长度的二进制键；两个计数结果使用与 XLang int 一致的 int64_t。创建或插入遇到分配失败时，XLang 抛 MemoryError，已有键和计数保持。Windows test/check.ps1 -SkipAot 与 Linux test/check.sh 的完整设计覆盖 C 独立模型、包外原生方法访问拒绝、XLang 故障边界和三路范例固定输出；Linux 另含 ASan/UBSan。Windows 默认门禁还要求核心与公开范例 AOT；当前首先受共享 VFS 头路径阻断。资源所有权和性能范围见包内 README。
