扩展库 / sysinfo

sysinfo

读取 Windows 和 Linux 主机的系统标识、CPU、内存与运行时间。

版本 1.0.0 · C / xlang · 无扩展库依赖

快速开始

import sysinfo

println(sysinfo.osName(), sysinfo.arch())
println(sysinfo.cpuCount())
println(sysinfo.memAvailable())

内存值是瞬时快照，连续调用可能不同；探测失败或 CPU 型号字段只有空白时，文本返回 unknown、数值返回 0。

接口

入口用途
osName / osVersion / arch / hostname系统、版本、架构及主机名的 UTF-8 文本。
cpuName / cpuCount处理器名称及全系统在线逻辑处理器数量；Windows 覆盖所有处理器组。
memTotal / memAvailable / memUsagePct物理内存总量、可用字节数及整数使用率百分比；Linux 可用量按 /proc/meminfo 的 MemAvailable 计算，不等同空闲页。探测失败返回 0，不伪报满载。
pageSize / uptime内存页字节数与系统运行秒数。

Windows 版本来自系统 API，主机名和 CPU 名经 Unicode API 转 UTF-8；Linux 的系统标识来自 uname，CPU 名和运行时间读取 /proc。Linux 内核的 CPU 信息字段因架构而异；没有 model name 时返回 unknown，不会以架构名冒充型号。系统返回非 UTF-8 文本也降级为 unknown。支持范围为 Windows/Linux，不承诺其他平台。

C 对照

#include "xrt.h"
#include "sysinfo_native.h"

int main(void)
{
    char* name = xsysinfo_os_name();
    int ok = name && name[0] != 0;
    xrtFree(name);
    return ok ? 0 : 1;
}

C 字符串结果由调用方用 xrtFree 释放；XLang 包装自动接管。每次公开调用清除之前的 XRT 错误；转换时若内存分配失败，则保留内存错误并返回空结果，不伪装为 unknown。完整双语范例位于 release/extlibs/sysinfo/examples/。

2026-10-19 复跑：C 范例可直接使用 xl run release/extlibs/sysinfo/examples/sysinfo_c.c 运行；Windows/Linux 包门禁将其与 GCC 编译运行、XLang 范例的同机输出对照。Windows 严格 GCC、C/XLang 双语输出通过；Linux 同次运行 C ASan/UBSan 与 XLang 边界。Windows 包级脚本每次使用独占构建目录，退出后只清理本次产物，不与并行门禁共用对象。六个整数 C 结果统一为 int64_t，与 XLang int 的 LP64 ABI 一致。Linux 内存可用量以前后两次系统快照对照；链接器夹具还验证不可读、负数、尾部垃圾及整数溢出时的降级，以及非 UTF-8 系统文本降级。Windows 伪注册表夹具验证首次分配失败及恢复。本机未覆盖多处理器组硬件。带输出范例 AOT 尚缺共享符号 xl6ValueDataSnapshotV1，未签收完整发布门禁。
