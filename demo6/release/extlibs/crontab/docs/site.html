扩展库 / crontab

crontab

本地时间 cron 调度。

严格解析五字段规则，查询匹配及下一次触发时间。

API

接口用途
isValid(expr)验证五字段表达式
matches(expr, timestamp)按进程本地时区匹配 Unix 秒
next(expr, timestamp)严格晚于输入的下一次分钟触发
describe(expr)字段摘要

范例

import crontab
int nextRun = crontab.next("*/15 * * * *", 1700000000)
println(nextRun)

DOM 与 DOW 都不以 * 开头时采用 OR；任一字段以 * 开头时按实际位图取 AND，*/2 仍保留步长约束。Linux 固定时区测试覆盖纽约的一小时跳时、Lord Howe 的半小时跳时与重复分钟，以及历史秒级时差与标准时切换；这些边界同时运行 C 与 XLang 用例。next 返回本地整分钟，不要求 Unix 秒数为 60 的倍数。describe 的分配失败在 C 中保留 XERR_MEMORY，在 xlang 中抛 MemoryError，清除故障后可重试。Windows 默认门禁现在于核心后构建运行完整范例 AOT 并与同机 C 输出对照；实测核心通过、范例仍缺共享 xl6ValueDataSnapshotV1，不能签收完整 AOT。时区、8 年搜索边界及 C 接口见包内 README。
