扩展库 / blake2

blake2

哈希校验

BLAKE2b/BLAKE2s 的字节、UTF-8 文本、文件和增量接口。内嵌便携 C 实现，复用宿主 XRT/xruntime，不需要额外 BLAKE2 DLL。

一次性与文件 API

下表的 b/s 分别对应 blake2b 和 blake2s 两组函数。BLAKE2b 默认摘要 64 字节、范围 1..64； BLAKE2s 默认 32 字节、范围 1..32。十六进制结果为小写，字符数量是摘要字节数的两倍。

函数参数与返回
version()返回内置实现的版本字符串。
blake2b/sHashHex(data, digestSize)data 为 Buffer 或 string，返回 string。
blake2b/sHashBytes(data, digestSize)相同输入，返回独立拥有型 Buffer。
blake2b/sKeyedHex(data, key, digestSize)两个 Buffer 或两个 string，返回 string。
blake2b/sKeyedBytes(data, key, digestSize)相同输入，返回独立拥有型 Buffer。
blake2b/sFileHex(path, maxInput, digestSize, onProgress)读取 UTF-8 路径的文件，返回 string。maxInput=268435456，onProgress=null。

文本及密钥按 UTF-8 字节计算；任意二进制使用 Buffer。BLAKE2b 密钥上限为 64 字节， BLAKE2s 为 32 字节，超过上限报错，不截断；空密钥等价于未使用密钥。 keyed hash 是原生 MAC，不是 HMAC，也不是口令存储的密码派生函数。

公开常量：BLAKE2B_OUT_LEN、BLAKE2S_OUT_LEN、 BLAKE2B_KEY_MAX、BLAKE2S_KEY_MAX。短摘要是独立初始化参数， 不是完整摘要的前缀截断。

增量对象

原生 *Native 成员仅供类内部包装使用；公开 keyed 构造器接收自带真实长度的 bytes，工厂将 Buffer 密钥复制成 bytes 后调用。C 指针/长度入口由 C 调用方保证配对；XLang 导入方不能自行伪造长度。

blake2b/sHasher(digestSize, maxInput=268435456) 创建无密钥对象， blake2b/sKeyedHasher(Buffer key, digestSize, maxInput=268435456) 创建持有密钥副本的对象。 对应类为 Blake2bHasher、Blake2sHasher、Blake2bKeyedHasher、Blake2sKeyedHasher。

成员合同
update(Buffer|string)追加输入，空输入有效。
digestHex() / digestBytes()读取快照，不结束状态；摘要长度由构造确定，没有额外长度参数。
inputBytes / valid成功接收的输入字节数，以及句柄是否非空。
clone()独立的增量状态，后续输入不影响原对象。
reset() as bool清除数据及失败状态，保留摘要长度、密钥和限额，成功返回 true。
import blake2

auto hash = blake2.blake2bHasher(16)
hash.update("ab")
auto branch = hash.clone()
hash.update("c")
branch.update("d")
assert hash.digestHex() == blake2.blake2bHashHex("abc", 16)
println(blake2.blake2bKeyedHex("你好 xlang", "密钥", 16))

update 的参数或限额失败后，需要 reset 才能继续使用；失败的输入不增加计数。 不同对象可独立运行，同一个可变对象须串行访问。对象析构释放并清零自己的密钥和状态， 不承诺擦除调用方副本、寄存器或系统交换页。

进度与错误

可选回调类型为 (func(int, int, int) as bool)?，参数依次为 inputBytes、 totalBytes、outputBytes；均按字节，未知总长为 0，outputBytes 恒为 0。 每块输入通知一次，最后再通知一次；空文件也通知完成。

string digest = blake2.blake2sFileHex("data.bin",
    onProgress = func(int inputBytes, int totalBytes, int outputBytes) as bool
        return true
    end)

回调同步执行，可以嵌套另一独立哈希。返回 false 抛 CancelledError；回调异常保留原类型和消息。 文件路径中的 NUL 报 ValueError，不会读取前缀文件。读取文件只借用输入，不修改源文件；失败或取消不会返回部分摘要。 读取期间不提供防止其他进程修改文件的一致性快照。

  • 非法摘要/密钥长度为 ValueError；输入超限为 RangeError；分配失败为 MemoryError。
  • 打开失败沿用 XRT FileError，读取失败为 IOError；clone 失败状态对象为 RuntimeError。
  • xlang 工厂及文件接口要求 maxInput 为正，默认 256 MiB；这是累计字节限额，不是 CPU 时间预算。

C API 与范例

核心头为 include/xrt_blake2.h，薄绑定头为 include/blake2_native.h。 xrtBlake2OptionsInit 初始化流对象配置，文件接口的显式限额使用 xrtBlake2LimitsInit；xrtBlake2b/sHash 写入调用方缓冲。 HasherCreate/Update/Digest/Reset/Clone/Destroy 提供相同增量语义。

C Digest 的长度必须等于 HasherDigestSize。File 借用 reader，从当前游标读到 EOF，不接管 reader 寿命。 C 调用方须检查 Reader 的关闭结果；XLang 文件哈希自行关闭文件，关闭失败不返回摘要。Reader 读取内存失败保留 MEMORY 分类和原始消息，不误报 IO。配置长度/版本必须匹配，除输入预算外的限额、标志和保留字段必须为零；通用资源初始化会设置无关的非零限额。错误配置在读取前拒绝。核心输入限额为零时关闭业务限制，但仍检查计数溢出。模块选择应在首次包含 XRT 前完成，依赖见包清单。

薄绑定 char* 借用当前 XRT 临时区，清理或回退后失效；长期保留需复制。 返回 Buffer 由调用方 xrtBufferDestroy。接管同一个句柄多次会破坏所有权，不允许重复 adopt。

教学：examples/extlibs/blake2.xl。对照： examples/extlibs/blake2_basic.xl 与 extlibs/blake2/examples/basic.c， 共同预期输出位于 examples/extlibs/blake2_basic.expected.txt。 从 demo6 目录可直接运行 release/xl.exe run release/extlibs/blake2/examples/basic.c，无需额外源文件参数。
