# RapidOCR model directory

Place OCR model files here for the default config:

- `ch_PP-OCRv4_det_infer.onnx`
- `ch_ppocr_mobile_v2.0_cls_infer.onnx`
- `ch_PP-OCRv4_rec_infer.onnx`
- `ppocr_keys_v1.txt`

This fixture includes the default model files. `download_models.ps1` is kept as a refresh helper when the upstream model files need to be updated.
