扩展库 / procps

procps

完整进程快照、UTF-8 名称与常驻内存查询。

Windows/Linux C、Linux sanitizer、中央及包内 XLang JIT 边界与双语范例固定输出对照已通过；C 教学范例也可直接单文件运行。进程快照接口为返回数组的 pids()，不保留旧字符串接口。XL AOT 仍受共享主线符号缺失阻断。

API

入口用途
pid / ppid / exists当前进程、父进程与存在性
pids / count系统进程快照与数量；相邻调用可能不同
nameUTF-8 可执行文件名
memKbRSS/Working Set，单位 KiB；不可读取或数据畸形时返回 -1

xlang

import procps
int selfId = procps.pid()
array<int> ids = procps.pids()
println(procps.name(selfId))

C 与范围

头文件 include/procps_native.h。C 调用方释放 xprocps_pids 返回的 XRT 值和 xprocps_name 返回的字符串。Linux 进程名含非法 UTF-8 时拒绝返回，XLang 抛 ValueError，C 返回 NULL 并设置 XERR_VALUE。Linux 的 statm 前两列必须是完整的非负整数，畸形数据按不可读取返回 -1，不静默接受有效前缀。公开 C 入口先清理旧 XRT 错误。目标进程可能退出或拒绝访问；接口不保证跨调用快照一致。详情与验证命令见包内 README。
