扩展库 / color

color

颜色工具

RGB/RGBA、HSV/HSL、命名色与对比度。C 输出由调用者持有，xlang 字符串独立拥有。

#3366CC #808080 #FFFFFF

规范化与混色

import color
string accent = color.normalize("#36c")
println(accent)
println(color.mix("#000", "#fff", 0.5))

依次输出 #3366CC、#808080。十六进制输入支持 3/4/6/8 位，# 可省略，不接受空白。 四位和八位写法的 alpha 在末尾；名称先用 fromName 转换，valid("red") 为 false。

全部函数

下列颜色/名称参数为 string，RGB/alpha 分量为 int，h/s/v/l/t 为 float；所有参数均必填。

调用返回与含义
valid(text)bool，是否为合法十六进制 RGB/RGBA。
red(text), green(text), blue(text), alpha(text)int，0..255；无 alpha 默认 255；非法为 -1。
hex(r,g,b), hexA(r,g,b,a)string，大写 #RRGGBB / #RRGGBBAA；分量越界为空串。
normalize(text)string，展开短写、舍弃 alpha；非法为空串。
hue(text)float，色相 [0,360)，灰色为 0。
saturation(text), value(text)float，HSV 的 S/V，范围 [0,1]。
lightness(text)float，HSL 的 L，范围 [0,1]；不是相对亮度。
fromHsv(h,s,v), fromHsl(h,s,l)string，转换为 RGB；有限 hue 环绕，其他有限分量截至 [0,1]。
luminance(text), contrast(a,b)float，相对亮度 [0,1] / 对比度 [1,21]。
isDark(text), isLight(text)bool，合法颜色按相对亮度 0.5 分界；非法均 false。
mix(a,b,t)string，编码后的 RGB 分量插值；有限 t 截至 [0,1]，舍弃 alpha。
fromName(name)string，148 个 CSS 命名色，ASCII 大小写不敏感。
toName(text)string，仅匹配不透明颜色；同值别名返回按字母顺序排列的第一个。

数值查询遇到非法颜色返回 -1，文本查询返回空串。NaN/无穷浮点参数返回空串； 分配失败属于错误，不能当作正常空结果。saturation 返回 HSV 饱和度，不是 HSL 饱和度。

使用边界

normalize/mix 不保留 alpha，luminance/contrast 不进行背景合成。透明颜色应先确定实际背景。 isDark/isLight 是方便判断，不是可访问性结论。工具不解析 rgb()/hsl() 文本、系统颜色或其他色域。

fromName 不接受 transparent/currentColor 或前后空白；toName 不模糊寻找近似色。 cyan/aqua 等别名可能得到同一个规范名称，不承诺恢复原输入。

颜色值参考 W3C 命名色表， 亮度参考 W3C sRGB 定义。

C 接口与所有权

include/color.h 的数值接口返回 bool/int64_t/double，八个文本接口接收 char *output 与 size_t capacity。 XCOLOR_HEX_SIZE=10，XCOLOR_NAME_SIZE=24，容量包含结尾 NUL。足够大的输出可与输入共用缓冲。

C 核心结果不用释放，各线程使用自己的缓冲；没有共享可变缓存，正常路径不分配。 NULL/零容量输出设置 XERR_ARGUMENT，容量不足设置 XERR_RANGE；非法颜色正常返回 false 和空串。 每次公开调用清除旧 XRT 错误。输入是借用的 NUL 结尾文本，不保留指针。

仅 color_native.h 的 *_text 桥返回需 xrtFree 的独立字符串，NULL 表示分配失败； xlang 已由 takeCstr 接管。普通 C 用户只链接 color_core.c 和所需 XRT，不需要语言编译器。

双语范例

发行目录运行 xl run examples/extlibs/color_basic.xl；C 对照为 extlibs/color/examples/basic.c。 范例覆盖 21 个 API，实现同一组转换与黑/白前景选择，按固定黄金输出核对。 在 demo6 根目录也可直接运行 xl run release/extlibs/color/examples/basic.c；该 C 范例只内嵌纯 C 核心。 开发仓库仍可用 tools/run_extlib_c.ps1 -Package color -Source release/extlibs/color/examples/basic.c。

AA/AAA 标签只表示普通文字的对比度阈值，不是整页可访问性认证。

验收范围

门禁检查 C 缓冲边界、输入输出重叠、非有限数、零分配核心、拥有结果的故障恢复， 四线程结果/错误隔离，独立数值和 148 个命名色参照，实际生成 C 原型、JIT/AOT、DLL 上下文及双语输出。

当前正式 xl.exe 的语言分配失败用例已通过。完整教学范例 AOT 仍等待共享文本快照符号修复； 源码驱动借用正式 DLL 的 TCC core，并非正式产品全量重建。此页不宣称全部发布形态已经准入。

xlang 字符串入口已拒绝内嵌 NUL，不把有效前缀误判为完整颜色。Linux 门禁现同次覆盖 C sanitizer/oracle、XLang 边界及分配故障、双语范例逐字节对照；32 位/ARM、TSan 和长期性能仍待验收。 Windows 当前可用 tools/check_extlib_color.ps1 -SkipAot 跑完非 AOT 检查；默认入口仍要求完整 AOT。 Linux 执行入口：tools/check_extlib_color.sh。
