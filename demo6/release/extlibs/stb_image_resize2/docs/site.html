扩展库 / stb_image_resize2

stb_image_resize2

用 Buffer 缩放 uint8 图片，支持 sRGB 与 linear 模式。

输入、输出各限 64 MiB；2 通道按灰度+alpha、4 通道按 RGBA 缩放。XLang 入口在传给 C 前拒绝尺寸及步长整数回绕。当前 Windows 默认门禁的核心与公开范例独立 EXE 均通过；Linux C ASan/UBSan、XLang JIT 与双语范例对照通过，Linux 独立 EXE 尚未验收。

API

函数用途
resizesRGB 颜色空间缩放；可指定输入行字节步长
resizeLinear线性空间缩放；参数与 resize 相同
available / version检查模块与查询所用 stb 版本

xlang

import stb_image
import stb_image_resize2
stb_image.StbImage image = stb_image.load("photo.png", 4)
Buffer small = stb_image_resize2.resize(image.pixels(),
    image.width(), image.height(), 4, 320, 240)

C

包含 include/stb_image_resize2_native.h。xstbir_resize 返回的 xbuffer* 由调用方以 xrtBufferDestroy 释放；输入像素仅借用。

Windows 可从 demo6 目录运行 powershell -NoProfile -ExecutionPolicy Bypass -File release/extlibs/stb_image_resize2/test/check.ps1，联合验证 C 边界、XLang 用例与双语范例的固定输出。灰度+alpha 的透明白/不透明黑缩放另核对固定像素值，C 与 XLang 均覆盖 sRGB 和 linear；Linux ASan/UBSan 门禁见包内 README。
