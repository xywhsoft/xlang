扩展库 / json5

json5

将 JSON5 配置文本解析为 xlang 动态值。

支持注释、尾随逗号、单引号、Unicode 标识符键名等 JSON5 语法；重复键拒绝。整份源文本须为有效 UTF-8，包括注释内容。输入上限 64 MiB，嵌套上限 64 层，容器项数上限 100 万。超限抛 RangeError，语法或编码错误抛 ValueError；valid 对两者均返回 false。

API

接口用途
json5.parse(text)返回保留原始类型的动态值
json5.valid(text)检查语法和包内数据约束；内存不足抛 MemoryError
json5.getValue(text, path)按简单点号路径取原始类型
json5.get(text, path)按简单点号路径取标量文本

十六进制字面量中的 e/E 是数字；如 0xdead、0xBEEF 在 int64 范围内保留整数类型，超出时才转为有限 float64。

范例

import json5
string source = "{host:'localhost', workers:4,}"
var config = json5.parse(source)
println(config["host"])
println(json5.valid(source))
println(json5.getValue(source, "workers"))
println(json5.get(source, "host"))

点号路径不适用于含点或解码后含 NUL 的键；此时先解析再用索引访问。路径查询先校验整份文档，尾部垃圾不会因提前命中而漏检；路径内嵌 NUL 会被拒绝。原始 NUL 源字节无效，字符串中的 \u0000 转义会按完整长度保留；getValue 可读取含 NUL 的值，get 不会返回截断文本。字符串中的 UTF-16 代理对合成为 UTF-8 字符，孤立代理项拒绝。显式 Infinity/NaN 可解析，有限数字字面量溢出 float64 时拒绝，不静默转换成无穷大。可选的官方 JSON5 2.2.3 对照已覆盖 474 个固定解析样本，其中 286 个还核对解析值，包含嵌套对象与数组；非有限数只核对解析结果，孤立代理项因 XRT 的 UTF-8 字符串合同另行测试。2026-10-25 当前 Windows 默认包门禁（含公开范例 AOT）及 Linux C ASan/UBSan、XLang JIT 双语门禁通过；Linux 独立 EXE 尚未验收。C/XLang 范例、资源限额、所有权和验证命令见包内 README。

examples/json5_c.c 同时包含包内解析器与原生桥，可直接用 xl run release/extlibs/json5/examples/json5_c.c 运行；Windows/Linux 包门禁将输出与严格 C 编译结果逐字比较。
