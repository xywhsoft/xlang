扩展库 / xml.etree

xml.etree

按元素组织的轻量 XML 读写。

适合读取配置与构建简单 XML；路径查询只支持直接子元素和 //name 后代匹配，并非完整 XPath。解析文本按显式字节长度直接传入，不创建整份输入的 Buffer 副本。

API

接口用途
xml.etree.create / parse / load创建元素或解析 XML
Element.child / append / set操作子元素和属性
Element.find / findAll执行受限的路径查询
Element.stringify(...) / save(...)序列化或原子保存元素树

范例

import xml.etree
auto root = xml.etree.parse("<catalog><book id='xlang'/></catalog>")
auto book = root.find("book")
assert book.get("id") == "xlang"

DTD 和外部实体被拒绝；C 解析接管 Reader 时，关闭失败按底层错误返回 MEMORY 或 IO，不返回未确认关闭的元素树。XLang 显式解析限额必须为正，C 的 XRT 限额配置以 0 表示不限制；写出缩进为 0..16。名称遵循 XML 1.0，创建非法名称会报错；写出拒绝非法字符、注释和处理指令。属性空白与文本回车往返保持原值；保存失败不会覆盖已有文件。树释放、后代查询和写出可处理调用方放宽限额后的深树，8192 层及分配故障已有 C 回归。C 调用方须释放 findAll 数组内已保留的元素引用，详见包内 README。共享 Linux 门禁通过 C ASan/UBSan、三包 XLang 边界及双语范例逐字对照；完整 AOT 仍受共享运行时缺符号阻断。
