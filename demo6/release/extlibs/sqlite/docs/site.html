扩展库 / sqlite

sqlite

数据库

内置 SQLite 的本地数据库，提供 Database、Statement、精确状态码及 C 接口。支持内存库、UTF-8 文件路径、事务与二进制数据，不依赖额外数据库 DLL。

参数绑定与查询

import sqlite

auto db = sqlite.memory()
assert db.execute("create table people(name text)")
auto insert = db.prepare("insert into people values(?)")
assert insert.bind(1, "O'Reilly") == sqlite.SQLITE_OK
assert insert.done()
insert.finalize()
var rows = db.query("select name from people")
println(rows[0]["name"])

参数从 1 开始，列号从 0 开始。绑定复制数据，不要求调用方保持原字符串或 Buffer 存活。

Database

接口合同
memory() / open(filename) / open_v2(filename, flags, vfs)独立内存库、读写创建文件、显式打开模式；空 vfs 使用 SQLite 默认值。
valid() / close() / close_v2()查询与释放连接。close 遇到未释放语句返回 SQLITE_BUSY 并保留连接；close_v2 延迟到语句释放后销毁。
execute(sql) / exec_code(sql) / last_error()成功布尔值、精确 SQLite 返回码、当前连接的 SQL 错误文本。
prepare(sql) / query(sql)拥有型语句、全部行字典数组。prepare 只接受一条语句；query 失败抛错，不返回部分成功。
begin() / commit() / rollback()事务操作，返回成功布尔值。
changes() / total_changes() / last_insert_rowid()64 位计数与行号；另有 last_insert_rowid_text()。
busy_timeout(milliseconds)设置锁等待上限；0 表示不等待，不自动重试整个事务。

Statement

接口合同
bind(index, int|float|string|Buffer) / bind_null(index)保留 64 位整数；Buffer 是 BLOB，NULL 与空值分开。
bind_text_bytes(index, Buffer) / bind_blob_text(index, string)精确长度 TEXT、把普通文本字节写为 BLOB。
step() / row_ready() / done()每次推进一次。step 返回状态码；两个布尔便利方法在错误时抛出 RuntimeError。
column_count() / column_name(column)元数据，可在 step 前读取。
column_type/int/float/text/blob/text_bytes/blob_text(column)读取当前行；必须先得到 SQLITE_ROW，列越界或没有当前行会报错。
value(column) / row()动态值、列名字典。BLOB 是 Buffer，SQL NULL 是 null；重复列名请用 SQL AS 区分。
reset() / clear_bindings() / last_error()重执行时保留绑定、清空绑定、当前语句所属连接的 SQL 诊断。
valid() / finalize()重复释放是成功空操作；释放后的其他对象操作报 RuntimeError。

二进制与寿命

auto stmt = db.prepare("select x'00ff2a'")
assert stmt.row_ready()
Buffer bytes = stmt.column_blob(0)
stmt.finalize()
// bytes 拥有副本，语句释放后仍可访问。
assert bytes.len() == 3 and bytes[0] == 0

含 NUL 的 TEXT 使用 bind_text_bytes/column_text_bytes；普通字符串读取会拒绝截断。 SQL NULL 与零长度 BLOB 不同，使用 column_type 或 value 区分。大结果集用 Statement 逐行读取，query 会物化全部行。

对象赋值共享身份，不复制句柄，不声明 copy/clone 能力。Database(point) 和 Statement(point) 接管原始句柄， 不增加引用；不得重复接管或从 C 再次释放。同一对象的多步操作由调用方串行化，不支持一边读列一边并发关闭/step/reset。

C 使用

公开桥接头是 include/sqlite_native.h，上游完整 C 头是 third_party/sqlite3.h。 句柄必须来自同一份 SQLite。借用文本副本保存至 XRT 临时区 clear/rewind；返回的 xbuffer 由 C 调用方 xrtBufferDestroy。

成对范例：examples/extlibs/sqlite_basic.xl 与 extlibs/sqlite/examples/basic.c，C 范例可直接 xl run 或 xl build。底层状态码入口保留 SQLite 返回码，高层 query 不吞掉 SQL 错误。
