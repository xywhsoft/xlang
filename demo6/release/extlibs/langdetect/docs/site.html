扩展库 / langdetect

langdetect

轻量语言判断。

严格 UTF-8、主导脚本识别与有限拉丁语种词表评分；已识别脚本须严格过半，平票返回 unknown。未收录的文字不参与统计。

API

接口用途
detect / code / script语言名、代码及脚本
confidence未校准的启发式分数
isChinese / isEnglish / isJapanese / isKorean与 detect 的结果比较，不增加独立识别规则
isValidUtf8 / lastError编码检查返回布尔值并清除旧错误；lastError 仅报告最近一次原生错误

范例

import langdetect
println(langdetect.detect("the garden is nice and the sky is blue"))
println(langdetect.script("Привет"))  // Cyrillic

不是通用统计语言模型；阿拉伯文标点、数字、组合附标以及覆盖区间的未分配码位不当作字母证据。汉字统计覆盖 Unicode 17 已分配的扩展 A-J 和兼容汉字补充区，包含补充平面，但仍不能仅凭汉字断定真实语种。语种范围、1 MiB 上限和 C 接口见包内 README。C 与 XLang 对照范例的输出一致。

C 接口的 confidence 返回 int64_t，与 XLang int 保持跨平台 ABI 一致；C 范例用 PRId64 可移植打印。Linux 包门禁覆盖 C ASan/UBSan、XLang 内嵌 NUL、输入上限和报错后恢复，并逐字对照双语范例。当前两平台的核心、边界和双语范例独立 EXE 均通过。

从 demo6 目录可直接运行 xl run release/extlibs/langdetect/examples/langdetect.c。Windows 默认 test/check.ps1 与 Linux test/check.sh 验证 C/XLang 边界、双语范例和 AOT；-SkipAot 只是 Windows 聚焦快测。旧共享缺符号仅属历史发布物；本包仍只是有限词表/脚本启发式，不是概率语言识别器。
