扩展库 / pinyin

pinyin

常用汉字的轻量拼音转写。

约 395 个单字固定读音；未收录字符原样保留。不分词、不处理多音字上下文或声调，不适合要求准确读音的全文处理。

API

接口用途
convert(text)将已收录汉字转为带空格的拼音
initials(text)将已收录汉字转为首字母，不额外插入空格

范例

import pinyin
println(pinyin.convert("中国"))   // zhong guo
println(pinyin.initials("中国"))  // zg

输入须为合法 UTF-8，不能包含 NUL。C 函数返回的独立字符串用 xrtFree 释放。Windows 可运行 release/extlibs/pinyin/test/check.ps1 -SkipAot：C/XLang 边界和三条范例路径分别对照固定中文输出；默认模式还验证核心与带输出范例 AOT。当前核心通过，范例仍缺共享 xl6ValueDataSnapshotV1，不能签收完整发布。Linux ASan/UBSan 由包内 test/check.sh 验证；本包只提供固定小字表。
