扩展库 / shellwords

shellwords

拆分命令行词法文本，或将参数编码为可安全传递的单个 shell 词。

版本 1.0.0 · C / xlang · 无扩展库依赖

快速开始

import shellwords

var words = shellwords.split("tool 'two words' --flag")
assert words[1] == "two words"
assert shellwords.split(shellwords.join(words))[1] == "two words"
assert shellwords.quote("A=B") == "'A=B'"
println(shellwords.quoteWindows("a b\\"))

本库只处理参数词法，不执行命令，也不做变量、通配符或命令替换。

接口

入口用途
split(text)按空白、引号和反斜杠拆分，保留空参数；不完整引号或转义报错。
quote(word)按 POSIX shell 的单参数规则引用；赋值词、保留词及尾随冒号的词也整体加引号，避免在命令位置被当作语法。
join(words)逐项引用字符串数组并用空格连接。
quoteWindows(word)按 MSVCRT 的 argv 引号与反斜杠规则编码单个参数。

quoteWindows 不负责 cmd.exe 的 &、|、% 等元字符，也不是 PowerShell 转义。POSIX C 入口保留非 NUL 的原始参数字节；Windows 入口只处理 CRT 引号，使用 CreateProcessW 时需由调用方转换有效 UTF-8 到 UTF-16。C 端包含 extlibs/shellwords/include/xrt_shellwords.h；拆分结果由调用方用 xrtValueRelease 释放，引用后的字符串用 xrtFree 释放。

验证与边界

xl run release/extlibs/shellwords/examples/basic.c
powershell -NoProfile -ExecutionPolicy Bypass -File release/extlibs/shellwords/test/check.ps1 -SkipAot
bash release/extlibs/shellwords/test/check.sh

C 教学范例可直接用 xl 单文件运行；Windows/Linux 包门禁核对直跑与严格 C 编译输出一致。Windows 严格 GCC、XLang 边界与双语同输出已通过；Linux 同次覆盖 C ASan/UBSan、中央与包内 XLang 边界，并将 C/XLang 范例逐字节对照共同的 golden 文件。C 测试逐字节验证 ASCII 1–127 的 split(quote(word)) 往返，并固定赋值词 A=B、A+=B、命令位置保留词和尾随冒号的词须整体引用；真实 /bin/sh 另核对参数字节及命令位置语法。测试逐点注入分配失败，验证拆分、拼接和两种引用入口的内存错误与恢复；Windows 子进程通过 CreateProcessW 与宽字符 wmain 核对 quoteWindows 的空参数、空格、引号、反斜杠、中文和非 BMP 字符在实际 argv 中往返。此验证不覆盖 cmd.exe 或 PowerShell 转义。C/XLang 另覆盖空参数、中文与引号混合及 UTF-8 组合字符往返。XLang 的单字符串入口遇内嵌 NUL 会拒绝，不会静默截断。完整 AOT 因主线缺少 xl6ValueIndexReadCopyV1 尚未签收。
