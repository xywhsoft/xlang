扩展库 / ansi

ansi

ANSI 样式、颜色和光标序列的纯文本构件。

使用 XRT 分配独立结果，不会写终端，也不会截断长文本。C/XL 包级测试与 Linux sanitizer 已通过；XL AOT 当前受共享缺符号阻断。

API

函数用途
bold / dim / italic / underline / blink / inverse / hidden / strike文本样式
fg / bg / fg256 / bg256 / fgTrue / bgTrue16 色、256 色和 RGB 颜色
up / down / left / right / nextLine / prevLine / column光标移动
clearScreen / clearLine / clearToEnd / hideCursor / showCursor终端控制序列
title / strip / displayWidth安全标题、CSI/OSC 剥离与单行列宽估算

xlang

import ansi
string styled = ansi.fg("中文", 32)
println(ansi.strip(styled))
println(ansi.displayWidth(styled))

displayWidth 将常见零宽字符计为零列，但只是终端列宽估算，不承诺 ZWJ 复合 emoji 等所有 Unicode 字素簇精确；文本入口拒绝内嵌 NUL，标题和 OSC 载荷拒绝双向控制符，畸形 ANSI/UTF-8、OSC 载荷中的 DEL/C1 控制字符和非法颜色参数报错。2026-10-20：Windows 默认门禁新增完整带输出范例 AOT 与 C 输出对照，当前构建因共享 xl6ValueDataSnapshotV1 缺符号失败；-SkipAot 的 C/JIT 快测通过，不代表发布签收。完整合同、C 所有权及验证命令见包内 README。
