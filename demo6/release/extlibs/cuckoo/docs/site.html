扩展库 / cuckoo

cuckoo

近似成员查询。

16 位指纹、固定容量、可删除且失败插入不会损坏原有数据。查询可能假阳性；仅删除已知插入的键，避免指纹碰撞误删其他项。

API

接口用途
cuckoo.create(capacity)创建容量受控的过滤器
add / contains / remove插入、近似查询与删除
count / buckets / clear状态与复用

范例

import cuckoo
cuckoo.CuckooFilter seen = cuckoo.create(10000)
seen.add("session:abc123")
println(seen.contains("session:abc123"))

过滤器可能误报存在，不应作为精确集合或权限检查；边界与 C 接口见包内 README。

C 构造容量使用 int64_t，对应 XLang int。C 侧有效键未命中返回 false 且无 XRT 错误；空句柄的计数和清空则显式报告参数错误。Windows C/XLang、核心 AOT 与 Linux ASan/UBSan 边界已通过；带输出 AOT 仍缺共享符号 xl6ValueDataSnapshotV1。

C 范例可直接运行 xl run release/extlibs/cuckoo/examples/cuckoo.c，也可独立用 GCC 构建；两种入口与 XLang 范例的输出已在 Windows/Linux 包级测试中对照。
