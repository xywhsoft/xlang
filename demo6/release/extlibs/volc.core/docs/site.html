扩展库 / volc.core

volc.core

火山引擎签名与请求的共享基础包。

离线哈希、规范化查询和签名预览可由 C 调用。当前 XLang 导入链停在独立维护的 xhttp.client，发布版脚本运行还受 ownership catalog 初始化故障阻断；真实云请求、并发和资源复用尚未验收。本页不代表生产可用。

API

入口用途
sha256_hex / hmac_sha256_hex离线摘要与 HMAC
canonical_query / json_string签名输入编码
sign_preview / sign_preview_acep / sign_preview_sts离线签名预览，不发请求
request / request_acep / request_sts经 xhttp.client 发送在线请求，尚未完成验收

示例

import volc.core
string query = volc.core.canonical_query("ListApps", "2020-01-01", "Limit=10\nName=x lang")

C 声明在 include/volc_core_native.h，离线范例在 examples/signing.c。显式日期须为有效的 YYYYMMDDTHHMMSSZ；省略时由 XRT 生成当前 UTC。*_spec 拒绝重复、未知、空白及无等号的声明行；逐行格式不能承载含换行的请求体，应改用定型请求函数。时长/超时值只有省略或留空才使用默认值，显式值必须是完整且位于 C int 范围的十进制整数；错误值在发请求前拒绝。路径须是未编码、以 / 开头的绝对路径，签名与 URL 共用编码结果。直接进入规范请求或授权头的签名字段拒绝 CR/LF、TAB 等控制字符；定型请求的请求体可包含换行。C 返回字符串由包持有，跨线程或长期保存前应复制；离线返回槽和诊断已按线程隔离，在线并发仍未验收。详细范围和复现命令见包内 README。
