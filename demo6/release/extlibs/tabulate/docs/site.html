扩展库 / tabulate

tabulate

用单元格数组生成纯文本终端表格。

支持空单元格、逗号文本和常见中文列宽；单元格限定为单行文本，拒绝 U+2028/U+2029 行与段落分隔符、常见零宽及双向控制符，写入失败自动回滚。完整 AOT 发布验收仍受共享链接问题阻断。

API

成员用途
create()创建表对象；分配失败时抛错
setHeaders(array<string>)替换或清除表头
addRow(array<string>)追加数据行
render / rowCount / colCount生成文本及读取表规模

xlang

import tabulate
tabulate.Table table = tabulate.create()
table.setHeaders(["Name", "City"])
table.addRow(["Alice", "北京, 中国"])
println(table.render())

这不是 CSV 解析器，也不承诺复杂 emoji 字素簇的精确终端宽度。C 行列计数使用与 XLang int 一致的 int64_t。Windows/Linux 门禁验证 C 边界、XLang 分配故障、私有原生入口编译负例与双语范例固定输出；Linux 另有 C sanitizer。Windows 默认门禁还要求公开范例 AOT 构建运行并与固定输出一致，当前在共享缺符号处失败；-SkipAot 只验证 C/JIT。C 接口和资源上限见包内 README。
