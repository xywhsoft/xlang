扩展库 / slugify

slugify

把标题变成可读的 URL 路径段。

ASCII 小写、有限拉丁转写、汉字/假名/韩文保留；严格验证 UTF-8 和输入长度。完整 AOT 发布验收仍受共享链接问题阻断。

API

函数用途
slugify(text)生成可读 slug
isAscii(text)判断原文是否仅含 ASCII 字节

xlang

import slugify
println(slugify.slugify("Café & 你好"))  // cafe-and-你好

& 和 @ 作为独立词转换，例如 a&b 得到 a-and-b。这不是完整 Unicode 转写，也不是 URL 编码或路径安全验证；不同标题可能产生同一 slug。范围、C 所有权和测试证据见包内 README。
