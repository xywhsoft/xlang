扩展库 / rss

rss

RSS 2.0 与 Atom 订阅源。

解析、识别与生成常用 feed 字段。底层复用 Expat/XML DOM，不接受 DTD 或外部实体。

API

函数用途
detect / parse识别并解析 RSS 2.0 或 Atom
parseRSS / parseAtom限定格式解析
buildRSS / buildAtom由对象和条目数组生成 XML

范例

import rss
var meta = {"title": "News", "link": "https://example.test", "description": "Updates"}
string xml = rss.buildRSS(meta, [{"title": "First", "guid": "1"}])
var feed = rss.parse(xml)
println(feed["items"][0]["title"])

detect 对无效格式或超限输入返回空字符串，内存不足则报错；C 调用方可检查 XRT 错误。解析输入恰好 8 MiB 可读取，超一字节时 C 报 XERR_RANGE、XLang 抛 RangeError。RSS 根节点必须写 version="2.0"，缺失或旧版本不作为 RSS 2.0 解析。生成 RSS 时 channel 需有 title/link/description；生成 Atom 时 feed 需有 id/title/updated，entry 需有 id/title/updated、作者与 content 或 link，作者可继承 feed。解析后 entry.author 是有效作者，优先级为 entry、entry.source、feed；扁平结果不保留作者来源。解析器仍宽容读取字段不完整的文档。生成器校验 XML 1.0 字符范围，拒绝 U+FFFE/U+FFFF；元素文本的 CR 和 Atom link 属性的 Tab/LF/CR 使用字符引用，回读不会因 XML 空白规范化变值；本包不校验链接 IRI。XML 正文恰好 16 MiB 可输出，超一字节时 C 接口报告 XERR_RANGE，不会截断；末尾 NUL 不计入正文限额。Atom 作者继承有独立的 examples/atom_author.xl 与 examples/atom_author_c.c，分别执行 XLang 和 C 后再对照输出。Windows 包内 test/check.ps1 默认覆盖严格 C、C/XLang 边界、双语对照、核心 AOT 及带输出范例 AOT；当前完整门禁在共享 xl6ValueDataSnapshotV1 缺符号处失败，-SkipAot 仅供聚焦开发。Linux test/check.sh 同次覆盖 C ASan/UBSan、XLang 用例及双语对照。输入限制、支持字段、C 结果所有权及完整范例见包内 README。

Atom 的 link 未设置 rel 时按 alternate 处理；feed 和 entry 都优先选择第一个 alternate 链接，没有时才回退到第一个 href。依据 RFC 4287。
