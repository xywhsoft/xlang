扩展库 / totp

totp

基于 HMAC-SHA1 的一次性验证码。

支持 Base32 密钥、HOTP/TOTP、可配置位数和有界时钟窗口；目前发布验收仍受共享 AOT 链接问题阻断。

API

函数用途
hotp(secret, counter, digits = 6)按计数器生成验证码
generate / generateAt按当前时间或指定 Unix 秒数生成
verify / verifyAt按窗口验证，返回布尔值

xlang

import totp
string secret = "GEZDGNBVGY3TQOJQGEZDGNBVGY3TQOJQ"
string code = totp.generateAt(secret, 59, 30, 8)
assert code == "94287082"
assert totp.verifyAt(secret, code, 59, 30, 8, 0)

限流、重放防护和密钥存储由应用负责。合法输入的输出分配失败报内存错误，失败后可重试。实时 C 入口先验证步长、位数和窗口，再读系统时钟；非法参数不会被时钟故障遮蔽。系统时钟故障不会被解释成有效的零时间戳。Windows 默认 test/check.ps1 验证 C/XL 边界、线程、固定 RFC 输出及核心/完整范例 AOT；-SkipAot 只运行 C/JIT 快测。当前核心 AOT 通过，完整范例构建受共享 xl6ValueDataSnapshotV1 缺符号阻断；Linux test/check.sh 另覆盖时钟故障注入与 C ASan/UBSan。完整参数约束与 C 接口见包内 README。
