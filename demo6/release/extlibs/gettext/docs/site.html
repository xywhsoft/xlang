扩展库 / gettext

gettext

读取 GNU PO/MO 翻译目录，按消息 ID、上下文与复数规则查找译文。

版本 1.0.0 · C / xlang · 无扩展库依赖

快速开始

import gettext

var catalog = gettext.parsePo("msgid \"hello\"\nmsgstr \"你好\"\n")
println(gettext.t(catalog, "hello"))
println(gettext.t(catalog, "missing"))

输出“你好”和原文“missing”。目录是独立数据对象，可同时保留多个语种。

接口与边界

入口用途
parsePo(text) / parseMo(bytes) / loadMo(path)解析 PO 文本或大小端 MO 二进制目录。
t(catalog, msgid) / tc(catalog, context, msgid)查询单数译文；未命中回退原文。
tn(catalog, id, plural, n) / tnc(catalog, context, id, plural, n)按 Plural-Forms 和上下文查询复数译文。

复数公式在导入时做语法检查和常见计数抽样，不保证任意计数都不会触发除零。实际查询遇到公式错误时抛 ValueError；未选中的条件分支不会执行，其他计数仍可继续查询。

支持 PO 多行文本、转义、上下文及顺序编号的复数项；无 Plural-Forms 时采用英语 n != 1 规则，n 必须非负。PO 的 fuzzy 普通译文不进入目录，空译文回退原文；空 msgid 的目录头仍保留。MO 空译文也回退原文。实际进入目录的重复译文键报格式错误，不再静默覆盖；被跳过的 fuzzy 或空单数译文不占键，不同上下文的同名消息仍可共存。PO 源文本与 MO 原文、译文仅接受 UTF-8；不会按目录头的 charset 自动转码，其他编码须先转为 UTF-8。MO 描述符长度之外的原文、译文结束 NUL 都会校验，缺失时拒绝目录；单数译文内部 NUL 也会拒绝，复数译文仍允许格式规定的 NUL 分隔符。原文只承载单数和复数两段，出现额外 NUL 段时报错，不会静默丢弃。PO 文本、路径及查询键不允许内嵌 NUL；MO 字节数据本身允许 NUL，因为它是二进制格式的一部分。上下文键分隔符 0x04 不能进入 PO 消息键或查询参数；MO 原文最多允许一个上下文分隔符。parsePo、parseMo 和 loadMo 均最多接受 64 MiB 输入；C 超限返回 XERR_RANGE，XLang 抛 RangeError。缺文件或读取失败保留 XRT 文件错误，坏 MO 为 XERR_VALUE。

C 的 parsePo 入口在 64 MiB 上限外一字节停止扫描，超限输入不再先执行无界 strlen；Linux ASan 已覆盖该边界。调用方仍须提供在终止字节或限额边界之前可读取的内存。

PO 的 C 风格转义包含 \x 十六进制字节、最多三位八进制字节及 \?；数字转义必须在 1–255 范围内，空十六进制、NUL 和超范围值会报格式错误，解码后的文本仍须是有效 UTF-8。按 GNU PO 字符串规则，不接受 \u / \U。

C 对照

#define XRT_MODULE_VALUE_CONTAINER
#define XRT_MODULE_UNICODE
#include "xrt.h"
#include "gettext_native.h"

int main(void)
{
    xvalue* catalog = xgt_parse_po("msgid \"hi\"\nmsgstr \"hello\"\n");
    char* text = xgt_t(catalog, "hi");
    int ok = text && text[0] == 'h';
    xrtFree(text);
    xrtValueRelease(catalog);
    return ok ? 0 : 1;
}

C 查询字符串用 xrtFree 释放，解析目录用 xrtValueRelease。完整双语对照范例位于 release/extlibs/gettext/examples/；从 demo6 根目录可直接运行 release/xl.exe run release/extlibs/gettext/examples/gettext_c.c。正式包仍分别编译目录与复数表达式源码。

解析或查询失败后可直接重试；后续成功调用会清除本线程旧的 XRT 错误。有效上下文的查找键分配失败返回 NULL 和内存错误，不会回退为原文。C 的 xgt_load_mo 使用 XRT 限额读取，保留文件读取的原始错误类别。
