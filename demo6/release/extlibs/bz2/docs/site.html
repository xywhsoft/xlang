快速使用

import bz2

Buffer packed = bz2.compress("你好，bz2", level = 6)
assert bz2.decompressText(packed, smallMemory = true) == "你好，bz2"

auto encoder = bz2.compressor()
encoder.update("left")
Buffer wire = encoder.drain()
encoder.update("right")
encoder.finish()
wire.append(encoder.drain())

接口

接口用途与默认值
compress(Buffer|string, level=9, maxInput=268435456, maxOutput=536870912)输出 Buffer；字符串长度使用 UTF-8 字节数。
decompress / decompressTextsmallMemory=false，maxInput=268435456，maxOutput=536870912，maxRatio=1000。
compressor / decompressor增量对象；压缩 workFactor=30，合法范围 0..250。
update / drain / finishfinish 返回 bool，不移交输出；完成后仍需 drain，drain 不重置计数。
valid / inputBytes / outputBytes / finished只读属性；解压器额外提供 members，finished 表示当前成员边界。
compressFile / decompressFilesource、destination、overwrite=true、限额及可选同步进度回调；含 NUL 路径报 ValueError。

文件回调

bz2.compressFile("input.bin", "output.bz2",
    onProgress = func(int inputBytes, int totalBytes, int outputBytes) as bool
        println(inputBytes, "/", totalBytes)
        return true
    end)

返回 false 抛 CancelledError；回调异常保留类型和消息，最终通知也可取消。常规失败不覆盖已有目标；不覆盖模式在预检后出现目标时仍拒绝最终替换。支持源目标同路径；当前发布物的文件 OOM 专项证据与其他边界见页首。

格式、限额和错误

支持空内容、低内存解码、串联成员；拒绝 CRC 损坏、截断和尾部垃圾。非法压缩数据及文件错误为 IOError，参数错误为 ValueError，限额为 RangeError，状态错误为 RuntimeError，分配失败为 MemoryError。

同一对象串行使用。已 drain 的数据无法撤回；倍率按已提交输入计算，需同时设置 maxOutput。限额不是 CPU 超时或编解码器工作内存限制。CRC 不是加密认证。

C 同等能力

xrt_bz2.h 提供版本化 options/error、一次性 Buffer、增量对象、Reader/Writer、文件事务及 xrtprogressproc。C 可直接使用，不依赖 xlang；只链接一份 XRT/xruntime 与 bzip2。C 只使用输入、输出和解压倍率限额；OptionsInit 清零无关的单项、条目、节点、深度字段，显式设置这些字段或 iFlags 会报参数错误。有效限额为零时关闭对应限制，XL 便捷接口要求正数。
