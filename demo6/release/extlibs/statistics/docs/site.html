扩展库 / statistics

statistics

对数值数组计算描述性统计、分位数和双变量关系。

版本 1.0.0 · C / xlang · 无扩展库依赖

快速开始

import statistics

var values = [2, 4, 4, 4, 5, 5, 7, 9]
println(statistics.mean(values))
println(statistics.median(values))
println(statistics.stdev(values))

上述结果分别为 5、4.5、2。除 count 外，输入必须是非空的有限数值数组；count 只统计有限数值，忽略非数值与 NaN/无穷大。

接口与边界

入口用途
count / sum / mean / median / mode / min / max / range计数和单变量汇总；并列众数取最小值。
variance / stdev / varianceSample / stdevSample总体和样本方差/标准差。
percentile(values, p) / quartiles / iqr / mad线性插值分位数、四分位距和平均绝对偏差；p 为 0–100。
geomean / harmmean几何与调和平均数；前者要求正值，后者要求非零。
covariance / covarianceSample / correlation / linearFit同长度数组的协方差、Pearson 相关系数和最小二乘拟合。
histogram(values, bins)1–100000 个等宽分箱的计数数组。

样本计算至少需要两个元素；常量输入不能计算相关系数或斜率。无效元素、非有限输入与无法表示为有限 float64 的结果会报错。求和、均值及分位数在安全区间保留次正规数，不因逐项缩放提前下溢；极值求和与均值共用缩放补偿累加，并单独保留缩放后可能下溢的小项。C/XLang 测试覆盖 [DBL_MAX, 1, -DBL_MAX] 及极值抵消后均值中的次正规残差，但不承诺任意输入的正确舍入。极值均值在恢复尺度前除以样本数，并把舍入结果限制在输入范围内；三个最大有限值的均值仍为最大有限值。方差和平均绝对偏差先缩放偏差再聚合；标准差独立计算，即使方差不可表示，只要标准差可表示，仍返回有限结果。调和平均数缩放倒数项，避免极小非零输入的中间溢出；倒数和为零仍报错。count 对非数组输入返回 0。

调和平均数的缩放倒数使用补偿求和；[1e-16, 1, -1e-16] 的有限结果不会因大项抵消而误报未定义。倒数和确实为零仍报错。

C 对照

#define XRT_MODULE_VALUE_CONTAINER
#include "xrt.h"
#include "statistics_native.h"

int main(void)
{
    xvalue* values = xrtValueArray();
    xrtValueArrayAppendNew(values, xrtValueFloat(2.0));
    xrtValueArrayAppendNew(values, xrtValueFloat(4.0));
    xvalue* average = xstat_mean(values);
    double number = 0;
    int ok = average && xrtValueGetFloat(average, &number) && number == 3.0;
    xrtValueRelease(average);
    xrtValueRelease(values);
    return ok ? 0 : 1;
}

C 结果由调用方 xrtValueRelease；失败返回 XRT null 值并设置错误。参数/定义域错误为 XERR_VALUE，分配失败为 XERR_MEMORY，XLang 分别抛出 ValueError 与 MemoryError。min/max/range 逐项校验并扫描极值，不复制整份输入数组；除结果外只用常量额外内存。完整双语对照范例位于 release/extlibs/statistics/examples/。

失败后可直接重试；后续成功的单数组、双数组或 count 调用会清除本线程旧的 XRT 错误。
