# 运行时与高级规则总览

本文是高级运行时能力的总览索引，不新增 `CGEN-*` 规则编号；对应的唯一规则编号分别落在 `09` 到 `23` 号细则文档中。

## 高级总览-001 按需运行时注入

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | 任意会触发 helper 的写法，例如 `var`、`async`、`crypto.hash(...)` |
| 生成规则描述 | 生成 C 文件前扫描 AST，判断是否需要注入 string、time、xvalue、async、function、http server、标准库封装等运行时。未使用的 helper 不生成，控制 C 文件体积。 |
| 生成器文件名和行号 | `xl6_cgen_module.c:41-69`，基础 needs `xl6_cgen_needs_basic.c:236-533`，上下文 needs `xl6_cgen_needs.c:16`、`203`、`422` |
| 对应生成的 C 代码 | `static ... xl6_helper(...) { ... }` 按需插入在用户代码前 |
| 中间形态伪代码 | `needs = scan(root); for each needs emit runtime block` |
| 实现同等功能手写的 C 代码 | 手写 C 通常只写用到的辅助函数；编译器自动完成这一步。 |
| 额外依赖的封装代码 | 所有 `xl6_*` helper 均属于这里的输出。 |
