# cgen 文件覆盖索引

本文件按 `demo6/src/cgen` 分片列出职责，帮助判断某条生成规则应该在哪个文件中查找。详细规则见 `01` 到 `09` 文档；全部 `xl6Cgen*` 函数入口见 `_function_index.generated.md`。

## 总入口

| 文件 | 规则性质 | 覆盖说明 |
| --- | --- | --- |
| `xl6_cgen.c` | 合并入口 | 按固定顺序 include cgen 分片，保持 static 边界仍在单翻译单元内工作；本身不直接生成语言规则。 |
| `xl6_cgen_module.c` | 直接生成 | `xl6CgenEmitC` 完整 C 文件生成流程：预扫描、运行时注入、声明顺序、函数体输出、main/top-level 包装、模块输出。 |
| `xl6_cgen_header.c` | 直接生成 | 生成导出头文件，覆盖 export 函数、变量、class、union、类型别名依赖。 |
| `xl6_cgen_entry.c` | 入口包装 | 对外 cgen API、文件读写和生命周期入口，不直接承载语言规则。 |
| `xl6_cgen_lifecycle.c` | 直接生成 | 生成 `xlInit/xlUnit` 生命周期声明与运行时代码。 |

## 名称、类型与状态

| 文件 | 规则性质 | 覆盖说明 |
| --- | --- | --- |
| `xl6_cgen_core_context.c` | 辅助 | 定义 cgen 上下文、cleanup、loop target、generic instance 等状态结构。 |
| `xl6_cgen_core_names.c` | 辅助/命名规则 | C 标识符编码、类型名编码、符号名拼接，影响所有生成结果的符号形态。 |
| `xl6_cgen_core_state.c` | 辅助 | 变量类型表、cleanup 栈、作用域关闭规则。 |
| `xl6_cgen_core_lookup.c` | 辅助 | class/custom/union/extern/type alias 查找，泛型替换入口。 |
| `xl6_cgen_core_types.c` | 辅助/类型映射 | xlang 类型到 C 类型的基础映射，决定 `int/string/array/point/custom/class` 等默认 C 类型。 |
| `xl6_cgen_core_generics.c` | 辅助 | 记录函数/类泛型实例，避免重复生成。 |
| `xl6_cgen_core_runtime_state.c` | 辅助/运行时状态 | 记录 runtime type desc、匿名函数、typed container storage 等状态。 |
| `xl6_cgen_type_infer.c` | 辅助/类型推断 | 表达式类型推断，是 call/for/member/index/function 等规则选择的前置条件。 |
| `xl6_cgen_type_generic.c` | 辅助/规则选择 | 泛型函数推断、字符串/type 比较、runtime type desc 收集。 |

## 表达式与语句

| 文件 | 规则性质 | 覆盖说明 |
| --- | --- | --- |
| `xl6_cgen_expr.c` | 直接生成 | `xl6CgenExpr` 的 AST 分派：名称、字面量、成员、索引、运算、调用、条件表达式等。细则见 `02`、`09`。 |
| `xl6_cgen_args.c` | 直接生成 | 字符串、容器字面量、var 打包、动态运算、可选/可变/命名参数输出。细则见 `06`。 |
| `xl6_cgen_value_object.c` | 直接生成 | typed container、class/custom/union 成员访问、方法调用、隐性 `toString`。 |
| `xl6_cgen_value_assign.c` | 直接生成 | 赋值、复合赋值、索引赋值、动态成员赋值、时间字面量。细则见 `07`。 |
| `xl6_cgen_stmt_dispatch.c` | 直接生成 | 语句 AST 分派、return、for in 总分派、break/continue 入口。细则见 `03`、`08`。 |
| `xl6_cgen_stmt_decl.c` | 直接生成 | 变量声明、多返回值声明/赋值、typed container 声明和资源管理。 |
| `xl6_cgen_stmt_loop.c` | 直接生成 | if/while/do/for/range、动态容器/typed container/generator 迭代、break/continue cleanup。细则见 `08`。 |
| `xl6_cgen_stmt_error.c` | 直接生成 | throw/assert/try/catch/finally/异常传播默认返回。 |

## 声明、类型和值对象

| 文件 | 规则性质 | 覆盖说明 |
| --- | --- | --- |
| `xl6_cgen_symbol.c` | 直接影响生成 | 函数重载、泛型后缀、多返回结构体名、函数值符号名。 |
| `xl6_cgen_decl_proto.c` | 直接生成 | 普通/extern/export 函数原型、class 方法原型、record/custom box runtime。 |
| `xl6_cgen_decl_union.c` | 直接生成 | union 声明、嵌套依赖、inline union 字段声明。 |
| `xl6_cgen_decl_class.c` | 直接生成 | class/custom 结构体、泛型 class 实例、custom extern/helper 原型。 |
| `xl6_cgen_decl_methods.c` | 直接生成 | class/custom 方法体、create/destroy、继承初始化、自动析构。 |
| `xl6_cgen_func.c` | 直接生成 | 普通函数、export 内部函数、export C ABI wrapper。 |
| `xl6_cgen_main.c` | 直接生成 | xlang main 包装、argv 到 xvalue array、top-level main。 |
| `xl6_cgen_abi.c` | 直接生成 | function 签名 ID、多返回签名结构、runtime type desc、`type(expr)`。细则见 `09`，后续仍需更细 ABI 专文。 |
