# 规则测试范例交叉索引

本文不新增 `CGEN-*` 规则，只用于把已整理的规则文档与当前 `demo6/test/cases`、`demo6/release/examples/feature_suite`、`demo6/release/examples/tutorial` 进行交叉核验。当前规则总数仍以 README 中的 843 条为准。

## 测试入口

| 入口 | 覆盖说明 |
|---|---|
| `demo6/test.bat` | 主回归入口，先构建，再运行标准库覆盖检查、feature suite、核心 CLI/cgen/import/export/sem/cgen 用例；大量用例会 `findstr` 检查生成 C/IR/ABI 元数据 关键片段。 |
| `demo6/test_all.bat` | 运行 `test.bat` 与 tutorial 回归。 |
| `demo6/test_dll.bat` | 构建 xl.dll，运行 `xl_dll_embed_string.exe`，再运行由 DLL API 编译出的脚本 exe。 |
| `demo6/release/examples/feature_suite/run_feature_suite.bat` | 按主题运行 demo6 功能套件，并验证 C ABI 导出。 |
| `demo6/test_tutorial.bat` | 运行 tutorial 示例，并验证导出到 C 的示例。 |

## 覆盖强度分级

| 分级 | 含义 | 当前区域 |
|---|---|---|
| 强覆盖 | 有 `.xl` 行为测试，同时检查生成 C/IR/ABI 元数据 片段或 C 宿主运行结果。 | import/package/export/header/class/custom/union/typed container/CLI build。 |
| 中覆盖 | 有运行型 `.xl` 或 feature suite 示例，但没有逐条检查生成文本。 | 多数表达式、控制流、标准库、并发运行示例。 |
| 间接覆盖 | 规则是内部状态或 helper，主要通过上层行为体现。 | cleanup 栈内部顺序、context 状态表、部分 type infer helper、字符串/路径小工具。 |
| 待机器化 | 人工矩阵已经覆盖到规则簇；若要进一步自动巡检，需要把每条 `CGEN-*` 规则映射到固定测试 ID。 | `CGEN-*` 规则到用例的机器可读映射。 |

## 后续工程增强

当前规则文档已经完成主干、P0、P1、P2 的人工交叉索引。后续若继续提升工程成熟度，建议优先做三件事：

1. 为每个 `CGEN-*` 规则增加可选 `验证用例` 字段，建立规则到 test/example 的机器可读一对一索引。
2. 把 `test.bat` 中的 `findstr`/PowerShell 断言逐步抽成更小的测试描述文件，降低脚本膨胀风险。
3. 对仍为间接覆盖的内部状态区域补少量“生成文本快照”用例，例如资源 cleanup 顺序、runtime needs 精确注入、function retain/release。
