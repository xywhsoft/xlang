# P0 参数与动态值生成细则

本文细化 `xl6_cgen_args.c` 中会显著影响 C 代码膨胀、临时值生命周期和调用约定的规则。

## CGEN-ARGS-001 参数表固定参数计数

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `func f(int a, int b = 1, ... arg)` |
| 生成规则描述 | 参数表扫描到第一个 `...` 或 `***` 后停止，前面的参数都是固定参数；固定参数里可包含默认值。调用输出固定参数时按位置或命名参数匹配。 |
| 生成器文件名和行号 | `xl6_cgen_args.c:1`、`9`、`16`、`23`、`37`、`54` |
| 对应生成的 C 代码 | 固定参数直接进入 C 函数签名：`f(long long a, long long b, xvalue arg)` |
| 中间形态伪代码 | `fixedCount = count params until vararg marker` |
| 实现同等功能手写的 C 代码 | 手写 C 要人为区分固定参数与可变参数容器。 |
| 额外依赖的封装代码 | 无。 |

## CGEN-ARGS-002 位置参数与命名参数查找

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `f(1, b = 2)` |
| 生成规则描述 | 每个固定参数先按命名参数查找；若未找到，则按当前位置参数取值；若仍未找到但参数有默认值，则输出默认值表达式。命名参数不会影响位置参数计数。 |
| 生成器文件名和行号 | 参数表达式解包 `xl6_cgen_args.c:67`，查找 `75`，参数名索引 `101`，已知函数调用输出 `1345` |
| 对应生成的 C 代码 | `f(1LL, 2LL)`；缺省时 `f(1LL, defaultExpr)` |
| 中间形态伪代码 | `for each fixed param: expr = namedArg(param.name) ?? positionalArg(i) ?? default` |
| 实现同等功能手写的 C 代码 | C 不支持命名参数，需要调用者按最终顺序手写。 |
| 额外依赖的封装代码 | 无。 |

## CGEN-ARGS-003 缺省参数展开

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `func f(int a = 10); f()` |
| 生成规则描述 | 默认参数不生成多个 C 重载函数；调用点缺参时直接把参数声明处的默认表达式生成到实参位置。 |
| 生成器文件名和行号 | `xl6_cgen_args.c:1345-1370`，匿名/function 参数调用 `xl6_cgen_args.c:1388-1410` |
| 对应生成的 C 代码 | `f(10LL)` |
| 中间形态伪代码 | `if arg missing && param has default: emit param.defaultExpr` |
| 实现同等功能手写的 C 代码 | C 调用端手动补默认值，或写包装函数。 |
| 额外依赖的封装代码 | 无；function 值 adapter 另见 callable 规则。 |

## CGEN-ARGS-004 `...` 数组可变参数打包

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `func f(int a, ... arg); f(1, 2, "x")` |
| 生成规则描述 | 超过固定参数数量的非命名位置参数被收集进 `array<var>`，生成 `xl6_xrt_array_varargs(count, boxed...)`。固定参数之前的命名参数不会进入数组可变参数。 |
| 生成器文件名和行号 | 计数 `xl6_cgen_args.c:1250`，生成 `xl6_cgen_args.c:1274`，调用输出 `xl6_cgen_args.c:1372-1384` |
| 对应生成的 C 代码 | `f(1LL, xl6_xrt_array_varargs(2, xvoCreateInt((long long)2), xvoCreateText((void*)"x", 0, false)))` |
| 中间形态伪代码 | `varargs = positional args where positionalIndex >= fixedCount` |
| 实现同等功能手写的 C 代码 | 手写 C 需要手动创建 xvalue array 并逐项 append。 |
| 额外依赖的封装代码 | xvalue runtime、`xl6_xrt_array_varargs`。 |

## CGEN-ARGS-005 `***` 字典可变参数打包

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `func f(*** arg); f(name = "a", value = 1)` |
| 生成规则描述 | 命名参数中未匹配固定参数名的项进入 `dict<var>`，键为参数名字符串，值用 xvalue 打包。 |
| 生成器文件名和行号 | 计数 `xl6_cgen_args.c:1303`，生成 `xl6_cgen_args.c:1322`，调用输出 `xl6_cgen_args.c:1376-1380` |
| 对应生成的 C 代码 | `f(xl6_xrt_dict_varargs(2, "name", xvoCreateText(...), "value", xvoCreateInt(...)))` |
| 中间形态伪代码 | `kwargs = named args where name not in fixed params` |
| 实现同等功能手写的 C 代码 | 手写 C 需要创建 dict 并插入键值。 |
| 额外依赖的封装代码 | xvalue runtime、`xl6_xrt_dict_varargs`。 |

## CGEN-ARGS-006 动态 array 字面量

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `[1, "x", true]` |
| 生成规则描述 | 普通表达式中的数组字面量始终生成动态 `xvalue array`，每个元素调用 `xl6CgenXValueFromExpr` 打包。和 `array<int> a = array[1]` 的静态容器规则不同。 |
| 生成器文件名和行号 | `xl6_cgen_args.c:1167` |
| 对应生成的 C 代码 | `xl6_xrt_array_varargs(3, xvoCreateInt(...), xvoCreateText(...), xvoCreateBool(...))` |
| 中间形态伪代码 | `ArrayLiteral(items) -> xvalueArray(varargs(box(item)))` |
| 实现同等功能手写的 C 代码 | 手写 C 创建 xvalue array 并 append 每个元素。 |
| 额外依赖的封装代码 | xvalue runtime、array varargs helper。 |

## CGEN-ARGS-011 静态 typed container 装箱为 var

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `array<int> values; var v = values` |
| 生成规则描述 | 如果表达式是被标记为 typed container storage 的变量，打包成 var 时先转换为动态 xvalue 容器，再绑定 runtime type desc，保留泛型类型信息。 |

| 对应生成的 C 代码 | `xl6_xrt_bind_type(xl6_xrt_typed_array_to_xvalue(xrtTypeInt(), values), xl6_runtime_type_desc_array_int())` |
| 中间形态伪代码 | `BoxTypedContainer(expr) -> typed_to_xvalue(itemType, expr) -> bind type desc` |
| 实现同等功能手写的 C 代码 | 手写 C 遍历 typed container，逐项 box 到动态容器，再绑定类型。 |
| 额外依赖的封装代码 | typed container to xvalue helper、runtime type desc。 |

## CGEN-ARGS-013 xvalue 借用/结果装箱

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `var b = a`、`var b = fooReturningVar()` |
| 生成规则描述 | 如果源表达式已经是 xvalue，借用表达式会 retain；拥有型返回值直接转移。该规则避免重复 box，也避免借用值提前释放。 |
| 生成器文件名和行号 | `xl6_cgen_args.c:291-298`，xvalue 结果判断 `xl6_cgen_args.c:395` |
| 对应生成的 C 代码 | `xl6_xrt_retain(a)` 或 `fooReturningVar()` |
| 中间形态伪代码 | `if expr is xvalue: return retain(expr) if borrowed else expr` |
| 实现同等功能手写的 C 代码 | 手写 C 需要根据 ownership 决定 retain。 |
| 额外依赖的封装代码 | xvalue retain/unref helper。 |
