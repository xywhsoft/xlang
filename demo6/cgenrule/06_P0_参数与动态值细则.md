# P0 参数与动态值生成细则

本文细化 `xl6_cgen_args.c` 中会显著影响 C 代码膨胀、临时值生命周期和调用约定的规则。

## CGEN-ARGS-001 参数表固定参数计数

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `func f(int a, int b = 1, ... arg)` |
| 生成规则描述 | 参数表扫描到第一个 `...` 或 `***` 后停止，前面的参数都是固定参数；固定参数里可包含默认值。调用输出固定参数时按位置或命名参数匹配。 |
| 生成器文件名和行号 | `xl6_cgen_args.c:1`、`9`、`16`、`23`、`37`、`54` |
| 对应生成的 C 代码 | 固定参数直接进入 C 函数签名：`f(long long a, long long b, xvalue arg)` |
| 中间形态伪代码 | `fixedCount = count params until vararg marker` |
| 实现同等功能手写的 C 代码 | 手写 C 要人为区分固定参数与可变参数容器。 |
| 额外依赖的封装代码 | 无。 |

## CGEN-ARGS-002 位置参数与命名参数查找

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `f(1, b = 2)` |
| 生成规则描述 | 每个固定参数先按命名参数查找；若未找到，则按当前位置参数取值；若仍未找到但参数有默认值，则输出默认值表达式。命名参数不会影响位置参数计数；若语义阶段未拦截缺少必填参数，cgen 兜底诊断为 `missing required argument for parameter`，不能退回泛化错误。 |
| 生成器文件名和行号 | 参数表达式解包 `xl6_cgen_args.c:67`，查找 `75`，参数名索引 `101`，已知函数调用输出 `xl6_cgen_args_containers.c:546` |
| 对应生成的 C 代码 | `f(1LL, 2LL)`；缺省时 `f(1LL, defaultExpr)` |
| 中间形态伪代码 | `for each fixed param: expr = namedArg(param.name) ?? positionalArg(i) ?? default` |
| 实现同等功能手写的 C 代码 | C 不支持命名参数，需要调用者按最终顺序手写。 |
| 额外依赖的封装代码 | 无。 |

## CGEN-ARGS-003 缺省参数展开

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `func f(int a = 10); f()` |
| 生成规则描述 | 默认参数不生成多个 C 重载函数；调用点缺参时直接把参数声明处的默认表达式生成到实参位置。 |
| 生成器文件名和行号 | 固定参数调用 `xl6_cgen_args.c:xl6CgenEmitFixedCallArgs`，匿名/function 参数调用 `xl6_cgen_args.c:xl6CgenEmitKnownFunctionArgs` |
| 对应生成的 C 代码 | `f(10LL)` |
| 中间形态伪代码 | `if arg missing && param has default: emit param.defaultExpr` |
| 实现同等功能手写的 C 代码 | C 调用端手动补默认值，或写包装函数。 |
| 额外依赖的封装代码 | 无；func 值 adapter 另见 callable 规则。 |

## CGEN-ARGS-004 `...` 数组可变参数打包

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `func f(int a, ... arg); f(1, 2, "x")` |
| 生成规则描述 | 超过固定参数数量的非命名位置参数被收集进 `array<var>`，生成 `xl6_xrt_array_varargs(count, boxed...)`。固定参数之前的命名参数不会进入数组可变参数。 |
| 生成器文件名和行号 | 计数 `xl6_cgen_args_containers.c:451`，生成 `xl6_cgen_args_containers.c:475`，调用输出 `xl6_cgen_args_containers.c:573-579` |
| 对应生成的 C 代码 | `f(1LL, xl6_xrt_array_varargs(2, xvoCreateInt((long long)2), xvoCreateText((void*)"x", 0, false)))` |
| 中间形态伪代码 | `varargs = positional args where positionalIndex >= fixedCount` |
| 实现同等功能手写的 C 代码 | 手写 C 需要手动创建 xvalue array 并逐项 append。 |
| 额外依赖的封装代码 | xvalue runtime、`xl6_xrt_array_varargs`。 |

## CGEN-ARGS-016 xvalue 比较/排序

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `v == 1`、`v < other` |
| 生成规则描述 | 只要比较任一侧是 xvalue，就按动态比较输出。相等/不等走 `xl6_xrt_basic_equal`，有序比较走 `xl6_xrt_basic_order` 和 mode。声明初始化到 `bool/int` 系列时，先声明 `T name = 0;`，再用标准 C 局部块缓存左右操作数、调用 helper、释放临时值并赋给目标变量；普通表达式位置仍保持既有内联临时块，作为后续压实目标。 |
| 生成器文件名和行号 | 判断 `xl6_cgen_args.c:454`，order mode `xl6_cgen_args.c:473`，普通表达式生成 `xl6_cgen_args.c:487`，声明初始化生成 `xl6_cgen_stmt_decl.c:208` / 接线 `xl6_cgen_stmt_decl_call_args.c:676` |
| 对应生成的 C 代码 | 声明初始化：`int compareDecl = 0; { xvalue __xl6_cmp_left_N = ...; xvalue __xl6_cmp_right_N = ...; int __xl6_cmp_result_N = xl6_xrt_basic_equal(...); ... compareDecl = (int)(__xl6_cmp_result_N); }`；普通表达式：`({ xvalue __xl6_cmp_left_N = ...; ... xl6_xrt_basic_order(...); ... })` |
| 中间形态伪代码 | `DeclInit(name, Compare(op,left,right)) -> name=0 -> eval left once -> eval right once -> runtimeCompare -> release operands -> assign result`；`Expr(Compare) -> box operands if needed -> dynamic compare -> release temps` |
| 实现同等功能手写的 C 代码 | 手写 C 调用 xvalue compare API。 |
| 额外依赖的封装代码 | xvalue runtime。 |

## CGEN-ARGS-017 xvalue 算术/逻辑/近似

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `v + 1`、`v and w`、`v ~= w` |
| 生成规则描述 | 动态算术通常输出 `xl6_xrt_basic_binary`，动态整数 `/`、`%` 输出可捕获错误的 checked bridge；逻辑输出 truthy 短路表达式，近似输出 dynamic approx helper。声明初始化、调用实参、赋值和普通表达式路径都使用同一除模检查语义，并保持左右操作数只求值一次。 |
| 生成器文件名和行号 | 算术判断 `xl6_cgen_args.c:584`、`593`，binary mode `xl6_cgen_args.c:603`，普通表达式 binary 生成 `xl6_cgen_args.c:635`，声明初始化 binary 生成 `xl6_cgen_stmt_decl.c:76` / 接线 `xl6_cgen_stmt_decl_call_args.c:488`，逻辑判断 `xl6_cgen_args.c:734`、生成 `753`，近似判断 `xl6_cgen_args.c:531`，普通表达式近似 `xl6_cgen_args.c:550`，声明初始化近似 `xl6_cgen_stmt_decl.c:289` / 接线 `xl6_cgen_stmt_decl_call_args.c:679` |
| 对应生成的 C 代码 | 普通动态算术为 `xl6_xrt_basic_binary(...)`；动态除模为 `xl6_xrt_basic_binary_checked(..., line, column)` 或释放输入的 `xl6_xrt_basic_binary_release_checked(...)`；逻辑为 truthy 短路表达式。 |
| 中间形态伪代码 | `DeclInit(name, DynamicBinary(op,left,right)) -> name=0 -> eval left once -> eval right once -> name=runtimeBinary -> release operands`；`DeclInit(name, Approx(left,right)) -> name=0 -> eval left/right -> runtimeApprox -> release operands -> assign result`；`Expr(DynamicOp) -> boxed operands -> runtime op -> managed release` |
