# P2 上下文状态表细则

本文细化 `xl6_cgen_core_context.c` 和 `xl6_cgen_core_state.c`。这些规则本身大多不直接输出 C 片段，但它们决定变量查找、作用域回退、class/union 去重、多返回结构体去重、异常跳转目标和运行时需求开关，是其他生成规则的共同状态基础。

## CGEN-STATE-001 变量跟踪表与 typed container 标记

| 项目 | 内容 |
|---|---|
| xlang 写法 | `int a`、`array<int> xs`、`var v` |
| 生成规则描述 | cgen 为每个已进入当前作用域的变量记录名称、类型节点和 flags。`XL6_CGEN_VAR_TYPED_CONTAINER` 标记用于区分 `array<T>/list<T>/set<T>/dict<T>` 的 typed storage 与裸动态容器，后续索引、借用和 cleanup 会据此选择不同 C 路径。 |
| 生成器文件名和行号 | `demo6/src/cgen/xl6_cgen_core_context.c:1` |
| 对应生成的 C 代码 | typed storage 走 `xrtTypedArray*` 等路径；动态容器走 xvalue 路径。 |
| 中间形态伪代码 | `trackedVar = { name, type, flags }` |
| 实现同等功能手写的 C 代码 | 手写 C 由变量声明类型直接决定，不需要运行变量跟踪表。 |
| 额外依赖的封装代码 | 变量跟踪表。 |
