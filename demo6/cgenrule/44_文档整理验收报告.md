# cgenrule 文档整理验收报告

本文不新增 `CGEN-*` 规则，只记录本轮文档整理的最终验收结果。

## 验收口径

- 唯一规则定义：834 条，以 `^## CGEN-[A-Z]+-[0-9]+` 作为规则定义格式。
- 高级总览：`04_运行时与高级规则.md` 只作为高级能力索引，不占用唯一规则编号。
- 验证矩阵：`35` 到 `42` 合计覆盖 834 条规则，分别对应主干/P0、P1 和 P2 各区域。
- 非规则文档：`README.md`、`00`、`05`、`34` 到 `44` 均不新增规则编号。

## 本轮整理动作

- 将 `04_运行时与高级规则.md` 改为高级总览，避免与细则文档重复定义规则编号。
- 将 `16_P1_声明return多返回细则.md` 的规则前缀从 `CGEN-STMT-*` 收口为 `CGEN-DRET-*`，避免与 `03_语句与控制流规则.md` 冲突。
- 将 `17_P2_module输出顺序细则.md` 的规则前缀从 `CGEN-MOD-*` 收口为 `CGEN-MODULE-*`，避免与 `01_入口与声明规则.md` 冲突。
- 将 `20_P2_泛型推断与运行时状态细则.md` 的规则前缀从 `CGEN-GEN-*` 收口为 `CGEN-GENERIC-*`，避免与 `11_P1_generator与yield细则.md` 冲突。
- 同步更新 `36`、`37`、`38` 号验证矩阵中的规则编号引用。
- 同步更新 `README.md`、`34_规则测试范例交叉索引.md`、`43_文档整理收口.md` 中的总规则数口径。
- 补齐 runtime fatal 生成口径：module 固定输出 `xl6_runtime_fatal`，function/callable 通过 `xl6_function_fatal` 委托该入口，typed container 写入失败不再记录为直接生成 `exit(3)`。
- 将 `CGEN-DRET-025` 的旧式无返回标题收口为“无值 return”，避免误读为 xlang 语言层重新引入 `void` 返回类型。
- 复核 DLL 生命周期命名、混编默认链接路径和工具链默认值说明：生成代码生命周期仍为 `xlInit` / `xlUnit`，DLL 进程级 API 为 `xlRuntimeInit` / `xlRuntimeUnit`；默认 XRT/TCC 链接路径由 `tools\xl6_toolchain_env.bat` 集中管理。
- 将旧路径、旧卸载命名和旧式无返回标题扫描固化进 `check_docs_index.ps1` / `check_cgenrule_docs.ps1`，防止文档口径回退。
- 清零 `src/cgen/*.c` 中泛化 `code generation error` 占位诊断，并将新增静态扫描接入 `test.bat`，防止生成器错误路径回退到无信息文案。
