## 证据等级

| 等级 | 含义 |
|---|---|
| 直接生成检查 | 测试脚本检查了生成 C/IR/XAPI 文本中的关键片段。 |
| 运行行为检查 | 通过 `xl run`、`xl build` 或手动 TCC 编译运行验证行为。 |
| 负例语义检查 | 通过 `sem_*` 或 `invalid_*` 用例确认错误路径。 |
| 范例覆盖 | feature suite/tutorial 展示写法，但不一定逐片段断言生成文本。 |
| 非阻断增强 | 目前已有可追溯证据，但仍可以继续补充针对特定分支的稳定断言。 |
