# P2 类型克隆与表达式推断细则

本文细化 `xl6_cgen_type_infer.c`。这部分规则决定 `auto`、泛型推断、函数调用返回值、容器字面量、`await`、channel/thread/sync 方法等表达式被推断为什么 xlang 类型，再由类型映射规则落到 C 类型。
