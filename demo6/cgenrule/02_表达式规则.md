## CGEN-EXPR-013 索引访问

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `arr[0]`、`dict["k"]`、`typed[0]`、`typedDict[key]` |
| 生成规则描述 | 如果 receiver 是静态 typed container，则生成 XRT typed get；typed array 通过 `xl6_xrt_typed_array_get_at` 集中处理 xlang 0 基索引到当前 XRT typed array 1 基 ABI 的转换。如果 receiver 是 xvalue 容器，则生成动态 xvalue get；safe index 增加空值/越界保护。dict 动态 key 和整数 key 分不同路径。 |
| 生成器文件名和行号 | 分派 `xl6_cgen_expr.c:80`、`83`，实现 `xl6_cgen_value_index.c:370`，typed dict raw get `81`，xvalue dict get `32`，safe get `55` |
| 对应生成的 C 代码 | `(*(long long*)xl6_xrt_typed_array_get_at(values, index))`、`xvoArrayGetValue(v, i)` |
| 中间形态伪代码 | `Index(receiver, key) -> receiver storage kind -> typed get or xvalue get` |
| 实现同等功能手写的 C 代码 | 手写 C 直接调用 `xrtTypedArrayGet(values, index + 1u)` 或 xvalue 容器 API。 |
| 额外依赖的封装代码 | xvalue runtime；typed array 依赖 `xl6_xrt_typed_array_get_at` 边界 helper。 |

补充：静态 typed container 的元素读取需要区分 xlang 语言层 `bool` 与 C ABI 的 `c_bool`。xlang `bool` 在本地 C 表达式中仍使用 `int` 承载，但 XRT typed container 内部的 `xrtTypeBool()` 元素按 C `bool` 宽度存储；因此 `array<bool>`、`list<bool>`、`dict<bool>` 的索引读取必须生成 `((int)(*(bool*)xl6_xrt_typed_require_item(...)))`，不能按 `*(int*)` 读取。该规则只作用于语言层 `bool`，不改变 `c_bool` 的 ABI 对齐语义。
