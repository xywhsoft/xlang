# 入口与声明规则对照表

## CGEN-MOD-001 完整 C 文件生成

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | 任意 `.xl` 编译单元 |
| 生成规则描述 | 先收集匿名函数、泛型实例、runtime type desc，再按依赖需求注入运行时，随后生成 union/class/custom/函数原型/函数体，最后生成 xlang `main` 包装或 top-level wrapper。所有后续规则都挂在这个总流程下。 |
| 生成器文件名和行号 | `xl6_cgen_module.c:1`，预扫描 `35-43`，运行时注入 `74-140`，声明排序 `142-231`，函数体 `233-258`，main/top-level `264-280` |
| 对应生成的 C 代码 | `#include ...`、基础 typedef、运行时 helper、类型声明、函数原型、函数体、`int main(...)` 或 `int xl6_top_level_main(...)` |
| 中间形态伪代码 | `root -> collect -> emit runtime -> emit type decls -> emit protos -> emit bodies -> emit entry` |
| 实现同等功能手写的 C 代码 | 手写时需要自己安排头文件、类型前置声明、运行时初始化、函数声明顺序和入口函数。 |
| 额外依赖的封装代码 | 根据 needs 扫描按需生成 `xl6_*` helper；基础依赖仍是 XRT 与 C runtime。 |

## CGEN-MOD-002 顶层语句包装

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | 顶层可执行语句，例如 `print("hello")`、`int a = 1` |
| 生成规则描述 | 如果没有 xlang `main` 但存在顶层运行语句，则生成一个 C `main`，在其中调用 `xlInit()`，逐条执行顶层语句，再 `xlUnit()`。声明类顶层节点不会进入这个 wrapper。 |
| 生成器文件名和行号 | `xl6_cgen_module.c:266-287`，顶层语句判断在 `xl6_cgen_core_types.c` 的 top-level helper 中 |
| 对应生成的 C 代码 | `int main(int argc, char** argv) { xlInit(); ...top level stmt... xlUnit(); return 0; }` |
| 中间形态伪代码 | `if no_main && has_runtime_stmt: wrap_stmt_list_as_main(root.runtimeStmts)` |
| 实现同等功能手写的 C 代码 | 手写 C 需要显式写 `main` 并自行调用初始化/卸载函数。 |
| 额外依赖的封装代码 | `xl6_cgen_lifecycle.c:25` 生成 `xlInit/xlUnit` 运行时。 |

## CGEN-MAIN-001 xlang main 入口

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `func main(...) as int` 或 `func main(...)` |
| 生成规则描述 | 如果存在 xlang main，则生成显式 C `main`，初始化 xlang/XRT 环境，构造 `arg` 数组，调用 xlang main，按返回类型决定 C main 返回值。只允许一个 xlang main。 |
| 生成器文件名和行号 | `xl6_cgen_main.c:33`，返回值判断 `xl6_cgen_main.c:25`，argv helper `xl6_cgen_main.c:1` |
| 对应生成的 C 代码 | `int main(int argc, char** argv) { xvalue arg = xl6_make_argv_array(argc, argv); int code = main(arg); ... }` |
| 中间形态伪代码 | `C main -> xlInit -> make arg -> call xl main -> cleanup arg -> xlUnit` |
| 实现同等功能手写的 C 代码 | 手写时需要自己把 `argc/argv` 转成 xvalue array 并保证异常/资源路径释放。 |
| 额外依赖的封装代码 | `xl6_make_argv_array`、`xlInit/xlUnit`、xvalue runtime。 |

## CGEN-FUNC-001 普通函数原型

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `func add(int a, int b) as int` |
| 生成规则描述 | 非泛型普通函数先输出 C 原型。单返回值映射到 C 返回类型；多返回值映射到签名哈希派生的 `XL6_Function_Return_<signature>` 结构体；无返回值映射 `void`。非泛型顶层 typed container 参数会使用 `xtarray/xtlist/xtset/xtdict` 静态句柄。 |
| 生成器文件名和行号 | `xl6_cgen_decl_proto.c:1`，typed container 返回/参数辅助在 `xl6_cgen_value_object.c:313`、`330`、`346`、`358` |
| 对应生成的 C 代码 | `long long add(long long a, long long b);` 或 `xtarray f(xtarray values);` |
| 中间形态伪代码 | `FuncDecl(name, params, returns) -> CProto(returnCType, symbol, paramCTypes)` |
| 实现同等功能手写的 C 代码 | `long long add(long long a, long long b);` |
| 额外依赖的封装代码 | typed container 参数/返回依赖 typed container runtime helper；普通标量无额外封装。 |

## CGEN-FUNC-002 普通函数体

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `func add(int a, int b) as int ... end` |
| 生成规则描述 | 输出与原型一致的 C 函数体，进入函数作用域后注册参数类型和 cleanup，生成 block，若函数没有显式 return，则在离开前释放本作用域 cleanup。 |
| 生成器文件名和行号 | `xl6_cgen_func.c:1`，参数注册 `xl6_cgen_decl_methods.c:1`，block `xl6_cgen_stmt_decl.c:3` |
| 对应生成的 C 代码 | `long long add(long long a, long long b) { ... return value; }` |
| 中间形态伪代码 | `enter_scope(params) -> emit block -> if no return emit cleanup -> leave_scope` |
| 实现同等功能手写的 C 代码 | 手写 C 需要自己管理局部对象析构，尤其 function/class/custom/xvalue/typed container。 |
| 额外依赖的封装代码 | cleanup 栈由生成器静态展开，不依赖单独 runtime。 |

| 对应生成的 C 代码 | `long long puts(const char* s);` |
| 中间形态伪代码 | `ExternFunc(alias, xlangSig) -> C prototype(alias)` |
| 实现同等功能手写的 C 代码 | `extern int puts(const char* s);` |
| 额外依赖的封装代码 | 无；类型转换可能触发 xvalue/type-convert helper。 |

## CGEN-FUNC-004 export 函数双层 ABI

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `export func add(int a, int b) as int` |
| 生成规则描述 | 生成一个内部实现符号和一个导出的 C ABI wrapper。内部实现走 xlang 自身规则；wrapper 使用 C ABI 类型并调用内部实现。 |
| 生成器文件名和行号 | 内部原型 `xl6_cgen_decl_proto.c:45`，wrapper 原型 `xl6_cgen_decl_proto.c:87`，内部函数 `xl6_cgen_func.c:46`，wrapper `xl6_cgen_func.c:91` |
| 对应生成的 C 代码 | `static long long xl6_export_add_impl(...); XL6_API long long add(...) { return xl6_export_add_impl(...); }` |
| 中间形态伪代码 | `ExportFunc -> emit internal impl -> emit public ABI wrapper` |
| 实现同等功能手写的 C 代码 | 手写 C 通常直接写导出函数；xlang 多一层用于隔离 xlang 调用约定和 C ABI。 |
| 额外依赖的封装代码 | C ABI 类型映射、导出宏、必要时多返回/var 打包。 |

## CGEN-FUNC-005 多返回值结构体

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `func pair() as (int, string)` |
| 生成规则描述 | 函数返回值超过 1 个时，按函数参数与返回值签名生成 `XL6_Function_Return_<signature>` 结构体，字段名固定为 `value0/value1/...`。同签名函数复用同一个结构体声明；函数 return 语句创建结构体临时值并逐字段赋值。 |
| 生成器文件名和行号 | 普通函数多返回名入口 `xl6_cgen_symbol.c:415`，签名结构体名/声明 `xl6_cgen_abi.c:194`、`199`、`209`、`235`，函数原型使用 `xl6_cgen_decl_proto.c:8-12`，return 分支 `xl6_cgen_stmt_dispatch.c:68-94` |
| 对应生成的 C 代码 | `typedef struct XL6_Function_Return_ABCD { long long value0; const char* value1; } XL6_Function_Return_ABCD;` |
| 中间形态伪代码 | `Return(a,b) -> tmp.value0 = a; tmp.value1 = b; return tmp` |
| 实现同等功能手写的 C 代码 | 手写 C 通常定义一个 struct 或通过 out 参数返回。 |
| 额外依赖的封装代码 | 多返回值结构体统一走签名 ID 版本的 return struct，见 `xl6_cgen_abi.c:209`。 |

## CGEN-TYPE-002 class 结构体和方法

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `class User int id func getId() as int ... end end` |
| 生成规则描述 | class 本体生成 C struct；继承通过父结构体字段嵌入；方法生成普通 C 函数，首参为 `self` 指针。create/destroy 有特殊规则，缺失 destroy 时可生成自动析构。 |
| 生成器文件名和行号 | class 声明 `xl6_cgen_decl_class.c:319`，字段默认初始化 `426`，方法原型 `xl6_cgen_decl_proto.c:239`，方法体 `xl6_cgen_decl_methods.c:197`、`391` |
| 对应生成的 C 代码 | `typedef struct xl6_class_User { long long id; } xl6_class_User; long long User_getId(xl6_class_User* self);` |
| 中间形态伪代码 | `ClassDecl -> C struct; Method(self, params) -> C func(self*, params)` |
| 实现同等功能手写的 C 代码 | 手写 C 通常写 struct + 一组以指针为首参的函数。 |
| 额外依赖的封装代码 | class 进入 var/typed container 时需要 record box runtime；函数字段需要 retain/release helper。 |

## CGEN-TYPE-004 custom 轻量类

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `custom File extern func read(...) ... end` |
| 生成规则描述 | custom 保存一个 opaque handle，成员函数直接映射到 C 函数；调用时把 `self.handle` 作为第一个参数传递。create/destroy 取决于声明，不强制内存管理。 |
| 生成器文件名和行号 | custom 声明 `xl6_cgen_decl_class.c:612`，extern 原型 `522`，helper 参数 `565`，方法体 `xl6_cgen_decl_methods.c:467`、`527`，调用 `xl6_cgen_value_object.c:453` |
| 对应生成的 C 代码 | `typedef struct xl6_custom_File { void* handle; } xl6_custom_File; result = c_read(self.handle, ...);` |
| 中间形态伪代码 | `custom.method(args) -> extern_symbol(custom.handle, args)` |
| 实现同等功能手写的 C 代码 | 手写 C 通常定义 handle struct，再写薄封装函数。 |
| 额外依赖的封装代码 | custom 进入 var 时使用 handle box runtime；有 destroy 时生成 handle drop。 |

## CGEN-HEADER-001 导出头文件

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `xl build --emit-header` 或 DLL/导出目标 |
| 生成规则描述 | 根据 AST 生成给 C 使用的 `.h`：类型声明、`XL6_Function` 公共 ABI、export 函数原型、export 变量声明。导出头文件只暴露 C ABI，不暴露内部 xlang helper。 |
| 生成器文件名和行号 | `xl6_cgen_header.c:743`，函数原型 `680`，变量 `728`，class/union 依赖 `438`、`523`、`582` |
| 对应生成的 C 代码 | `#pragma once ... typedef struct XL6_Function { ... } XL6_Function; ... XL6_API long long add(long long a, long long b);` |
| 中间形态伪代码 | `Exported AST -> dependency sorted C header` |
| 实现同等功能手写的 C 代码 | 手写 C 需要同步维护 `.h`，容易和生成的 C 实现漂移。 |
| 额外依赖的封装代码 | 导出宏、类型依赖展开。 |
