## 维护准则

1. 新增或修改 cgen 规则时，同步更新对应 `CGEN-*` 对照表与验证矩阵。
2. 对每条规则至少保留一个 test/example 证据；没有覆盖时补测试或记录为非阻断增强项。
3. 对复杂规则生成一次 C 输出样例，确认文档中的 C 模板不是凭印象写的。
4. 每轮结束运行规则计数、占位符扫描和行号引用检查，保持 `CGEN-*` 数量与 README 口径一致。
