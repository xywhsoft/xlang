## 剩余风险与后续增强

| 缺口 | 建议补法 |
|---|---|
| 泛型实例、runtime type desc 和函数值 adapter 的“去重”已分别由 `cgen_generic_dedupe.xl`、`cgen_type_desc_dedupe.xl`、`cgen_function_adapter_dedupe.xl` 的生成文本计数测试覆盖。 | 后续可继续扩展到泛型 class 方法和 extern function adapter。 |
| `CGEN-NAM-033` 同名同类型参数数量的泛型函数签名后缀缺少专门快照。 | 增加 `cgen_generic_signature_suffix.xl`，构造两个同名泛型模板，让 `__sig` 后缀成为必须条件。 |
| 调用解析内部入口边界主要靠最终行为证明。 | 为 `ResolveCallFunc` 与 `ResolveCallFuncWithTypeArgs` 相关路径补显式泛型推断和非泛型同名函数共存的生成断言。 |
| 类型推断覆盖多但分散。 | 后续可以整理一份 `cgen_auto_inference_matrix.xl`，集中验证 `auto` 对字面量、容器、function、await、member、index、call 的 C 类型输出。 |
