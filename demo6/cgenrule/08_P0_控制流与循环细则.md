# P0 控制流与循环生成细则

本文细化 `xl6_cgen_stmt_loop.c` 与 `xl6_cgen_stmt_dispatch.c` 中的基础控制流、`for in` 分派、range、动态容器、typed container、generator、`break/continue` 生成规则。

## CGEN-LOOP-001 if / elseif / else

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `if a then ... elseif b then ... else ... end` |
| 生成规则描述 | `if` 首条件和 `elseif` 条件都会先尝试语句级临时值 lowering；动态比较、动态近似、动态短路逻辑、`in` 等 bool-like 条件会分别生成 `int __xl6_if_cond_N` 或 `int __xl6_elseif_cond_N`，再输出 `if (__xl6_*_cond_N)`。不能语句级化的条件交给 `xl6CgenConditionExpr`。为保持 `elseif` 条件的按需、按序求值，生成器把链条输出为嵌套 `else { if (...) { ... } }`；`else` 仅在块内有语句时输出。 |
| 生成器文件名和行号 | 条件 helper `xl6_cgen_stmt_branch.c:1`、`xl6_cgen_stmt_branch.c:30`、条件分支 `xl6_cgen_stmt_branch.c:78`、elseif tail `xl6_cgen_stmt_branch.c:112`、总入口 `xl6_cgen_stmt_branch.c:142`、dispatch `xl6_cgen_stmt_dispatch.c:388` |
| 对应生成的 C 代码 | `if (condA) { ... } else { int __xl6_elseif_cond_1 = 0; ...; if (__xl6_elseif_cond_1) { ... } else { ... } }` |
| 中间形态伪代码 | `If(cond, thenBlock, elseifList, elseBlock) -> emit first if -> else { emit elseif tail recursively }` |
| 实现同等功能手写的 C 代码 | 与生成代码基本一致，只是 xlang 条件会自动处理 `var` truthy。 |
| 额外依赖的封装代码 | 无。 |

补充边界：`if` 首条件、`elseif` 条件、`while` 条件和 `do while` 条件都已覆盖动态 bool-like 条件的语句级 lowering。`RISK-CALL-001` 仍保留开放，因为普通表达式位置和复杂 await fallback 仍需继续逐项收口。

## CGEN-LOOP-002 while 循环

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `while cond do ... end` |
| 生成规则描述 | 普通 `while` 仍输出 C `while (...)`。如果条件是可语句级化的动态 bool-like 表达式，则输出 `while (1)`，在循环顶部生成 `int __xl6_while_cond_N` 并用 `if (!__xl6_while_cond_N) { break; }` 离开循环。循环体前压入 loop target，体后弹出；循环体末尾生成 `__xl6_continue_N:` 标签，循环外生成 `__xl6_break_N:` 标签。这样 `break`/`continue` 可以统一用 `goto` 并在跳转前执行清理。 |
| 生成器文件名和行号 | `xl6_cgen_stmt_loop.c:3`、`xl6_cgen_stmt_loop.c:11`、`xl6_cgen_stmt_loop.c:14`、`xl6_cgen_stmt_loop.c:16`、`xl6_cgen_stmt_loop.c:18`、`xl6_cgen_stmt_loop.c:31`、`xl6_cgen_stmt_loop.c:55`、`xl6_cgen_stmt_dispatch.c:392` |
| 对应生成的 C 代码 | 普通条件：`while (cond) { ... __xl6_continue_1: ; }`<br>动态 bool-like 条件：`while (1) { int __xl6_while_cond_1 = 0; ...; if (!__xl6_while_cond_1) { break; } ... __xl6_continue_1: ; }`<br>`__xl6_break_1: ;` |
| 中间形态伪代码 | `if dynamicBoolLike(cond): while true { condTemp = eval(cond); if !condTemp break; body; continueLabel } else: while cond { body; continueLabel } breakLabel` |
| 实现同等功能手写的 C 代码 | 普通 C 可直接写 `while`；若需要资源清理和多层跳出，则也常用 `goto` 标签。 |
| 额外依赖的封装代码 | 无。 |

## CGEN-LOOP-003 do while 循环

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `do ... while cond` |
| 生成规则描述 | 普通 `do while` 仍输出 C `do { ... } while (...)`。如果尾部条件是可语句级化的动态 bool-like 表达式，则输出 `while (1)`，先生成循环体，再在原 continue 标签之后生成 `int __xl6_do_cond_N`，并用 `if (!__xl6_do_cond_N) { break; }` 离开循环。两条路径都使用与 `while` 相同的 loop target、continue 标签和 break 标签；`continue` 标签位于 body 末尾、条件判断之前，符合 do-while 的 continue 语义。 |
| 生成器文件名和行号 | `xl6_cgen_stmt_loop.c:65`、`xl6_cgen_stmt_loop.c:73`、`xl6_cgen_stmt_loop.c:76`、`xl6_cgen_stmt_loop.c:85`、`xl6_cgen_stmt_loop.c:87`、`xl6_cgen_stmt_loop.c:104`、`xl6_cgen_stmt_dispatch.c:396` |
| 对应生成的 C 代码 | 普通条件：`do { ... __xl6_continue_1: ; } while (cond);`<br>动态 bool-like 条件：`while (1) { body; __xl6_continue_1: int __xl6_do_cond_2 = 0; ...; if (!__xl6_do_cond_2) { break; } }`<br>`__xl6_break_1: ;` |
| 中间形态伪代码 | `if dynamicBoolLike(cond): while true { body; continueLabel; condTemp = eval(cond); if !condTemp break } else: do { body; continueLabel } while cond; breakLabel` |
| 实现同等功能手写的 C 代码 | 与生成代码基本一致。 |
| 额外依赖的封装代码 | 无。 |

## CGEN-LOOP-005 for in 总分派

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `for item in iterable ... end` |
| 生成规则描述 | `for in` 入口先识别 `range(...)`；否则推断右侧类型，只允许 range、array、list、set、dict、generator 或 var。generator 走 generator 规则；typed container storage 或 typed container 返回调用走 typed 规则；其余走动态 xvalue iterable 规则。若 AST 形态缺少目标、iterable 或 body，兜底诊断为 `malformed for-in statement`。 |
| 生成器文件名和行号 | `xl6_cgen_stmt_dispatch.c:1`、`xl6_cgen_stmt_dispatch.c:6`、`xl6_cgen_stmt_dispatch.c:8`、`xl6_cgen_stmt_dispatch.c:14`、`xl6_cgen_stmt_dispatch.c:20`、`xl6_cgen_stmt_dispatch.c:23` |
| 对应生成的 C 代码 | 入口本身不直接输出循环体，而是分派到 `xl6CgenForRange`、`xl6CgenForGeneratorIterable`、`xl6CgenForTypedContainerIterable` 或 `xl6CgenForXValueIterable`。 |
| 中间形态伪代码 | `if range: emitRange; else if generator: emitGenerator; else if typed: emitTyped; else emitXValue` |
| 实现同等功能手写的 C 代码 | 手写 C 需要先确定容器类型，然后选择对应 XRT 遍历 API。 |
| 额外依赖的封装代码 | 无。 |

## CGEN-LOOP-006 for range 参数与循环骨架

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `for i in range(10) ... end`、`for i, v in range(2, 10, 2) ... end` |
| 生成规则描述 | range for 只支持 1 或 2 个迭代变量，range 参数数量必须是 1、2 或 3。生成局部作用域，计算 start/stop/step 和内部 index。三参数 range 会在进入 C `for` 前检查 `step == 0`，运行期为 0 时抛出 `RangeError` 并走统一错误传播，避免动态 step 形成死循环。step 正数时条件为 `< stop`，负数时条件为 `> stop`。若 AST 形态缺少目标、iterable 或 body，兜底诊断为 `malformed range for-in statement`。 |
| 生成器文件名和行号 | `xl6_cgen_stmt_loop.c:551`、`xl6_cgen_stmt_loop.c:561`、`xl6_cgen_stmt_loop.c:563`、`xl6_cgen_stmt_loop.c:573`、`xl6_cgen_stmt_loop.c:581`、`xl6_cgen_stmt_loop.c:608` |
| 对应生成的 C 代码 | `if (step == 0) { xl6_error_raise("RangeError", "range step cannot be 0", "", line, column); ... }`<br>`for (long long value = start; (step > 0) ? (value < stop) : (value > stop); value += step, ++index) { ... }` |
| 中间形态伪代码 | `start, stop, step = normalizeRangeArgs(args); guard step != 0; for value = start; rangeCond; value += step` |
| 实现同等功能手写的 C 代码 | `for (long long v = 0; v < 10; ++v) { ... }` |
| 额外依赖的封装代码 | 无。 |

## CGEN-LOOP-009 动态 xvalue iterable 临时值

## CGEN-LOOP-011 动态 list 遍历

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `for v in listValue ... end`、`for key, v in listValue ... end` |
| 生成规则描述 | 动态 list 先生成 `XL6_XrtIterSnapshot*`，通过 `xl6_xrt_list_snapshot(iter)` 把 XRT list 的公开 walk 结果快照为 `{index,value}` 数组，再按普通 C `for` 遍历 snapshot。单目标暴露 retained value；双目标暴露稀疏 int64 key 和 retained value。快照失败会进入 `xl6_runtime_fatal(3)`，snapshot 由 cleanup 栈统一释放。 |
| 生成器文件名和行号 | `xl6_cgen_stmt_loop.c:359`、`xl6_cgen_stmt_loop.c:369`、`xl6_cgen_stmt_loop.c:370`、`xl6_cgen_stmt_loop.c:385`、`xl6_cgen_stmt_loop.c:396`、`xl6_cgen_stmt_loop.c:409`、`xl6_cgen_stmt_loop.c:416` |
| 对应生成的 C 代码 | `XL6_XrtIterSnapshot* s = xl6_xrt_list_snapshot(iter); for (unsigned int pos = 0; pos < s->count; ++pos) { XL6_XrtIterItem* item = &s->items[pos]; long long key = item->index; xvalue v = xl6_xrt_retain(item->value); }` |

| 实现同等功能手写的 C 代码 | 手写 C 可调用 `xrtListWalk` 构造稳定快照，再遍历快照数组。 |
| 额外依赖的封装代码 | 依赖 `xl6_xrt_list_snapshot`、`XL6_XrtIterSnapshot` 和 snapshot cleanup。 |

## CGEN-LOOP-015 generator 遍历

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `for item in gen ... end`、`for index, item in gen ... end`，其中 `gen` 是 `generator<T>` |
| 生成规则描述 | generator for-in 支持一个或两个目标变量。生成器右侧表达式生成 `XL6_Generator*`；如果右侧是名字，会把源变量清零以转移所有权。循环使用 `xl6_generator_next` 推进，并用 `xl6_generator_value_into` 把当前值写入目标变量。双目标形式会在 `while` 外生成 0 基 `long long __xl6_gen_index_N`，每轮把第一个目标设为当前 index，循环体和 `continue` cleanup 之后递增。若 AST 形态缺少目标、iterable 或 body，兜底诊断为 `malformed generator for-in statement`。 |
| 生成器文件名和行号 | `xl6_cgen_stmt_loop.c:777`、`xl6_cgen_stmt_loop.c:801`、`xl6_cgen_stmt_loop.c:833`、`xl6_cgen_stmt_loop.c:836`、`xl6_cgen_stmt_loop.c:847`、`xl6_cgen_stmt_loop.c:873`、`xl6_cgen_stmt_loop.c:880`、`xl6_cgen_stmt_loop.c:883` |
| 对应生成的 C 代码 | `XL6_Generator* gen = expr; long long genIndex = 0; while (xl6_generator_next(gen, "", line, col)) { long long index = genIndex; T item = default(T); xl6_generator_value_into(gen, &item, sizeof(T), "", line, col); ...; genIndex += 1; }` |

## 本文件观察到的优化风险

| 编号 | 观察 |
| --- | --- |
| RISK-LOOP-001 | 已收口：动态 list/dict 遍历不再直接生成 XRT AVL iterator 和节点布局访问，而是集中到 `xl6_xrt_list_snapshot` / `xl6_xrt_dict_snapshot`；helper 内部使用 XRT 公开 `xrtListWalk` / `xrtDictWalk` 构造稳定快照。 |
| RISK-LOOP-002 | 已收口：typed dict 遍历按 `keyLen` 复制出 NUL 结尾 key copy，并通过 `XL6_CGEN_CLEANUP_XRT_PTR` 自动释放，避免非 NUL 结尾 XRT key 造成越界读取；RC0 明确把 typed dict 的 `for key in dict<string>` 循环目标定义为文本 `string`，不承诺表达含零字节的 binary key，后续若引入 bytes/binary key 将作为新能力单独设计。 |

补充守门：returned typed dict 在循环体内抛异常时，生成代码必须先释放当前 `__xl6_typed_key_copy_N`，再销毁 `__xl6_typed_iter_N`，最后跳转到 `__xl6_try_catch_N`。`cgen_typed_container_for_in_returned.xl` 使用 `try + for key, score in makeScores() + throw` 验证运行行为，`test.bat` 用正则锁定 `xrtFree(__xl6_typed_key_copy_N)`、`xrtTypedDictDestroy(__xl6_typed_iter_N)`、`goto __xl6_try_catch_` 的顺序。
| RISK-LOOP-003 | 已收口：字面量 step 0 由语义检查拒绝，动态 step 0 由生成代码在进入 C `for` 前抛出 `RangeError`，`cgen_range_step_runtime_zero.xl` 覆盖运行期失败路径。 |
| RISK-LOOP-004 | 已收口：`var` iterable 的运行期分派遇到非 array/list/set/dict 时抛出 `TypeError`，`cgen_for_in_var_non_container.xl` 覆盖生成 guard、错误运行时注入和运行期失败诊断。 |
