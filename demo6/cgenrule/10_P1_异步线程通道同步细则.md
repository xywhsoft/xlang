# P1 异步、线程、通道与同步对象生成细则

本文细化 `xl6_cgen_async.c` 中的 async/await、channel、mutex/sem/cond/rwlock、thread 生成规则。该文件同时负责注入一组并发运行时声明和小型 helper。

## CGEN-ASYNC-001 并发运行时需求扫描

| 字段 | 内容 |
| --- | --- |
| xlang 写法 | `async func f()`、`await f()`、`channel<int>(1)`、`mutex()`、`thread(entry)` |
| 生成规则描述 | AST 中出现 async 函数、await、yield、future/channel/thread/generator/sync 类型，或出现 `thread`、同步对象构造、同步方法调用时，会标记需要 async runtime。该扫描决定是否注入 future/channel/thread/sync 相关 C 声明与 helper。 |
| 生成器文件名和行号 | `xl6_cgen_async.c:71`、`xl6_cgen_async.c:78`、`xl6_cgen_async.c:92`、`xl6_cgen_async.c:100` |
| 对应生成的 C 代码 | 触发后会注入 `xfuture`、`xchannel`、`xrtMutexCreate`、`xrtThreadCreate` 等声明。 |
| 中间形态伪代码 | `needsAsyncRuntime = contains(async/await/future/channel/thread/sync call)` |
| 实现同等功能手写的 C 代码 | 手写 C 需要显式 include/声明 XRT 并发 API。 |
| 额外依赖的封装代码 | `xl6CgenEmitAsyncRuntime` 输出的 runtime block。 |

## 本文件观察到的优化风险

| 编号 | 观察 |
| --- | --- |
| RISK-ASYNC-001 | async 结果类型通过 `xl6CgenAsyncResultType` 只接受单返回值；多返回值 async 当前没有完整模型。 |
| RISK-ASYNC-002 | channel/sync/thread 方法接收者当前要求是名字，复杂表达式接收者不会走这些方法规则。 |
| RISK-ASYNC-003 | `await` 获取 typed 结果后解引用 future 内部 value 指针，但没有在 await 表达式生成点释放 future；future 生命周期依赖变量 cleanup 或用户管理。 |
| RISK-ASYNC-004 | channel 发送通过 `memcpy` 复制值，对含 function 字段的 class/custom 等复杂所有权类型需要更细生命周期策略。 |
| RISK-ASYNC-005 | sync/thread 许多失败路径直接返回 bool 或 0，没有接入统一异常模型，RC 前应统一错误语义。 |
