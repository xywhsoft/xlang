# P1 异步、线程、通道与同步对象生成细则

本文细化 `xl6_cgen_async.c` 中的 async/await、channel、mutex/sem/cond/rwlock、thread 生成规则。该文件同时负责注入一组并发运行时声明和小型 helper。

## CGEN-ASYNC-001 并发运行时需求扫描

| 生成规则描述 | AST 中出现 async 函数、await、yield、future/channel/thread/generator/sync 类型，或出现 `thread`、同步对象构造、同步方法调用时，会标记需要 async runtime。该扫描决定是否注入 future/channel/thread/sync 相关 C 声明与 helper。 |
| 生成器文件名和行号 | `xl6_cgen_async.c:71`、`xl6_cgen_async.c:78`、`xl6_cgen_async.c:92`、`xl6_cgen_async.c:100` |

## 本文件观察到的优化风险

| 编号 | 观察 |
| --- | --- |
| RISK-ASYNC-001 | async 结果类型通过 `xl6CgenAsyncResultType` 只接受单返回值；多返回值 async 当前没有完整模型；`sem_async_multi_return.xl` 以 `multi-return` 诊断锁定为语义错误。 |
| RISK-ASYNC-002 | 已收口：channel/sync/thread 方法接收者必须是具名变量，复杂表达式接收者由 `sem_channel_receiver_expr.xl`、`sem_sync_receiver_expr.xl`、`sem_thread_receiver_expr.xl` 负例和集中诊断断言锁定为语义错误。 |
| RISK-ASYNC-003 | 已收口：`await asyncCall()` 这类直接 async 调用临时 future 会在 await statement expression 内释放；function/class 结果会先 retain 再释放 future，具名 future 仍由变量 cleanup 管理并保持 repeated await 语义。`cgen_async.xl` 和 feature suite `11_concurrency.xl` 覆盖 int、void、function、class 临时 await。 |
| RISK-ASYNC-004 | 已收口：`channel<T>` 语义层只允许 bool/int/float/time/point 等可按值复制元素；string、class、function 等复杂所有权类型由 `sem_channel_string_element.xl`、`sem_channel_class_element.xl`、`sem_channel_function_element.xl` 负例和集中诊断断言锁住，因此不会进入当前 `memcpy` 发送路径。 |
| RISK-ASYNC-005 | 已收口：async 任务启动、channel 构造、sync 构造和 thread 构造的空句柄/空 future 失败路径已统一抛 `AsyncError`、`ChannelError`、`SyncError` 或 `ThreadError`；`tryLock`、`tryWait`、`waitTimeout` 等业务性 false/timeout 结果仍保持普通返回值语义。 |
