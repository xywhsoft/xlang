# P2 入口判定细则

本文细化 `xl6_cgen_entry.c`。该分片用于在 module 生成前识别顶层运行语句和 xlang `main` 函数，决定是否需要生成脚本式 top-level main、是否使用显式 main 包装，以及入口名称比较是否大小写敏感。

## CGEN-ENTRY-001 入口文本比较大小写敏感

| 项目 | 内容 |
|---|---|
| xlang 写法 | `func main()` 与 `func Main()` |
| 生成规则描述 | 入口判定使用 `strcmp` 精确比较，只有两侧非 NULL 且字节完全相同时才相等。因此 `main` 是唯一 main 入口名，`Main` 不会被当作入口。 |
| 生成器文件名和行号 | `demo6/src/cgen/xl6_cgen_entry.c:5` |
| 对应生成的 C 代码 | `func main()` 会触发 `int main(int argc, char** argv)` 包装；`func Main()` 只是普通函数。 |
| 中间形态伪代码 | `equals = a != null && b != null && strcmp(a,b)==0` |
| 实现同等功能手写的 C 代码 | C 语言入口同样要求精确的 `main` 符号。 |
| 额外依赖的封装代码 | 无。 |

## CGEN-ENTRY-002 顶层运行语句筛选

| 项目 | 内容 |
|---|---|
| xlang 写法 | 文件顶层直接写 `print("hi")`、`var a = 1` |
| 生成规则描述 | 顶层节点只要不是 import、函数、extern/export 函数或变量、export const、类型别名、extern 类型别名、custom、union、class，就被视为顶层运行语句。存在这类节点时，module 生成会走 top-level main 包装路径。 |
| 生成器文件名和行号 | `demo6/src/cgen/xl6_cgen_entry.c:10` |
| 对应生成的 C 代码 | 顶层语句被包装进生成的 `main` 或脚本入口函数中。 |
| 中间形态伪代码 | `runtimeStmt = node.kind not in declaration/import/type/class/custom/union set` |
| 实现同等功能手写的 C 代码 | C 不允许裸顶层语句，必须手动写进 `main`。 |
| 额外依赖的封装代码 | top-level main 生成路径。 |

## CGEN-ENTRY-003 xlang main 函数识别

| 项目 | 内容 |
|---|---|
| xlang 写法 | `func main(...)` |
| 生成规则描述 | 只有 AST kind 为普通函数 `XL6_AST_FUNC`，且第一个子节点名称为精确小写 `main` 时，才是 xlang main 入口。async main、extern main、export main 或大小写不同的名称不走该入口识别。 |
| 生成器文件名和行号 | `demo6/src/cgen/xl6_cgen_entry.c:28` |
| 对应生成的 C 代码 | 生成显式 C `main` 包装，内部初始化 xlang 运行环境并调用 xlang main。 |
| 中间形态伪代码 | `node.kind == FUNC && firstChild.text == "main"` |
| 实现同等功能手写的 C 代码 | C 直接定义 `int main(...)`。 |
| 额外依赖的封装代码 | xlang main wrapper。 |

## CGEN-ENTRY-004 主入口查找与顶层运行语句存在性

| 项目 | 内容 |
|---|---|
| xlang 写法 | 一个模块中声明 `func main()`，或只有顶层语句 |
| 生成规则描述 | 主入口查找从根节点子节点按源顺序扫描，返回第一个符合 main 入口判定的函数；顶层运行语句检查同样按源顺序扫描，任一节点符合顶层运行语句筛选则返回真。这两个结果共同决定 module 生成是否输出 xlang main 包装或 top-level main。 |
| 生成器文件名和行号 | `demo6/src/cgen/xl6_cgen_entry.c:39` |
| 对应生成的 C 代码 | `int main(int argc, char** argv) { xlInit(); ... xlUnit(); }` 或顶层语句包装函数。 |
| 中间形态伪代码 | `find first main func; hasTopLevelRuntime = any runtimeStmt(root.child)` |
| 实现同等功能手写的 C 代码 | 手写 C 只能有一个入口，顶层语句必须手动挪入入口函数。 |
| 额外依赖的封装代码 | module main/top-level main 生成路径。 |
