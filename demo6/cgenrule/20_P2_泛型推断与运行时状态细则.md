# P2 泛型推断与运行时状态细则

本文细化 `xl6_cgen_core_generics.c`、`xl6_cgen_core_runtime_state.c` 和 `xl6_cgen_type_generic.c`。这些分片主要负责规则选择和状态收集：泛型实例是否需要生成、typed container 是否走静态 XRT 容器、runtime type desc 是否需要注入、匿名函数捕获如何记录，以及 `auto` / 泛型函数调用如何推断 C 类型。

## CGEN-GENERIC-001 泛型函数实例去重

| 项目 | 内容 |

| 对应生成的 C 代码 | 只生成一份 `xl_gen_max__int(...)`。 |

| 实现同等功能手写的 C 代码 | 手写 C 只会写一份具体类型函数。 |
| 额外依赖的封装代码 | 泛型实例表。 |
