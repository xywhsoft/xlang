# P2 调用解析与默认值细则

本文细化 `xl6_cgen_resolve_match.c` 和 `xl6_cgen_resolve_call.c`。这些规则决定某个 xlang 调用最终绑定到哪个普通函数、泛型函数、class 方法、custom 方法或构造函数，也决定默认值表达式如何生成。

## CGEN-RES-001 字面量与目标参数类型的基础匹配

| 项目 | 内容 |
|---|---|
| xlang 写法 | `foo(1)`、`foo(1.2)`、`foo("x")`、`foo(true)` |
| 生成规则描述 | 字面量匹配用于无法克隆表达式类型时的兜底：int 字面量可匹配 `int/int64/int32`，float 可匹配 `float/float64/float32`，string 只匹配 `string`，time 只匹配 `time`，bool 只匹配 `bool`；其他表达式默认允许进入下一层判断。 |
| 生成器文件名和行号 | `demo6/src/cgen/xl6_cgen_resolve_match.c:1` |
| 对应生成的 C 代码 | 不直接输出；影响调用候选是否可用。 |
| 中间形态伪代码 | `switch literal kind -> allowed target type names` |
| 实现同等功能手写的 C 代码 | C 编译器按原型做字面量转换。 |
