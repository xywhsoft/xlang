# Set 驻留值转换与方法合同

原生 Set 已具备接收和返回语言动态值的方法及快照迭代协议。基础值按内容、
可变对象和容器按引用身份、Future 按控制块身份作为键。转换使用真实 XRT
typed-value 接口，不在 Cgen 中复制转换、哈希表或遍历算法。

语言 Set 的生产者和消费者仍待统一切换；本批是切换所需的驻留接口，不是
三组标准库的总验收，也不改变公开 API 的决策范围。

## 完整类型域与转换

原生 owner 保留完整的逻辑准入、精确物理槽描述和不可变驻留转换器。
转换器不能持有模块上下文；引用槽固定使用共享的 retained-reference 转换器，
保留对象引用而非克隆内容。普通内建槽可使用 XRT 默认转换。

投影绑定在成功和失败路径均消费输入 owner。相同转换器允许重复绑定，
不同转换器拒绝覆盖。克隆、集合代数和快照保留绑定；未绑定 owner 不能调用
boxed 方法。null 与空字符串保持不同，nullable 类型的元素身份与非 nullable
boxed 身份分别验证。内嵌 NUL 不截断字符串和 bytes。

族探测只识别真实生产者，不授予类型准入。所有方法独立检查生产者能力、
完整类型域和操作占用状态，外来句柄不转换为私有 owner，也不回退到 wire Set。
回调重入受 checked 规则约束；处理拒绝必须消费完整失败结果，清除诊断指针
不等于处理了无诊断失败。

## 方法与迭代

驻留方法提供添加、存在检查、删除、读取和取走、数量和容量、清空、预留和收缩、
克隆、哈希、相等、子集、超集、不相交、合并及四种集合代数。添加成功和
“新元素”分别表示，存在检查返回 false 不代表调用失败。输出仅在 checked 成功
时发布，属于原生协议，不重新引入语言 byref。

自定义槽投影在 XRT 取走操作提交删除前验证返回值的逻辑域。即使转换回调
返回 true 或非空 Value，无诊断的首个失败也必须拒绝结果、释放中间值；错误
投影不能导致元素被提前删除。已提交删除后的清理错误仍报告，不能回滚已经
执行的析构。

快照拥有独立存储，保持正向或反向插入顺序。投影与前进合并为一个 checked
步骤；进入迭代操作后的失败是粘滞状态，不冒充 EOF。源集合修改或释放不影响
快照；引用元素仍共享实例，快照不是深拷贝对象图。

## 验收与剩余工作

`check_stdlib_set_native.py` 覆盖严格 C O0/O2，11 条 raw-slot 与 17 条 boxed
完整分配失败前缀，每种优化共 173 次尝试；检查输入数量、输出发布、逐点内存账本、
首错、无诊断失败、投影绑定、nullable string、char、引用、Future 和快照。
八个实际源码变异必须成功编译后被同一测试拒绝，包含取走前准入、无诊断解码
失败、克隆丢失投影和外来句柄误判。

冻结的选定源码分别重建 Windows 和 Linux 编译器，并回归按需组件登记与
相邻 List、持久化路径。Linux ASan/UBSan 覆盖选定原生闭包，不代表整个编译器
或发布 DLL 均已完成 sanitizer 验收。证据位于 `E:/xlang-validation/stdlib53-b188-*`
和 Linux 对应目录；失败尝试保留。

`SET_NATIVE` 按需引入 typed Set Value 能力和驻留引用转换；未使用 Set 时不因
这些接口自动引入组件。后续仍需闭合 XLIR Set 工厂和递归类型域、统一语言方法、
var 分发、迭代、导入与持久化，然后完成 Dict 和发布总验收。DEV-XRT-53 保持
进行中；CRT 0 项、XRT 19 项未决策及对象池最后开发的安排不变。
