# 三组标准库接入长期任务

立项：2026-10-02。状态：进行中；53 是原生模块数，不是 53 个新命名空间。

用户已批准此前评估方案并要求补全及测试。复用 XRT 算法和 xruntime typed
对象生命周期；不把原生内部实现逐个包装为公开类，不在 Cgen 添加库函数体。
每批冻结输入、集中检测、集中修复，再统一验收并提交。专项通过不代表全仓 RC0。

## 批次与验收

1. 文本根基：清理 raw pointer → strlen 的拥有结果；char/bytes、size、UTF-8、数字与编码。
2. Pattern/Regex：编译对象、独立捕获、查找/替换/拆分/集合与资源预算。
3. 系统：绝对/本地/单调时间，文本与 DST；保留 env，封闭 signal 交付线程。
4. 进程：direct/shell、owned streams、完整结果、期限/取消、pipeline、Future、PTY。
5. 容器：typed 基础集合增补、Buffer codecs、Queue/Stack/OrderedMap/SlotMap。
6. 总验收：跨平台严格 C、JIT/AOT、错误/寿命/实际 OOM、生成代码声明化及按需闭包。

每项完成标准：公开文档 + 声明/ABI/效果/所有权 + 运行/负例/裁剪测试。
原生 C 子模块只作为内部依赖的项目，以公共功能覆盖及正确裁剪为验收标准。
CRT 全局 exit、通用非字符串 dict 键、对象池与未批准扩展不计入此次完成范围。

## 已完成批次

### B1：string 拥有结果与声明默认参数（2026-10-02）

已迁移 15 个公开入口：lower/upper、trim/ltrim/rtrim、filter、replace、
slice/mid、left/right、repeat、reverse、removeAt、insert。slice/mid 共用
一个原生入口，共 14 个 resident 符号。完整 API 合同见《文本标准库接入.md》。

- 标准库只保存 extern 声明；可选 size 在语言调用点补齐，物理 C ABI 保持
  完整固定参数。XLIR 校验借入/拥有结果、保守效果和 XRT 线程错误观察。
- 不再经 rawpointer/take-cstr/strlen 恢复结果。返回 Data/Size，保留 NUL；
  byte cap 超出实际输入夹紧，切断 UTF-8 scalar 拒绝，索引使用 scalar。
- 修复 XRT repeat(nonempty,0) 的一字节分配后越界复制；新增
  xrtStrReplaceSized，由同一替换实现交付精确长度，不重扫输出。
- Windows 专项 44 项检查通过：严格 C 编译和执行、TinyCC JIT、独立 AOT、
  确定性、14 份 ABI 合同变异、6 个非法声明/默认参数负例、存量回归。
  原生宿主强制 14 个真实分配失败点，结果/错误/逻辑分配账本均符合合同。
- 独立产物门通过：40 个 resident 组件、1600 对依赖、300 个声明与实际导出
  归属一致；4 个样例的实际原生闭包编译/执行通过。TEXT_VALUE 组件仅在
  使用时选中，STRING/UNICODE_TEXT 为原生根；这不是组件内每个函数的
  链接器级裁剪证明，也不是全仓 RC0 或 53 模块完成证明。
- XRT Windows 模块化与单头字符串测试及公开 API 文档门通过。早期 Linux
  原生 adapter 与 XRT 单头的 ASan/UBSan 检查通过；之后 WSL 不再识别
  发行版，最终版本的完整 Linux xlang/JIT/AOT 仍待验收，不用旧结果代替。

### B2：查询、char/bytes、填充与 glob/距离（2026-10-02）

迁移 25 个已有公开入口并新增 string.glob/string.distance：共 27 个原生
入口，与 B1 合计 42 个公开入口/41 个 resident 符号。补齐查询和多输入
size 参数；charAt 返回 char、byteAt 返回 uint8、chars 返回 array<char>、
bytes 返回连续 bytes。编辑/填充以唯一 XRT 算法交付精确 Data/Size。

- 分离 TEXT_QUERY/BINARY/CHARS/GLOB/DISTANCE 的按需原生根，标准库
  声明不包含算法函数体。XLIR 同时检查参数完整性、语义整数宽度、char
  物理 ABI、array<char> 元素、拥有结果、错误与效果，不用名称猜测语义。
- 集中修复语言集合遗漏的 char 装箱准入/索引/安全索引/dict 键/遍历，
  使用统一 scalar projection；XRT Value Set 拒绝 CHAR/UINT 的旧边界
  已修正，复用已有数值规范哈希，并验证去重与 clone 隔离。
- XRT 新增 PadLeft/Right/CenterSized，原有入口委托同一实现，NUL 长度
  无重扫；普通失败清零，输出与输入别名拒绝且不修改输入，OOM 明确传播。
- Windows 298 项冻结输入检查通过；19 条拥有结果实际 OOM 路径，
  bytes/chars/distance 的独立进程分配失败前缀扫描覆盖 1/212/1 个点，
  部分结果与逻辑分配账本均平衡。8 个正向严格 C/JIT/AOT/确定性样例、
  9 个 ABI/默认参数负例、合同变异与原有标准库回归通过。
- 45 个 resident 组件、2025 对依赖、327 个声明/实际导出身份和 8 个
  独立产物实际原生闭包通过；规范原生登记校验 3601 符号/421 候选根。
- XRT Unicode 文本 modular/single/property/OOM，以及 Value Set 的
  modular/single 回归通过。最终 Linux 全语言宿主仍待验收。

### B3：独立拆分值与类型安全连接（2026-10-02）

split/splitLines/join 三个旧入口迁移为声明，新增 fields；拆分精确返回
array<string>，join 精确借入 array<string>，不隐式转换动态项。与 B1/B2
合计 46 个公开入口/45 个 resident 符号。输入/分隔符/每项 byte cap、NUL、
严格 UTF-8、独立值与失败清理合同见《文本标准库接入.md》。

- 拆分以 XRT 零分配片段迭代器为唯一算法源，仅装配拥有式 STRING 元素，
  避免先构造 xstrlist 后再次复制。输入替换、覆盖数组项和销毁不影响保存值。
- join 建立借入视图表；XRT 新增 xrtStrJoinSized，由旧连接的同一布局/写出
  实现交付长度，无 strlen。普通失败清零，输出与视图表/输入字节别名拒绝。
- XLIR 的数组参数/结果合同同时检查元素 ABI、元素拥有形态、完整数组
  形态、借入参数和效果/错误。拒绝物理载体相同的 array<int>/array<char>。
- Windows 589 项冻结输入检查通过；B3 短字段分配失败前缀扫描为
  split/lines/fields/join 10/10/10/2 点，大字段为 71/71/71/2 点，每个
  扫描另验证最终无故障路径，部分结果与逻辑分配账本平衡。12 个正向
  严格 C/JIT/AOT/确定性样例、11 个 ABI/默认参数负例及原有回归通过。
- 独立产物验证 47 个组件、2209 对依赖、331 个声明/实际导出及 12 个
  实际原生闭包。仅连接不选 TEXT_SPLIT 或 XRT_MODULE_STRING_SPLIT；
  仅拆分不选 TEXT_JOIN。既有语言错误/值转换等基线根仍保留。
- XRT string/string_split modular/single、属性/OOM、sized join 的模块化
  和直接单头边界回归、公开文档门通过；规范登记 3602 符号/421 候选根。
  正式 Windows DLL 重建后新入口及发布示例运行通过。最终 Linux 全语言
