# 三组标准库接入长期任务

立项：2026-10-02。状态：进行中；53 是原生模块数，不是 53 个新命名空间。

用户已批准此前评估方案并要求补全及测试。复用 XRT 算法和 xruntime typed
对象生命周期；不把原生内部实现逐个包装为公开类，不在 Cgen 添加库函数体。
每批冻结输入、集中检测、集中修复，再统一验收并提交。专项通过不代表全仓 RC0。

## 批次与验收

1. 文本根基：清理 raw pointer → strlen 的拥有结果；char/bytes、size、UTF-8、数字与编码。
2. Pattern/Regex：编译对象、独立捕获、查找/替换/拆分/集合与资源预算。
3. 系统：绝对/本地/单调时间，文本与 DST；保留 env，封闭 signal 交付线程。
4. 进程：direct/shell、owned streams、完整结果、期限/取消、pipeline、Future、PTY。
5. 容器：typed 基础集合增补、Buffer codecs、Queue/Stack/OrderedMap/SlotMap。
6. 总验收：跨平台严格 C、JIT/AOT、错误/寿命/实际 OOM、生成代码声明化及按需闭包。

每项完成标准：公开文档 + 声明/ABI/效果/所有权 + 运行/负例/裁剪测试。
原生 C 子模块只作为内部依赖的项目，以公共功能覆盖及正确裁剪为验收标准。
CRT 全局 exit、通用非字符串 dict 键、对象池与未批准扩展不计入此次完成范围。

## 已完成批次

### B1：string 拥有结果与声明默认参数（2026-10-02）

已迁移 15 个公开入口：lower/upper、trim/ltrim/rtrim、filter、replace、
slice/mid、left/right、repeat、reverse、removeAt、insert。slice/mid 共用
一个原生入口，共 14 个 resident 符号。完整 API 合同见《文本标准库接入.md》。

- 标准库只保存 extern 声明；可选 size 在语言调用点补齐，物理 C ABI 保持
  完整固定参数。XLIR 校验借入/拥有结果、保守效果和 XRT 线程错误观察。
- 不再经 rawpointer/take-cstr/strlen 恢复结果。返回 Data/Size，保留 NUL；
  byte cap 超出实际输入夹紧，切断 UTF-8 scalar 拒绝，索引使用 scalar。
- 修复 XRT repeat(nonempty,0) 的一字节分配后越界复制；新增
  xrtStrReplaceSized，由同一替换实现交付精确长度，不重扫输出。
- Windows 专项 44 项检查通过：严格 C 编译和执行、TinyCC JIT、独立 AOT、
  确定性、14 份 ABI 合同变异、6 个非法声明/默认参数负例、存量回归。
  原生宿主强制 14 个真实分配失败点，结果/错误/逻辑分配账本均符合合同。
