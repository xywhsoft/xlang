# 三组标准库接入长期任务

立项：2026-10-02。状态：进行中；53 是原生模块数，不是 53 个新命名空间。

用户已批准此前评估方案并要求补全及测试。复用 XRT 算法和 xruntime typed
对象生命周期；不把原生内部实现逐个包装为公开类，不在 Cgen 添加库函数体。
每批冻结输入、集中检测、集中修复，再统一验收并提交。专项通过不代表全仓 RC0。

## 批次与验收

1. 文本根基：清理 raw pointer → strlen 的拥有结果；char/bytes、size、UTF-8、数字与编码。
2. Pattern/Regex：编译对象、独立捕获、查找/替换/拆分/集合与资源预算。
3. 系统：绝对/本地/单调时间，文本与 DST；保留 env，封闭 signal 交付线程。
4. 进程：direct/shell、owned streams、完整结果、期限/取消、pipeline、Future、PTY。
5. 容器：typed 基础集合增补、Buffer codecs、Queue/Stack/OrderedMap/SlotMap。
6. 总验收：跨平台严格 C、JIT/AOT、错误/寿命/实际 OOM、生成代码声明化及按需闭包。

每项完成标准：公开文档 + 声明/ABI/效果/所有权 + 运行/负例/裁剪测试。
原生 C 子模块只作为内部依赖的项目，以公共功能覆盖及正确裁剪为验收标准。
CRT 全局 exit、通用非字符串 dict 键、对象池与未批准扩展不计入此次完成范围。

### B18a：时间核心的声明化标量接入

本批是 time 的第一段，不是 time/time_local/time_text 完成。补充和迁移：

- `time.fromDate(year, month, day)`、`time.fromTime(hour, minute, second,
  microsecond=0)`、`time.fromDateTime(year, month, day, hour=0, minute=0,
  second=0, microsecond=0, offset=0)`。所有整数先检查再转 C int，月份
  4294967297 等不再绕回合法值。offset 为 UTC 以东秒数，不是当地时区。

  溢出，`time.toUnix()` / `time.toUnixMs()` 对负数向负无穷取整。

### B26：typed Process Future 与通用协作取消（2026-10-03）

`Process.waitAsync()` 返回 `future<ProcessExitStatus>`；非零退出、重复等待、
独立结果、receiver 提前释放及同进程多等待者均有正式夹具。私有
readiness 桥接以精确 `future<bool>`/物理 bool 盒子返回；公开层沿正常

factory 非阻塞但可失败；XLIR 检查 Future carrier、元素、空值/所有权、

公共合同见《进程标准库异步等待.md》。

| `insert(index, string/bytes/Buffer, size = -1)` | 插入原始字节；index 须在 0..length |
| `resize(size, fill = 0)`、`trim()` | 新尾部填充 0..255；trim 收缩至实际长度，包括空值释放 |
| `remove(index, count = -1)` | -1 移除剩余全部；其他越界范围报错，不截断变更区间 |
| `toBytes(size = -1)`、`text(size = -1)` | 独立拥有结果；text 验证完整 UTF-8，保留内嵌 NUL |
| `BufferIter(source, size = -1)`、`for byte in buffer` | 创建时 O(n) 复制一次；每步 O(1)，元素 uint8；源重分配/替换不影响迭代 |
| iterator `close()`、`closed` | 幂等释放快照；关闭或耗尽的 `__next__()` 返回 false、uint8(0) |

size -1 为完整输入，非负 size 截断到实际字节长度，<-1 报 RangeError。
字符串作为二进制输入时允许选取 UTF-8 的原始字节前缀；text 输出不
接受半个 scalar 或非法字节，不能以 strlen/隐式补码页转换掩盖损失。
appendBytes 的旧 string/c_size 外观退出，统一使用 append(bytes, size)。
原有默认/容量构造、单字节和 bulk API 本批未宣称已迁移。

迭代器只拥有复制的原始字节，没有源 Buffer、语言边或生成回调。
native policy 仅按实际 resident Ops 与 Trace 双身份被宿主接纳；不
将任意不透明指针变成可跨对象图的凭据。遍历状态限制在创建线程，
最终退役可在所有权串行化后的其他线程进行。close 先发布关闭/断开
状态，再执行 free，分配器 hook 重入不能重复释放。destroy 保留先前
错误，创建和 valid Take 的失败退役完整，invalid policy 不消费原槽。

删除旧 Cgen 的 NUL 扫描/char* 字符串复制与 raw-parent BufferIter
函数体，减少 emitter 81 行；新接口生成 extern 调用，不再生成这些

## B49：Stack 显式 try 结果与可空值核心合同

## B50：可空标量元素的统一布局与按需原生描述

闭合 B49 收尾复现的 `Stack<int?>` 构造拒绝：bool、I64、U64、float32、

- 原始队列无字符串场景的旧共享模板不再引用未选择的 string helper。
