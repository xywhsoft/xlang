# 原生拥有值的共享闭包存储

2026-10-13。普通原生键和可空原生键已支持可变词法捕获。读写闭包及
嵌套闭包共享同一绑定，函数返回后绑定仍有效；写入替换绑定的拥有值，
不会修改调用者原先传入的基础值。本批不增加参数修饰或公开标准库 API。

## 拥有值传输

新建原生 cell 保存永久的原生叶值描述和独立的零初始化载荷。创建入口
单独登记供应方，旧 Cell V1 操作表保持原布局。V1 通用创建不能直接
创建新原生 kind；原生入口先核对已声明的大小、对齐、复制和清理能力。
cell 不保存生成回调或模块局部描述，载荷也没有语言对象图边。

读取是借用观察。存入其他变量、返回或传给需要独立值的消费者时，IR
明确发出 checked 复制。替换使用既有拥有交换：先发布新值并返回旧的
SSA owner，再独立清理旧值。普通 terminal release 和图清理都先退出
自身 mutation／freeze 再销毁载荷；图清理先 detach 原始存储。

参数提升为 cell 复用统一拥有值取得操作，代替原来的 string／Value
两条专用分支。参数原存储和新 cell 分别拥有独立值，cell 创建失败时
临时取得的值由既有错误边回滚。模块明确登记原生 cell 存储版本，验证器
核对该要求；Cgen 仅选择创建入口、原生描述和已有传输操作。

普通 cell 访问仍由调用者串行化。参与对象图冻结不等于并发变量锁，
本批不授予无锁跨线程修改共享绑定的能力。

## 语言核心修正

函数类型参数的 nullable 后缀现在由普通与虚拟 token 类型识别器一致
消费。函数值调用推断消费完整已检查签名；命名函数值先解析类型别名，
保留单返回值的 nullable 结构，不回退为不完整的类型名字。

可变捕获按内建 ABI 能力准入原生值，不按 `SlotMapKey` 拼写放行。
只读兄弟闭包与嵌套闭包继续使用绑定已确定的 cell 表示，不能保存写入
之前的旧快照。测试同时覆盖普通键、可空键、别名函数签名、来源参数、
await 后的引用、生成器完成与提前退出。

## 双平台验收

Windows 323、Linux 322 个完整源码编译单元通过。专项分别通过 522、
571 阶段，包含严格独立 C O0／O2、实际 JIT、module 和 AOT；每个
优化等级执行 100 次 checked 主入口及模块清理。

每端 408 次完整复制／分配前缀通过。失败后清理并重试，内存数量和
字节平衡通过。注入限于调用线程，不代表 executor 线程 OOM 已认证。
7 个共享捕获和 3 个拥有交换的 11 项 IR 篡改均被验证器、C／头文件
发射和原生计划拒绝。

每个优化等级运行 1000 次共享交换，检查独立取得的值在 cell 终结后
仍有效；包含 1002 次描述清理、图退役、未初始化 cell、错误描述与
两次创建分配失败。健康清理不触发分配。跨线程 try-freeze 探针核对
销毁不在 cell 的 mutation／freeze 中。两个实际坏供应方分别省略
原生析构或保留 cell mutation，均被拒绝。

Linux ASan／UBSan 覆盖生成程序、全部 42 个所选供应方及两个宿主。
旧 nullable 闭包／cell、原生只读捕获及 13 种旧 cell 形状每端完成
16 个 JIT／module／AOT 阶段；包括 string、var 和 nullable string 参数。
此前六类可空原生元素专项在新编译器上通过双端回归。

整批三组声明／严格 C 检测每端 294 夹具、587 阶段通过。驻留目录
通过 284 组件、1458 个精确导出和 13 个拒绝对照；基本程序仍只有
原先三个供应方，不选择原生 cell 组件。

证据位于 `E:/xlang-validation/stdlib53-b251-*` 与 Linux 的
`/var/tmp/xlang-stdlib53-b251-*`。最终证书核对所选源码、完整编译输入、
产物及日志；中途失败尝试和诊断部分链接不计入最终验收。
