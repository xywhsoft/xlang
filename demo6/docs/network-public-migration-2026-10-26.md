# 网络旧用例迁移与显式关闭：2026-10-26

本批修复 TCP 的真实生命周期缺陷，迁移旧网络 fixture／范例与重叠 BAT
断言，并使用重新正常构建的两端产品验收；不是五组长期任务全部封板。
只使用数值地址、自有字面回环和本机接口元数据，不做公网 DNS、探测或
网络／密码学安全专项。未修改独立 XRT、固定快照、时间 ABI 或 Cgen。

## 明确的关闭合同

用户批准：显式 `close()` 成功后保留已排队发送，直至真实物理关闭；随后
失去最后语言引用不能将它改成中止。没有显式关闭的自动释放仍中止，
显式 `abort()` 优先且不能被后续 `close()` 撤销。

旧实现的 last-owner retirement 无条件调用 native Abort，违反上述合同。
现在由私有原子关闭状态区分自动释放、正常关闭、中止；成功 Close 仅将
自动状态 CAS 为正常关闭，Abort 单向覆盖。调用 scope 防止 Close／状态
发布期间退役。真实资源登记、原生 pin 与 Engine 拥有边维持至终态；
退役按实际状态报告 BUSY／ERROR，不伪造完成，也不新增隐藏语言 owner。

这不承诺对端应用已消费数据或关闭必定在有限时间内完成；Engine／模块
整体关闭与独立取消是更高层清理边界。详见 [TCP 合同](tcp-managed-transport.md)。

原生测试在实际 NetEngine 工作线程上设置有界事件门，阻止 native I/O，
排队 65,536 字节、Close 两次并释放最后 owner，等待真实退役 worker 已
尝试处理后才放行；检查全字节（含 NUL）送达、实际物理关闭和堆账本。
检查用 Hold 不增加语言 owner；另测 Close→Abort→Close 不撤销中止。
四个真实错误实现必须失败，包括恢复旧的无条件 Abort 实现。

## 旧用例与公开面

先对 187 个原始网络相关文件做只编译发现，保留首轮失败记录；8 个旧
正例仍依赖已退役 API，另一个 Redis 包依赖问题不纳入本批扩展库修改。
迁移这 8 个正例、3 个公开范例，并把另 2 个 resolver 用例改为数值地址，
不使用公共 DNS。保留真实 TCP／UDP 传输、NUL、异步拥有 bytes、实际
NetBuffer 链、跨 16 项旧快路径边界的 vector／batch，以及 checked 清理。
新增两个负例，拒绝用异构动态数组冒充精确 Buffer／UdpMessage 数组。

`03_core_base_10.bat` 与 `08_stdlib_extended.bat` 只迁移用户明确批准的
网络重叠断言：检查驻留调用和旧生成实现缺席，不要求旧 wrapper 或 string
Future；其他 CRT／字符串工作区修改不纳入提交。六段实际 BAT 断言在
新产品生成 C 上执行，不只检查文字存在；三份 xlang/C 范例结果逐行一致。

新增 `check_network_public_shipping.py` 与明确的 18 用例清单。公共宿主
每个正例只编译一次，检查 typed／lowered IR、重复 C 一致性、头文件、
JIT、module、checked 退役和 AOT。再做 GCC O0／O2 严格 C、迁移后的
独立 AOT 执行及导入检查、普通 CLI；负例拒绝 C／header 且无部分输出。
只有三个真实产品进入隔离部署，不提供源码或替换对象。GCC 所需规范
声明 SDK 单独提取，不以源码实现替代产品 VFS。

源码批量控制器另支持显式清单，默认 30 正例＋4 负例不变；六种非法
清单在访问编译 cohort 或创建输出前拒绝。源码批次不冒称发布验收。

## 仍开放

TLS Stream 目前仍有 last-owner 直接 Abort 路径，必须核对组合对象的显式
关闭与物理完成合同；本批 TCP 成功不能代替它。其余跨组逐项矩阵、相关
嵌套编译／IDE 覆盖和完整 RC0 条件继续核对。整个工作区仍有无关未提交
改动，本文候选是明确冻结的输入，不是发布全部工作区的声明。

本轮另试 Windows PowerShell 5 的全局 XLIR 入口，当前源码 driver 构建器
使用该宿主不存在的 `Path.GetRelativePath`，在构建前置阶段停止；没有把
它记为本轮守卫通过。两版 PowerShell 的 BAT wiring 与实际六段 BAT
断言已通过；该源码构建器兼容问题另行修复，不以旧 cohort 冒充当前源码。

未决策 CRT 0／XRT 11；内存池最后，不扩展未批准模块。
