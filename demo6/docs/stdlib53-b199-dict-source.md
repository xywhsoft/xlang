# Dict 原生语言工厂与驻留方法

2026-10-11。Dict 字面量、默认值、类字段默认值和命名可变参数包改用
真实 typed Dict 驻留所有者；擦除到 var 是显式 Value 操作，不是 wire
对象的类型重标。Set 键规则保持：基础值按内容，可变对象／容器按引用身份。

## 语言与运行时合同

Typed XLIR 用完整 Dict 构造配方提供家族、精确文本键、元素存储与准入域。
规范 Dict 词汇在源类型之后登记，隐式字面量不依赖其他 Dict 声明存在。
命名可变参数的 parser 简写在 Typed 边界规范化，不让后端解释源类型名。
每个字面量在元素计算前保护部分容器，键使用完整 string SSA 和 xstrview。
静态及 erased 索引保留内嵌 NUL；动态算术复合赋值复用统一 checked 算术合同。

count、nullable count、capacity、contains、remove、clear、reserve、trim、
take、浅复制、右优先合并和减键调用 `xl6_dict_methods` 的 13 个驻留入口。
负 reserve 是 RANGE；缺失 remove 返回 false，缺失 take 返回拥有型 null。
合并和减键在私有结果上工作，失败不发布部分结果或修改输入。take 先取得
有效拥有型元素再移除键；已提交的修改不因后续清理错误承诺回滚。

原生权限来自实际所有者、布局和完整准入域。显式 wire OBJECT 仍可用于
宿主／持久化边界；它不承担语言工厂。两个输入的原生／wire 四种合并组合
都经过实际提供方验证。错误作用域失败、无诊断失败和退役首错独立处理。

Cgen 只根据已验证的 RuntimeOp、类型 ABI 和声明选择入口；删除旧的两个
Dict 代数算法模板，不恢复 AST／方法名称，也不按提供方符号名前缀猜家族。
公共 List／Set／Dict 构造管线在工厂失败后停止投影，保留原始失败。

## 验收范围

Windows／Linux 冻结源码完整重建分别为 294／293 个对象。两端主专项
各完成 203 阶段、98 条方法／生成函数完整故障前缀；17 个实际构造入口
和 12 次方法／代数调用执行了 255 次 IR 篡改拒绝，全部在 C／头文件输出前拒绝。
5 个独立编译的错误实现对照全部被检测，JIT 与严格 O0／O2 按需 AOT 通过。

主夹具的模块初始化在 O0／O2 各完成 438 次分配尝试，精简夹具各 65 次，
均覆盖首次无故障、反复初始化／终结和内存账本。精简生产闭包独立链接，
不包含 List／Set／嵌套 Dict schema 提供方。Linux 所选原生专项另通过
ASan／UBSan 的 65 阶段、90 条完整前缀；不外推为完整共享库或编译器认证。

Dict 动态／精确索引、List 索引、Set 源入口与实际目录的邻近回归均通过。
最终来源证书逐项核对选择源码、编译输入和产物哈希；实际目录为 255 个
组件、1352 个导出、65025 对依赖和 13 个被检测的错误目录对照。
旧文档守卫 14 项历史失败和两项文本守卫历史首个失败须独立记录，不计为全仓通过。
入口为 `tools/check_stdlib_dict_source.py`；证据根为 E 盘 `stdlib53-b199-*`
和 Linux `/var/tmp/xlang-stdlib53-b199-*`。早期夹具语法错误、失效的旧裁剪
断言、提供方管线失败以及并发选择索引导致的一次冻结失败均保留。

MemoryDebug 仅作为测试账本扩展，不把它算作生产组件根。

作用域注入使用 GNU ld 包装，覆盖 checked 原生 Dict 工厂／投影／合并／
减键提供方内部的入口。它不证明真实 OS 上下文耗尽可恢复；既有生成的
语言展开 TLS 重绑定仍采用致命不变量规则，本批不修改或认证这一规则。
