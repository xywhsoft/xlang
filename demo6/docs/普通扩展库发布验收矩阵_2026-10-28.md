# 普通扩展库发布验收矩阵（2026-10-28）

## 口径与基线

本表逐名对照[普通扩展库优先级清单](普通扩展库开发优先级_2026-10-12.md)，
P0/P1/P2/P3 为 13/30/24/33，合计 **100 个，唯一且无遗漏**。
活动发布目录中没有 `acme`；`xbot` 仍存在，但不在本任务中，不删除。
XRT 专门维护包、XUI/XGE 等继续由独立上下文维护，不重新计入普通队列。

整理起点为 `bb7c6b45e`，本工作树的编译器源码基线为 `d64672903`。
本轮开始时 master 已到 `8f71d3014`，尚未合入本工作树。
2026-10-28 按用户许可执行标准 build.bat，三件套与附属验证程序重建
成功；三件套哈希仍与下表一致，拥有型导出的跨包 JIT/AOT 通过。
本工作树的主线源与 XRT 均未改，没有同步最新 master。
因此下列现场结果只描述已固定的发布物，**不能宣称最新 master 的状态**。

证据分两层：分包 README 记载的既有门禁，以及本线程本轮/近期实际执行结果。
这不是 100 包的再次全量回归，也不是最终发布完成证明。每个包的名称链接
指向其证据与 API 合同；“有通过记录”不能自动升级为新编译器上的当前绿灯。
