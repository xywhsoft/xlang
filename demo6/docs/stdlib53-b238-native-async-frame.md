# 原生拥有值在异步帧中的保存和退役

完整 SlotMapKey 已接入真实 await 机器。原生键参数取得独立拥有值，
局部键、复制结果和成对游标可保存跨两次 await；正常恢复、恢复后
抛错和 finally 都按统一 IR 的拥有动作交接与清理，不经过装箱。

本批不改变 XRT／xruntime 算法，也不另建调度器。Future 原生结果、
原生 callback／task 捕获、Future 元素遍历、WaitQueue 和三组发布
总门仍待完成；对象池仍最后，未决策范围没有扩大。

## 物理帧和语言合同

新增 ContinuationFrameLayoutV3 与 FrameRuntimeV5 Allocate，接收
独立 V2 捕获描述。旧 V2 描述不被强转成新描述；实际 ticket、Watch、
source 和 outer 字段仍由同一运行时验证尺寸、对齐与相互不重叠。
捕获槽和初始化标志不能覆盖这些输送字段。

V2 捕获引擎使用物理帧的实际分配长度。复制成功才提交槽和初始化
标志；源与后继帧的交接及回滚继续消费精确动作列表。帧私有销毁、
词法清理和最终退役使用同一捕获清理方法，精确类型槽先清空，
资源释放在 mutation／freeze 之外执行。

队列、Watch、稳定 producer、代码租约和 once-only 取消状态机
保持原实现。新旧帧使用同一真实引用和收集适配器；独立 pin 可保留
已退役的物理帧，但不能延长已经清空的语言拥有槽。

统一 IR 新增 native-value async 参数捕获与新版物理帧 ABI。
Cgen 输出已验证的 V2 捕获、常驻发布符号及类型化空值，原生
结构体不会被初始化成 NULL。独立 borrowed SSA 原生复制 spill
尚无完整失败边界，仍明确拒绝，不增加隐藏错误路线。
