## 维护要求

- 新增或修改语言规则时，先更新 `demo6/docs` 中对应设计文件。
- 新增或修改代码生成行为时，同步更新 `demo6/cgenrule` 中对应 `CGEN-*` 规则和验证矩阵。
- 新增测试或范例后，如它证明某条规则，应同步补入对应验证矩阵。
- 新增设计文档后，必须把文件加入 `demo6/docs/README.md`。
- 新增、删除、重命名文档或改变文档身份后，必须同步维护 `demo6/docs/文档状态矩阵.md`。
- 新增 `README.md` 入口文档后，必须同步登记到文档索引口径；构建产物临时目录和第三方依赖副本不作为 DEMO6 文档入口。
- 新增或修改范例 README 后，必须保持其命令行示例不硬编码旧工具链路径；工具链默认值只允许集中在 `tools\xl6_toolchain_env.bat`。
- 不再使用裸待办标记作为设计状态；未完成内容应写成“当前边界”“后续设计议题”或“暂缓能力”。
