# xlang DEMO6 表达式与控制流设计

本文档记录 DEMO6 已确认的基础运算符、表达式和控制流口径。

本文档只包含基础语言能力，不包含：

- 模块系统。
- 错误处理。
- 异步、协程、生成器。
- class/native-backed class 的成员解析与生命周期细节。
- 运算符重载。
- 调用侧参数展开。
- `new` / `delete` 对象生命周期。

## 1. 总原则

本文件中的设计必须服从 DEMO6 第一绝对原则：xlang 能够和 C 完美混编。

因此：

- 基础运算符应能直接 lowering 到清晰的 C 表达式或简单 helper 调用。
- 控制流应能直接 lowering 到清晰的 C 控制流。
- 不在基础表达式层引入动态分发、反射或隐式运行时机制。
- 对象分发、异常传播、异步状态机等高级语义后续单独设计。

## 2. 运算符

### 2.1 赋值

基础赋值：

```xlang
a = b
```

复合赋值：

```xlang
a += b
a -= b
a *= b
a /= b
a %= b
a **= b
```

空值赋值：

```xlang
a ?= b
```

规则：

- `a ?= b` 表示当 `a` 为 `null` 时才赋值为 `b`。
- 赋值目标必须是可赋值左值。
- `const` 目标不能被赋值或复合赋值。
- 赋值是语句能力，不作为普通表达式产生值。

### 2.2 算术

```xlang
a + b
a - b
a * b
a / b
a % b
a ** b
```

规则：

- `**` 表示幂运算。
- `**` 右结合。
- `+` 同时用于数值加法和字符串拼接；具体类型规则后续在类型检查中细化。

### 2.3 比较

```xlang
a == b
a != b
a < b
a <= b
a > b
a >= b
a ~= b
a in b
```

规则：

- `==` / `!=` 表示相等/不等。
- `<` / `<=` / `>` / `>=` 表示有序比较。
- `~=` 表示近似相等。
- `in` 表示成员/包含判断。

类型细则：

- `~=` 表示近似相等，按类型静态分派到对应 typeops/helper。
- 整数近似相等使用 XRT 的 `xrtIntApprox`。
- 浮点近似相等使用 XRT 的 `xrtNumApprox`。
- 字符串和时间近似相等沿用 DEMO5 的设计方向，但必须优先落到 XRT；如果 XRT 暂时缺少对应函数，则放入 xlang 补充 helper，按 XRT 命名风格实现，后续迁入 XRT。
- `in` 采用 Python 风格成员判断。
- `value in array/list` 判断值是否存在。
- `value in set` 判断集合成员是否存在。
- `key in dict` 判断字典键是否存在。
- `sub in string` 判断子串是否存在。
- `value in range(...)` 判断整数是否落在 range 序列中。

### 2.4 逻辑

```xlang
a and b
a or b
not a
!a
```

规则：

- `and` 与 `or` 短路求值。
- `not` 与 `!` 都表示逻辑非。
- 条件表达式的结果必须是 `bool`。

### 2.5 位运算

```xlang
a & b
a | b
a ^ b
~a
a << b
a >> b
```

规则：

- 位运算面向整数类型。
- `~` 表示按位取反。

### 2.6 空值与条件

空合并：

```xlang
a ?? b
```

三元条件：

```xlang
cond ? a : b
```

规则：

- `a ?? b` 表示当 `a` 非 `null` 时取 `a`，否则取 `b`。
- `cond ? a : b` 中 `cond` 必须是 `bool`。
- `?:` 只作为表达式存在，不替代 `if` 语句。

### 2.7 成员与索引

成员访问：

```xlang
obj.name
obj?.name
```

索引访问：

```xlang
obj[index]
obj?[index]
```

规则：

- `obj.name` 表示普通成员访问。
- `obj?.name` 表示安全成员访问。
- `obj[index]` 表示普通索引访问。
- `obj?[index]` 表示安全索引访问。
- 安全访问在 receiver 为 `null` 时返回 `null`。
- 对象动态成员、元方法、operator dispatch 不属于本文基础口径。

### 2.8 range

DEMO6 第一阶段不设计独立的范围运算符。

range 采用 Python 风格函数式写法：

```xlang
range(stop)
range(start, stop)
range(start, stop, step)
```

规则：

- `range(stop)` 表示从 `0` 到 `stop`，不包含 `stop`。
- `range(start, stop)` 表示从 `start` 到 `stop`，不包含 `stop`。
- `range(start, stop, step)` 使用显式步长，`step` 不能为 `0`。
- 第一阶段 range 只支持整数。
- `stop` 采用排除边界，保持与 Python 一致。
- `step` 可以为负数。
- `range(...)` 产生可用于 `for in` 和 `in` 判断的 range 值。
- DEMO5 中曾实现过 `..` / `OP_RANGE`，但它不是 DEMO6 当前口径的一部分，第一阶段不进入词法和语法。

### 2.9 箭头

```xlang
func(int x) as int => x + 1
```

规则：

- `=>` 用于箭头匿名函数。
- 详细函数语法见 `函数设计.md`。

## 3. 运算符优先级

DEMO6 基础表达式优先级从高到低如下：

```text
1.  ()  []  .  ?.  ?[]
2.  一元 +  一元 -  not  !  ~
3.  **
4.  *  /  %
5.  +  -
6.  <<  >>
7.  <  <=  >  >=  in
8.  ==  !=  ~=
9.  &
10. ^
11. |
12. and
13. or
14. ??
15. ?:
```

结合性：

- `**` 右结合。
- `?:` 右结合。
- 其他二元运算符默认左结合。

说明：

- 赋值类语法是语句，不进入普通表达式优先级。
- `::` 由泛型显式实例化使用，详见 `泛型设计.md`。
- `:` 仍用于字典/list 字面量中的键值分隔，以及 `?:` 的条件分支分隔。

## 4. 表达式基础

### 4.1 字面量表达式

支持：

- `null`
- `true` / `false`
- 整数字面量。
- 浮点字面量。
- 字符串字面量。
- time 字面量。
- 数组、列表、集合、字典字面量。

字面量细节见 `语言基础设计.md`。

### 4.2 名称与括号

```xlang
name
(expr)
```

规则：

- 名称表达式引用变量、常量、函数、类型等符号。
- 括号用于改变表达式组合顺序。

### 4.3 一元表达式

```xlang
+a
-a
not a
!a
~a
```

规则：

- 一元 `+` / `-` 面向数值类型。
- `not` / `!` 面向 bool。
- `~` 面向整数类型。

### 4.4 二元表达式

二元表达式包括：

- 算术表达式。
- 比较表达式。
- 逻辑表达式。
- 位运算表达式。
- 空合并表达式。
- 成员判断表达式。

### 4.5 调用表达式

普通函数调用：

```xlang
f(a, b)
```

命名参数调用：

```xlang
f(a, mode = "write", retry = 3)
```

方法调用：

```xlang
obj.method(a, b)
```

泛型显式实例化调用：

```xlang
max::<int>(1, 2)
```

规则：

- 表达式位置不采用 DEMO5 的 `f<T>(value)` 泛型调用。
- 命名参数只允许出现在调用参数表中。
- 由于赋值不作为表达式，`name = value` 在调用参数表内没有普通赋值二义性。
- 位置参数必须位于命名参数之前。
- 命名参数与可选参数、`***` 字典可变参数的匹配规则见 `函数设计.md`。
- 方法调用语法可以用于普通类型方法、class 方法、native-backed class C API 映射等场景。
- 具体分发规则不在本文展开。

### 4.6 成员表达式

```xlang
obj.name
obj?.name
```

规则：

- 普通成员访问要求 receiver 非空。
- 安全成员访问允许 receiver 为 `null`。
- 对 class 字段、class 方法、native-backed class extern 方法的具体解析顺序后续在类型系统设计中细化。

### 4.7 索引表达式

```xlang
obj[index]
obj?[index]
obj[index] = value
```

规则：

- 索引表达式可用于数组、列表、字典等容器。
- 安全索引访问允许 receiver 为 `null`。
- 索引赋值要求左侧为可赋值位置。

### 4.8 类型构造/转换表达式

```xlang
int(value)
float(value)
string(value)
point(value)
```

规则：

- `Type(expr)` 表示类型构造或类型转换。
- 是否允许自定义类型构造、构造参数规则、失败诊断等后续在类型系统中细化。

## 5. 控制流

### 5.1 if

基础形态：

```xlang
if cond
    ...
elseif other
    ...
else
    ...
end
```

`then` 形态：

```xlang
if cond then
    ...
end
```

单行形态：

```xlang
if cond then return 1
if cond then return 1 else return 2
```

规则：

- 条件必须是 `bool`。
- `elseif` 可以出现多次。
- `else` 最多出现一次。
- `if` 块必须用 `end` 结束，单行形态除外。

### 5.2 while

```xlang
while cond do
    ...
end
```

规则：

- 条件必须是 `bool`。
- 循环体必须用 `end` 结束。

### 5.3 do-while

```xlang
do
    ...
while cond
```

规则：

- 循环体至少执行一次。
- `cond` 必须是 `bool`。

### 5.4 for-in

单变量：

```xlang
for value in values
    ...
end
```

双变量：

```xlang
for index, value in values
    ...
end

for key, value in dict_value
    ...
end
```

range：

```xlang
for i in range(10)
    ...
end

for index, value in range(2, 10, 2)
    ...
end
```

range 规则：

- `range(stop)`、`range(start, stop)`、`range(start, stop, step)` 与表达式章节一致。
- range 的 `stop` 不包含在序列内。
- `step` 不能为 `0`。
- 第一阶段只支持整数 range。

基础 iterable：

- `array`
- `list`
- `set`
- `dict`
- `range`
- `var` 持有的上述容器

暂不纳入本文基础口径：

- generator。
- class/native-backed class iterator 分发。
- 异步迭代。

### 5.5 break / continue

```xlang
break
continue
break 2
continue 2
```

规则：

- `break` 跳出当前循环。
- `continue` 继续当前循环下一轮。
- `break N` 跳出第 N 层循环。
- `continue N` 继续第 N 层循环。
- `N` 必须是正整数常量。

### 5.6 return

无返回值：

```xlang
return
```

单返回值：

```xlang
return value
```

多返回值：

```xlang
return a, b
```

规则：

- `return` 必须匹配当前函数声明的返回值数量和类型。
- 无返回值函数可以使用 `return` 提前退出。
- 多返回值函数使用逗号分隔返回值。

## 6. 暂缓并入项

以下 DEMO5 能力不作为本文基础口径并入，后续单独设计：

- `try` / `catch` / `finally`。
- `throw`。
- `assert`。
- `async` / `await` / `future` / `task` / `channel`。
- `yield` / `generator`。
- `new` / `delete`。
- `op_call`、`op_index`、`op_index_set` 等 operator dispatch。
- 动态成员、对象虚分发、元方法。
- 调用侧数组展开。
- 调用侧字典展开。

说明：

- 函数定义侧的 `...` / `***` 可变参数已在 `函数设计.md` 中固定。
