# 统一图深复制合同与恢复隔离

Dict-only、Set 内嵌 Dict 和其他混合集合的深复制已改为统一 IR
提供方计划。生成 C 只传递计划并调用一个驻留图引擎，不再根据
List／Set 组合选择不同的生成门面。本批不改变公开 API，也不代表
三组 53 模块或发布二进制已完成验收。

## 复制与恢复合同

旧深复制选择器丢弃 Dict 位，含 Dict 的类实际复制后仍共享原容器。
深复制指令现在声明完整的 List／Set／Dict 提供方集合；最终 lowering
统一生成该字段，验证器独立重算源类型的完整存储图。持久化跳过的
字段仍参与复制，派生布局、开放类型和递归域也保留所需能力。

叶类型使用既有无提供方入口，非叶使用
`xl6ValueDeepCloneNativeV1(value, graphPlan)`。同步、async 和 generator
共用同一物理调用。所有子边进入同一个引用映射，副本内部仍共享同一
子对象，但不会共享原可变容器。Set 的基础键按内容、可变对象和容器
按引用身份；深复制后的身份键属于副本，继续修改内容不破坏成员查询。

JSON／XLON 共享默认子对象的隔离节点也声明完整计划。一个参数的
恢复回调仅作 ABI 适配，不包含遍历或复制算法。持久化投影复用同一
提供方集合，List 数据投影仍使用 compact 提供方，普通复制保留稀疏键。
`xl6ValueDeepCloneNativeV1` 从 AOT 专用表迁入共用 JIT／AOT 登记，
没有新增导出函数、原生组件或 XRT 算法。

## 专项验收

Windows 和 Linux 完整源码分别构建 295 和 294 个对象。四个语言
用例覆盖 Dict 类及直接容器、混合 Array／List／Set／动态图、async／
generator，以及独立 JSON／XLON 恢复隔离；生成 C 确定性、JIT 和
独立裁剪产品均通过。

- 每端 258 个专项阶段，10 条深复制指令和两个恢复隔离节点。
- 74 项真实 IR 篡改在输出 C 或声明头前拒绝；包括漏选 Dict、未知
  提供方、错误操作码、操作数、类型和错误分支。
- 严格 C11 O0／O2 各四条完整分配故障前缀，每端共 1778 次运行，
  每条到达首次未命中注入的成功运行，并核对释放账本。
- 一个实际编译的错误实现保留合法图计划但省略 Dict 提供方；运行
  时副本隔离断言失败，不能把编译失败当作负对照通过。
- Dict-only 和 continuation 产品不带 List／Set 提供方；所有新产品
  不带旧按组合分拆的深复制门面。
- Linux 的 O0 所选生成／运行时闭包通过完整 ASan／UBSan 前缀，
  O2 独立严格运行；没有宣称整个编译器或发布动态库 sanitizer 通过。

驻留目录保持 256 个组件、1354 个实际导出、65536 个依赖对与
13 个负对照。相邻 copy、Set、Dict 导入和恢复提供方回归使用实际
源码构建；选择源码与实际输入、头、对象和产物逐项核对。
夹具中原生专用测试函数原来误带旧门面进裁剪产品，已与语言共用
观察函数隔离；原生专用向量及错误实现检查保留。

专项证据为 `E:/xlang-validation/stdlib53-b202-verify-win-dev1/` 与
`/var/tmp/xlang-stdlib53-b202-verify-linux-dev1/` 的 `graph-clone`；
更新后的相邻 copy 和恢复回归在双端 `stdlib53-b202-extra-*-dev1/`。
最终选择源码及产物证书使用双端 `stdlib53-b202-index-*-dev5.json`
和 `stdlib53-b202-products-*-dev5.json`。

## 仍需修复的核心边界

混合全局状态下的 JIT 恢复仍有缺口。模块租约可达全部全局对象，
但当前恢复读边界只声明目标类型的容器家族。目标只有 Dict、其他
全局已初始化 List／Set 时，实际 JIT 恢复返回 checked 状态错误；
同一独立裁剪 AOT 产品正常。后续需要在统一 IR 中声明完整的活跃
模块图读取能力，不能靠放宽未知资源认证解决。

`for item in object.members` 的直接字段接收器另有迭代 ABI 准入缺口；
具名 typed Set 的迭代路径已通过。本批保留这两个失败证据在开发
快照及诊断产物中，不把独立用例通过解释为混合模块场景已完成。

直接槽优化、完整资源策略、性能、全 53 模块和 shipping 总验收继续。
原有 14 项文档索引诊断和两个文本 guard 的历史首错不变，不宣称
这些 guard 全局通过。CRT 无未决项，19 个 XRT 未决策组不扩展，
对象池最后；长期任务保持进行中。
