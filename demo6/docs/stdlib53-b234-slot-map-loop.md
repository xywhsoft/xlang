# SlotMap 原生遍历与退出清理

SlotMap 的普通函数遍历已经接通 Sem、统一 IR、Cgen 和原生游标。
单变量取得完整 SlotMapKey，双变量取得同次快照的键和值；丢弃绑定
分别选择仅键、仅值或计数入口。原生完整键跨 yield 的帧合同仍未完成，
对应生成器明确拒绝生成 C；这不是 SlotMap 全执行模式或三组标准库封板。

## 公开遍历语义

`for key in slots` 遍历完整键，`for key, value in slots` 遍历同次捕获
的键和值。`for key, _` 不复制值，`for _, value` 不复制键，`for _`
和 `for _, _` 只捕获初始数量。四种工厂由 IR 操作明确选定，生成 C
没有按源类型猜测键语义、字典回退或整数槽号降级。

快照捕获后，clear、删除或销毁原表不改变已捕获的遍历结构。基础值按
已有值合同复制，对象和容器保留已批准的引用语义，不等于深克隆。
完整键拥有独立实例记录，保留实例身份和代际，但不让原表及其元素
继续存活；退出循环后保存或返回该键仍然安全。

遍历中的字符串和 bytes 保留精确长度，包括内嵌 NUL 和 UTF8。
公开验收覆盖 int、窄整数、char、nullable 标量、string、nullable string、
bytes、nullable bytes、原生键值、类对象和嵌套数组。

## 类型和生命周期合同

SlotMap 的键数组词汇在完整类型闭包阶段建立，然后再派生布局、准入
和持久化合同。程序无需调用 keys 或把键存为元素，才能取得合法的
遍历类型；循环分类不再引入过晚的未规划数组。

来源获取采用 IR 已确定的 named borrow、owned temporary 或 observed
collection 合同。临时来源与观察所得来源在捕获期间保持拥有权，成功
捕获后通过统一清理事务释放；捕获或清理失败都保留真实错误结果。

完整键通过 xl6ValueIteratorKeyCopyV3 直接复制到空原生结果，不先装箱
再拆箱。验证器跟踪隐藏游标和单次初始化的待提交临时存储，证明其
来源确实有键通道；仅值或计数游标不能伪装成键生产者。

工厂 NULL、键复制的 bool 加输出、推进的成功与 found 是不同合同。
没有可分配的诊断对象时，失败仍进入 checked 错误路径，不伪装成 EOF。
键和值在成功发布之后才成为迭代拥有者；break、continue、return、
throw、finally、投影失败和首次推进失败均复用统一退出清理。

生成器仅值遍历使用既有游标和拥有字符串帧，正常耗尽及提前关闭均有
语言执行验证。持有完整原生键跨 yield 仍明确拒绝；原生键跨 await、
原生值生成器结果及 Future 元素遍历须继续闭合，不能由同步专项推定。

## 双平台源产物验收

Windows 和 Linux 分别从 314 和 313 个当前源码编译单元构建编译器。
每端新循环专项通过 878 个阶段，包含两个语言夹具的 JIT、严格 C、
O0 和 O2 每夹具各 1000 次生命周期执行，以及 510 个完整故障前缀。
四个工厂、直接键复制和分配失败均覆盖首次未命中前缀，失败后同操作
重试，最终内存平衡。Source、SDK、编译对象、日志和产物均固定哈希。

18 种类型和来源形态通过 216 项 typed IR 篡改及两种实际坏实现对照。
52 个原生游标指令另拒绝 786 项合同篡改；两层合计 1002 项。
无输出的失败路径也检查 C 和头文件拒绝发布，而不只检查诊断文字。

完整程序与四个最小遍历程序分别独立链接 O0 和 O2，共 10 个程序，
不链接编译器或发布运行时，也不使用 MODULE_ALL。实际执行和 nm
确认最小程序不带其他游标工厂；仅值和计数不带键 schema 工厂、键
快照或配对生产者。公共 ValueIterator 单元中的共享辅助入口仍属于
公共单元，不宣称其每一个未调用符号都已单独裁剪。

公共 module 和 AOT 程序均执行通过。既有 SlotMap 专项每端通过
780 个阶段、610 个故障前缀、49 个方法合同和 499 项篡改；另有
8 个旧容器遍历夹具的 64 个阶段。Set 和 Dict 的旧计数断言已按当前
原生工厂更新，八个夹具与上个提交的实际生成入口数量逐项一致。

常驻登记每端核对 275 个组件、1427 个实际导出及 13 个拒绝对照。
本批没有增加原生组件、修改 XRT 或 xruntime，既有游标 V2 布局保持
不变。这里验证的是当前源码产物，不等于重新认证 shipping DLL、
内嵌 VFS 或全仓 RC0。
