# DEMO6 本轮工程骨架优化任务

本文档记录本轮长期任务的执行边界，避免优化过程扩大成新的语言功能设计。

## 目标

- 建立 CompileUnit 流程：同一个 `.xl` 文件在一次命令中只解析和语义检查一次。
- 将 ABI 元数据 从“直接打印 JSON”升级为内部元数据模型，再序列化为 `.abi.json`。
- 改造 `run` / `build` 的临时目录，避免并行执行时争用固定文件。
- 为 package resolver 保留结构化入口，不手写临时 JSON 解析器。
- 保持现有语言功能、测试、范例行为稳定。

## 不做事项

- 不新增未设计的语法。
- 不实现完整远程包管理器。
- 不引入 `.xli`。
- 不做 C parser。
- 不把 XRT 改造成只服务 xlang 的专用库。

## 实施顺序

1. 新增 `XL6_CompileUnit`，集中 parse + sem + moduleName。
2. 改造 CLI 内部的 cgen/header/ABI 元数据/build 路径复用 CompileUnit。
3. 新增 `XL6_CompileUnit`，由 AST 构建元数据模型，再输出 JSON。
4. `build` 直接读取 ABI 元数据 模型的 entry 信息，不扫描 JSON 文本。
5. `run` / `build` 使用独立临时目录，保留 `--save-temps` 调试选项。
6. 补充回归测试并运行完整 `test.bat` 与 feature suite。
