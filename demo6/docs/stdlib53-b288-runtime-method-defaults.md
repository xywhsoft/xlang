# 动态方法默认值的 IR 执行合同

动态方法与绑定方法在调用时执行非字面量默认表达式，支持副作用、
接收者、前序参数及已有动态适配类型。显式提供参数时不执行它的
默认值；重载匹配不执行任何默认表达式。

## 求值与拥有

非字面量默认值登记为 PROGRAM，指向独立的 argument-default
IR 函数。函数借入接收者及已经绑定的参数前缀，按原声明顺序执行
表达式，返回独立拥有的值。字符串、bytes、函数值和 typed Array
使用原有类型与生命周期机制，不经过额外的动态装箱往返。

函数具有独立的 checked 失败边界。默认值失败时不会进入目标方法；
调用适配器清理此前取得的参数和默认值，保留原始失败。借入前序
string／bytes 不允许默认返回值与其共享可修改存储，返回使用既有
值复制与 pending-owner 提交规则。

PROGRAM 的声明、函数身份、返回类型、前缀顺序和存储类型由验证器
独立检查。同源适配器可共享精确程序，每个程序只有一个失败边界；可达动态调用
将默认程序及其依赖纳入统一可达性闭包。默认程序产生的 named
adapter 与闭包进入同一 growing work queue，不遗漏晚登记依赖。

## 解析与生成

开放动态接收者上的类方法优先于同名容器操作，即使类方法的参数
数量不符合容器操作也不能提前拒绝。只有满足容器合同的调用才登记
集合 fallback；实际对象不是对应类或容器时仍按 checked 规则拒绝。

Cgen 只输出登记程序的物理调用、状态分支和既有参数清理，不解析
默认表达式，也不按默认函数名称生成算法。常量默认值仍使用原有
精确描述符，不增加表达式执行函数。没有新增标准库 API 或驻留导出。

## 验收范围

`tools/check_stdlib_runtime_method_defaults.py` 覆盖按次求值、命名参数、
接收者、前序依赖、string／bytes 独立值、函数值与 Array 默认值、
绑定方法、越界 wrapping、原始错误及目标未进入。整数常量、File
map／lock、回调、float32 和 bytes 默认值同时回归。

门禁包含确定性 C、严格 O0／O2、JIT、checked module、生产 AOT、
实际裁剪产物、IR 破坏反例和完整同步分配前缀。故意删除动态适配器
字符串释放的生成代码必须被账本检出。Linux sanitizer 只覆盖生成 C
与测试宿主，不代表全部提供方或额外裁剪产物已插桩。

Windows、Linux 普通和 Linux 指定插桩通道各 122 项通过。165 个
默认值／程序身份／前缀／错误与可达性破坏反例在输出前拒绝；
O0／O2 各完成正常用例 92 个、错误用例 25 个同步分配前缀，
包含首次未触发点 91／24，模块退役后账本平衡。删除字符串释放
的坏实现被三条通道检出。双端各 310 个三组夹具通过严格编译；
驻留目录保持 304 组件、1507 导出，92416 对闭包和 23 个负控通过。

普通 erased `xcall` 与匿名闭包的运行时默认表达式按
[动态函数默认参数合同](stdlib53-b289-runtime-callable-defaults.md) 接入；
typed 函数形参准入、异步动态返回、可空函数参数、其他动态编解码、工作线程与对象图故障、模块组合及
真实卸载、完整时区和发布总验收继续；三组 53 模块目标不因此结项。
CRT 无未决项，XRT 19 组未决策、WaitQueue MPMC 与对象池最后不变。
