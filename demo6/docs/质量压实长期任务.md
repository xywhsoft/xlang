# 质量压实长期任务

本文件记录 DEMO6 已实现功能的长期压实任务，目标是持续补齐范例、测试和实现质量，而不是新增未设计语法。

## 当前原则

- 只压实已经实现且设计文档允许的功能。
- 不为了兼容旧版本引入额外回退路径。
- 测试和范例必须进入守门脚本，避免“文件存在但无人运行”。
- 修复优先选择简单直接的实现，尽量减少新抽象。
- 与 XRT 重叠的能力继续优先使用 XRT。

## 本轮继续压实：range 动态 step 0
