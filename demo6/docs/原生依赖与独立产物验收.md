## Windows Regex／Pattern 的精确独立链接

旧 Windows 工具将整组编译器运行时对象带入严格宿主，连带引入未被用例选择的宿主 API。现在每份夹具都由同一实际 IR 产物计划选择驻留源，并单独编译真实发射的 XRT TU；强制包含生成 C 仅用于宿主 TU，避免向驻留源传播 ABI include guard。实现 TU 补上 `lib/xruntime` 包含目录，测试宿主需要的 `MEMORY_DEBUG` 明确作为诊断依赖选择，发射的原始 native 文件本身保持不变。

二十五份夹具都将实际 AOT 保存的 `xl6_xrt_impl.c` 与计划发射内容逐字节核对；严格宿主直接链接所选源，不通过 `xl.dll` 补足依赖。Windows 完整 6,023 项、Linux 完整 6,031 项通过，各保留二十五个正例、十八个 ABI 负例、四个私有成员负例、两个未声明数组负例，以及原生和语言 OOM。两端均运行实际 1,567,504 对目录检查，全部输入、日志、产物和 native 选择另行复核。
