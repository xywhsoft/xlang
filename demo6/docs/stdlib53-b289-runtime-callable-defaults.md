# 动态函数默认参数的 IR 执行合同

普通 `xcall` 与匿名闭包在每次调用时执行非字面量默认表达式。
默认值支持前序参数、闭包捕获、精确 string／bytes 和已有动态桥接类型。
显式提供参数时不执行对应默认值。

## 求值顺序与存储

调用先检查并投影全部显式实参，再按声明顺序执行缺省参数。
后面的实参类型错误不会触发前面的默认值副作用。所有参数准备成功后
才进入目标函数；失败时清理已产生的拥有值并保留首个错误。

PROGRAM 描述符指向独立 argument-default IR 函数，借入前序参数
和源闭包的物理捕获槽，返回独立拥有的结果。描述符和执行地址受既有
闭包代码租约保护。函数身份、返回类型、前缀顺序、捕获上下文、
存储和可达性由 IR 验证器核对，Cgen 不重新解释默认表达式。

默认表达式创建的闭包若修改前序参数，该默认程序显式创建私有 cell。
cell 拥有取得的参数副本，返回的闭包可继续保有它，不修改调用者实参。
实际捕获环境已有的共享 cell 则借入原 cell，不创建不一致快照。
字符串／bytes 索引写入属于值绑定替换，捕获分析按已验证写 ABI
将其登记为可变绑定，容器元素写入不因此变为参数重绑定。

## 编译与错误边界

默认程序复用统一 CFG、pending-owner 提交、参数 cell prologue 和
终端清理。多个同源 named adapter 可共享一个精确默认程序；每个
程序仍只有一个独立失败边界。编译失败路径释放函数的参数 cell 元数据。

常量默认值保留精确描述符，不新增执行函数。本次没有新增标准库 API
或驻留导出；新增的内部描述符不提供发布前 ABI 兼容承诺。

捕获、默认闭包的私有前序参数、nullable string、float32 及原始错误。
