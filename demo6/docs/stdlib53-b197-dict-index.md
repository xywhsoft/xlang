# Dict 动态索引与拥有边界

2026-10-11。原生 typed Dict 已接通语言动态索引：`var source` 的
`source[key]` 读取和赋值通过驻留分发识别真实 Dict，不再把原生载体当作
不支持的对象而返回空值。静态 Dict 工厂、直接槽读取、递归导入及恢复仍继续迁移。

## 索引与错误合同

字符串键传递完整字节跨度，空键、内嵌 NUL、UTF-8 与前缀键互不混淆。
原生分支先验证私有家族，再使用其不可变逻辑域、物理槽和驻留转换。
未经绑定、错误身份、游标、BUSY、转换错误和无诊断失败都经 checked 边界传播，
不能伪装为缺失键。真正缺失键和不支持的动态读取组合保留原有 canonical null 规则。
外部 HANDLE 仅有相同类型编号不能取得 Dict 权限。

读取返回拥有型 Value；字符串投影与源槽独立，引用值保留真实引用，结果可在
替换、清空和释放源 Dict 后继续使用。赋值观察接收者与键，恰好消费一次输入，
成功、准入拒绝和边界无法建立均遵守这一规则。销毁回调不能替换先前失败；
提交后发生清理失败仍返回 checked 失败，不承诺回滚已提交的写入。
没有新增语言借用、参数修饰或 byref 机制。

生成代码仍调用 `xl6ValueIndexReadCopyV1` 和 `xl6ValueIndexSetTakeV1`。
分发和算法都驻留在运行时，Cgen 不追溯 Dict 类型名称、不复制容器实现。
开放动态索引声明包含 Dict 提供方；静态 Array 查询仍不引入该分发闭包。

## 验证范围

Windows 与 Linux 使用冻结源码的完整编译器对象，分别为 292 与 291 个。
O0／O2 运行原生索引、实际生成函数和按需链接程序；JIT 验证显式 wire 输入。
实际生成函数另接受真实 typed Dict 外部输入，并检查正常及失败路径的 `finally`、
调用者输入保留、拥有结果和内存账本。

动态读写的 XLIR 验证覆盖拥有／消费、may-raise、null-result／foreign-scope
物理错误合同。39 次元数据破坏均在 C 与头文件输出前拒绝。
每端索引专项包含 56 条完整故障前缀，覆盖读取命中、读取缺失、插入和替换，
直到每条首次无故障命中。5 个独立编译的错误实现均被拒绝，包括漏掉原生
分支、读写截断 NUL 键和边界进入失败时不消费输入。

裁剪验证分成两个层次：纯生产依赖闭包独立执行生成模块；注入原生 Dict 的
测试另列输入工厂所需的三个提供方及 String 类型模块，不把测试依赖算成
生产选择。Linux 的额外 ASan／UBSan 只覆盖所选原生索引闭包，不代表整个
编译器、共享库或全部生成代码经过 sanitizer。

List 动态索引、Array 拥有读取与写入边界、Set 源入口、Dict 原生基础和通用
消费者复测通过。驻留目录仍为 253 个组件、1335 个实际导出，完整 64009
依赖配对与 13 个错误目录对照通过。文档检查保留 14 项历史失败；两个旧
文本 guard 的首个失败不变，均不记作全仓通过。
