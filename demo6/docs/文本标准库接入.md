# 文本标准库接入

本页记录 B1/B2 文本合同；53 模块剩余工作见《三组标准库接入长期任务.md》。

## 首批 string API

以下函数返回独立拥有的 string，保留内嵌 NUL；成功的空串也拥有有效空值。
输入在调用期只读，返回值之后的修改不影响原始输入或另一次调用的结果。

| API（前置参数） | 追加可选参数 |
|---|---|
| lower(text)、upper(text)、reverse(text) | size = -1 |
| trim(text, chars = "")、ltrim、rtrim | size = -1, charsSize = -1 |
| filter(text, chars) | size = -1, charsSize = -1 |
| replace(text, oldText, newText) | size = -1, oldSize = -1, newSize = -1 |
| slice(text, start, count = -1)、mid | size = -1 |
| left(text, count)、right(text, count)、repeat(text, count) | size = -1 |
| removeAt(text, start, count) | size = -1 |
| insert(text, start, part) | size = -1, partSize = -1 |

`size` 是 UTF-8 **字节上限**：`-1` 使用实际长度；非负数与实际长度取较小值；
小于 `-1` 抛 RangeError。上限切断 UTF-8 scalar 时抛 ValueError（XRT Unicode
错误包含偏移），不静默产出坏字符串。多输入分别设上限，先选片段再执行运算。

`start/count` 是 Unicode scalar 索引/数量；负索引从末端计算，越界范围按 XRT
切片合同夹紧。slice/mid/removeAt 的 `count=-1` 表示余下全部，小于 -1 拒绝；
left/right/repeat 的 count 必须非负，right(text,0) 和 repeat(text,0) 返回空串。
输出长度溢出报 RangeError；分配失败报 MemoryError，不退化为空串。

lower/upper 仅变换 ASCII 字母，不宣称 Unicode case folding。
trim 的空字符集合表示 ASCII 空白 `space/tab/CR/LF/VT/FF`；传入集合按 scalar
匹配，包含 NUL 合法。filter 删除指定集合。replace 是区分大小写、非重叠的
字节子串替换，空 oldText 返回独立原值；三个输入均须是有效 UTF-8。

## B2：查询、字符、字节、填充及匹配

本批迁移 25 个旧公开入口，新增 `string.glob`、`string.distance`，均为
声明直接调用。所有 size 参数为可选字节上限，`-1`/夹紧/非法负值合同同 B1。

| API（前置参数） | 追加可选参数 | 结果/语义 |
|---|---|---|
| len(text) | size = -1 | int；Unicode scalar 数 |
| byteLen(text) | size = -1 | int；原始字节数 |
| compare(left, right, ignoreCase = false)、equals | leftSize = -1, rightSize = -1 | int 的符号 / bool；仅 ASCII ignoreCase |
| contains(text, part, ignoreCase = false)、indexOf、lastIndexOf、count | size = -1, partSize = -1 | bool / scalar 索引 / 非重叠数量 |
| startsWith(text, prefix, ignoreCase = false) | size = -1, prefixSize = -1 | bool |
| endsWith(text, suffix, ignoreCase = false) | size = -1, suffixSize = -1 | bool |
| hasAny(text, chars) | size = -1, charsSize = -1 | scalar 集合相交 |
| isEmpty(text)、isBlank(text)、isUtf8(text) | size = -1 | bool；Blank 仅 ASCII 空白 |
| charAt(text, index) | size = -1 | char；不是 string 或普通整数 |
| byteAt(text, index) | size = -1 | uint8；取原始 UTF-8 字节 |
| chars(text) | size = -1 | array<char>；独立数组，元素为实际 CHAR 值 |
| bytes(text) | size = -1 | bytes；独立连续字节值，不是整数数组 |
| remove(text, part, ignoreCase = false) | size = -1, partSize = -1 | string；删除非重叠子串 |
| padLeft(text, width, pad = " ")、padRight、padCenter | size = -1, padSize = -1 | string；width 为 scalar 数，保留精确 NUL 字节长度 |
| like(text, pattern, ignoreCase = false) | size = -1, patternSize = -1 | bool；glob 的便利入口 |
| glob(text, pattern, flags = 0) | size = -1, patternSize = -1 | bool；flags 0，或 1=ASCII 忽略大小写 |
| distance(left, right, limit = -1) | leftSize = -1, rightSize = -1 | int；scalar Levenshtein 距离，超过限额返回 -1 |
| sim(left, right) | leftSize = -1, rightSize = -1 | float；归一化相似度 |
| approx(left, right, tolerance = 0.95) | leftSize = -1, rightSize = -1 | bool；sim >= tolerance |

索引查询未命中返回 -1；空子串 count 为 0。charAt/byteAt 的负索引从末端
计算，超出范围抛 RangeError（不返回空串或 0 伪装成功）。charAt/chars 与
文本算法要求选中片段为有效 UTF-8；byteLen/byteAt/bytes 是原始字节操作，
允许上限落在多字节 scalar 内部。isUtf8 在片段非法时返回 false；非法 size
仍报 RangeError。NUL 是合法 Unicode scalar，也可作为模式和集合成员。

填充不会截短原文；空 pad 使用空格，每侧从模式起点独立循环。Center
将不足宽度的一半（向下取整）放在左边，余数放在右边；width 为字符数量，
不是终端显示列数。距离 limit 必须为 -1 或非负，容差必须在 [0,1]（NaN
也拒绝）。限额超出与 OOM 是不同状态：前者无错误地返回 -1，后者抛
MemoryError。glob 未匹配无错误返回 false，非法模式抛 ValueError；未知 flags
抛 RangeError。

字符数组使用目前语言集合的 xvalue carrier，元素精确为 XVALUE_CHAR；
尚未把全体语言集合迁移为 xruntime typed 原生存储。B2 补齐了已有集合的
char 装箱准入、普通/安全索引、dict 动态键及遍历投影，复用封闭 scalar
projection，Cgen 仅机械选择 xrtValueGetChar。XRT Set 准入遗漏也已修正，
字符与数值相等时复用既有规范哈希，不另造一套集合算法。

## 实现边界

标准库保存 extern 声明，XLIR 检查完整参数、managed string 借入/拥有结果、
保守 effect 与 XRT 错误观察 ABI。原生适配器 `xl6_text_value.c` 使用 XRT 字符串/
Unicode 算法，返回 `xstrview {Data, Size}`；Cgen 只发头、声明、调用和语言清理。
不使用 take-cstr、strlen 或分配槽位推测结果长度。XRT 的 `xrtStrReplaceSized`
从唯一替换实现交付它已算出的字节长度，原有 xrtStrReplace 复用该实现。

独立产物按使用选择 TEXT_VALUE、TEXT_QUERY、TEXT_BINARY、TEXT_CHARS、
TEXT_GLOB、TEXT_DISTANCE。结果编辑、查询、二进制值、字符数组、glob 与
距离组件分别声明实际 XRT 原生根，不把 glob/距离/值容器合并进普通查询
组件。语言核心原有的错误/清理/类型等根仍保留；不宣称组件内逐函数链接裁剪。

XRT 新增三个 Pad*Sized，与旧 Pad* 共用唯一布局和写出实现，在已知结果
长度处交付 Size；别名输出槽被拒绝且不改输入，普通失败清零。标准库的
byteAt 虽语义为 uint8，物理 ABI 仍是语言的 int64 carrier；XLIR 同时检查
语义宽度和 C ABI，char 使用独立 uint32 scalar ABI，chars 检查完整元素类型。

## 验收范围（2026-10-02）

`tools/check_stdlib_text_values.ps1` B1 的 44 项专项在 B2 扩展为 298 项冻结
输入检查：8 个样例的严格 C/JIT/AOT、确定性、41 个原生符号的 ABI 变异、
9 个非法 ABI/默认参数负例及 4 个存量回归。原生拥有结果测试强制 19 条
真实 OOM 路径；独立进程逐前缀分配失败扫描覆盖 bytes 1 个、chars 212 个、
distance 1 个分配点，三种最终无故障路径也运行验证。全部失败均释放部分
结果并经逻辑分配账本验证平衡；该数字不是全库所有 OOM 路径的保证。

独立产物门验证 45 个组件、2025 对依赖、327 个声明/实际导出归属和 8 个
实际原生闭包。XRT Unicode 文本模块化/单头/属性/OOM 测试及 Value Set
模块化/单头回归通过；原生链接登记为 3601 符号/421 候选根。专项不代表
全套语言门禁或全仓发布通过。

Windows 正式 DLL 与当前源码宿主均有运行验证。Linux 原生 sanitizer 早期
检查通过，但最终完整语言宿主验收因 WSL 发行版不可用保留待验收。
拆分/格式、数字/编码、Pattern/Regex、系统/进程和 typed 容器批次仍未完成。
