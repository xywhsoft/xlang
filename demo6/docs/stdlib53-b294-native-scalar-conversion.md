# C 标量显式转换与精确投影

静态与动态 `c_*` 显式构造采用同一安全数值规则；`as` 和 typed
读取仍为精确、无损投影，不把显式构造的舍入规则带入匹配。
本批修复已有构造与投影路径，不增加标准库函数或公开语法。

## 规则

20 个平台 C 数值 profile 按目标平台实际宽度和符号性转换，包括
char、wchar、long、size、指针宽度整数、bool、float 和 double。
语言 char 是 Unicode 码点；C char／wchar 是平台整数，不混淆二者。

显式构造允许数值转换；浮点转整数先检查目标范围，再向零截断。
超出范围报 RangeError，NaN／Infinity 转整数同样报 RangeError。
负数转无符号整数拒绝，包括负的小数，不先截断成零掩盖越界。
浮点缩窄正常舍入，有限溢出报 RangeError；NaN／Infinity 保留。
64 位整数直接转 float 使用直接转换，避免经过 double 的双重舍入。
动态文本、null 和非数值载体不隐式解析，报 TypeError；文本解析
仍使用已有显式 parse 接口。反射 type 不属于数值构造的静态输入。

精确 `as c_int` 等读取保持原有名义身份与值域约束，失败报 TypeError。
`as c_int?` 的 null 或类型／值域不匹配返回 null；真正的 checked
失败仍传播。type 及 nullable type 复用原有反射身份投影，不增加
数值到 type 的构造。

## IR 与原生供给方

显式构造和精确投影使用独立、闭合的 IR runtime op。源物理类型、
目标类型／身份、输入 profile、返回表示和 MAY_RAISE 合同在 IR
验证，不由 Cgen 从名字或 AST 反推。失败状态必须紧接 ERROR_TEST，
源临时 owner 在成功与失败分支退役，保留第一个 checked 失败。

静态和动态构造共用同一原生转换核心；非对齐输入／输出通过真实
标量 union 及 memcpy 处理，成功前不发布输出。精确读取／装箱与
显式转换拆成独立供给方，纯投影程序不引入本批显式构造的两个
提供方。既有共享诊断／字符串转换依赖不能冒称全部裁光；原生
模块及运行时组件仍按可达、已验证操作选择并核对独立产物。

当前构造统一使用 checked 路径，包括安全常量和同型构造。
后续应在 IR 做范围证明与常量折叠，消除已证明安全的检查；不能
在 Cgen 增加猜测、绕过验证或另造一套不安全 C cast 规则。
隐式 C ABI 适配不属于这次显式构造语义的扩大范围。

## 冻结源码验收

本批证据位于 `E:/xlang-validation/stdlib53-b294-*` 及 Linux
对应目录。原生合同覆盖 20 个目标 profile、660 组转换和 69 个
范围拒绝；正常转换 fail-after-zero 零分配、非对齐输出及保护字节
检查通过，失败不发布输出。精确 nullable 不匹配保留原错误。

Windows／Linux 完整源码提供方构建完成；双平台各 310 个三组
既有夹具严格编译通过。驻留目录双平台各验证 308 个组件、1515
个精确导出、94864 对依赖闭包及 23 个拒绝负控。
Windows／Linux 普通与 Linux 指定插桩通道各 372 个阶段；专项包含
严格 C O0／O2、JIT、模块、AOT、确定性生成及四份独立裁剪产物。
2260 个坏 IR 反例均在 C／头文件输出前拒绝，其中本批新增 938 个。
O0／O2 各完成显式构造 36、精确投影 27、错误边界 16 个同步分配
前缀，首次未命中点分别为 35、26、15，所有失败及退役账本平衡。
纯投影产物排除本批两个构造提供方；数组展开继续排除 Dict。
Linux 指定插桩仅覆盖生成 C 和测试宿主，不代表全部驻留提供方插桩。
