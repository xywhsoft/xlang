# XGE 弹窗延迟修复验收

已在 XGE 原生层修复并同步实际发布目录。XGE 提交 `2e8ee6d203fe96684b32d2a2a3606ec03fef7465`；GUI 使用 xlang `203566e9350dd48d4088576367d9b609fe1cf1fc` 的完整 108 单元隔离源码，以 `-O2 -Wall -Wextra -Werror` 重编。未混入并行中的 IDE／语言服务器修改。

根因是 Window 类型查询反复注册 23 个样式属性，每次均触发整个工作台刷新；MsgBox 首次注册再叠加 12 次。现在缓存类型初始化、将相同定义注册设为无副作用操作，并为完整 MsgBox 首次构造建立原生事务。属性注册表增加 ID／名称索引，实际属性更新及继承传播行为保持不变。

| 关于 | 6748.641 ms | 2.2950 ms |
| 消息框 | 9604.924 ms | 84.3833 ms |

关于重复打开为 0.88–1.16 ms，消息框为 1.95–2.75 ms；重复类型查询 0.0005 ms，不改变样式代数。上表是打开／构造耗时，首次后续渲染另需约 25／19／20 ms，原始逐帧数据见 `timings.json`。候选目录与真实发布目录各测试 3 轮。

首次消息框仍有一次必要的全局样式初始化，不声称零耗时。新增索引在 64 位 Context 中占 4096 字节、每属性两个指针，无独立索引分配。
