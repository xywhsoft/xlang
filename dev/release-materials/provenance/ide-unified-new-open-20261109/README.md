# 统一新建／打开与空白工作空间

首页、文件菜单、工具栏和 Ctrl+N／Ctrl+O 使用相同的两个全局动作。新建默认进入控制台工程模板；打开使用 xlw/xlp/xl/c 联合过滤，按实际类型分流并保留未保存确认。删除旧分类入口、重复快捷键和工具栏两个分类下拉按钮；项目菜单保留添加引用等管理动作。最近打开使用首页同一历史快照，菜单取12项，更多转到首页。

固定分类增加工作空间，提供空白工作空间。模板种类改为 file/project/workspace 枚举；工作空间表单只包含名称、位置和子目录。后台复用模型导出与不覆盖发布，生成同名 .xlw，不附带工程或源码，发布成功后才切换工作空间。图标表示一个集合连接多个工程，提供4:3大图和16/32像素树图。

匹配重编113个GUI对象，-O2、-Wall -Wextra -Werror。十组专项通过：模板/统一入口110项、首页126项、工具栏91项、文件对话框64项，注册与真实生成、动作唯一性/快捷键、输入/IME/撤销/删除/焦点、设置、共享查找、编辑器。验证空白工作空间嵌套/平铺发布、冲突拒绝、空模型、取消无写入、最近菜单和首页关闭后调用。截图及正式目录隐藏启动通过。

新建行为变化相关的旧夹具改为实际选择单文件模板；无渲染宿主的编辑器单元夹具直接创建文档，完整原生入口由其他专项覆盖。文件对话框每次使用新目录，避免上一次验收留下的目标触发额外覆盖确认。XGE、编译器和语言服务器字节保留，未推送线上。父交付的40号字体/极小资源弹窗底栏限制继续保留，不宣称全仓通过。release/不进入Git。
