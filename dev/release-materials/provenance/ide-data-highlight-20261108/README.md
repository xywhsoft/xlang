# 固定关联窗口与结构化数据高亮

已更新 `release/win_x64/xlang_ide.exe`，保持 0.6.1、-O2。文件关联窗口关闭可调整尺寸能力并隐藏最大化按钮；边角拖动和标题栏双击不会改变大小／最大化，仍允许布局系统按字号、DPI 和视口适配。

注册 json、xlon、jsonl、xlonl 四种 CodeEdit 模式并按大小写无关扩展名识别，接通语言菜单／工具栏切换、另存为扩展名与筛选、文档支持校验及会话／未保存恢复。新模式不触发 C/xlang 源码语义补全。JSON 严格区分字符串、转义、数字、字面量与结构；XLON 额外识别 bytes/time/float/set/intmap 和自定义标签、可选注释。JSONL／XLONL 每行重置未完成词法状态，错误记录不会污染后续行；单文档按括号及注释提供折叠，字符串中的括号忽略。实际刷新共享词法 token，折叠不重复词法扫描。高亮不代替格式或 schema 校验。

11 项专项／回归通过：128 项词法断言、63 项真实文件编辑／手动模式／输入撤销／干净及未保存重启／按类型恢复断言、155 项关联窗口检查（含原生边角拖动和标题栏双击）、既有 C/xlang/text 高亮、文档、会话、输入／删除／撤销／中英文 IME／点击焦点、71 项共享查找、设置、12 弹窗 2789 项布局和 32 项实际未保存输入阻断／编译运行检查。四种数据格式的原生截图及新的关联窗口截图已保存。发行位置隐藏启动和截图通过。

111 个 GUI 单元按一致公共头文件重新编译；最后仅词法空白处理实现细化重编其所属单元。编译器、运行时、语言服务器、XGE 与线上渠道保持原字节，其他并行源码开发未纳入本次合格 GUI。验收为 Windows 针对性检查，不宣称全仓测试通过。

源码与复现脚本见配套 source-delta.zip，准确输入／对象身份、日志与截图见 evidence.zip。开发说明见 `ide/docs/data-highlighting.md`；release 文件继续被 Git 忽略。
