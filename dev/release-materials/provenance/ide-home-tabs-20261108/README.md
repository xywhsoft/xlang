# 首页标签共存与表格外框

已更新本地 release/win_x64/xlang_ide.exe，版本保持 0.6.1、-O2。表格整体外框恢复 IDE_BORDER 原主题颜色，仍保留单层外框、淡内部网格和整行选择，不恢复单元格焦点内框。

移除打开／切换／重置编辑器时主动隐藏首页的代码，首页与文件标签共存并允许原生关闭。手动关闭首页后，后续打开或关闭文件不会自动重新打开；视图 → 首页可以恢复同一个页面。关闭首页不会关闭源文件；关闭后台源文件不切离首页。首页仍存在时关闭最后一个源文件会返回首页，已关闭则保持关闭。工作空间的自动布局重置保留已关闭状态，显式恢复默认布局仍恢复默认首页。会话重启保留关闭状态、活动文件，以及同时有打开文件时的活动首页。

8 个专项／回归套件通过：首页 123 项、Dock 工具窗格 149 项，以及原生输入／删除／撤销／Unicode IME／点击焦点、共享查找、设置／字体、动作菜单、工作台和会话。首页覆盖实际 caption／tab 关闭热区、文件共存、前后台关闭、关闭后不复活、重新打开、工作空间自动重置及多种重启组合。四主题逐一检查外框精确颜色；首页与文件同时存在的真实截图见 evidence.zip。正式安装位置隐藏启动和截图通过。
