# 新建模板与注册式创建表单

固定工程／独立文件分类，每次默认控制台工程；模板行使用 96×72 DIP 的 4:3 图标、标题、作者／版本和两行说明。工程存在显式工作空间时默认加入当前，否则默认不关联。通用表单与自定义字段共用注册机制、条件显示、类型校验、固定底栏和内容滚动。清空历史必须确认。

六个内置模板图标带可编辑 SVG 和透明 PNG；XL/C 复用文件关联图标。用户模板位于设置目录旁 templates/，JSON 定义字段与资源，导出 validate/create 函数经后台 xl.exe run 调用，使用独立 JSON 请求／结果和日志。发布版 examples/templates/hello 是完整可运行示例；接口与限制见 ide/docs/project-templates.md。

原生树图标专用绘制回调提交 XGE ad064dc3，保持树的文字、选择和命中行为。将该项定点移入已验收 SDK，未切换其他公共布局。实际截图复核修正图标整数除法和多行输入缓存关闭导致的不可见问题。

全量匹配重编 113 个 GUI 对象，-O2、-Wall -Wextra -Werror，C LSP 默认关闭。七组 IDE 专项通过：首页 126 项、模板表单 55 项、注册／生成器、原有四模板实际构建、C/xlang 输入／删除／撤销／IME／焦点、设置、共享查找；额外通过真实混合工程和 DLL 构建、自定义模板生成运行、回调取消。两组原生树专项通过，SDK 材料 18 项通过，旧导出保留，仅增加图标回调导出。正式 release/win_x64 隐藏启动通过。
