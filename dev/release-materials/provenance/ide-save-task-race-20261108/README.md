# 保存后立即构建被误停与集成帮助标题

“命令集成帮助”的 Dock 标题、视图菜单和默认正文标题统一为“集成帮助”，稳定窗口 ID 未改变。

报错来源是 IDE 文件协调层，不是 XGE 渲染资源争用。原子保存改变文件身份/时间戳，延迟通知被直接当作输入编辑；保存前开始的旧快照还可能迟到；替换窗口中实测出现 ERROR_SHARING_VIOLATION(32) 和短暂 FILE_NOT_FOUND(2)。

修复：已保存基线内容一致的通知不再取消新任务；保存成功记录单调时间边界，丢弃更早开始的快照并请求后台重扫；监听工作线程对短暂共享冲突、非稳定读取和从存在转为暂时缺失做有界确认，每轮扫描共享 35 ms 重试预算；未确认的共享失败不等同于输入编辑。持久删除、真正外部修改、未保存编辑和最终输入/编译器回执校验仍保留。UI 线程没有新增文件正文读取或等待。

同一真实保存/监听/任务夹具在原对象组稳定复现误停，新对象组通过 156 项断言；连续三轮、共 24 次立即保存构建通过。覆盖真实旧快照延迟交付、同内容原子替换、共享失败、真实编辑/外部修改/删除。IOCP 监听专项、输入/Unicode/IME、71 项查找、32 项真实未保存依赖阻断、真实 xlang 编译运行/终端和构建输出检查通过。108 个 GUI 对象按一致的内部事件结构重新编译，保持 -O2。实际 release/win_x64/xlang_ide.exe 已替换并通过隐藏启动和截图验证。

两项旧综合测试仍失败，原对象组和新对象组失败输出一致，已保存对照：file_sync_test 的旧折叠可见性断言；standalone_task_test 的选中项目 ID 断言。它们没有被计为通过，也未据此宣称全仓回归完成。

新夹具加入 build.ps1 -Tests 的编译清单，并排除其直接纳入的 file_sync 对象，避免重复定义。单独运行方式：task_save_watch_test.exe <独立验收目录> <该测试自身的完整路径>；旁边需有常规测试构建产生的 xide_task_program.exe。完整复现脚本和精确源码在配套 source-delta.zip；构建身份、日志和截图在 evidence.zip。编译器、语言服务器、XGE DLL 和线上 ver2 没有更新，release 文件未加入 Git。
