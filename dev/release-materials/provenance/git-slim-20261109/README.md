# Git 仓库瘦身与材料迁移

2026-11-09 对全部本地分支、标签和树检查点执行产物路径过滤。2,881 个旧提交逐一验证，非目标文件字节、权限及合并拓扑保持一致；本地材料、六个工作区的未提交源码和索引的非目标条目保留。

原 Git 对象库约 778 MiB，过滤后约 164 MiB。移出的开发快照、验收归档、截图、大日志、OpenCV 下载工作副本和历史模型保留在原本机路径，并以独立材料包提供。小型索引在 dev/release-materials/materials-index.json；恢复方法见 docs/git-repository-size.md。完整历史路径/版本目录保存在材料包，旧回执不改写。

本目录保存旧新提交映射、分支映射及专项验收。九项恢复/门禁测试通过，真实归档和历史别名恢复通过；Git fsck 通过。预算工具测量待推送引用的独立压缩包，250 MiB 提醒、350 MiB 拒绝；已有 Git LFS pre-push 被保留并串联。CI 增加同一检查入口，不宣称运行了全仓编译回归。

远端是否已完成替换以 published.json 为准。远端替换完成后仍需管理员执行服务端 GC，释放旧历史；其他克隆应保护本地改动后重新克隆或迁移到新历史，避免普通 merge 把大文件历史带回。独立备份位于仓库外，不会被推送。
