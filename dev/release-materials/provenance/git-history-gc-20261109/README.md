# Git 发布产物历史回收

2026-11-09 完成本地 Git 对象回收，约 1.85 GiB 降至 778 MiB，回收约 1.09 GiB。原统计使用 Git 的四舍五入单位，精确回收字节不作伪精确声明。

此前列明的 release/、demo*/release/、ide/release/ 等发布路径以及指定的 103 MB 开发快照，已从全部本地分支、标签和树检查点历史剔除。本轮不再重写这些干净提交；删除的是重新指向 Gitee 旧历史的 origin/master、origin/HEAD 两个本地远端跟踪引用，随后回收旧对象。Gitee 的真实引用和 remote URL 均未改变，不把远端跟踪伪装成已同步。旧远端提交对象已不在本地，git fsck --full --no-reflogs 通过。

所有本地分支、标签、检查点和 6 个工作区索引保持；1,084 份未提交源码内容一致。14,578 份运行文件均仍存在，其中一个 ch03.xl 示例在检查期间被其他操作修改，保留了该修改。本轮 Git 操作未删除运行文件。独立旧历史备份 before.bundle 已重新验证，包含旧主线、远端提交和标签；备份位于仓库外，不在推送内容中。

剩余体积主要来自开发源码快照、验收归档和 OpenCV 开发材料，详见 receipt.json 的剩余对象分类。这些内容不属于 release 发布目录，保留其原始字节及路径；归档测试夹具里的 release/include 是检查输入，也保留。

## 远端状态

Gitee 仍指向历史清理前的 596cab8f6。两次精确租约原子推送均被服务端配额检查拒绝；用户执行服务器 GC 后仍报告 1819.605 MiB 超过 1024 MiB。删除本地跟踪引用不等于清理服务器。普通 fetch/pull 旧远端会再次引入旧对象，在远端历史迁移完成前请避免该操作。
