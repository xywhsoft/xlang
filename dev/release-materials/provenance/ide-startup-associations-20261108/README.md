# 文件关联与后台启动验收

已安装到 `release/win_x64/xlang_ide.exe`，保持 0.6.1 和 -O2。
“设置 → 文件关联”提供工作空间 xlw、工程 xlp、脚本 xl 的登记和独立默认关闭的 C 选项，支持检查、修复、注销与不再提示。四种文件图标以固定资源 ID 内嵌，含 16—256 像素的九种尺寸。

启动首先显示命令列表加载占位；后台准备目录、索引、补全描述和节点，UI 批量交付，然后检查关联，最后准备与启动更新器。首帧和编辑不等待目录。提示排队避让已有模态窗口，目录重载失败保留可用快照；稳定条目、搜索及阅读位置延迟恢复。后台任务不持有 app/控件指针，关闭和重载会退役旧任务；登记中保留退出保护。

登记只写当前用户的自有 ProgID、OpenWith 和应用能力，不覆盖其他编辑器默认值，不写受保护的 UserChoice。Windows 需要用户选择默认应用时打开系统设置确认。便携目录移动可重新修复。多个实例串行操作，写失败回滚，注销保留未知元数据。

17 项专项/回归通过：217 项隔离注册表检查（22 个写入失败回滚边界），目录拥有交付/取消，首次占位和加载期间编辑，51 项关联窗口检查，离线更新器实际进程与退役，输入/中英文 IME/C 与 xlang、71 项共享查找、32 项真实未保存输入阻断与编译运行、会话/阅读恢复、79 项自动帮助、设置菜单、2789 项现有弹窗布局和终端换行等。8 个实际 GUI 启动场景通过，包括四类文件入口、指定帮助条目、目录缺失和预期失败的无效条目；发行位置的隐藏启动与截图通过。四组 ICO 的资源 ID 和所有九种尺寸均从实际 EXE 验证。

本机约 19,975 条命令的后台准备约 0.35—0.41 秒，完整树的 UI 交付约 7—8 毫秒；筛选/选中条目的交付约 11—14 毫秒。这是本轮样本，并非普适 P99 指标或完整启动耗时。

注册表写入测试使用独立 HKCU 子树并清理；真实系统默认应用仅做只读查询。没有替用户更改实际默认应用，也没有自动验收真实 ms-settings 页面中的用户确认。更新器测试使用离线桩，未访问或发布线上更新。验收为针对性回归，未重跑全仓测试。编译器、语言服务器、XGE DLL 和扩展包保持原字节；其他并行语义/LSP 工作未混入本次 GUI 源码。

源码、图标和复现脚本在配套 source-delta.zip；精确编译输入、对象哈希、日志和截图在 evidence.zip。详细开发接口和测试命令见 `ide/docs/file-associations.md`。release 产物继续被 Git 忽略。
