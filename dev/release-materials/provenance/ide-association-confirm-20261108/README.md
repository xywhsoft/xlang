# 文件关联确认窗口

已更新 `release/win_x64/xlang_ide.exe`，版本仍为 0.6.1，保持 -O2。

操作按钮仅“关闭 / 确定”。关闭、标题栏 X 和 Escape 丢弃草稿，不写设置、不更改关联。确定在后台按全部勾选结果创建／修复或取消本路径拥有的关联；全部不选可全部取消。成功才保存勾选与提示偏好并关闭，失败保留窗口与草稿供重试。不再自动提示移到底栏左侧，与右侧按钮垂直居中；内容单独滚动。默认窗口由原约 710×602 缩为 526×398 DIP。

底栏支持通用左侧控件，并保留既有按钮布局。额外修复原关联窗口未纳入界面字体更新的问题，避免调整字体后保留旧字体句柄。

76 项新窗口断言通过：真实按钮点击、关闭前后设置文件逐字节相同、混合勾选、全部取消、C 独立选择、失败不保存、未知设置保留、后台顺序、操作中关闭保护，以及 16/24/40 字号和三种尺寸下的左侧位置、垂直居中、固定底栏及内容滚动。隔离注册表 236 项检查通过；原 12 弹窗 2789 项布局、输入／删除／撤销／中英文 IME／焦点、71 项共享查找及设置回归通过。六项专项／回归全部通过，发行位置隐藏启动与截图通过。

注册表测试仅操作临时 HKCU 子树；UI 测试使用模拟关联后端，未替用户改变真实默认应用。111 个 GUI 单元以一致头文件重编，最终仅布局实现居中细化重编其所属单元。编译器、运行时、语言服务器、XGE 和线上更新渠道没有改变，其他并行工作保留。此为针对性验收，不宣称全仓回归。

源码与复现脚本见配套 source-delta.zip；准确输入／对象哈希、日志和截图见 evidence.zip。release 字节继续被 Git 忽略。
