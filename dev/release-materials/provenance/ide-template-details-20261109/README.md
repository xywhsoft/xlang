# 模板列表与创建按钮细化

底部按钮宽度保留完整文字、原生按钮内部留白及边框。树分类使用专用 16×16 网格图标和 32×32 高 DPI 图，不再缩小 4:3 大图。作者／版本紧跟标题；可选 website 在标题行右侧显示“点击查看说明”，HTTP/HTTPS 地址由系统默认浏览器打开，缺省不显示。

虚拟行绘制仍只处理可见条目；文字宽度仅在字体或布局变化时重算，点击区域复用同一布局。链接在父控件捕获阶段处理，保留原生列表的选择、滚动和键盘行为；按下拖出取消、正常点击打开均验证，取消／切分类释放捕获。

匹配重编 113 个 GUI 对象，-O2、-Wall -Wextra -Werror。六组 Windows 专项通过：首页 126 项、模板表单 59 项、注册／实际生成、C/xlang 输入／IME／焦点／删除／撤销、设置、共享查找。九组 website 元数据用例覆盖有效／空／类型错误／不允许协议／无主机／空格／内嵌 NUL。浏览器调用在测试中拦截，未访问外部网页。截图复核及正式 release/win_x64 隐藏启动通过。

已本地安装，XGE／编译器／语言服务器字节保留，未发布线上更新。此为定点 Windows 验收，不代表全仓回归；旧交付限制继续保留。准确来源、对象与运行时哈希见 receipt、evidence 和 sources 的增量材料。release/ 不进 Git。
