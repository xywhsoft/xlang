# 行内关联状态与复选框对勾

已更新 `release/win_x64/xlang_ide.exe`，保持 0.6.1 和 -O2。

四行关联状态分别放在对应 checkbox 右侧，文字垂直居中；真实有效关联显示绿色“当前已关联”，未关联显示正文色“当前未关联”。已登记但尚待 Windows 默认应用确认不能显示为已关联；查询不可用时明确显示状态未知。草稿勾选不改变实际状态显示。下方常驻四行状态块移除，错误／执行提示仅在需要时出现。窗口由 526×398 缩为 486×298 DIP，保留固定底栏、关闭／确定语义及内容滚动。

对勾消失的根因在 IDE 主题：checkbox.check.color 与选中填充的 choice.accent.color 同为 IDE_ACCENT。XGE 原生仍在绘制两段对勾线。改用独立对比色 token：浅色主题使用 IDE_ON_ACCENT，深色主题的浅色选中背景使用 IDE_BG。修复作用于 IDE 内全部同类 checkbox，没有更改或重编 XGE。

149 项窗口断言通过，含关闭不写入、确认／取消关联、失败与偏好保护、三种字号与尺寸、实际状态和草稿分离、四主题绿色／正文色、行内位置和对齐。四种主题均实际渲染四个全选 checkbox，并读回 RGBA 验证每个方框内部同时存在填充像素和对比色对勾像素；四张原生截图均保存在 evidence.zip，暖纸白截图已经目视核对。输入／删除／撤销／中英文 IME／点击焦点、71 项共享查找、设置和原 12 弹窗 2789 项布局回归通过。五项专项／回归均通过；已安装位置隐藏启动与截图通过。

仅改两个编译单元，复用上一合格 GUI 中 109 个逐项校验哈希的对象；所有公共头文件保持相同。编译器、运行时、语言服务器和 XGE 文件未改变；其他并行开发内容保留。未替用户更改真实文件关联，未发布线上更新，也不宣称全仓测试通过。

精确源码及复现脚本见配套 source-delta.zip，编译输入／对象身份、日志和截图见 evidence.zip；release 继续被 Git 忽略。
