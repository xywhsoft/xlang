# 表格内部网格单像素修复

修复表头竖分隔线、表头底线和数据行网格。原 drawLine 的抗锯齿羽化导致 nominal 1px 实际占 2px（横线）／3px（表头竖线）；改为无羽化网格 quad，沿用顶点颜色混合路径，保留主题颜色和整体外框。半透明交点只绘制一次。100% 的真实 OpenGL 像素对照：修复后横竖均为 1px，不透明与 alpha110 两组中心 RGBA 均与原版本逐像素相同。高 DPI 仍遵循 IDE 的逻辑像素缩放。
