# 工程创建表单布局

工程与工作空间的创建子目录复选框分别附在对应名称输入框右侧。布尔字段使用自带文字的复选框，无重复 label。输入行选项按内容宽度排列，窄窗口／大字体保留换行。共享表单标签与输入使用相同行高，并垂直居中文字；不关联工作空间时隐藏启动选项，创建任务也不使用隐藏的启动值。

113 个 GUI 对象匹配重编，-O2、-Wall -Wextra -Werror。模板表单 70 项、首页 126 项、输入／IME／删除／撤销／焦点、设置、共享查找五组通过。专项验证实际勾选、同排位置、标签中心和 none/create/current 切换，截图及正式目录隐藏启动通过。

扩展 dialog_layout_test 在 40-DIP／700×460 的资源管理弹窗底栏边界失败。上一版未修改的 GUI 对象与匹配头文件编译相同夹具，亦在第104行失败，两份日志字节完全相同。此前常规字号／尺寸阶段已完成，但套件整体未通过；本轮明确记录既有边界，未改断言或宣称全仓通过。
