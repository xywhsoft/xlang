# xlang 0.6.1 发布验收

版本 **0.6.1**，代号 **0x00000601**，C API ABI **1**。Windows 和 Linux 实际发布目录已安装配套 CLI／核心库，Windows IDE、SDK 版本头、显示元数据及内嵌编译资源同步。

Windows 更新版本 API 和资源单元并复用已验收对象；Linux 两份原生库重新以 -O2 构建。每个平台四种序列化 API 对象均重编，其他对象逐项核对哈希。嵌套 JIT 和独立 AOT 程序均实际返回代号 1537。四个核心库的导出符号集合没有变化。

验收包括两平台的版本接口、独立 C SDK、JIT／AOT、默认 SDK、嵌套编译、字符串嵌入、argv／错误边界及 Windows 关于窗口、GUI 启动；清理工具的 9 项安全检查通过。发布检查脚本修复了旧平铺路径和固定 0.6.0 预期值，Linux C 示例使用同一份跨平台 C 夹具。未执行全仓测试。

清理从发布目录移出 **22.09 MiB**：删除失效缓存／空闲设置锁，将临时 Linux ELF 映像和 6 份本地 Agent 日志归档到 `build/release-0.6.1-20261108/cleanup-extra/`。日志正文未提交。用户设置、诊断、SDK、扩展库和运行资源保留；清理阶段保留文件的哈希一致。

命令目录仍为 **19,971** 项、207 个公开包和 591 份可用源码，公开内容不变，只刷新运行库指纹。当前交付索引清除了失效的旧数据条目，按两套平台记录现存已跟踪数据。既有本地字体保留，未新增字体二进制提交。独立维护的本地 `mdo.exe` 保持原文件及版本，单列为外部组件，不纳入 xlang 的 Git 交付。

本轮包含与核心库匹配的两份既存 DEF 清单；不纳入语义／语言服务器开发和旧平铺 release 目录的既有删除。当前目录整理与远端发布分别管理：本轮未发布远端，也未修改更新器安装迭代号。

完整哈希、构建参数、验证记录和来源见 `receipt.json`、`evidence.zip`。源码增量见 `dev/release-materials/sources/release-0.6.1-20261108/manifest.json`，继承的源码材料和历史报告原始字节保留。
