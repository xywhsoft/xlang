# 未采用的 canonical 文本共享缓冲区候选

本目录保存本轮候选的九项 IDE 源码差异文件及精确摘要，供重放和后续函数资产研究。它是稀疏源码覆盖，不是独立源码树，也不是发行版；当前仓库默认实现已恢复至实验前版本，根 `release/` 未安装该候选。

候选通过全新 224 次编译／127 原生回归、四种真实 C 遗漏拒绝、62 进程增量与全新分析对照，以及 56 套既有协议回归。它减少了受控构造中的可见分配入口，但未满足预先登记的完整性能条件，因此没有进入默认路径。完整结论和失败样本见 [实验说明](../../../../ide/docs/lsp-canonical-type-storage.md) 及 `dev/release-materials/provenance/lsp-canonical-arena-20261102.json`。

`manifest.json` 记录原始工作路径、归档路径、候选摘要、五项原有文件的基线摘要、构建报告身份和当时仓库 HEAD。其余源码依赖仍来自完整 IDE 基线和已审核的统一前端闭包；只复制本目录不能编译服务。

复现时，在完整源码副本中恢复这九项文件，核对 manifest 的候选摘要，再运行其中的 `ide/tools/build_lsp_core.py`。前端使用实验记录中的精确统一组合；构建和测试输出使用新的专用目录。`check_lsp_index_arena.py` 必须与该次完整通过构建一起使用，它会核对全部实际输入与产物，再编译真实 C 错误变体。不要将候选文件覆盖到正在运行的发行包，也不要把历史报告中的工作路径改写成归档路径。

本轮 `product-full-v2` 的 775 项输入可由此覆盖与其余未变输入共同核对，129 项产物保持原摘要；默认恢复后的原构建 772 项输入／128 项产物也重新核对通过。该归档只保留实验材料，不增加新的默认特性、版本或性能准入声明。
