# Earlier XGE/XUI tutorial source

These 28 XGE and 48 XUI scripts use the earlier XgeApp/XuiApp wrapper APIs.
Their original bytes are retained for reference and indexed by SHA-256.
They are not runnable examples for the current declarative packages and have
not been ported or counted as passing modern API tests. The source snapshot
does not restore those wrapper APIs or claim a matching historical SDK.

Maintained examples live under lib/bindings/{xge,xui}/examples and are published
with their matching runtime packages. The original runtime scripts are only
removed during the separately qualified final example publication. User IDE
settings and other runtime resources are outside that operation.
