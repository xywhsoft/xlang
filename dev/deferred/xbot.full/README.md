# xbot 完整自动化栈延期区

这里保存依赖高级 HTTP 客户端、设备后端、视觉模型和平台 SDK 的 xbot 完整自动化栈。
这些源码不进入当前发布包，也不允许通过父目录穿越被其他包隐式编译。

当前发布边界：

- `xbot` 只提供稳定的基础结果与坐标模型。
- `xbot.agent` 提供不依赖网络和设备 SDK 的离线 Agent 工具体系。
- HTTP、远程日志、资源下载、设备、视觉、云签名/INI 配置原生适配和 `xbot.all`
  聚合入口在完成对应扩展依赖适配后再恢复。

恢复时必须建立正式包依赖和独立测试，不得重新引用 `release/extlibs` 中其他包的私有源码。
