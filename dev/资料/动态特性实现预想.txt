拼接函数名调用、判断函数是否存在：
	全局函数表：函数名 = 函数指针
	可以获取函数名，可以获取指针
	
函数重新设置：
	所有函数都定义为指针，真正的函数随机命名，将值传给指针，这样改变指针 = 改变函数。
	全局函数表中的函数指针，实际上是一个二层指针
	
Native函数：
	导入函数、导出函数不具备动态特性，可在函数声明时添加 Native 关键字使这个函数不具备动态特性
	或者添加 Dynamic 关键字声明这是一个动态函数
	
参数传递：
	参数使用栈进行传递，
	
G 表：
	全局表，全局环境使用这个表，全局环境相当于一个元编程对象，可以通过对G表的设置实现元编程能力



type 使用 class 代替（class兼具结构体和类的特点，淘汰掉 type）
dict、table 使用 object 代替（object具备动态特性）



函数编译为随机名，导出函数增加
