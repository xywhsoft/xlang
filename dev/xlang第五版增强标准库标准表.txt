- 本表是 [xlang第五版增强标准库设计方案.txt](/D:/Git/x-lang/xlang第五版增强标准库设计方案.txt) 的实施清单版本。

三、核心模块职责摘要
------------------

1. std.core
- 最短路径公共能力
- print / println / eprint / eprintln
- len / empty / panic / exit

2. std.types
- 类型反射与类型辅助

3. std.math
- 数值与数学函数

4. std.fmt
- 格式化输出与文本生成

5. std.str
- string 文本与字节语义相关能力

6. std.regex
- 正则表达式

7. std.encode
- base64 / hex / url / utf8 相关编码解码

8. std.pack
- pack / unpack / 定长读写 / 字节序

9. std.hash
- hash32 / hash64 及 xrt 已有安全可保留算法

10. std.crypto
- xrt 已有安全算法能力

11. std.iter
- 迭代算法

12. std.array / std.list / std.set / std.dict
- 容器算法层
- 基础操作主路径仍是类型方法

13. std.error / std.assert / std.log / std.trace / std.debug
- 错误、断言、日志、调试、跟踪

14. std.io / std.fs / std.path / std.dir / std.env / std.process / std.host / std.os
- 文件、路径、目录、环境、进程、主机、平台

15. std.future / std.task / std.channel / std.sync / std.thread / std.atomic
- 并发、异步、同步原语

16. std.net.*
- 网络与协议

17. std.json / std.query / std.template
- JSON、查询串、模板

18. std.sys.*
- 系统级底层能力

六、稳定性规则
--------------

1. 已进入本表的模块名不随意重命名
2. 已进入本表的公共函数名不随意重命名
3. 已进入本表的公共类型名不随意重命名
4. 允许新增函数、重载、常量、类型方法
5. 不允许破坏既有参数顺序与返回语义
6. 基础容器的主交互方式是类型方法，不在模块层重复造基础操作入口
