# 普通扩展库复验队列（2026-10-27）

本表跟踪[普通扩展库优先级清单](../../docs/普通扩展库开发优先级_2026-10-12.md)中已有明确共享阻断的包，**不是** 100 包的发布签收表。包名来自各包 README 与最小复现；同组症状相似不等于已证明同一根因。未列出的包也不能据此自动视为完成。

当前 Windows 发布版 SHA-256 为 `CCF98FF05BAAA71C1827EAA0C8B7A011A9A17EAB1AECD593CD89848D227C5A2B`；构建和最小结果见[发布版阻断记录](2026-10-27_release_rebuild.md)。在主线修复前，不修改扩展库去识别编译器私有句柄，也不把失败用例移出默认门禁。

| 共享边界 | 已报告受影响包 | 修复后先做什么 |
| --- | --- | --- |
| 语言 `var` 数组/字典传给原生 `xvalue*` | `bson`、`cbor`、`clipboard`、`com`、`epub`、`fix`、`graph`、`ical`、`json.patch`、`msgpack`、`netrc`、`rss`、`shellwords`、`sitemap`、`srt`、`statistics`、`tar`、`terraform_state`、`toml`、`vcard`；另有 `csv` 的嵌套数组问题 | 先跑[容器投影最小复现](foreign_var_container_projection.md)中的不同容器、嵌套与所有权路径，再逐包运行默认 C/XLang JIT/AOT、双语范例和故障注入门禁；不得以单个 `netrc` 正例代表全组。 |
| 顶层 native-backed class 的 AOT 退出清理 | `blake3`、`consistent_hash`、`daemon`、`hyperloglog`、`lru`、`rtree`、`sharedmem`、`skiplist`、`tabulate` | 先跑[顶层对象最小复现](global_native_class_aot_fini.xl)，确认正常输出后退出码为 0，再跑各包保留的顶层对象 AOT 红例和完整默认门禁。 |
| 包外仍可调用私有原生构造器 | `blake2`、`blake3`、`floatEnv`、`sharedmem`、`stb_image`、`stb_truetype`、`zip` | 先用 `xl check` 验证包外调用被拒绝，再跑各包公开构造路径；**不要执行**当前会通过检查的伪造指针负例。 |
| `cli.parseOs` 缺少运行时符号 | `cli` | 先跑 `test/cases/extlib_cli.xl`，再跑 CLI 包的 Windows/Linux 默认门禁。 |

另有不同性质的独立阻断：`money` 的原生数组与语言数组相等性、`xml.dom` 的公开 `Node` 类型可见性、`serial` 的析构期字段清理、`singleinstance` 的双上下文并行执行、`volc.*` 的 HTTP 依赖链，以及 `zip`/`tar` 的根目录锚定原子替换能力。它们不能随上述四组自动关闭，须按各自包 README 和 `dev/extlib_blockers/` 的最小复现逐项复验。

复验原则：先确认当前源码重建的发布物及其哈希，再跑最小复现；只在最小复现转绿后运行对应包的完整门禁。保留原有红例与失败阶段，C 或 JIT 的部分通过不等于整包发布签收。
