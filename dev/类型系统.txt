	重载函数名：
		xf4_name_i8_s_s_fn
		xc4_class_name_i2_f4_s_i4
		
		第一位：
			x 为固定的函数名首位符号，后跟着参数数量（可变参数的 ... 或 *** 算作一个参数）
		
		第二位：
			f 为函数
			c 为 class 成员函数
			g 为 class 属性（读取）函数
			l 为 class 属性（写入）函数
		
		第三位：
			数字代表参数数量
		
		class：
			为类名的 hex 编码（如果有命名空间，则连通命名空间一起 hex 编码，这样做是为了支持中文函数名）
		
		name
			为函数名的 hex 编码（如果有命名空间，则连通命名空间一起 hex 编码，这样做是为了支持中文函数名）
		
		后续 _ 分割：
			为参数类型，基础类型直接写基础类型声明值
