五、当前最小已落地能力映射
------------------------
- ☑ std.str 最小语义已由现有 string 方法覆盖

- ☑ std.future / std.task / std.channel 最小语义已由语言与 runtime 覆盖
- ☑ protocol 注册矩阵已覆盖 Callable / Indexable / Iterable / Iterator / Awaitable 的 builtin 注册
- ☑ extern / xle / runtime 主链路已具备后续标准库接入基础
- ◐ 官方扩展库 source 包骨架已验证（examples/xle_official/libs/x.csv）
- ◐ 官方扩展库 native 包骨架已验证（examples/xle_official_native/libs/x.image.bmp）
- ☑ 显式泛型空容器声明可保留声明类型（array/list/dict），用于标准库源码包内部 typed state
- ☑ C 后端已生成普通函数 raw 前置声明，source 包内部函数可先调用后定义
