# yaml：占位实现，暂停发布级开发

`release/extlibs/yaml/yaml_native.c` 当前不是 YAML 解析器，只按行查找
`key:`，用进程全局固定长度缓冲区返回结果。`xyaml_get`、`xyaml_key_at`、
`xyaml_list_count` 对输入长度没有边界检查，`xyaml_emit_pair` 用 `sprintf`
写入 8192 字节静态缓冲区。并发调用会互相覆盖返回值，嵌套、引号、转义、
块标量、映射/列表组合均不能可靠处理。

最小风险输入：给 `xyaml_emit_pair` 传入超过 8192 字节的键或值会写越界；
给 `xyaml_get` 的目标值传入超过 4096 字节也会写越界。不要把它当作
安全 YAML 解析器发布或处理不可信输入。

本任务遵守“核心能力尚未实现的包暂不开发”边界，不通过扩张这些静态缓冲区
伪装修复。后续单独选定真实 YAML 后端和支持范围，替换整个占位实现，
补 C/XL 正反例与格式互操作测试。当前文件仍在发布树中，正式发布前应
移除或禁用此包；本任务未擅自删除公开目录。
