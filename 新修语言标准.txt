注释语句：

变量定义语句：
	变量定义语句使用类型前置写法，例如定义一个整数：
		int a
	定义变量时可以赋初值：
		int a = 0
	支持在同一行定义多个变量：
		int a = 0, b = 1, c = 2
		相当于：
			int a = 0
			int b = 1
			int c = 2
	定义多个变量可以赋初值，也可以使用默认值：
		int a, b = 1, c, d = 2, e
		相当于
			int a
			int b = 1
			int c
			int d = 2
			int e
	可以使用自动类型，根据值推测出对应的静态类型：
		auto a = 1
		a 为 int 类型
	可以定义变体类型变量：
		var a = 1
		a = "asd"
		变体类型变量可以在运行时更改值的类型
	变量定义初值可以赋值为数组、列表、集合、字典：
		array a = [1, 2, 3]
		list a = [1:100, 2:200, 3:300]
		var a = []			// 无成员时默认代表数组
		collect a = {1, 2, 3}
		dict a = {a:1, b:2, c:3, "  中文":4}
		var a = {}			// 无成员时默认代表字典
		var a = [1, 2, 3]
		使用 [...] 或 {...} 表示的数组、列表、集合、字典成员值默认为 var
	可以使用 new 语句创建对象（包含class、object或内置基础类型）
		dict a = new dict(int)		// 创建一个成员只能包含 int 的字典
		int a = new int(1234)		// 相当于 int a = 1234
		也可以创建自定义类和对象，相当于调用对应类或对象的构造函数



常量定义语句：
	常量定义只需要在变量定义的基础上前面加个 const：
		const int a = 1
	常量定义必须赋值，定义后不可修改
	常量定义赋初值时，可以代入表达式，但表达式中不允许出现变量

条件分支：
	if exp then code line
	if exp
		code block
	elseif exp
		code block
	else
		code block
	end



条件选择（使用 if 语句实现 select 语句的优势功能，不额外增加 select 语句）：
	if exp in A, B, C then code line
	if exp in 1 to 10 then code line
	if exp in A, B, C
		code block
	elseif exp in 1 to 10
		code block
	else
		code block
	end



计次循环：
	for i = 1 to 10[ step x]
		code block
	end



迭代循环：
	for [k, ]v in obj
		code block
	end



条件循环：
	while exp do
		code block
	end
	do
		code block
	while exp end



循环跳出：
	break				只跳出当前循环，相当于 break(1)
	break(2)			跳出当前循环后，再立刻跳出外层循环一次
	continue			跳过本轮循环
	continue(2)			跳过两轮循环



函数定义：
	function name(params)
		code block
	end



函数可选参数：
	function name(a, b = 1, c = 2)
		code block
	end
	可选参数只能出现在尾端，不能出现在前端，避免参数传递出现歧义



函数可变参数：
	function name(a, ...)
		code block
	end
	使用 ... 表示数组型可变参数，使用可变参数的函数，内部会自动生成 arg 参数，表示可变参数数组
	
	function name(a, ***)
		code block
	end
	使用 *** 表示字典型可变参数，使用可变参数的函数，内部会自动生成 arg 参数，表示可变参数字典



函数返回值写法：
	return x
	return				无返回值，直接退出函数
	不限制返回值的数据类型，永远使用变体类型



类定义：
	class name[ : parent]
		create(param)
			// 构造
		end
		destroy()
			// 析构
		end
		body
	end
	parent 表示父类，类的父类只能是其他类
	类支持构造、析构
	对象代码块内，可使用 self 代表对象自身
	
	class name : object
		create(param)
			// 构造
		end
		destroy()
			// 析构
		end
		body
	end
	继承自 object 的类表现为对象类（支持自定义字段、元编程等特性）
	
	类语句内可以使用结构体和共用体：
	class name : object
		create(param)
			// 构造
		end
		destroy()
			// 析构
		end
		struct name
			// 结构体
		end
		union
			// 共用体
		end
		body
	end



对象成员函数：
	class name
		function func(param)
			block code
		end
	end
	
	可以在结构域外定义，name 改为 class.name 即可：
	function class.name()
		block code
	end



对象属性：
	class name
		get name(param)
			block code
		end
		set name(param, val)
			block code
			return 1
		end
	end
	同一名称的属性，参数数量只能差一个，set 比 get 多一个参数，在最后面，代表设置的新值
	可以在结构域外定义，name 改为 class.name 即可
	
	属性可以传递多个参数，第二个参数开始，为索引参数：
	class name
		get name(param, idx)
			block code
		end
		set name(param, idx, val)
			block code
		end
	end



元编程：
	meta func(param)
		block code
	end
	meta 代表实现一个元语言方法
	支持的元方法列表：
		set：设置了一个未知的成员值
		get：读取了一个未知的成员值
		call：调用了一个未知的函数
		callself：调用了本身
		to：类型转换



立即值表示：
	十进制整数：
		数字直接表示
	八进制整数：
		&O数字表示
		不支持C语言0开头的表示方法，歧义过大
	十六进制整数：
		0x数字表示
		&H数字表示
	二进制整数：
		0b数字表示
		&B数字表示
	浮点数：
		正常表示，可使用科学计数法
	逻辑值：
		true、false
	字符串：
		"文字内容，支持换行回车，支持转义符"
		'文字内容，支持换行回车，不支持转义符，表达单引号本身用两个单引号'
		使用文件编码方式保存的字符串，例如文件使用 utf8，则这个字符串就是 utf8 类型的
		'''多行字符串'''
		"""多行字符串"""
	ANSI字符串：
		#A"文字内容"
		#A'文字内容'
		不管文件用什么编码，都以 ANSI 编码存储（OEM编码）
	UNICODE字符串：
		#W"文字内容"
		#W'文字内容'
		不管文件用什么编码，都以 UNICODE 编码存储
	UTF-8字符串：
		#U"文字内容"
		#U'文字内容'
		不管文件用什么编码，都以 utf-8 编码存储
	动态编码字符串：
		#T"文字内容"
		#T'文字内容'
		转换为对应的编码储存，对应编码为编译器编译时指定的编码
	模板字符串：
		`hello {$varname}`
		#A`hello {$varname}`
		#W`hello {$varname}`
		#U`hello {$varname}`
		#T`hello {$varname}`
		模板字符串可以直接将变量代入字符串，模板字符串编码规则与字符串编码规则相同
	数组：
		[value, ...]
		数组下标总是从 0 开始，不允许出现负数下标
	列表：
		[1:1, 2:2, 3:3， ...]
	表：
		{key=value, ...}
	集合：
		{key1, key2, ...}



索引：
	数组专有：
		var[-index]						从后向前的索引
	数组、列表：
		var[index]						访问元素
		var[a to b]						截取数组的一部分
		var[a, b, c, d, ...]			按照索引截取数组的一部分，数组索引会按照顺序重新排列
	表：
		var[index]
		var[~index]						按照通配符匹配，截取表的一部分
		var[a, b, c, d, ...]			按照索引截取表的一部分
