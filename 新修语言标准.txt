变量定义语句：
	变量定义语句使用类型前置写法，例如定义一个整数：
		int a
	定义变量时可以赋初值：
		int a = 0
	支持在同一行定义多个变量：
		int a = 0, b = 1, c = 2
		相当于：
			int a = 0
			int b = 1
			int c = 2
	定义多个变量可以赋初值，也可以使用默认值：
		int a, b = 1, c, d = 2, e
		相当于
			int a
			int b = 1
			int c
			int d = 2
			int e
	可以使用自动类型，根据值推测出对应的静态类型：
		auto a = 1
		a 为 int 类型
	可以定义变体类型变量：
		var a = 1
		a = "asd"
		变体类型变量可以在运行时更改值的类型
	变量定义初值可以赋值为数组、列表、集合、字典：
		array a = new array(1, 2, 3)	// 创建数组
		list a = [1:100, 2:200, 3:300]	// 列表字面量
		var a = []						// 空列表
		set a = new set(1, 2, 3)		// 创建集合
		dict a = {a:1, b:2, c:3, "  中文":4}	// 字典字面量
		var a = {}						// 空字典
		使用 [...] 表示的列表成员值默认为 var
		使用 {...} 表示的字典成员值默认为 var
		空数组使用 new array() 创建
		空集合使用 new set() 创建
	可以使用 new 语句创建对象（包含class、object或内置基础类型）
		dict a = new dict(int)		// 创建一个成员只能包含 int 的字典
		int a = new int(1234)		// 相当于 int a = 1234
		也可以创建自定义类和对象，相当于调用对应类或对象的构造函数

条件分支：
	if exp then code line
	if exp
		code block
	elseif exp
		code block
	else
		code block
	end



条件选择（使用 if 语句实现 select 语句的优势功能，不额外增加 select 语句）：
	if exp in A, B, C then code line
	if exp in 1 to 10 then code line
	if exp in A, B, C
		code block
	elseif exp in 1 to 10
		code block
	else
		code block
	end
	
	!!! 注意 !!!
	这里的 in 和 to 是一种特殊语法糖，仅存在于 if 和 do while 语句的条件表达式中。
	语法糖仅在 in 后面有多个值时生效：
		if exp in A, B, C			// 语法糖，in 后有多个值
		if exp in 1 to 10			// 语法糖，使用 to 表示范围
		if exp in [1, 2, 3]			// 运算符，in 后是单个列表表达式
	编译时将展开为标准的比较表达式：
		if exp in A, B, C
		展开为：if (exp == A) or (exp == B) or (exp == C)
		
		if exp in 1 to 10
		展开为：if (exp >= 1) and (exp <= 10)
	
	此语法糖不可用于其他上下文（如普通表达式、赋值语句等）。
	当 in 后面是单个表达式时，使用运算符章节中的 in 运算符语义（判断是否包含在集合、列表、字典、对象内）。

迭代循环：
	for [k, ]v in obj
		code block
	end
	
	支持遍历的类型：
	列表（list）：
		for v in lst				// 遍历值
		for i, v in lst				// 遍历索引和值
	数组（array）：
		for v in arr				// 遍历值
		for i, v in arr				// 遍历索引和值
	字典（dict）：
		for k, v in tbl				// 遍历键和值
		for k in tbl				// 遍历键
	集合（set）：
		for v in setObj				// 遍历元素（自动去重排序）
	字符串（string）：
		for ch in str				// 遍历字符，ch 为 int32 类型（UTF-32 字符代码）
	对象类（class : object）：
		for k, v in obj				// 遍历对象的所有属性

	do
	while exp in A, B, C
	展开为：

资源管理语句（with）：
	with 资源表达式
		code block
	end
	
	with 语句用于自动管理资源，在代码块结束时自动释放/清理资源。
	
	互斥锁自动加锁/解锁：
		var mtx = mutex()
		with mtx
			// 自动加锁，块结束时自动解锁
			sharedData += 1
		end
	
	带变量声明的 with 语句：
		with var hFile = open("test.txt", "r")
			// 文件在块结束时自动关闭
			var sContent = hFile.read()
		end
	
	多资源管理（用逗号分隔）：
		with var hSrc = open(sSrc, "r"), var hDst = open(sDst, "w")
			hDst.write(hSrc.read())
		end
		// 两个文件都自动关闭
	
	支持嵌套 with 语句。
	即使发生异常，with 也会确保资源被释放。
	
	实现原理：
	with 语句在编译时展开为 try-finally 结构：
		// 源代码
		with var hFile = open("test.txt", "r")
			var sContent = hFile.read()
		end
		
		// 展开为
		var hFile = open("test.txt", "r")
		hFile.__enter__()		// 调用 meta enter
		try
			var sContent = hFile.read()
		finally
			hFile.__exit__()	// 调用 meta exit
		end
	
	资源管理协议：
	自定义类型通过实现 meta enter 和 meta exit 支持 with 语句：
		class MyResource : object
			meta enter()
				// 获取资源，进入 with 块时调用
			end
			meta exit()
				// 释放资源，退出 with 块时调用（包括异常情况）
			end
		end
	
	内置类型的默认行为：
		类型				enter 行为			exit 行为
		mutex				lock()				unlock()
		rwmutex(读)			rlock()				runlock()
		rwmutex(写)			wlock()				wunlock()
		file				(已打开)			close()
		数据库连接			(已连接)			disconnect()
		自定义类			meta enter()		meta exit()
	
	多资源处理顺序：
		with var a = res1(), var b = res2(), var c = res3()
			// code
		end
		// 获取顺序：a -> b -> c
		// 释放顺序：c -> b -> a（栈式，后进先出）



函数定义：
	function name(params)
		code block
	end
	
	参数类型声明：
	参数可以声明数据类型，也可以不声明（不声明则为 var 类型）：
		// 带类型声明的参数
		function add(int a, int b)
			return a + b
		end
		
		// 不带类型声明的参数（默认为 var，仅 xcall 支持）
		function process(a, b, c)
			return a + b + c
		end
		
		// 混合使用（仅 xcall 支持）
		function format(string sName, age, city)
			return `{$sName}, {$age}岁, 来自{$city}`
		end
	
	注意：cdecl 和 stdcall 调用约定的参数必须声明数据类型，因为需要与 C 语言 ABI 兼容。
	
	调用约定：
	函数默认使用 xcall 调用约定（通过数据结构传递参数）
	可以在 function 关键字前添加调用约定关键字：
		xcall function name(params)		// xLang Call（默认）
			code block
		end
		cdecl function name(params)		// C Call
			code block
		end
		stdcall function name(params)	// Stdcall
			code block
		end
		fastcall function name(params)	// fastcall
			code block
		end



外部函数声明（extern）：
	用于声明来自外部库的函数，不包含函数体。
	
	单个外部函数声明：
		extern cdecl function printf(string sFormat, ...)
		extern stdcall function MessageBoxA(int hWnd, string sText, string sCaption, int uType)
	
	DLL 导入（批量声明）：
		extern "user32.dll" {
			stdcall function MessageBoxW(int hWnd, string sText, string sCaption, int uType) as MessageBox
			stdcall function GetSystemMetrics(int nIndex)
		}
	
	使用 as 关键字可以为导入的函数指定别名。
	extern 声明的函数必须指定调用约定（cdecl/stdcall/fastcall）。

函数返回值写法：
	return x
	return				无返回值，直接退出函数
	
	返回值类型声明：
	默认不声明返回值类型时，返回值为 var 类型：
		function add(int a, int b)
			return a + b		// 返回值为 var 类型
		end
	
	类型前置声明，明确指定返回类型：
		int function multiply(int a, int b)
			return a * b		// 返回值为 int 类型
		end
	
	多返回值（仅 xcall 调用约定支持）：
		function divmod(int a, int b)
			return a / b, a % b		// 返回两个值
		end
		
		// 接收多返回值
		int iQuotient, iRemainder = divmod(17, 5)
		
		// 也可以只接收部分返回值
		int iQuotient = divmod(17, 5)		// 只接收第一个
	
	注意：cdecl 和 stdcall 调用约定不支持多返回值，因为它们需要与 C 语言 ABI 兼容。



命名参数：
	函数调用时可以使用命名参数，提高可读性：
		function createPerson(string sName, int iAge, string sCity)
			// ...
		end
		
		// 使用命名参数调用
		createPerson(sName: "张三", iAge: 25, sCity: "北京")
		
		// 命名参数可以打乱顺序
		createPerson(sCity: "北京", sName: "张三", iAge: 25)
		
		// 混合使用（位置参数必须在前）
		createPerson("张三", iAge: 25, sCity: "北京")
	
	注意：命名参数仅在 xcall 调用约定下支持。

类定义：
	class name[ : parent]
		create(param)
			// 构造
		end
		destroy()
			// 析构
		end
		body
	end
	parent 表示父类，类的父类只能是其他类
	类支持构造、析构
	对象代码块内，可使用 self 代表对象自身
	
	成员可见性：
	使用 public、private、protected 关键字控制成员的访问权限：
		public				公开，任何地方都可以访问（默认）
		private				私有，仅类内部可以访问
		protected			受保护，类内部和子类可以访问
	
	示例：
		class Person
			public string sName			// 公开属性
			private int iAge			// 私有属性
			protected string sId		// 受保护属性
			
			public function getName()
				return self.sName
			end
			
			private function validate()
				// 内部方法
			end
		end
	
	class 与 object 的区别：
		class 类似 C++ 的 class，用于定义固定结构的类型
		object 是一种特殊的基类，当 class 继承自 object 时，将获得动态字典特性
	
	普通 class：
		- 成员在编译时确定，不能动态添加
		- 访问不存在的成员会报错
		- 内存布局固定，效率更高
	
	class : object（对象类）：
		- 具备字典特性，可动态添加/删除属性
		- 可使用 obj["key"] = value 语法设置任意属性
		- 可使用 for k, v in obj 遍历所有属性
		- 支持元编程（meta 函数）
		- 适合动态数据处理场景
	
	class name : object
		create(param)
			// 构造
		end
		destroy()
			// 析构
		end
		body
	end
	
	类语句内可以使用结构体和共用体：
	class name : object
		create(param)
			// 构造
		end
		destroy()
			// 析构
		end
		struct name
			// 结构体
		end
		union
			// 共用体
		end
		body
	end

对象属性：
	class name
		get name(param)
			block code
		end
		set name(param, val)
			block code
			return 1
		end
	end
	同一名称的属性，参数数量只能差一个，set 比 get 多一个参数，在最后面，代表设置的新值
	可以在结构域外定义，name 改为 class.name 即可
	
	属性可以传递多个参数，第二个参数开始，为索引参数：
	class name
		get name(param, idx)
			block code
		end
		set name(param, idx, val)
			block code
		end
	end



元编程：
	meta func(param)
		block code
	end
	meta 代表实现一个元语言方法
	支持的元方法列表：
		set：设置了一个未知的成员值
		get：读取了一个未知的成员值
		call：调用了一个未知的函数
		callself：调用了本身
		to(type)：转换为指定类型，如 meta to(int)、meta to(string)
		from(type)：从指定类型转入，如 meta from(float)、meta from(string)
		enter：进入 with 语句块时调用（资源获取）
		exit：退出 with 语句块时调用（资源释放，包括异常情况）

	数组：
		new array(value, ...)
		数组使用 new 语法创建，下标从 0 开始
		数组基于连续内存实现，索引必须从 0 开始且连续，性能高
	列表：
		[key:value, ...]
		列表使用中括号表示，key 为 int64 类型
		[] 表示空列表
		列表基于 AVL 树实现，支持稀疏存储，索引可为 int64 范围内的任意整数
	
	数组与列表的区别：
		特性				数组 (array)			列表 (list)
		底层实现			连续内存				AVL 树
		索引范围			0 开始，必须连续		int64 任意整数
		稀疏存储			不支持				支持
		随机访问性能		O(1)					O(log n)
		插入/删除性能		O(n)					O(log n)
		内存占用			较小					较大
		适用场景			紧凑、顺序数据		稀疏、灵活索引
	字典：
		{key:value, ...}
		字典使用花括号表示，key 为字符串类型
		{} 表示空字典
		
		键名解析规则：
			裸标识符作为字面量键名：
				{ name: "Tom", age: 25 }
				// 等价于 { "name": "Tom", "age": 25 }
			
			显式字符串键（支持特殊字符）：
				{ "my-key": 123, "带空格的键": 456 }
			
			变量/表达式作为键（使用方括号）：
				var key = "name"
				{ [key]: "Tom" }			// 等价于 { "name": "Tom" }
				{ ["pre_" + key]: "value" }	// 支持表达式
	集合：
		new set(value, ...)
		集合使用 new 语法创建，元素自动去重排序



索引：
	数组专有：
		var[-index]						从后向前的索引
	数组、列表：
		var[index]						访问元素
		var[a to b]						截取一部分
		var[a, b, c, d, ...]			按照索引截取一部分，索引按顺序重新排列
	字典：
		var[key]						访问元素
		var[~pattern]					按照通配符匹配，截取字典的一部分
		var[a, b, c, d, ...]			按照键名截取字典的一部分



异步编程：
	支持 async/await 和协程(yield)两种异步模式。
	
	async/await 语法：
		// 定义异步函数
		async function fetchData(url)
			var response = await http.get(url)
			var data = await response.json()
			return data
		end
		
		// 带返回类型的异步函数（async 在最前面）
		async string function fetchText(url)
			var response = await http.get(url)
			return response.text()
		end
		
		// 调用异步函数
		async function main()
			var data = await fetchData("http://api.com")
			print(data)
		end
	
	并发执行：
		// 等待所有任务完成
		var results = await parallel(
			fetchData("url1"),
			fetchData("url2"),
			fetchData("url3")
		)
		
		// 等待第一个完成的任务
		var first = await race(
			fetchData("url1"),
			fetchData("url2")
		)
	
	协程（生成器）：
		// 使用 yield 创建生成器函数
		function range(n)
			for i = 0 to n - 1
				yield i
			end
		end
		
		// 使用生成器
		for v in range(10)
			print(v)
		end
	
	手动控制协程：
		// 创建协程
		var co = coroutine(function()
			print("step 1")
			yield "result1"
			print("step 2")
			yield "result2"
			return "done"
		end)
		
		// 恢复执行
		var r1 = resume(co)		// "result1"
		var r2 = resume(co)		// "result2"
		var r3 = resume(co)		// "done"
		
		// 检查协程状态
		if co.status == "dead"
			print("协程已结束")
		end
	
	Awaitable 类型：
		// 所有 async 函数返回 Awaitable 对象
		var task = fetchData("url")		// 不加 await，返回 Awaitable
		// ... 其他代码 ...
		var data = await task				// 稍后等待结果
	
	异常处理：
		async function riskyTask()
			try
				var data = await fetchData("url")
				return data
			catch e
				print("Async error: " + e.message)
				return null
			end
		end



作用域规则：
	与 C 语言一致，采用块级作用域：
	- 全局作用域：在所有函数外部定义的变量
	- 局部作用域：在函数或代码块内部定义的变量
	- 内层作用域可以访问外层作用域的变量
	- 内层定义的同名变量会遮蔽外层变量
	- 变量在定义它的代码块结束时自动释放
	
	示例：
		int g = 100				// 全局变量
		
		function test()
			int a = 1			// 局部变量
			if true
				int b = 2		// 块级局部变量
				a = a + b		// 可以访问外层的 a
			end
			// b 在此处不可访问
		end

类型转换：
	不支持 C 语言风格的隐式类型转换，使用类型名作为转换函数：
	
	基础类型转换：
		int(value)				// 转换为整数
		int8(value)				// 转换为 int8
		uint32(value)			// 转换为 uint32
		float(value)			// 转换为浮点数
		float64(value)			// 转换为 float64
		string(value)			// 转换为字符串
		bool(value)				// 转换为布尔值
		time(value)				// 转换为时间
	
	容器类型转换：
		array(value)			// 转换为数组
		list(value)				// 转换为列表
		set(value)				// 转换为集合
		dict(value)				// 转换为字典
	
	自定义类型转换（通过元方法）：
	class 需要定义 meta to 元方法才能转换为特定基础类型：
		class Distance
			private float fMeters
			
			// 转换为 float
			meta to(float)
				return self.fMeters
			end
			
			// 转换为 string
			meta to(string)
				return `{$self.fMeters}m`
			end
			
			// 支持从 float 转入
			meta from(float f)
				self.fMeters = f
			end
		end
		
		// 使用
		var d = new Distance(100)
		var f = float(d)			// 调用 meta to(float)
		var s = string(d)			// 调用 meta to(string)
		var d2 = Distance(50.5)		// 调用 meta from(float)
	
	特殊规则：
		- 函数类型不能转换为其他类型
		- var 类型可以转换为其他任何类型（运行时检查）



模块系统：
	文件包含（文本替换，用于头文件）：
		include "header.xlh"
		将指定文件的内容直接插入当前位置，类似 C 语言的 #include
	
	模块导入：
		import math					// 导入整个模块，使用 math.sin() 访问
		import math.sin				// 导入单个成员，可直接使用 sin()
		import math.sin, math.cos	// 导入多个成员
		import math as m			// 别名导入，使用 m.sin() 访问
	
	模块定义：
		每个 .xl 文件自动成为一个模块
		模块名称默认为文件名（不含扩展名）
		模块内所有定义默认为私有，需要显式导出
	
	导出语法：
		export function foo()
			// 导出函数
		end
		
		export class Bar
			// 导出类
		end
		
		export const PI = 3.14159	// 导出常量
		export var config = {}		// 导出变量
	
	模块路径：
		- 相对路径：import "./utils"
		- 绝对路径：import "/lib/math"
		- 标准库：import math（从标准库目录查找）
	
	模块初始化：
		模块可以包含顶层代码，在首次导入时执行
		模块只会被初始化一次，后续导入使用缓存



错误处理：
	支持 try-catch 和错误返回值两种方式。
	
	try-catch 语法：
		try
			// 可能抛出异常的代码
			var f = open("file.txt")
			var data = f.read()
		catch e
			// 异常处理，e 为 Error 对象
			print("Error: " + e.message)
		finally
			// 无论是否发生异常都会执行（可选）
			f.close()
		end
	
	抛出异常：
		throw Error("Something wrong")			// 抛出 Error 对象
		throw Error(code: 100, message: "Failed")	// 带错误码
		throw "Simple message"						// 抛出字符串（自动包装为 Error）
	
	Error 内置类型：
		class Error
			var code		// 错误码（可选）
			var message		// 错误消息
			var stack		// 调用栈信息
		end
	
	错误返回值方式：
		// 函数返回多个值
		function divide(a, b)
			if b == 0
				return null, "Division by zero"
			end
			return a / b, null
		end
		
		// 使用
		var result, err = divide(10, 0)
		if err != null
			print("Error: " + err)
		else
			print(result)
		end
	
	快速错误检查：
		// 如果表达式为假，抛出异常
		assert condition, "Error message"
		assert x > 0		// 默认错误消息："Assertion failed"



多线程：
	支持系统级多线程，利用多核 CPU 并行执行。
	
	创建线程：
		// 创建线程对象
		var t = thread(function(arg)
			print("Thread running: " + arg)
			return "result"
		end)
		
		// 启动线程
		t.start("hello")
		
		// 等待线程结束，获取返回值
		var result = t.join()
		
		// 线程属性
		t.id			// 线程ID
		t.status		// "pending" / "running" / "finished" / "error"
		t.detach()		// 分离线程（不需要 join）
	
	简化的 spawn 语法：
		// 启动并行任务（自动创建线程）
		var handle = spawn
			heavyComputation()
		end
		
		// 等待结果
		var result = await handle
	
	互斥锁：
		var mtx = mutex()
		
		mtx.lock()
		// 临界区代码
		mtx.unlock()
		
		// 自动解锁语法
		with mtx
			// 自动 lock/unlock
			sharedData += 1
		end
		
		// 尝试加锁（非阻塞）
		if mtx.trylock()
			// 成功获取锁
			mtx.unlock()
		end
	
	读写锁：
		var rwlock = rwmutex()
		
		rwlock.rlock()		// 读锁（共享）
		// 读取共享数据
		rwlock.runlock()
		
		rwlock.wlock()		// 写锁（独占）
		// 修改共享数据
		rwlock.wunlock()
	
	信号量：
		var sem = semaphore(5)	// 初始值 5
		
		sem.wait()		// P 操作，减 1
		sem.signal()	// V 操作，加 1
	
	条件变量：
		var cond = condition()
		var mtx = mutex()
		
		// 等待线程
		with mtx
			while not ready
				cond.wait(mtx)
			end
		end
		
		// 通知线程
		with mtx
			ready = true
			cond.signal()		// 唤醒一个
			cond.broadcast()	// 唤醒所有
		end
	
	原子操作：
		var counter = atomic(0)
		
		counter.load()			// 读取
		counter.store(10)		// 存储
		counter.add(1)			// 原子加
		counter.sub(1)			// 原子减
		counter.exchange(20)	// 交换
		counter.cas(old, new)	// 比较并交换



通道 (Channel)：
	线程间通信的推荐方式。
	
	创建通道：
		var ch = channel()			// 无缓冲通道（同步）
		var ch = channel(10)		// 缓冲通道，容量 10
	
	发送和接收：
		ch.send(value)				// 发送（可能阻塞）
		var value = ch.recv()		// 接收（可能阻塞）
	
	非阻塞操作：
		var ok = ch.trysend(value)	// 尝试发送
		var value, ok = ch.tryrecv()	// 尝试接收
	
	关闭通道：
		ch.close()
	
	遍历通道（直到关闭）：
		for msg in ch
			print(msg)
		end
	
	select 多路复用：
		select
			case msg = ch1.recv()
				print("from ch1: " + msg)
			case msg = ch2.recv()
				print("from ch2: " + msg)
			case ch3.send("hello")
				print("sent to ch3")
			default
				print("no channel ready")
		end



线程池：
	管理一组工作线程，适合大量短任务。
	
	创建线程池：
		var pool = threadpool(4)	// 4 个工作线程
	
	提交任务：
		var future = pool.submit(function(x)
			return x * x
		end, 10)
		
		// 获取结果
		var result = future.get()	// 阻塞等待
		var result = await future	// 异步等待
	
	批量执行：
		var results = pool.map(function(x)
			return x * x
		end, [1, 2, 3, 4, 5])
	
	关闭线程池：
		pool.shutdown()			// 等待所有任务完成
		pool.terminate()		// 立即终止



协程与线程的配合：
	// async/await 默认在单线程上运行（异步 I/O）
	async function fetchAll(urls)
		var results = []
		for url in urls
			var data = await http.get(url)	// 协程切换，不阻塞
			results.append(data)
		end
		return results
	end
	
	// 在线程池上执行 CPU 密集任务
	async function processData(data)
		var result = await threadpool.run(function()
			return heavyComputation(data)
		end)
		return result
	end
