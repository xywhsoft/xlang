数组与列表的区别：
	特性				数组 (array)			列表 (list)

	稀疏存储			不支持				支持
	随机访问性能		O(1)				O(log n)
	插入/删除性能		O(n)			O(log n)
	内存占用			较小					较大
	适用场景			紧凑、顺序数据		稀疏、灵活索引

索引：
	数组专有（索引从 0 开始）：
		arr[idx]						正常索引
		var[-idx]						从后向前索引（编译时映射为 length - idx）
		var[a to b]						截取一部分（返回数组）
		var[a, b, c, d, ...]			按照索引截取一部分（返回数组）
	数组、列表：
		var[idx]						正常索引（list 使用 int64 做 key，因此正数负数都支持作为索引使用）
		var[a to b]						截取一部分（返回列表）
		var[a, b, c, d, ...]			按照索引截取一部分（返回列表）
	字典：
		var[key]						访问元素
		var[~pattern]					按照通配符匹配，截取字典的一部分
		var[a, b, c, d, ...]			按照键名截取字典的一部分
	字符串（索引从 0 开始）：
		str[idx]						返回第 i 个字符
		str[-idx]						返回倒数第 i 个字符（编译时映射为 length - idx）
		var[a to b]						返回字符串中的某一段



作用域规则：
	与 C 语言一致，采用块级作用域：
	- 全局作用域：在所有函数外部定义的变量
	- 局部作用域：在函数或代码块内部定义的变量
	- 内层作用域可以访问外层作用域的变量
	- 内层定义的同名变量会遮蔽外层变量
	- 变量在定义它的代码块结束时自动释放
	
	示例：
		int g = 100				// 全局变量
		
		function test()
			int a = 1			// 局部变量
			if true
				int b = 2		// 块级局部变量
				a = a + b		// 可以访问外层的 a
			end
			// b 在此处不可访问
		end



类型转换：
	不支持 C 语言风格的隐式类型转换，使用类型名作为转换函数：
	
	基础类型转换：
		int(value)				// 转换为整数
		int8(value)				// 转换为 int8
		uint32(value)			// 转换为 uint32
		float(value)			// 转换为浮点数
		float64(value)			// 转换为 float64
		string(value)			// 转换为字符串
		bool(value)				// 转换为布尔值
		time(value)				// 转换为时间
	
	容器类型转换：
		array(value)			// 转换为数组
		list(value)				// 转换为列表
		set(value)				// 转换为集合
		dict(value)				// 转换为字典
	
	自定义类型转换（通过元方法）：
	class 需要定义 meta to 元方法才能转换为特定基础类型（可以抛出异常）：
		class Distance
			private float fMeters
			
			// 构造函数
			create(float val)
				fMeters = val
			end
			
			// 请求将类型转换为特定类型
			meta to(type t)
				if t == float
					// 转换为 float
					return self.fMeters
				elseif t == string
					// 转换为 string
					return `{$self.fMeters}`
				else
					return null
				end
			end
			
			// 支持从 float 转入
			meta from(type t, var val)
				// 支持从 float 转入
				if t == float
					self.fMeters = val
				else
					self.fMeters = 0.0
				end
			end
		end
		
		// 使用
		var d = new Distance(100)
		var f = float(d)			// 调用 meta to(float)
		var s = string(d)			// 调用 meta to(string)
		var d2 = Distance(50.5)		// 调用 meta from(float, 50.5)
	
	如果两种类型分别实现了对各自的 to 和 from 元方法，按照以下方式设定优先级：
		目标类型的 from 方法 > 源类型的 to 方法，当调用目标类型的 from 方法返回 null 时，会再尝试调用源类型的 to 方法
	
	可以调用 to 和 from 方法转换类型（会调用对应的元方法）：
		obj.to(string)
		obj.from(int, 1000)
	
	内置类型转换规则：
		由于 null 不可声明为变量类型，所以任何类型都不能转换为 null
		bool：数字 0 为 false，其他值为 true（浮点数也是）；字符串空返回 false，其他值为 true；null 为 false，其他值为 true
		int：null 为 0；true 为 1；false 为 0；数字和浮点数可以互相转换可能损时精度；字符串可以转换为数字；
		float：null 为 0.0；true 为 1.0；false 为 0.0；数字和浮点数可以互相转换可能损时精度；字符串可以转换为数字；
		string：null 为 ""；true 为 "true"；false 为 "false"；数字、时间、指针、数组、列表、集合、字典、类、对象类都可以转换为字符串（以各个类型的表达方式展示）。
		time：只能和 int64、string 相互转换
		point：只能和整数类型相互转换，或转换为字符串
		array：可以转换为列表，可以和 set 互相转换（但可能丢失排序），可以转换为字符串			// 可以通过特定函数，将 list 和 dict 的 key、val 转换为 array
		list：可以从 array 转换，可以转换为字符串
		set：可以和 array 相互转换（但可能丢失排序），可以转换为字符串
		dict：可以转换为字符串
		function：不可以和任何类型相互转换（包括 point，因为 point 不包含调用信息）
		class 和 custom 只能根据 to 和 from 元方法决定能够转换为哪些数据类型

变量定义语句：
	变量定义语句使用类型前置写法，例如定义一个整数：
		int a
	定义变量时可以赋初值：
		int a = 0
	支持在同一行定义多个变量：
		int a = 0, b = 1, c = 2
		相当于：
			int a = 0
			int b = 1
			int c = 2
	多返回值写法(编译阶段会检查函数定义，只有定义了多返回值的函数，才能使用这种写法)：
		auto (a, b) = foo()
		不同类型的多返回值，可以先定义后接收：
		int iCode
		string sRet
		(iCode, sRet) = foo()
		等号左侧值使用括号包起来多个变量的情况，是属于多返回值的专用写法，编译期间会检查右值，右值必须为函数，或多值赋值写法，否则会报错：
		(a, b) = (b, a)
		
	定义多个变量可以赋初值，也可以使用默认值：
		int a, b = 1, c, d = 2, e
		相当于
			int a
			int b = 1
			int c
			int d = 2
			int e
	可以使用自动类型，根据值推测出对应的静态类型：
		auto a = 1
		a 为 int64 类型
	可以定义变体类型变量：
		var a = 1
		a = "asd"
		变体类型变量可以在运行时更改值的类型
	变量定义初值可以赋值为数组、列表、集合、字典：
		array a = new array(1, 2, 3)	// 创建数组
		list a = [1:100, 2:200, 3:300]	// 列表字面量
		var a = []						// 空列表
		set a = new set(1, 2, 3)		// 创建集合
		dict a = {a:1, b:2, c:3, "  中文":4}	// 字典字面量
		var a = {}						// 空字典
		空数组使用 new array() 创建
		空集合使用 new set() 创建
	可以使用 new 语句创建对象（包含class、object或内置基础类型）
		dict a = new dict(int)		// 创建一个成员只能包含 int 的字典
		int a = new int(1234)		// 相当于 int a = 1234
		也可以创建自定义类和对象，相当于调用对应类或对象的构造函数



常量定义语句：
	常量定义只需要在变量定义的基础上前面加个 const：
		const int a = 1
	常量定义必须赋值，定义后不可修改
	常量定义赋初值时，可以代入表达式，但表达式中只能出现常量和立即值（字面量）



条件分支：
	if exp then code line
	if exp
		code block
	elseif exp
		code block
	else
		code block
	end



条件选择（使用 if 语句实现 select 语句的优势功能，不额外增加 select 语句）：
	if exp in [A, B, C] then code line
	if exp in 1 to 10 then code line
	if exp in 1 to 10 step 2 then code line			// 相当于 exp in [1, 3, 5, 7, 9]
	if exp in [A, B, C]
		code block
	elseif exp in 1 to 10
		code block
	else
		code block
	end
	
	当 exp in array 为立即值（字面量）编译时将展开为标准的比较表达式：
		if exp in [A, B, C]
		展开为：if (exp == A) or (exp == B) or (exp == C)
	
	当 exp in 1 to 10 编译时，将展开为范围比较表达式：
		if exp in 1 to 10
		展开为：if (exp >= 1) and (exp <= 10)
	
	当 exp in 1 to 10 step 编译时，将展开为范围比较表达式 + 条件判断：
		if exp in 1 to 10 step 2
		展开为：if (exp >= 1) and (exp <= 10) and ((exp - 1) % 2 == 0)

		code block
	end
	
	支持遍历的类型：
	
	数组（array）：
		for v in arr				// 遍历值
		for i, v in arr				// 遍历索引和值
	列表（list）：
		for v in lst				// 遍历值
		for i, v in lst				// 遍历索引和值
	字典（dict）：
		for k, v in tbl				// 遍历键和值
		for k in tbl				// 遍历键
	集合（set）：
		for v in setObj				// 遍历集合元素
	字符串（string）：
		for ch in str				// 遍历字符，ch 为 int32 类型（UTF-32 字符代码）
	对象类（class or object）：
		for k, v in obj				// 遍历对象的所有属性
		for k in obj				// 遍历对象的所有键
	
	也可以实现计次循环（range 也可以遍历）：
	
	for i in 1 to 10
		code block
	end
	for i in 1 to 10 step 2
		code block
	end



条件循环：
	// 前置条件检查
	while exp do
		code block
	end
	
	// 后置条件检查（至少执行一次）
	do
		code block
	while exp end
	
	和 if 语句一样，支持对 in、to 语句的展开优化



循环跳出：
	break				只跳出当前循环，相当于 break 1
	break 2				跳出当前循环后，再立刻跳出外层循环一次
	continue			跳过本轮循环，相当于 continue 1
	continue 2			跳过两轮循环



资源管理语句（with）：
	with 资源表达式
		code block
	end
	
	with 语句用于自动管理资源，在代码块结束时自动释放/清理资源。
	
	互斥锁自动加锁/解锁：
		mutex mtx = new mutex()
		with mtx
			// 自动加锁，块结束时自动解锁
			sharedData += 1
		end
	
	带变量声明的 with 语句：
		with open("test.txt", "r") as hFile
			// 文件在块结束时自动关闭
			var sContent = hFile.read()
		end
	
	多资源管理（用逗号分隔）：
		with open(sSrc, "r") as hSrc, open(sDst, "w") as hDst
			hDst.write(hSrc.read())
		end
		// 两个文件都自动关闭
	
	支持嵌套 with 语句。
	即使发生异常，with 也会确保资源被释放。
	
	实现原理：
	with 语句在编译时展开为 try-finally 结构：
		// 源代码
		with open("test.txt", "r") as hFile
			var sContent = hFile.read()
		end
		
		// 展开为
		file hFile = open("test.txt", "r")
		hFile.__enter__()		// 调用 meta enter
		try
			var sContent = hFile.read()
		finally
			hFile.__exit__()	// 调用 meta exit
		end
	
	资源管理协议：
	自定义类型通过实现 meta enter 和 meta exit 支持 with 语句：
		class MyResource extends object
			meta enter()
				// 获取资源，进入 with 块时调用
			end
			meta exit()
				// 释放资源，退出 with 块时调用（包括异常情况）
			end
		end
	
	内置类型的默认行为：
		类型					enter 行为			exit 行为
		mutex				lock()				unlock()
		file				(已打开)				close()
		数据库连接			(已连接)				disconnect()
		自定义类				meta enter()		meta exit()
	
	多资源处理顺序：
		with res1() as a, res2() as b, res3() as c
			// code
		end
		// 获取顺序：a -> b -> c
		// 释放顺序：c -> b -> a（栈式，后进先出）



函数定义：
	
	// 默认返回值（返回 var 类型，默认为 null）
	function name(params)
		return				// 缺省返回 null
	end
	
	// 设置返回值类型
	function name(params) as int
		return 0
	end
	
	// 多返回值
	function name(params) as int, string
		return 0, "text"
	end
	
	// 无返回值（兼容 C 语言）
	function name(params) as void
		return				// 退出函数，无返回值
	end



函数参数类型声明：
	参数可以声明数据类型，也可以不声明（不声明则为 var 类型）：
	
	// 带类型声明的参数
	function add(int a, int b)
		return a + b
	end
	
	// 不带类型声明的参数（参数默认使用 var 数据类型）
	function process(a, b, c)
		return a + b + c
	end
	
	// 混合使用（未声明类型的参数使用 var 数据类型）
	function format(string sName, age, city)
		return `{$sName}, {$age}岁, 来自{$city}`
	end



函数调用约定
	函数默认使用 xcall 调用约定，可以在 function 关键字前添加调用约定关键字
	cdecl、Stdcall、fastcall 为 ABI 兼容其他语言函数调用使用，并不支持所有 xlang 语言特性。
	
	// xLang Call（默认）
	xcall function name(params)
		code block
	end
	
	// C Call
	cdecl function name(params)
		code block
	end
	
	// Stdcall
	stdcall function name(params)
		code block
	end
	
	// fastcall
	fastcall function name(params)
		code block
	end



函数可选参数：
	function name(a, b = 1, c = 2)
		code block
	end
	可选参数只能出现在尾端，不能出现在前端，避免参数传递出现歧义



函数可变参数：
	
	// 数组可变参数（仅 xcall 支持）
	function name(a, ...)
		print(arg)				// 输出数组
	end
	使用 ... 表示数组型可变参数，使用可变参数的函数，内部会自动生成 arg 参数，表示可变参数数组
	
	// 字典可变参数（仅 xcall 支持）
	function name(a, ***)
		print(arg)				// 输出字典
	end
	使用 *** 表示字典型可变参数，使用可变参数的函数，内部会自动生成 arg 参数，表示可变参数字典
	
	导入 xlang 环境的 cdecl 函数可以支持 ... 可变参数调用（但需要注意数据类型，xlang 不会进行类型转换，数据类型传递不正确可能导致程序崩溃）



函数返回值写法：
	return						// 无返回值或返回 null
	return x					// 单个返回值
	return x, y, z				// 多返回值
	
	// 默认不声明返回值类型时，返回值为 var 类型：
	function add(int a, int b)
		return a + b		// 返回值为 var 类型
	end
	
	// 声明类型，明确指定返回类型：
	function multiply(int a, int b) as int
		return a * b		// 返回值为 int 类型
	end
	
	// 多返回值（仅 xcall 调用约定支持）：
	function divmod(int a, int b) as int, int
		return a / b, a % b		// 返回两个值
	end
	
	// 接收多返回值（使用括号接收多个返回值时，必须接收全部返回值，编译器会进行参数数量和类型检查[可使用 auto 类型接收]，会报类型不匹配错误）
	auto (iQuotient, iRemainder) = divmod(17, 5)
	
	// 等号左侧值使用括号包起来多个变量的情况，是属于多返回值的专用写法
	(iQuotient, iRemainder) = divmod(17, 5)
	
	// 也可以只接收第一个返回值，编译器自动丢弃其他返回值数据
	int iQuotient = divmod(17, 5)		// 只接收第一个返回值
	
	注意：cdecl 和 stdcall 调用约定不支持多返回值，因为它们需要与 C 语言 ABI 兼容。



命名参数：
	函数调用时可以使用命名参数，提高可读性：
	
	function createPerson(string sName, int iAge, string sCity)
		// ...
	end
	
	// 使用命名参数调用
	createPerson(sName: "张三", iAge: 25, sCity: "北京")
	
	// 命名参数可以打乱顺序
	createPerson(sCity: "北京", sName: "张三", iAge: 25)
	
	// 混合使用（位置参数必须在前）
	createPerson("张三", iAge: 25, sCity: "北京")



外部函数声明（extern）：
	用于声明来自外部库的函数，不包含函数体。
	
	// 单个外部函数声明
	extern cdecl function printf(string sFormat, ...) as string
	extern stdcall function MessageBoxA(int hWnd, string sText, string sCaption, int uType) as int32 alias msgbox
	
	// DLL 导入（批量声明）：
	extern "user32.dll"
		stdcall function MessageBoxW(int hWnd, string sText, string sCaption, int uType) as int32
		stdcall function GetSystemMetrics(int nIndex) as int32
	end
	
	使用 alias 关键字可以为导入的函数指定别名。
	extern 声明的函数必须指定调用约定（xcall/cdecl/stdcall/fastcall）。



枚举类型：
	enum name
		VALUE1			// 默认为 0
		VALUE2 = 10
		VALUE3			// 自动为 11
	end
	
	基本用法：
		enum Color
			RED
			GREEN
			BLUE
		end
		
		var c = Color.RED
		if c == Color.GREEN
			print("绿色")
		end
	
	指定底层类型（不指定则默认为 int）：
		enum Status as int8			// 使用 int8 存储
			OK = 0
			ERROR = -1
		end
	
	字符串枚举：
		enum HttpMethod as string
			GET = "GET"
			POST = "POST"
			PUT = "PUT"
			DELETE = "DELETE"
		end
	
	位标志枚举：
		enum Flags
			NONE = 0
			READ = 1
			WRITE = 2
			EXECUTE = 4
			ALL = READ | WRITE | EXECUTE
		end
		
		var perm = Flags.READ | Flags.WRITE
		if (perm & Flags.READ) != 0
			print("可读")
		end



类定义：
	class name[ extends parent]
		create(param)
			// 构造
		end
		destroy()
			// 析构
		end
		body
	end
	parent 表示父类，类的父类只能是其他类
	类支持构造、析构
	对象代码块内，可使用 self 代表对象自身
	
	成员可见性：
	使用 public、private、protected 关键字控制成员的访问权限（成员变量、成员函数、属性、共用体都可以使用）：
		public				公开，任何地方都可以访问（默认）
		private				私有，仅类内部可以访问
		protected			受保护，类内部和子类可以访问
	
	示例：
		class Person
			public string sName			// 公开属性
			private int iAge			// 私有属性
			protected string sId		// 受保护属性
			
			public function getName()
				return self.sName
			end
			
			private function validate()
				// 内部方法
			end
		end
	
	class 与 object 的区别：
		class 类似 C++ 的 class，用于定义固定结构的类型
		object 是一种特殊的基类，当 class 继承自 object 时，将获得动态字典特性
	
	普通 class：
		- 成员在编译时确定，不能动态添加
		- 访问不存在的成员会报错
		- 内存布局固定，效率更高
		- 元编程支持有限
	
	class extends object（对象类）：
		- 具备字典特性，可动态添加/删除属性
		- 可使用 obj["key"] = value 语法设置任意属性
		- 可使用 for k, v in obj 遍历所有动态添加的属性
		- 支持更多元编程特性（meta 函数）
		- 适合动态数据处理场景
	
	类语句内可以使用共用体（兼容 C 语言，可以使用 public、private、protected 关键字控制访问权限）：
	class name extends object
		union name
			// 共用体
		end
		create(param)
			// 构造
		end
		destroy()
			// 析构
		end
		body
	end
	
	类定义的成员不能使用相同的名字（get、set算一个成员），包括成员变量、属性、共用体成员



对象成员函数：
	class name
		function func(param)
			block code
		end
	end
	
	可以在结构域外定义，name 改为 class.name 即可：
	function class.name()
		block code
	end
	
	构造函数也可以在结构域外定义：
	create className(param)
		// 构造
	end
	destroy className()
		// 析构
	end



对象属性：
	class name
		get name(param)
			block code
		end
		set name(param, val)
			block code
			return 1
		end
	end
	同一名称的属性，参数数量只能差一个，set 比 get 多一个参数，在最后面，代表设置的新值
	可以在结构域外定义，name 改为 class.name 即可
	
	属性可以传递多个参数，第二个参数开始，为索引参数，若存在同名的 get 和 set，set 的参数数量必须 = get 参数数量 + 1，且额外参数必须在末尾，否则直接报错。：
	class name
		get name(param, idx)
			block code
		end
		set name(param, idx, val)
			block code
		end
	end
	
	也可以在结构域外定义，name 改为 class.name 即可：
	get class.name(param, idx)
		block code
	end
	set class.name(param, idx, val)
		block code
	end



元编程：
	meta func(param)
		block code
	end
	meta 代表实现一个元语言方法
	支持的元方法列表：
		set：设置了一个未知的成员值（仅支持对象类）
		get：读取了一个未知的成员值（仅支持对象类）
		call：调用了一个未知的函数（仅支持对象类）
		callself：调用了本身
		to(type)：转换为指定类型
		from(type, val)：从指定类型转入
		enter：进入 with 语句块时调用（资源获取）
		exit：退出 with 语句块时调用（资源释放，包括异常情况）











错误处理（构思中）：
	支持 try-catch 和错误返回值两种方式。
	
	try-catch 语法：
		try
			// 可能抛出异常的代码
			var f = open("file.txt")
			var data = f.read()
		catch e
			// 异常处理，e 为 Error 对象
			print("Error: " + e.message)
		finally
			// 无论是否发生异常都会执行（可选）
			f.close()
		end
	
	抛出异常：
		throw(Error.IO, "Something wrong", 1000)
	
	Error 内置类型：
		class Error
			var type		// 异常类型
			var message		// 错误消息
			var code		// 错误码（可选）
			var stack		// 调用栈信息
		end
	
	断言：
		assert condition, "Error message"
		assert x > 0		// 默认错误消息："Assertion failed"



异步编程（构思中）：
	支持 async/await 和协程(yield)两种异步模式。
	
	async/await 语法：
		// 定义异步函数
		async function fetchData(url)
			var response = await http.get(url)
			var data = await response.json()
			return data
		end
		
		// 带返回类型的异步函数（async 在最前面）
		async string function fetchText(url)
			var response = await http.get(url)
			return response.text()
		end
		
		// 调用异步函数
		async function main()
			var data = await fetchData("http://api.com")
			print(data)
		end
	
	并发执行：
		// 等待所有任务完成
		var results = await parallel(
			fetchData("url1"),
			fetchData("url2"),
			fetchData("url3")
		)
		
		// 等待第一个完成的任务
		var first = await race(
			fetchData("url1"),
			fetchData("url2")
		)
	
	协程（生成器）：
		// 使用 yield 创建生成器函数
		function range(n)
			for i = 0 to n - 1
				yield i
			end
		end
		
		// 使用生成器
		for v in range(10)
			print(v)
		end
	
	手动控制协程：
		// 创建协程
		var co = coroutine(function()
			print("step 1")
			yield "result1"
			print("step 2")
			yield "result2"
			return "done"
		end)
		
		// 恢复执行
		var r1 = resume(co)		// "result1"
		var r2 = resume(co)		// "result2"
		var r3 = resume(co)		// "done"
		
		// 检查协程状态
		if co.status == "dead"
			print("协程已结束")
		end
	
	Awaitable 类型：
		// 所有 async 函数返回 Awaitable 对象
		var task = fetchData("url")		// 不加 await，返回 Awaitable
		// ... 其他代码 ...
		var data = await task				// 稍后等待结果
	
	异常处理：
		async function riskyTask()
			try
				var data = await fetchData("url")
				return data
			catch e
				print("Async error: " + e.message)
				return null
			end
		end



模块系统（构思中）：
	文件包含（文本替换，用于头文件）：
		include "header.xlh"
		将指定文件的内容直接插入当前位置，类似 C 语言的 #include
	
	模块导入：
		import math					// 导入整个模块，使用 math.sin() 访问
		import math.sin				// 导入单个成员，可直接使用 sin()
		import math.sin, math.cos	// 导入多个成员
		import math as m			// 别名导入，使用 m.sin() 访问
	
	模块定义：
		每个 .xl 文件自动成为一个模块
		模块名称默认为文件名（不含扩展名）
		模块内所有定义默认为私有，需要显式导出
	
	导出语法：
		export function foo()
			// 导出函数
		end
		
		export class Bar
			// 导出类
		end
		
		export const PI = 3.14159	// 导出常量
		export var config = {}		// 导出变量
	
	模块路径：
		- 相对路径：import "./utils"
		- 绝对路径：import "/lib/math"
		- 标准库：import math（从标准库目录查找）
	
	模块初始化：
		模块可以包含顶层代码，在首次导入时执行
		模块只会被初始化一次，后续导入使用缓存
