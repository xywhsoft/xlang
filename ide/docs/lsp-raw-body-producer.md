# 原始函数体的增量生产

2026-10-29，M7a2b68a，开发服务 0.97。本切片通过默认补全的真实 raw 函数体省略及阶段性能验收，完整 LSP 与整体性能目标仍为 active。首版继续外部 xlang-ls.exe，未来保留 opaque C 边界并入 xlc.dll，不包含 DAP 或运行／调试态补全。

## 默认生产路径

默认补全在原编译器私有 AST 复制之前判断是否可省略未改正文：独立持有已有不可变语法单元，只复制当前头部与正文占位，当前查询所在函数保持完整。原导入、标准库、语义上下文、完整来源／坐标／类型／符号及分配区间证明仍全部执行。成功后恢复当前头部事实，并独立持有原正文事实；不保留旧完整检查结果来冒充函数单元。

范围为普通非泛型 func、显式返回类型、没有内部实体／yield／标准库特征贡献的独立正文。构建工具核对固定原标准库中 146 个类型及 18 个成员查询名字的完整域；即使标准库位已置位，原匹配事件仍计入正文贡献。完整 raw 模块头、原始请求路径、解析候选、清单、包环境与原生语义上下文必须一致，不以局部读集合代替完整上下文准入。

来源身份沿用已有 XRT 绝对路径接口。原始 AST 路径和请求拼写仍进入完整证明。关闭的入口可能保留配置路径拼写；没有原来源报告精确身份的函数继续完整复制，其余已证明函数仍可复用，避免每次编辑都做无效部分尝试。

省略后如遇预处理、语义、分配、来源或坐标证明失败，丢弃整个私有尝试，进行一次干净完整重试。公开完整 AST 请求独立执行原始全量查询，受各自输入和锁保护；不暴露部分树。没有旧 memo 时直接调用原完整复制器，再登记已完成来源，省去无用投影构造。

## 所有权与冷路径

继续使用原 parser/import/stdlib/sem 和 XRT 数组、映射、字符串、原子引用、互斥及分配器。现有前端上下文 TLS 槽增加 raw 指针，作用域为 48 字节，不新增 TLS 域。raw 作用域与 memo 各有 32 MiB 已知容量预算，模块环境为 8 MiB；不挪用原 64 MiB 语义事实预算。这些局部容量不等于全进程 RSS、瞬时峰值或调用方保留的历史结果。

冷路径容量在原本必须执行的来源绑定遍历中完成。构建工具从固定原 AST 函数机械派生带计量的版本；原生成 AST 实现仍作为逐字节相同前缀保留，私有节点布局不变。单节点容量谓词由完整 generic 算法和派生遍历共享，包含 childCapacity、字符串、二进制 literal 等原字段。完整值在不可变语法单元发布前写入；raw 及 word 所有者复用该值。

原来源函数只访问 children 和 inferredType。遇到 semanticDeclaredType、池节点、过深或无法完整计量的数据，新 helper 只拒绝可选计量，不改变原来源绑定结果，继续原完整 generic 算法。generic 的临时同来源快取仅跳过同一指针的重复映射查询，同路径文字的不同来源对象仍分别计量。原完整类型证明已枚举所有 located 边；raw 单元按原谓词统计稀疏头部，以完整证明计算正文补集，避免再次遍历已证明正文。
