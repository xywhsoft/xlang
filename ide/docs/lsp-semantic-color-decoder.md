# IDE 语义着色的后台解码

2026-11-10，M7b3a。服务已经提供标准 semanticTokens full/range/delta；本阶段完成 IDE 侧可独立验收的解码与结果所有权基础，加入实际 GUI 链接。尚未在初始化消息中启用语义 token、发出着色请求或改变编辑器绘制。

## 数据与执行

`services/semantic_color_result.{h,c}` 使用 XRT 管理不可变结果、线程、锁和条件变量。图例为本客户端支持的 12 种原生角色及 declaration/readonly/async 的有序子集；不能识别或重复的图例不启用着色。角色和修饰符与主题颜色分离。

full 的整数数据和 delta 的编辑都经过验证。delta 可以乱序，所有偏移都基于同一旧整数数组；排序保留相同偏移的原始次序，支持先插入、后替换的合法组合，拒绝相交删除或删除后同偏移插入。编辑可以落在五元组内部。结果直接复制未改变片段和插入片段一次，不先克隆再逐段挪动。完整响应可以替代 delta 响应。缺少旧 resultId、图例不同、整数越界、数量或结构错误时拒绝应用，旧结果保持不变。resultId 只用于整数历史，不证明文档新鲜度。

解码沿已验证的不可变 UTF-8 文本单向前进，保留原始 BOM、CRLF/CR/LF；UTF-16 端点必须精确落在字符边界，范围不得重叠。不会为每个 token 重扫长行前缀。扫描按实际消耗的字节数轮询取消，避免非对齐四字节 Unicode 始终错过绝对偏移模数。范围以原始字节偏移保存，可按精确词法跨度二分查找，供之后覆盖可见标识符颜色。

本模块只接收当前原生服务的单行 token 契约；零长度、跨行或超过行尾的 token 整体拒绝，回退词法高亮。它不执行通用第三方服务中多行 token 的行尾裁切规则。源错误的 null 是合法的空结果，清除着色及旧历史 ID。文档身份、版本、连接、输入和配置代次仍须由后续控制器在发布与绘制时核验；解码结果本身不携带新鲜度承诺。

单个任务最多 65,536 token、327,680 个整数，源文本最多 8 MiB。默认已知容量预算 16 MiB，包含结果对象、整数、范围、ID 和临时编辑数组，记录实际结果容量及阶段峰值；不包含输入 JSON、文本、借用的上一结果、分配器开销或其他任务。各个任务的额度不是整个进程的内存上限。

## 有界工作线程

`xideColorDecoderSubmit` 只复制小图例，成功时转交已有 JSON、文本和旧结果的所有权。每个解码器具有一个运行任务、一个等待任务、一个完成槽和一个退休槽。满槽返回失败且不接管参数，由调用者施加背压；不会增加无界队列。

取消只改变当前 token 并通知线程；普通路径不 join、不在 UI 上递归释放 JSON 或大结果。过期完成对象及显式退休对象均由同一线程释放。新 token 严格递增，解码前、扫描中及发布时检查取消；只有仍匹配的完成结果能被取走。唤醒回调只通知拥有者。最终销毁必须在调用者停止并发访问后进行，是唯一等待线程退出的路径。

## 验收与复现

在真实 `release/win_x64` 使用测试专属 EXE 别名，匹配 XGE SDK/DLL，保留全部六个默认程序／引擎的摘要。对象和日志位于 `ide/build/Release/lsp-semantic-color-ui-20261110`，F 盘保存大材料。

- 三个常规 C 夹具：175 项解码／生命周期检查，332,391 项故障／容量断言（包含 327,680 次大输入数组构造），16 项实际工作线程暂停检查。真实分配失败覆盖 full 的 4 个和 delta 的 5 个生产分配点，逐个取消位置、精确容量边界和原结果不变均验证。
- 工作线程阻塞在真实整数读取内部时，取消仍返回，旧结果不能发布；新任务有界排队，过期结果和退休数组在非 UI 线程释放。另一组测试在完成唤醒处暂停，验证取消后不交付及 JSON 释放线程。
- 四个实际 C 破坏对照分别删除代理项内部端点证明、旧图例证明、改回绝对偏移模数轮询，以及改为拥有者释放退休对象；现有夹具全部检出。不是仅修改预期值。
- 真实服务输出由 Python 独立计算 UTF-16／UTF-8 预期，再送入同一 IDE C 解码器；8 个场景、1,897 项逐整数／范围检查通过，包含 BOM／CRLF／中文／emoji、空 delta、两次编辑 delta、源错误清除与恢复、未知历史返回完整数据。编译器路径不存在，证明使用原生后端。
- 完整重建 116 个 GUI 共享对象，配对既有合格服务执行 26 项 GUI 回归，包括 C/xlang 输入、删除／撤销、Unicode/IME、焦点、补全、签名、导航、引用及搜索；另检查 IME、浅色补全和深色搜索截图。本轮服务生产源码未改变，原 162 项原生回归资料继承核对，不计为重新执行。

完整 GUI 构建在新夹具及注册项继续编写前已冻结源码；新增的测试工具和测试列表没有改变实际解码生产对象。最终源／对象对应和这些仅测试差异独立记录，不将旧对象冒充新消费者。

本阶段没有替换默认 IDE／语言服务，没有推送线上；没有进行新的端到端性能准入，也不撤销既有矩阵和 A/A 失败。下一阶段继续接通低开销样式覆盖接口、请求／响应路由、文档／配置失效、IME／关闭／重连的渲染守卫，然后验收可见语义着色和 UI 开销。重命名、格式化、引擎资产对齐、大工程及长期运行验收仍待完成。
