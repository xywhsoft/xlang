# 跳转到行与列

编辑菜单、真实代码编辑器的右键菜单和 Ctrl+G 共用 `editor.gotoLine` 动作，稳定 ID 为 77；对应 SDK 原生命令为 `XUI_CODE_COMMAND_GOTO_LINE`。C、头文件、xlang、纯文本、未命名与只读文档均可定位；没有打开文档时禁用。

输入 `12` 跳到第 12 行的开头，输入 `12:3` 跳到第 12 行第 3 列。行、列从 1 开始，允许周围空格和 Tab，拒绝零、负数、整数溢出、额外分隔符及超出文档的行列。行尾位置和最后的空行可定位。打开时预填当前行列并全选；Enter 或“跳转”确认，Escape 或“取消”关闭并保留原阅读位置。

列号沿用固定 SDK 的编辑器坐标，与状态栏一致，按 Unicode 字素簇计算。中文、非 BMP emoji 和“字母＋组合音标”各占一个光标位置，Tab 占一列；不是 UTF-8 字节位置、UTF-16 单元或展开 Tab 后的屏幕列。通过 SDK 文档与选区接口转换，不另建一套坐标规则。

## 文档和交互边界

窗口记录稳定文档 ID 与实际 CodeEdit 版本。确认时重新查找仍打开且仍为活动文档的同一身份；正文变化、活动文档变更或关闭后复用控件时拒绝旧请求，用户可取消后重新打开。正常 UI 的标签切换与其他公共动作受模态保护；后台文件监视使用已有公共模态暂停规则。活动任务的停止仍沿用现有例外。

确认前不预览或移动光标。有效定位清除原多选区，形成单一光标并恢复编辑器焦点；只展开包含目标行的折叠区间，其他折叠保持，随后让目标整行进入视口，并在空间允许时保留一行相邻阅读余量。使用扣除滚动条后的公开视口和实际文本几何，文档首尾由 SDK 钳制。定位不改正文、版本、磁盘文件、脏标记或撤销/重做记录。无效输入显示原因并保持原选区、折叠和滚动；取消保留多选区与滚动。

普通属性、搜索及其他输入框不触发代码文档 Ctrl+G。跳转输入框保留原生编辑与输入法处理器；空的活动组合和非空组合期间 Enter 都不会提前确认，组合结束后才允许确认。窗口接入统一界面字体、字号布局和滚动协议；小视口、大字号下按钮可滚动访问，设置写入失败恢复原字体。

## 实际验收

[`goto_view_test.c`](../tests/goto_view_test.c) 在独立 Windows 桌面运行真实 XGE/XUI，通过公开原生输入、菜单条目点击和按钮点击核对全部入口。测试覆盖 Unicode 字素簇的真实字节结果、非法边界、空文档/末尾空行、组合输入、只读及三种语法模式、取消保留多选区、提交清除额外选区、真实撤销/重做、文档版本/身份失效、折叠祖先展开与兄弟折叠保留、滚动及字体回滚。125% 和 200% DPI 各使用实际渲染目标。

完整应用验收同时运行既有真实 C/xlang 语义、混编、SDK 和便携包门；最新数量、截图来源及最终摘要见 [实施进度](progress.md)。独立测试中的后端身份/版本变化由协调器直接注入，以验证失效保护；菜单、按键、输入法、按钮与图像使用实际控件和固定 SDK。未添加导航历史、用户自定义快捷键或全工程搜索。
