# 编辑器 minimap 与菜单边框

C、xlang 及其他文档编辑器、新建文档和两个语法演示页默认启用 XUI 原生 minimap，宽度为 96 DIP。它接管竖向滚动，横向滚动条保留。窄编辑器由 XUI 按可用宽度收缩；IDE 不添加第二套滚动逻辑。帮助代码块及构建日志保持各自的滚动方式。

主题中的 `codeedit.minimap.viewport_color` 使用当前主题强调色和 46/255 透明度，避免当前视口覆盖缩略图中的代码。切换主题只更新绘制属性，不改变文本、选择和文档版本。

右键菜单的第二圈来自 XGE Menu 的焦点描边：Popup 已经绘制外框，Menu 因键盘导航而获得焦点时又绘制了内框。此前 `f40c123d` 只在 ComboBox 的菜单颜色中禁用了焦点色，并没有修复普通菜单。现在 XGE Menu 由已打开的 Popup 承载时只绘制 Popup 外框，仍保留键盘焦点、当前项高亮和嵌入式菜单的焦点描边。
