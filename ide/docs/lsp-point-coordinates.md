## 实现边界

原生定义／悬浮视图原先先复制文本、建立行表，再生成六个端点／节点，使用密集桶或排序重新扫描文本并转换坐标，最后再次遍历节点生成光标表。本次保留同样的事实、范围、标量列、文本、声明唯一性、所有权、发布代次和可选失败回退，在一次原生事实遍历中校验范围并生成光标表，删除该视图的临时端点、范围和选择数组。完整符号／高亮／引用表的原始转换路径仍保留。

`xls_text` 的不透明布局增加每行 ASCII 前缀边界及稀疏标量／UTF-16 检查点。ASCII 前缀直接换算；Unicode 区域每隔至少 256 字节在标量边界记录位置，查询从最近检查点继续解码，避免超长行反复从行首扫描。`xlsTextSourcePosition` 同时验证原编译器的一基行／标量列和字节端点，返回 UTF-16 位置；错误行、标量内部、CRLF 内部、越界及列不一致均拒绝，失败不改变输出。

源码行界是独立条件：不能让全局检查点查找跨到另一行后，使用那一行的累计列接受错误来源。检查点的 UTF-16 计数、换行重置与查询解码分别有独立反例验证。

文本仍复制并完整验证 UTF-8，行表仍在文本修改后重建；本次没有复用前端全部已有文本所有者，也没有实现 rope、零复制或完整增量类型／最终 IR。`xlsTextOffset` 的逆向 UTF-16 查询仍沿用原扫描。`xlsTextStorageBytes` 按实际行表、检查点和缓冲容量计费；每行元数据比旧行表增加一个 `size_t`。64 MiB 可选视图和 66 MiB bank 限额保留，这些并不是全进程或完整 check 的内存预算。

## 正确性和 IDE 联调

证据目录：`ide/build/Release/lsp-text-coordinates-20261101/`。普通程序均在根 `release/` 验证，构建对象、源码夹具和日志保留在上述目录。上一版服务副本只用于版本比较。

- `full` 从源头编译 221 个对象，124 组原生测试通过。后续检查点及遍历合并版本使用同一公共头、前端和 XRT；`incremental` 复核未改输入及对象，重新编译文本、导航实现与文本测试，重新链接并运行全部 124 组测试。后者是增量构建，不是第二次全新编译。
- 文本测试 1,500,214 项，对实际夹具的每个字节／合法端点做独立平面标量遍历对照，含 BOM、中文、非 BMP、LF／CR／CRLF、长 ASCII／Unicode 行、跨行错误位置、检查点和修改后的旧／新快照。导航测试 127,549 项，保留原完整导航逐点对照、来源／所有权守卫、真实分配拒绝、额度回退和四个读者。
- `negatives` 的六种实际 C 源码遗漏均编译、链接后被运行期测试检出：标量列、来源行界、检查点 UTF-16、查询 UTF-16、换行累计量重置及原生导航绕过编译器坐标验证。
- 根发布服务的 56 套协议通过。IDE 输入／删除／撤销／Unicode／IME／点击焦点、59 项参数提示、256 项补全断言，以及 C/xlang 的实际打开、编译和执行通过；原始失败和后续说明分别保存。

联调发现并修复两项独立问题：Windows PowerShell 5 按本机编码读取无 BOM／LF 脚本时，中文注释吞掉后一行服务路径赋值；构建脚本改用 ASCII 注释。新版 SDK 的模糊排序还会把 `zip.ZipInfo`、`zip.ZipArchive` 和 `zeromq.zmtpVersion` 混入 `zzPi` 的两个正确重载中；目录提供者现在先按完整输入前缀筛选，再交给 SDK 排序，原重载和插入／撤销断言不变。

GUI 的全部 C 单元编译及链接通过，但普通构建末尾的目录覆盖检查因并行 BSON 源码／清单修改而拒绝：`release/extlibs/bson/src/bson.xl`、`release/extlibs/bson/xlang.package.json`。本任务不覆盖该并行工作，不把这一结果记为完整普通发布构建通过。后续界面修复使用精确记录的单源增量对象组合进行验证。

GUI 原始结果另记录了最后一个空 `release/tmp` 父目录的检查失败；13 个实际操作均成功。该空目录使用核对过的绝对路径非递归移除，原始失败结果保持，补充功能验收独立记录。未删除任何非空或并行临时内容。

收尾将本轮原生测试生成的 31 个目录、101 个文件从 `ide/` 根目录移入证据目录的 `fixture-artifacts/`，原始生成器、运行时间区间与移动前后完整文件哈希记在 `fixture-migration.json`，历史报告中的原路径保持。构建器现在在构建输出目录运行原生测试，编译工具仍使用原工作目录；实际更新后的运行函数重放了全部 124 份冻结测试程序，并满足原各用例时间上限，程序／归档未变，`ide/` 根目录无新增夹具。此项仅验证运行目录调整，未冒领一次新的源码全量构建；补充结果为 `workspace-final.json`。
