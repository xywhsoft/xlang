# 光标分析的磁盘入口缓存

M7b6j，2026-11-15。修复打开再关闭工程入口时，补全及签名帮助多做一次原生分析的问题。此前 worker 在接受入口的在线正文后，会把同入口的闭合磁盘缓存当成过期角色删除；返回磁盘时只能重新构建。新的原生回归在上一阶段服务上真实失败，未修改原协议检查的构建次数断言。

闭合入口的光标角色现在可以留在原有缓存中，只要对应查询文档仍存活。在线入口与磁盘入口仍由 `semanticMatches` 严格分开；打开入口不会复用磁盘事实。返回闭合入口后，原有 session 仍比较当前输入，并验证磁盘、依赖和探测守卫。缓存保留不授予新鲜度，也不绕过取消、配置身份、输入租约或结果发布检查。检查和依赖角色继续原有入口表示变化规则。

原生用例验证两种光标操作均为冷查询构建 1 次、打开入口后累计 2 次、关闭入口后仍为 2 次，且关闭查询复用原来的实际结果对象。入口的未保存正文不同于磁盘；补全比较独立完整原生 JSON/AST，签名比较实际签名信息和完整 AST。入口打开期间磁盘发生变化、同字节原子替换、查询文档身份变化均不能错误命中；默认空闲路径仍保持严格身份规则。

没有新增 worker、解析器或缓存层，也不在裁剪路径增加文件 I/O 或正文比较。保留角色计入原有 LRU、最多 8 个默认 session 和 64 MiB 输入存储预算；一槽缓存仍允许正常淘汰和重建。输入计费不等于总 RSS，原生语义对象、共享存储、临时分配和其他模块另有开销。

原先失败的完整配置协议工具现在通过，覆盖闭合入口缓存恢复、同字节身份替换、真实包内容变化及恢复、配置取消和增量分析。原生缓存、入口表示、分配失败及校准取消测试同时验证未改变检查角色的裁剪规则；故障注入 fixture 补齐了后续新增 worker 导出函数的私有名称，避免与正式 worker 符号相撞。原始失败保留。实际编译的反例分别恢复过早淘汰、忽略查询寿命、忽略容量及跳过两类磁盘守卫，测试必须拒绝这些实现。

这项验收证明上述路径减少了真实原生构建，不构成全目标的延迟、RSS、耐久或平台准入。IDE 名称预填、标准工作区自动加载、引擎资产对齐、通用编辑应用及其余适用 LSP 继续推进。此前三项旧对话框问题未在本阶段修复或计为通过。正式程序、SDK、active delivery 和线上更新未替换。材料入口：`dev/release-materials/provenance/lsp-cursor-root-cache-20261115.json`。
