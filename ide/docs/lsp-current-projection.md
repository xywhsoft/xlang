# 原生记录投影与成员补全

2026-11-11，M7b4q 将分析前端升级到提交 `11f49ad32f4025f143d73c89cd9a446c3daad982` 的 `current-projection-20261111` 家族。继承 0.6.2 产品输入，在此前 457 项依赖中审查 17 项变化，并加入语义层与 IR 层的两个原生记录投影实现，共固定 459 项输入。此后并行任务的 foreign pack 修改不属于本次构建；这里的“当前”指这个明确版本，不代表随时跟随工作区文件。

## 行为与复用

分析直接采用编译器的 `@c_projection()`、原生序列与投影参数兼容规则。未保存、不完整的 `row.` 表达式可补全投影 C 结构体、普通 C 结构体和 union 的字段。字段列表复用原生接收者解析、首个字段查找、声明类型克隆、规范类型显示及原补全输出器；带 `@c_name("actualValue")` 的 `value` 字段仍显示和插入 `value`。类、静态成员、继承、别名和可空接收者继续遵守原规则，没有另建 C 字段推断或全局 AST 扫描。

新 IR 的 `foreignRecordAbi` 和拥有所有权的 `foreignRecordSource` 纳入派生缓存键。前者显式编码，后者按内容及 NULL 状态编码，不依赖地址或结构体填充。创建、失败清理和释放仍由原生实现负责；外部记录的持久 IR 共享继续保守拒绝，不将新字符串偷偷接入旧共享所有权方案。既有派生阶段、参数掩码、分类准入及拓扑观察优化均保持启用。普通 64 个打开文件覆盖、65,536 条解析候选和原有预算没有扩展。

输入准备支持 LF、CRLF 以及登记的 SDK 布局。未知内容与缺失依赖均拒绝，两个新增实现文件缺失时也返回明确的输入错误。新家族独立登记，历史家族仍保留原行为。

## 验证

- 304 个真实原生编译消费者、189 项链接产物、188 项原生 fixture、13 组协议检查通过；配对 GUI 完整重编译 116 个对象，29 项 GUI fixture 通过。私有 fixture 现在优先包含产品实际使用的最终生成单元，补回先前矩阵遗漏的语义 token 守卫（32,789 项检查）。
- 新 IR 专项 908 项检查覆盖全部 256 个 ABI 判别值、字符串地址独立性／内容／NULL、全新 IR 对照、生产者销毁后的持有结果、真实分配失败与恰好一次释放。显式启用 XRT 内存统计，并包装实际释放调用；删除 ABI 键、字符串键或原生释放的三个破坏版本全部被检出。
- 459 项逐文件内容破坏全部拒绝，LF／CRLF 准备及缺失／额外契约共六项检查通过。最终生成器重新运行后与实际编译的 C 单元逐字节一致，所有编译依赖、对象和链接产物摘要重新核对。
- 新协议的十项检查覆盖投影规则、诊断、定义／悬浮／引用、错误恢复及三类聚合字段补全，且不依赖执行编译器。此前已验收服务可复现不支持新投影的行为。更新后的 GUI 补全 fixture 共 269 项断言，验证候选显示、逻辑名称、Enter 插入及撤销，同时保留 C／xlang 输入、Unicode／IME 和聚焦回归。

原始失败记录保留：第一次构建的私有 fixture 警告分组错误、早期矩阵登记错误、未支持聚合成员的协议失败及未启用内存统计时不足以检出释放缺失的试验。后续明确的修复与最终通过记录分别保存，未覆盖失败记录。此阶段没有重跑整体性能验收，也不据此声称零开销或完整 LSP 已完成。
