# 普通检查复用原生函数树（M7a2b112）

本阶段接通普通增量检查的原生函数树复用。已验证且未变化的顶层函数可直接保留旧原生树，不再复制其函数体、重建语义类型树或重放最终标注；当前索引收集和完整 IR 构建／验证继续执行。其他函数沿用原检查路径，完整长期目标仍未完成。

## 准入与原规则

复用原有原始单元、预处理环境、语义事实、来源／坐标证明、符号区间和最终收据。原始语法单元的独立身份先证明函数源码未变；函数整体的字节区间、行列必须与上轮实际位置一致。当前局部符号起止、类型分配起止、所有已定位类型的当前坐标视图，以及完整最终类型环境和原执行区域区间继续精确比较。任一不确定项均拒绝这次省略，原始身份或尺寸缓存本身不提供语义证明。

原 C-owned 验证器会补写外部参数与 C 标记返回类型的标志，不能在共享树上重复写入。因此复用前使用同一原生 `xl6COwnedBaseName` 取得保守的无写入证明：包含相关标记或外部可调用声明的子树保持独占。原验证器先处理本轮完整新声明与私有函数头，组合成功后再遍历完整树；原验证器正文不变。

最终环境在原 C-owned 首轮之后取得，避免新声明标志尚未补写时使用过早的环境。所有借用候选全部验证成功后才一起安装旧函数；提交循环不分配、不回调、不设取消点。新模块使用 M111 的组合所有权，旧函数仍由其原所有权组和 XRT 锁管理。

当前函数头仍可能被语义作用域或类型注册表引用。安装原生函数后，分离的本轮函数头保留到原上下文、注册表和语义临时节点全部退休，再释放。后续类型／计划钩子跳过借用树，真实执行区域计数器按已证明的原区间推进；意外帧不一致会拒绝整个私有尝试，并保护共享树不被写入。

原最终类型补写、计划规则及 C-owned 生产正文与 M111 逐字节一致。新代码不实现另一套推导、C 互操作或执行计划规则。

## 保留成本

`ast_size` 从原显式函数计量中提取公共只读计量：显式单元继续原逻辑节点／容量配额；跨轮所有者则按共享存储组计入完整已知池 backing 上界、实际子数组容量、字符串、字面量及来源记录。尺寸遍历不读取来源生命周期计数，不复制 AST。

每个新原生森林在私有构造结束时取得一次快照。此后不能继续向可达池分配；普通检查在发布前结束构造 pin，池不能继续增长。借用森林保留原快照，同组只计入一次；即使只保留一个小函数，也不以其逻辑节点大小代替被固定的池容量。默认已知原生保留上限 32 MiB，验证控制只能缩小它，零配额保持原路径。

快照是保守的已知分配上界，可能包含已释放的旧池页或同组其他函数的历史容量；它不是进程 RSS。分配器、临时映射、原有语义／原始单元／IR 配额仍需分别观察。原始单元由既有语法资产独立持有，不保留旧模块根、检查或来源报告，也不复制一份完整旧文档；原始单元自身的源码片段与树仍按既有配额计费。

没有可借用所有者时直接使用原完整复制，不建立无效的投影。原始单元尺寸缓存独立于语义准入，位置变化的完整复制记录可复用已知尺寸；这不会允许位置变化的函数树借用。

## 回退与统计

原始复制已省略函数体后，任何预处理、语义、坐标、分配额度、完整最终环境、区域或必要组合分配失败，均先销毁私有尝试，再从完整输入执行一次原路径。负返回值明确作为失败处理，不能被 C 的布尔判断当作成功。取消和一般基础设施错误保持原有处理，未完成的树或部分诊断不发布。

销毁私有尝试时先摘除借用根，再释放语义与原生引用；组合成功后的模块及 IR 各自拥有所需引用。旧检查／根／报告可先退休。复制统计累计两次尝试的实际工作，包含已丢弃尝试；池节点统计与当前可见的历史共享节点分开理解。取消后的空结果不再额外调用一次性取消谓词，缓存提交边界保持。

## 性能结果

固定同前端 M111 基线，32／512 函数、14 代改动，A/A 四对、A/B 八对，只执行原定一轮；分别完成 960／1,920 请求和 64／128 进程。原 64 项门槛分别失败 1／6 项，性能未准入。A/A 失败项为 32 函数单文件字面量热 P95（18.287→19.420ms，超过 19.201ms 门槛）；不能把这项基线波动用来豁免 A/B 失败。
