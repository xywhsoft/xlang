# XUI 文件与目录选择

2026-10-12，将剩余 Windows 文件 / 目录选择入口改为 SDK `xuiFileDialog`。统一实现为 `src/ui/file_dialog.c`，支持打开文件、保存文件和选择目录；应用源码不再调用 `GetOpenFileNameW`、`GetSaveFileNameW`、`SHBrowseForFolderW` 或 `MessageBoxA/W`，构建移除 `comdlg32` 链接依赖。此增量处理对话框依赖，其他平台服务与整个 IDE 的跨平台构建属于后续工作。

| 入口 | 调用模块 |
| --- | --- |
| 打开文件、保存未命名文件、另存为 | `src/ui/editor_view.c` |
| 打开 / 保存工作空间、打开项目、添加已有项目、添加文件 | `src/ui/workspace_view.c` |
| 代码字体与界面字体文件 | `src/ui/font_view.c` |
| 新项目父目录 | `src/ui/template_view.c` |
| 旧工程来源、目标父目录、xlang 入口 | `src/ui/import_view.c` |
| 项目引用文件 | `src/ui/references_view.c` |
| ICO、应用清单、新资源配置位置 | `src/ui/resource_view.c` |
| xlang 编译器 | `src/ui/task_view.c` |
| clangd C 语言服务器 | `src/ui/c_completion_view.c` |

文件选择器使用 SDK 窗口、磁盘 / 文件列表、路径面包屑、文件名和过滤器。目录导航、过滤、键盘确认、Esc、标题栏关闭和保存覆盖确认均由 XUI 控件处理；保存模式在确认前补全缺省扩展名。选中结果统一为 UTF-8 绝对路径并使用 IDE 内部的规范格式。

选择器在当前业务窗口上方显示，背景阻止误操作，过滤菜单和 SDK 覆盖消息框保留更高的显示层级。控件尺寸、行高和窗口标题栏随界面字体缩放，40 DIP 字体仍可使用。取消嵌套选择返回原业务窗口，保留其草稿和焦点。

SDK 回调只记录结果；IDE 在事件分发结束后销毁选择器，再继续操作。主菜单的打开、保存、项目管理和工具设置通过消息管理器的操作记录继续；选择期间工作空间、项目选择或保存文档版本变化时取消该次继续，防止结果应用到另一份状态。业务表单的浏览按钮只回填相应字段，创建和应用仍使用原有验证与事务保护。

应用提示、警告和确认继续使用 [XUI MsgBox](window-dialogs.md)。平台异常报告在 XUI 可用时使用 XUI；渲染器本身不可用时的独立紧急报告仍隔离在平台模块中，不调用 `MessageBoxA/W`。
