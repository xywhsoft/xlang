# 结构化数据高亮

IDE 为 `.json`、`.xlon`、`.jsonl`、`.xlonl` 分别注册 CodeEdit 语言模式，扩展名不区分大小写。打开、另存为、会话及未保存文档恢复均保留对应模式，也可从“编辑 → 语言模式”或工具栏语言菜单手动切换。

JSON 高亮双引号字符串、JSON 转义、数字、`true/false/null` 和结构标点。无效数字形式、非法转义、单引号和注释不作为正常 JSON 语法着色。XLON 在相同规则上识别 XRT 的 `bytes(...)`、`time(...)`、`float(...)`、`set[...]`、`intmap{...}` 及 `app.id(...)` 等自定义标签，并高亮可选注释。注释／自定义标签是否允许仍由读取时的 XRT 配置决定。

JSONL／XLONL 沿用各自的 token 分类，但在物理换行处重置未完成的字符串和注释；前一条记录缺少结束符不会把后续记录全部染成字符串／注释。行格式不生成跨记录折叠。单文档 JSON／XLON 可按真实括号 token 折叠对象、数组、标签载荷以及多行注释，字符串中的括号不参与折叠。

这套能力是词法高亮，不代替完整格式校验、schema 或读取器的资源限制。所有 token 区间使用 CodeDocument 的 UTF-8 字节偏移；编辑器将 CRLF 归一为内部 LF。实际编辑刷新时，同一批 token 同时用于着色缓存与折叠，避免为了折叠重复词法扫描。结构化数据不会进入 C/xlang 源码语义补全。

实现位于 `src/lang/languages.c` 与 `src/lang/structured_data.inc`，语言注册、支持范围及扩展名识别集中管理。专项测试：

- `data_language_test.exe`：四种注册、大小写扩展名、数字／转义／标签／注释、UTF-8/CRLF、局部及小容量词法输出、逐行错误恢复、折叠和真实编辑器缓存。
- `data_language_view_test.exe <独立验收目录>`：真实文件打开、七种语言菜单、输入与撤销后的高亮、四张原生截图、干净／未保存文档重启以及按类型恢复。

可通过 `ide/tools/build.ps1 -Tests` 编译上述测试；产物为开发验收材料，不随运行时发行。
