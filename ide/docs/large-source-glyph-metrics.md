# 单次排版内的原始字形度量复用

2026-10-11，SDK48 私有实验，基于 SDK47。保持定版 Dock 布局及 C/xlang 双语法。新增原始字体整数度量复用，通过语义和窗口比较；长行性能仍待验收，未替换固定 SDK 或便携候选。

## 实现与边界

至少 256 字节的排版调用使用 64 槽、1536 字节的固定表。它只保存 immutable face 与 glyph 对应的原始整数 advance、右边界及是否有轮廓，不保存已乘字号的结果。每次读取实际图集状态，已有字形图集时立即读取其当前 advance 和墨迹边界；尚无图集时才查询表，并在原位置乘实时倍率、按原规则取整。碰撞重新读字体数据，失败不缓存；短文本保留原度量调用。

因此，同一 face 的不同字号可以共享原始整数；回调中变化的字号仍即时参与计算；建立图集或改变已有图集数值后，其当前值仍优先。只有原排版消费的 advance 与右边界经此路径读取，字体解析、引用、kerning、UTF-8、Emoji 和浮点累计继续原规则。表在调用结束失效，无新堆分配或跨帧缓存；字体 face 及资源在调用期间保持稳定。

本版保留 128 槽字符解析表和 SDK47 的 Emoji 匹配表。此前 SDK19 曾试验直接缓存已缩放的两项数值，本版采用原始 face 数据和实时图集、倍率检查；SDK19 的材料及不选作候选的记录保留。

## 实际验证

- 完整 SDK 严格 O2/Werror 编译退出 0，283.937 秒。仅 `src/xge_text_run.c` 相对 SDK47 改变，公开头相同。
- 完整引擎夹具冷编译退出 0，276.094 秒；原生运行退出 0，7.578 秒。使用 241 份引擎材料、116 个分编译 XUI 单元、14 份夹具和原 DPI adapter，只有一个 XRT owner。
- 新增 148,274 项断言、36,964 次逐位数值比较；64 组实时倍率、4 组实时图集、3 组失败检查，最大 193 个不同 glyph，包含 7 个空轮廓观察。
- 覆盖共享 face、不同字号、分数及邻近倍率、正负零和负倍率、超过 64 槽的输入、图集建立后重复调用、受控改变图集数值，以及失败返回不改输出与表。原 16 组回调字号变化和 29,024 个位置比较继续通过。
- SDK47 的 495 组匹配及 6 组检查点、原 63 组检查点、52 组编辑几何、8 个真实 C/xlang 控件、3 组取消、78 组绘制像素对、39 组缓存重放、24 组水平候选和 108 对旧 GPU 像素比较继续通过。逻辑 DPI 测试不代替实体混合 DPI 或 IME 验收。
- 首轮原 SDK Unicode 和 Emoji 检查退出 0；document 严格链接退出 0，但因比较器漏建原测试要求的 `build` 目录，保存文件检查退出 1。原失败目录、源码及日志保留。新目录的 document 专项补齐此前检查器已使用的目录准备，严格链接和原生运行退出 0；没有重跑已通过的前两项，也没有修改 SDK 来修复这个夹具问题。
- 六个当前应用检查通过，使用已有产物，没有重编译应用。5954 个导出名称及序号与 SDK47 一致；这不构成相对固定 SDK 的完整 ABI 验收。
- 持久准备重新生成 241 份引擎和 10 份应用覆盖，逐项一致。持久测试显式核对冷编译的引擎、14 份夹具、DPI adapter、参数、产物及日志后复用，再执行原生比较退出 0，7.062 秒；其默认冷编译分支未再次执行。命中计数可能因进程中的指针散列冲突不同而变化，各次都要求实际命中，语义计数逐项一致。
