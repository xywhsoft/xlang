# XUI 窗口与消息框迁移清单

2026-10-12，按已定版的传统 IDE 方案实施。业务对话框统一使用真实 `xuiWindow`，公共实现为 `src/ui/dialog.c`；错误、警告和确认使用 SDK `xuiMsgBox`，公共实现为 `src/ui/message_box.c`。

后续已将文件与目录选择入口也迁移为 SDK `xuiFileDialog`，包含“添加已有项目”；入口清单、异步选择和验证见 [XUI 文件与目录选择](file-dialogs.md)。下文的 `cb-4291f399` 与窗口 v3 包为前一增量记录，最新构建和可启动版本以[当前候选](../CURRENT-CANDIDATE.md)为准。

确认采用异步回调：消息框关闭后，在后续事件轮询中继续原操作，不在绘制线程中嵌套渲染循环。文档确认绑定文档身份和版本；磁盘覆盖额外绑定磁盘快照；工作空间确认绑定当前模型和项目选择。等待期间内容发生变化时重新确认。保存全部、退出和工程操作保留本次操作已确认的决定；取消终止待继续操作。另存为选择的路径保留至该次操作结束。

启动失败时先写入诊断，再在独立的 XGE / XUI 环境显示消息框；保留原错误码与恢复结果。如果图形或字体系统本身无法初始化，才使用不依赖渲染器的 Win32 紧急报告窗口。源代码不再调用 `MessageBoxW`。

命令提示、补全、悬停、菜单和组合框继续使用适合短暂内容的 SDK popup；查找 / 替换原已使用 SDK window。主界面的左右 Dock 与中央编辑器下方底栏布局保持定版方案。

业务窗口与背景拦截面板位于浮动窗口层，覆盖工作台及其浮动 Dock；窗口内的下拉菜单继续位于 SDK 弹出层，消息框位于更高的模态层。这样既保留窗口边界，又允许下拉菜单在打开后的同一轮输入中正常选择。配置窗口的普通字体与 40 DIP 字体测试覆盖这一关系。

验证入口：`dialog_message_test` 验证真实窗口拖动、缩放、关闭与 Esc、表单草稿、消息框取消 / 否 / 是、延迟继续与磁盘快照变化；已有业务窗口测试继续覆盖各自事务、滚动、字体与输入行为。`check_runtime_failure.py` 继续验证真实 GUI 失败路径、诊断写入与可见错误内容。

交付构建为 `build/cb-4291f399`，87 个生产模块与 107 项产物严格编译通过，构建期间源码变化为空。工作台创建使用成对的 `xuiStyleBeginUpdate` / `xuiStyleEndUpdate`，初始化失败也结束批量更新；窗口仍由原生 `xuiWindowCreate` 创建。SDK67 创建控件时会重复注册样式属性，逐次解析已存在的工作台；本机私有诊断的工作台创建时间由约 14 秒降到约 0.5 秒。该观测只表示本机场景。

启动窗口与界面字体测试保持原来 60 秒总限额，独立 IDE 子进程保持原来 15 秒限额。最终构建的窗口消息框 65 项检查、独立启动与字体测试通过；实际 IDE 子进程的启动检查约 1.5–2.3 秒。当前提供者对应的标准回归已分段完成，最终主程序生成 38 张新渲染图；不使用中间构建的通过记录代替最终构建验证。

最终便携包为 `dist/portable-20261012-xui-windows-v3`，同一构建通过 15 项载荷 / 解压拒绝检查、2 次默认工具链原生运行与搬迁、4 次包内应用启动及 12 张新图。异常报告通过 212 项检查、9 次真实启动和 7 张 XUI 错误报告图；帧故障恢复通过 260 项检查、12 个进程与 5 次重启。各业务窗口的已有原生测试覆盖取消、事务保护、40 DIP 双轴滚动、草稿、字体与 DPI。[本轮核验记录](../build/window-msgbox-20261012/result.json)绑定精确构建、包摘要及各段日志；[当前候选](../CURRENT-CANDIDATE.md)提供启动入口。

本轮曾发现配置下拉菜单被业务窗口遮挡，修正后普通配置与项目测试窗口的原生选择、取消、应用和大字体滚动均通过。最初的 C 补全回归曾遇到一次 clangd 异常退出，单独复查及窗口修正后的完整 C 补全检查均通过。工作区清理移除了部分历史构建材料：默认提供者与 SDK 来源从已验证便携包按摘要恢复，不覆盖现有文件；后段回归使用同版本的包内提供者，旧补全能力后备使用已有工具链测试程序。相关日志及来源记录均位于 `build/window-msgbox-20261012`。

最终标准回归的前段因重命名检查器的证据输出目录限制停止，按原检查器要求将四个证明目录放入当前冻结构建内后续跑。后段的旧版基类类型导航空结果断言与当前编译器能力不符，改用脚本已有 `--type-facts` 分支，29 项类型导航检查及余下清单通过。没有修改断言、超时或目录保护，也没有将这两次中断记录改写为成功；日志及续跑来源分别保留。专门的扩展 / 聚合 / 标量 ABI 可选门本轮未全部重复。
