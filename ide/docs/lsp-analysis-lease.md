# 语言服务源码读取暂停

M7b5i，2026-11-12。外部原生 `xlang-ls.exe` 新增连接内的分析暂停协议，供混合源码事务的宿主屏障使用。它保留常驻分析 actor、模块资产和语义缓存；不关闭、重建语言服务。后续 [M7b5j IDE 双连接与本地读取参与者](lsp-ide-analysis-lease.md)已提供组合接口，完整宿主仍需其他条件；标准重命名与 `workspace/applyEdit` 仍未启用。

初始化结果的 `capabilities.experimental.analysisLease: 1` 表示支持。较旧的 GUI SDK 分析实现没有经过认证的开放任务池空闲查询，报告 `0` 并拒绝暂停，不根据普通负载计数伪造静默确认。

请求 `xlang/suspendAnalysis`，参数严格为 `{ "token": 1 }`。令牌是正的有符号 64 位整数，在同一连接内每次成功受理都必须递增；同一时刻只有一个待确认或已持有的令牌，不能嵌套。计数耗尽后需要新连接。重复、旧令牌不能改变当前屏障。

服务器先阻止所有新分析入口，协作取消原有检查、补全、签名、语义标记、引用、工作空间符号和后台索引工作，停止诊断巡检。响应会延迟到真实检查线程退出、所有 actor 的普通任务及清理尾部均已结束。普通任务统计的 `queued/running == 0`、Future 已就绪或查询对象已释放均不能代替此条件。等待期间仍处理退出、取消、恢复及不读源码的状态查询，不在所有者线程等待磁盘或 join。

公开 `xrtTaskPoolWaitFor` 要求任务池已关闭，不能用于需要恢复的缓存 actor。原生服务自己的 XRT 实现编译单元因此提供内部查询：沿用 XRT 的 entry 生命周期协议和互斥锁，直接调用其现有普通任务与 finalizer 空闲谓词。没有新增一套任务计数，没有修改 XRT ABI。该适配依赖匹配的 XRT 实现，需要随其版本重编译与验证；它不是跨 SDK 的通用 API。调用者必须持有任务池并停止新提交与销毁。

成功响应包含 `token`、`held`、`invalidated`、`deferred`、`inputSerial` 和 `epoch`。只有 `held: true` 才可作为服务进程静默的确认。宿主仍需分别确认两个语言服务进程、IDE 任务/监视/索引与打开操作、全部文档及请求/配置/来源/物理策略，才能写入源码。连接断开、错误或无法得到确认时不得假定成功；已经开始写入时必须按事务恢复策略处理，不能因为通信失败放开其他读者。

暂停期间的文档打开、改动、保存、关闭、文件监视和配置通知保持原 DOM 顺序，不应用到在线模型。它们与传输队列共用原有 **256 条、64 MiB 编码字节**上限；移入待恢复队列不腾出准入额度。溢出沿用连接失败处理，不静默丢消息；这不是无限期离线缓冲。输入通知首次延后时发送一次 `xlang/analysisLeaseInvalidated`；宿主应撤销旧准备结果并完成必要的回滚，不能继续使用旧输入证明。`xlang/analysisLeaseState` 可查询当前持有和失效状态。

新的分析、初始化及配置请求返回可重试错误 `-32001`；配置通知延后，配置请求由调用方恢复后重发。纯状态/统计请求可以继续处理。`$/cancelRequest` 只能放弃尚未确认的暂停请求；确认后旧取消消息不解除屏障，因为宿主可能已经写入源码。`shutdown/exit` 始终可以结束连接。

请求 `xlang/resumeAnalysis` 使用准确的当前令牌。宿主须先完成提交、回滚或恢复协调。恢复会把原通知队列整体接回后续请求之前，不复制正文；随后重新核验磁盘输入、调度当前文档诊断和后台索引。缓存保留不代表旧证明继续有效。恢复响应表示已解除暂停，随后发送的 `xlang/inputState` 回执才覆盖此前已重放的文档通知。提前放弃尚未确认的令牌也必须显式恢复，或取消该待确认请求。

此接口没有加入普通键入热路径。静默确认仍有锁、内核状态查询、控制消息编码、取消清理与服务器轮询成本，不宣称硬实时、整体 RSS 或端到端输入延迟上限。全目标性能验收、IDE 宿主组合及最终运行时交付仍需继续。

专项协议测试见 `ide/tools/check_lsp_analysis_lease.py`。原生测试使用实际 actor/XRT 实现的精确源码前缀，私有访问器仅取得真实池与投递实际 finalizer；逐一阻塞 13 类池的 finalizer，证明普通负载均为零时仍不能确认暂停，另覆盖真实任务过程和析构、精确/过期/耗尽令牌、确认前后取消、总队列容量与顺序重放。构建、运行摘要与大材料索引见 `dev/release-materials/provenance/lsp-analysis-lease-20261112.json`。

已有协议回归中，11 个程序通过；配置回归在第 184 行“关闭根文档后复用原缓存构建计数”的断言失败，上一阶段已验收服务也在同一断言失败，实际配置、导出及声明选择正确。本阶段保留两者原始失败资料，未修改该断言或把此程序计为通过；关闭根文档后的缓存路由与计数需要后续单独核对。窄 GUI SDK 没有原生 actor 的 TaskPool API，原生参与者在其编译配置下保持禁用；已重编译并验证实际 GUI 生产闭包。
