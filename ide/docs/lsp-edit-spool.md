# WorkspaceEdit 混合文档的持久化准备包

M7b5c，2026-11-11。`platform/workspace_edit_spool` 为整个文本编辑计划生成可重新读取的准备包，供后续混合提交与失败恢复使用。本阶段只准备和验证恢复数据，不修改编辑器或源码，不代表用户批准，未启用标准重命名或 `workspace/applyEdit`。

工作线程接收不可变计划，以及每个打开文档恰好一个借用的保存基线。调用期间调用者保持基线租约及 raw/text 不变；关闭文件复用物理校验器、已固定的文件句柄和同次解码的 BOM/EOL。构造成功后释放临时计划租约；文件校验器同样只保留路径、句柄、快照与编码，不保留计划正文。对象由单个工作线程顺序使用，无 GUI 指针。

每个文档记录保存时原始字节、编辑前 LF 正文、编辑后 LF 正文、编码后待写字节，以及路径/URI、身份/修订/版本、关闭文件快照、编码、变更标记和关联的注释索引。未保存正文允许与保存基线不同；正文回到保存基线时复用原始字节，关闭文件无正文变化时同样复用，保留混合换行。注释标签、描述和确认要求保留，始终 `approved=false`；可选 binding 仅是恢复上下文，不能授权。

复用 XRT map/array/JSON/SHA-256、现有编码器、快照、恢复锁和状态文件原子写入器。正文按长度和摘要去重，不增加独立服务程序的平台依赖。专用作用域内只有一个待处理 `edit-journal.json`，格式 `xlang-ide-edit-spool-1`、状态 `prepared`；不要与会话检查点根目录混用。正文以 CREATE_NEW 创建普通单链接文件，名称严格为 `recovery/edit-<UUID>-NNNN.body`，拒绝重解析。64 KiB 分块导出从已固定源码句柄读取，拒绝空目标与任意被固定源码身份重合，核对原始摘要及前后完整元数据。

先写入、FlushFileBuffers 并重读核对全部正文，验证文本/编码/注释/来源关系，再尝试发布 marker。标记“已尝试发布”在原子写调用之前设置：即使返回失败，也可能已经替换成功，此时保留所有正文。发布前失败仅按自身持有的新正文句柄请求删除，失败留下的孤立文件保留；不删除未知文件。Destroy 只释放资源，始终保留已发布或结果不确定的数据。成功后固定并重读 marker，核对实际记录。

Open 取得恢复锁，固定 marker 和每个正文，验证 literal 文件名、身份/属性/大小/摘要与全部文本编码关系。payload 的 lastWrite 可能在最后一个写句柄关闭时才最终确定，因此 payload 比较不要求该时间相等；源码仍要求完整时间和属性一致。原源码已变更或删除仍可读取准备包；Open 不重新固定源码，也不授予恢复写入权力。

最多 512 文档、2,048 唯一正文，每正文 16 MiB、LF 正文 8 MiB；既有和新增恢复正文共用 512 MiB、8,192 目录项额度，未知条目也计数。默认 128 MiB、最大 256 MiB 的已知存储预约包含计划、借用基线保守容量、路径与数组/键记账、48 MiB 编码临时额度。通用 JSON/map/分配器内部、独立受限的文件校验器及操作系统句柄额外消耗内存；预约不是整体峰值/RSS 保证。

后续 M7b5d 增加了[已固定文件的逐文件写入与恢复](lsp-edit-file-write.md)，由完整的宿主意图/同意围栏约束。多文件写入/回滚事务、进程退出后的恢复写回、包退役、IDE 调度和确认界面仍未完成，跨打开/关闭目标的全局物理别名、请求/项目/配置/来源围栏也仍待整合。不能把准备包存在解释成可以直接应用。准备与重开会重复读取、散列和解码，通用帮助函数仍有不可抢占片段；未进入普通输入或增量循环，不宣称全工程性能、掉电持久性或 Win7 实机认证。

原生与匹配 XGE 的 GUI 配置分别检查准备包、原始导出及异常处理，构造实际运行在工作线程。覆盖 BOM/CRLF/混合换行、未保存基线、去重、注释关联、原所有者释放、子进程退出后重开、marker 写前/写后返回失败、写入/flush 失败、损坏记录/正文、硬链接、联接及取消。原生 XRT 内存统计经过实际分配对照确认启用；初始化 GUID、随机数和原子文件服务后比较组件堆块/句柄平衡，保留无 Spool 的独立基础服务对照。

348 个观测到的直接分配/数组插入拒绝点在同一路径的独立冷进程逐点运行；98 个准备取消点逐点检查。原文件校验器常规回归及 39 个冷态拒绝点重新运行。8 个真正修改生产实现的变异在预期断言失败，早期测试/脚本失败记录保留。完整编译 121 个 IDE 单元并运行 GUI 回归，包含 C/xlang 输入、删除、撤销、Unicode/IME、点击焦点及已打开文档批量编辑。
