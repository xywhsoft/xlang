# 源码事务的任务调度暂停

M7b5h，2026-11-12。任务服务增加显式的源码屏障参与接口，配合[文件监视器握手](lsp-edit-file-sync-lease.md)供完整宿主控制器组合。标准重命名入口仍未启用，独立工具链查询、语言服务和索引线程不由这个接口暂停。

`xideTasksSuspend` 只设置实例内递增令牌，不分配或释放请求，不等待或取消活动任务。原有排队请求保留；新的工程构建、运行、测试、单文件及带输入保护的请求全部在路径解析、请求复制、合并和输入失效处理前拒绝。持有期间 Poll 可以退役已退出的请求，但不启动下一任务。用户仍可交互输入、关闭标准输入、停止或取消任务。

`xideTasksSuspended(tasks, token)` 需要准确令牌，并核对每个真实 worker HANDLE 已退出。已发布 succeeded/failed/cancelled 不能替代线程退出。普通串行调度也改为使用现有 completedWorker 检查；Busy 在终结状态已经发布但线程仍存活时继续为真。排队请求可以被冻结而不妨碍“工作线程已静默”的确认，Busy 与 Suspended 因此有不同含义。

Resume 只能释放准确的当前令牌，不自动启动任务。尚在等待的源码操作可以提前放弃暂停；已经修改源码的持有者必须先完成提交、回滚或明确恢复协调，并在恢复调度前通过现有 InvalidateInput 通知实际变化的路径。它不会把旧排队请求当作新请求，亦不会默认取消全部请求。下一次正常 Poll 按原顺序启动仍有效的排队工作。

执行目标查询在持有期间禁用构建、运行和测试，TaskView 的直接入口也在保存文档或项目之前拒绝任务操作。停止和关闭输入仍可用。普通键入、撤销以及与该参与者无关的文档操作不增加正文扫描。暂停请求和拒绝提交路径的探针观察到零次直接所有者 malloc/calloc/free；查询仍有历史任务遍历、互斥锁及非阻塞内核检查成本，不宣称硬实时或整体 RSS/延迟上限。

专项测试运行真实 taskWorker、编译器子进程和交互程序。受控编译器从真正的不可变请求清单读取夹具控制数据，不修改产品的构建/运行环境语义。真实 worker 完成以后由 CreateThread 的测试 trampoline 暂缓其线程返回，独立验证终结状态已经发布仍不能确认静默、Busy 不能提前清除、普通串行调度不能抢先启动下一任务。测试还覆盖被动等待、排队冻结、拒绝提交没有输入失效副作用、提前放弃、精确/耗尽令牌、显式输入失效后拒绝旧请求，以及真实 XUI 的操作查询和保存前拒绝。

具体断言、匹配 SDK/程序摘要、变异及大材料索引见 `dev/release-materials/provenance/lsp-edit-tasks-20261112.json`。完整宿主组合、来源与物理策略、注释确认、恢复界面、协议启用和端到端性能验收仍需继续。
