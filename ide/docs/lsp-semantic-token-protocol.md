# 语义高亮的标准协议与后台执行

2026-11-10，M7b2。在[已检查索引分类基础](lsp-semantic-tokens.md)之上，实现 `textDocument/semanticTokens/full`、`range`、`full/delta`。本阶段是服务端能力：现有 IDE 尚未请求和叠加语义颜色；配套 GUI 的输入及原有语言功能已验证。默认发行程序与线上通道均未替换。

## 协议与所有权

遵循 [LSP 3.17 Semantic Tokens](https://microsoft.github.io/language-server-protocol/specifications/lsp/3.17/specification/#textDocument_semanticTokens)。图例只包含客户端支持的类型与修饰符；类/接口等可退回 type，参数/属性等可退回 variable，方法可退回 function。无法表达的类型留给词法着色。relative 格式及相应请求未协商时不提供该能力；明确声明不叠加词法颜色的客户端暂不启用。本轮仍提供符号语义分类，不提供关键字/注释/字符串等完整词法 token 流。

输出使用五整数相对编码及 UTF-16 长度。range 返回完整的边界相交 token，首个 token 仍相对文档起点；空范围返回空数组，不生成历史结果 ID。delta 在整数数组上求最长公共前后缀，产生一个编辑；相同数组产生空 edits，未知或收益不足的基线返回完整数据。历史数据每文档保留两份，已知对象及实际整数容量合计至多 16 MiB，超额淘汰旧响应，关闭文档时释放。历史中没有 AST、检查、源文本或协议 JSON；resultId 只标识数组，不证明语义仍然新鲜。

`semantic_token_positions` 复用原有完整批量坐标转换器。一次有序扫描核对原字节偏移、编译器标量坐标、UTF-8/CRLF 边界和 BOM 前缀，再产生 UTF-16 范围；不会为每个 token 从 Unicode 长行起点重扫。取消按实际消耗字节计数，避免用 offset%4096 在非对齐四字节字符中漏掉轮询。分类与坐标构造的已知对象和数组容量共用 16 MiB 上限；JSON 树、线程栈、分配器开销和既存检查不在此上限内，不能把它当作进程 RSS 限制。

请求使用 XRT 后台线程执行输入验证、分类、坐标、编码和 JSON 树构造。协议服务最多同时持有四个任务，包含已取消但线程尚未终止的任务；其余请求进入已有有界队列。普通取消只置标志，不等待线程；只有观测到真实线程终止才回收，退出时才会等待剩余任务。请求独立保留检查，宿主检查对象销毁不造成悬空引用。

宿主只为真正出现在本次来源报告中的打开文件捕获任务。仅在快照列表出现的无关文件必须按自身入口重新分析；某入口的语义错误不能遮蔽另一个已打开文件。发布仍核对版本、文档身份、配置/全局代次、实际原生检查身份、原输入守卫及前后原生验证。源错误返回 null；资源/基础设施失败返回错误；取消或内容变化不返回旧 token。

## 验收

编译对象位于 `ide/build/Release/lsp-semantic-token-wire-20261110`，在 F 盘保存任务材料；所有测试程序均通过临时别名在真实 `release/win_x64` 运行并清理。

- `build-v3/result.json`：268 个实际输入闭包，44 个消费者更新，全部链接对象和归档成员核验；40 项宿主/新增原生夹具实际运行。
- `core-regression-v1/result.json`：另 122 项原生夹具实际运行，合计 162 项常规原生回归。核心检查对象新增了一个头文件依赖，故补齐了完整核心回归。
- `final-build-v1/result.json`：保持既有服务版本 0.101 的最后一次单对象编译及链接。新方法通过能力协商启用；未放宽旧验收对原版本的约束。
- `semantic_tokens_wire_test`：311 项，覆盖图例映射、BOM/UTF-16 对照、范围相交、整数 delta 重建、取消点、被拒绝/未加载来源和脱离宿主的任务所有权。
- `guards-v3/result.json`：32,789 项（含长文本生成断言），实际伪造标量列/字节端点/UTF-8 内部端点；验证 128 KiB 非对齐 Unicode 扫描的取消及预算恢复。删除坐标证明或漏掉扫描轮询的两个实际 C 破坏对照均以退出码 1 检出。
- `protocol-final-v1/result.json`：九套 stdio 协议，含新增 15 类语义 token 场景和原有八套模块、补全/静态分析、工作空间符号及复用回归。入口使用不存在的编译器路径，证明不是 CLI 代答。
- `worker-barrier-v1/result.json`：真实投影函数暂停时，四任务取消仍能响应，排队第五项可恢复；编辑撤销旧请求；同代次磁盘依赖变化在原生预检后仍拒绝发布旧结果。
- 配套 115 对象 GUI 完整编译，使用最终服务执行 26 项联调：C/xlang 输入、删除/撤销、Unicode/IME、焦点、补全、签名、导航、引用及工作空间搜索。另检查三张 IME/补全/搜索界面截图。

旧失败与原始报告保留：构建器曾把同内容头文件路径迁移当成变化；收紧到有明确内容/路径证明的复用，同时保持所有实际头变更消费者重编。四个直接包含 C 实现的旧测试对象曾在链接中被遗漏替换，回归检出后修正并逐项核对实际消费者。初版协议测试暴露两个已打开独立入口间的切换问题，已增加覆盖并修正。试用的 0.102 版本字符串与旧固定版本验收冲突，因此保持原服务版本，不修改或绕开旧测试。测试自身的预算/类型假设错误及修正前源码均保留。

以上证明协议正确性、后台边界和已有 GUI 可用性，不是端到端性能准入。本轮不重置既有整体矩阵或 A/A 失败，也不据此宣称完整 LSP 已完成。
