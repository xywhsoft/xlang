# 帮助交互性能与 XGE 更新（2026-10-31）

本次修复位于 XGE 的保留式 XUI 布局／控件层。IDE 帮助仍把 Markdown 转为 Label、表格和只读 CodeEdit，没有替换富文本引擎或裁剪文档内容。

## 原因与实现

- 长帮助的 Label 在父布局和实际排版宽度之间切换，单个约束缓存失效，每帧重新复制、整形和测量大量文字。Label 现在保存最近四组尺寸，键包含文本版本、字体、换行、行段间距、DPI 与显式测量失效代次；仅缓存成功的数字尺寸，不额外保留文字布局、字形或位图。
- CodeEdit 的光标与选区更新只刷新绘制与 IME 锚点，文档修改和实际几何变化继续使布局失效。
- 自定义布局容器平移等尺寸内容时，使用排版结果更新世界坐标，不把位置再次反馈成测量输入。真实尺寸变化仍走原有失效路径。
- 显式 `xuiWidgetInvalidate(label, XUI_WIDGET_DIRTY_LAYOUT)` 仍重测该 Label，供字体后端在字体句柄不变时改变度量使用。失败测量、重入修改及重入销毁有专项覆盖。

## 实际测量

同一主机、1920×1280 原生隐藏窗口、100% DPI、O2，选择 `http1.writeChunkLine`：17,598 条命令、2 份文档、961 个块，其中 951 个 Label、10 个 CodeEdit。每组 24 帧；统计包含真实输入、应用帧、布局、更新和绘制，未启用诊断程序的实验缓存。

| 场景 | 原 SDK 平均 ms/帧 | 更新后平均 ms/帧 | 更新后 P95 ms/帧 |
| --- | ---: | ---: | ---: |
| 滚动偏移更新 | 142.5152 | 4.3246 | 5.1913 |
| 实际滚动条拖动 | 142.6227 | 5.2042 | 6.5456 |
| 实际代码选区拖动 | 142.6981 | 1.7248 | 2.2951 |

滚动条实际偏移由 0 变为 6,998，代码选区由 7 延伸到 50，确认实际交互发生。此为本机短采样的应用帧耗时，不代表所有文档、首次打开、任意硬件或显示器的帧率承诺。原始基线在 `F:\xlang-validation\help-lag-audit-20261031`，新证据在 `F:\xge-help-20261031`。

## 配套 SDK 与接入

XGE 提交为 `93b446cf83ce20284f41aa794ed61e3302348ac4`。从 Git archive 隔离构建 `ide` 配置，未混入 XGE 工作区的其他开发改动。SDK 记录 759 份来源材料、165 个编译单元，以及 5 份有原始摘要、最终摘要、差异和载荷的兼容补丁：Unicode 查找、CodeEdit、背景注释索引、XRT 进程树清理及其来源记录。活动补丁以 `third_party/xge_sdk/provenance/compatibility-patches` 为准；历史 `third_party/sdk_patches/xge3-find-compat` 不是本 SDK 的重建输入。

旧补丁按新版的事务性区间清除重放：清除一段指示器只删除相交字节，保留两侧；新增的背景索引容量在发布拆分结果前申请，失败保留旧模型，绘制查询不分配。Unicode 空匹配继续逐标量推进，保留组合字符的全部匹配位置。

IDE 补全提供者按新版 SDK 返回已初始化的输出项数量，零容量返回零；实际提供内容继续由有容量的请求检查。来源查看器给只读编辑器显式注册取消动作，使 Escape 正确关闭查看器并恢复原编辑焦点。

公开头、配置、导入库和 DLL 整套更新，GUI 的 107 个编译单元使用 O2 重建。语言服务器不需要重建：其 XRT 声明逐字节不变，原服务器的 53 个 XGE 名称导入及新 GUI 的导入均已核对。SDK 仍由 `xge.dll` 单独拥有 XRT。

## 验证入口

XGE 的 `tests/xui/build_help_interaction_test.bat` 覆盖 400 次多约束命中、100 次滚动和 100 次光标更新，包含 IME、宽度重排、字体／DPI、失败和回调重入；旧上游 DLL 作为负例会在重复整形断言处失败。另运行 Label、CodeEdit、ScrollView、ScrollFrame、布局、文本、DPI、渲染调度等专项。

IDE 验收覆盖帮助真实像素、2,500／3,200 行代码块、章节、阅读恢复、查找、来源按钮／Escape、背景区间与实际绘制，含字体及 125%／200% DPI。SDK 使用 `tools/verify_xge_sdk.ps1` 与 `tools/check_sdk_materials.py` 校验匹配载荷及来源闭包。此轮未扩展为整套语言服务器或标准库验收。
