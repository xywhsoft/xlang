# 原生退出计划的生产结果复用

本阶段实现退出计划结果复用及普通检查接入，但发行配置默认关闭。只有当前生产者实际读取的输入完全相同，才能复用一份独立的退出计划结果。函数结构或类型等输入变化时，继续执行原生生产者。完整语义检查、前置 IR 阶段和完整原生验证器均保留。

`XLS_EXPERIMENTAL_IR_EXIT_REUSE` 默认是 `0`。关闭时不编译缓存调用、资产字段、额外统计和相应 TLS 路径；实际预处理对照确认 IR、检查器、协议统计及服务入口与 0.108 的代码令牌一致，仅归一化服务版本号。开启时相应代码与已通过功能验收的候选一致。它与节点共享开关相互独立，两个优化在发行包中均关闭。修改该开关必须全量重建，不能混用不同配置的对象。

开发时可在新的构建目录为 `build_lsp_core.py` 添加 `--cflag=-DXLS_EXPERIMENTAL_IR_EXIT_REUSE=1`。原生批次审核通过只代表代码适用，不代表性能获准；未知批次仍使用原生生产者。以下机制、预算和 `analysis.irExit` 统计只适用于显式开启的配置。

普通检查还采用规模准入：复用已经统计的 `XL6_SourceReport.bytes`，分析源文本总量至少 64 KiB 才分配退出计划缓存预算。较小输入继续执行原生生产，不增加树遍历来决定是否缓存。这是性能政策，不是语义等价证明；内部显式预算 API 仍可用于独立验证缓存机制。

这不是任意函数改动后的最终 IR 局部生产。节点编号、结构和输入表必须一致；此前的跨批次记录链接器仍未因此进入普通分析。

## 准入证明

`native_ir_exit_profile.py` 在构建时审核原生 IR 源码、头文件及完整依赖批次，另核对退出计划生产者及其传递调用的 44 个函数体，包括退出步骤回调。仅审核通过的批次定义 `XLS_NATIVE_IR_EXIT_PRODUCTION`；其他批次保留原生生成。服务运行期间不扫描源码或计算这些摘要。

精确键覆盖：

- 27 个节点整数输入，另保留节点文本的五种判断结果：空指针、空串、`_`、`destroy`、其他非空文本。这与原生生产者的四处文本读取逐一对应，适用于所有节点。
- 根、节点和子列表数量、有序子列表、运行时类型映射。
- 类型池、枚举布局／变体／载荷、函数、泛型特化、值初始化器七张表的完整值。字符串和向量按内容比较，长度显式编码，不使用地址或 C 填充字节。

该生产者不读取字面量载荷、源码坐标及其他被排除字段。`generatorClosePointAbi` 是其输出而非输入。键不代替语义分析；本次分析产生的其他 ABI 输入仍须完全匹配。

节点投影在栈上批量编码，每个节点只追加或比较一次。命中时按顺序与已保存的精确键比较，无需创建第二份键；不存在仅凭散列放行的路径。键处理按节点／表记录检查取消。

## 所有权、预算和失败处理

XRT 分配的单个资产拥有键、清理动作、退出计划、退出步骤及每个节点的生成器关闭 ABI。资产使用原子引用计数，不保留旧分析、AST、模块或结果链。新模块单独拥有三个可变输出数组；分配完成后才替换其输出。

资产的已知保留存储有独立 8 MiB 上限，计入对象、对齐、输出数据、键容量和终止字节。原始 IR 片段的 32 MiB 预算保持独立。`analysis.irExit` 报告查询、复用、捕获、回退、原生生成、键字节、已知保留字节及上限；它们是结果创建时的统计，精确快照命中不会重新执行生产者。

此上限不是整个分析、XRT 堆或进程 RSS 上限。未命中时临时键使用 XRT 字符串缓冲区的几何扩容；一次扩容请求可能暂时超过逻辑键预算，随即拒绝并释放。该匹配 XRT 批次的扩容请求小于 12 MiB 加 16 字节；分配器内部重分配、元数据和旧缓冲区的瞬时重叠另计。命中路径不分配键，当前模块的输出克隆仍计入其正常存储。

预算不足、键或资产分配失败时，放弃缓存并保留原生生成。输出克隆失败时释放尚未发布的数组，再执行原生生成。取消不发布结果，完整原生验证器仍可拒绝任何错误输出。

## 验收状态

原型已验证字面量／坐标编辑、局部名称变更、类型／运算变化回退、32 代结果退休、四线程读取、预算边界以及分配失败和键处理期间取消。批量编码与原编码在 64 组边界向量上逐字节一致。原型同时通过真实 stdio 功能矩阵和七组定向协议检查。

首个候选保留冷启动与首次编辑两项性能失败；批量编码候选在固定 32 进程／480 查询中通过 40 项限制，四类交互链 CPU 几何平均改善约 3.0%。这是组件筛选，不能代替正式程序、小文件、配对 IDE 和完整发布验收。

正式首个图像通过 229 项原生、33 组协议、55 组配对 GUI 和 47 个编辑器事务模式。输入键夹具更新为观测新的检查入口，保留 167 项断言及 217 次完整键对照；诊断队列夹具使用真实读操作的同步门，保留队列、取消隔离和完整磁盘校验，742 项检查通过。

初轮小文件 CPU 窗口不足 1 秒，保留全部样本并将该轮标为测量不成立。扩展工具保持原有延迟序列和 500 ms 间隔，在精确重复后追加固定数量的真实连续编辑请求，并分别保留原节奏 CPU、补充 CPU 的 5% 限制及至少 1 秒的精度要求。后续正式运行收齐 64 进程、4,608 次延迟查询和 12,288 次补充查询，94／96 项通过，大文件 CPU 几何平均改善约 4.3%；保留小文件热 P95 和首次改动 P50 两项失败，未替换发行程序。由此增加 64 KiB 规模准入，并对新图像重新编译和验收。

规模准入图像再次完成 64 进程、4,608 次延迟查询和 12,288 次补充查询，88／96 项通过，大文件 CPU 几何平均改善约 2.04%，但有八项小文件延迟或 CPU 限制失败。保留完整结果，不以重复同图像测试或放宽门限消除失败。当前尚未将剩余回退可靠地归因于单一开销，故保留优化实现，发行构建退回编译期关闭的原生路径。
