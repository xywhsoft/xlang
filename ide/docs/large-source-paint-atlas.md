# 绘制图集复用实验与取舍

2026-10-11，SDK49 在一次内部绘制候选收集中复用成功取得的字形图集记录。严格构建、原生几何及绘制检查通过，但同批窗口测量没有表现出稳定的整体响应收益，因此不选入当前可运行候选。SDK48 集成候选继续保留。

## 实现与正确性

64 槽表以字体对象和 glyph 索引区分记录，占 3584 字节，仅存在于一次稳定字体的内部候选收集。成功返回后才写入表；失败、空输出或无效参数继续使用原返回值。后续绘制仍查询实际图集和 SVG 资源。公开头文件没有变化，DLL 的 5954 个导出名称及序号与 SDK48 相同。

完整 SDK 严格 O2/Werror 构建退出 0，耗时 258.500 秒。保留所有旧检查并新增图集对照的完整引擎夹具，严格编译退出 0，耗时 261.765 秒；实际原生运行退出 0，耗时 6.203 秒。新增 31,892 条断言覆盖 9,254 次图集比较、193 个不同字形、9 个图集扩容或独立调用状态变化用例、4 个失败用例及空字形。

既有字偶、实时度量变化、Emoji、检查点恢复、取消、控件生命周期和 GPU 像素检查继续通过；3 项 SDK 检查、6 项相关编辑器检查也通过。上述是此私有 SDK 的专项验证，不代表完整应用回归或便携包发布验收。

## 同批原生窗口结果

SDK48 与 SDK49 使用相同的 83 份探针应用对象，分别运行 C/xlang、2/16 MiB、多行/单行输入，共 16 组，每组完成 45 条原生检查。8 对 1600×1000 窗口截图逐像素一致。以下为单行输入的最长编辑帧：

| 语言 | 输入 | SDK48 ms | SDK49 ms |
| --- | --- | ---: | ---: |
| c | 2 MiB | 160.244 | 184.596 |
| c | 16 MiB | 1222.828 | 1275.408 |
| xlang | 2 MiB | 162.323 | 158.215 |
| xlang | 16 MiB | 1232.090 | 1202.507 |

本批 C 的长行最长编辑帧变慢，xlang 略有改善；16 MiB 的帧仍约 1.2 秒。每种组合只有一次观测，背景负载未隔离，不能据此宣称统计显著的改善或退化。该实验没有满足选择新实现所需的稳定整体收益，极长行性能仍待验收。

## 后续重点

上一轮[主线程诊断](large-source-sdk48-profile.md)及当前代码表明，完整排版和远处可见范围计算仍涉及整行遍历。下一步检查编辑后可见范围缓存失效、检查点与行布局复用之间的关系，先测量各路径的实际调用与耗时，再修改。正确性要求继续保留字素边界、Tab 列、字体与 Emoji 度量、裁剪及失败回退。
