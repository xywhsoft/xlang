## 构建和执行记录的区别

核对确认 169 份当前产品源文件均在严格构建的 774 份输入中；输入的当前副本和构建副本摘要一致，84 个对象及 106 个输出摘要匹配。便携目录实际有 4,725 份文件，其中清单列出 4,724 份，清单自身单独绑定；文件集合、大小、摘要及核心产物与严格构建一致。

含渲染的完整回归实际退出码为 0，用时 1,038.063 秒。其基础 `-CompilerPath` 是历史 `demo6-semantic-862cd3b4-9827-4983-ae59-0f5562ab97bd` 编译器；补全、桥接、映射、构建输入、类型、标量、聚合和扩展查询参数使用当前 `compiler-c-native-extensions-v1` 编译器。不能把这份回归概括为“所有测试均使用当前默认编译器”。

当前便携包的默认编译器另有十项实际检查，退出码均为 0，包括搬迁运行、源码材料、真实扩展混编及界面、聚合／标量、输入观察、来源上下文与 GUI 父进程生命周期。包内 `xl.exe` 摘要与该默认编译器一致。原生字体／恢复检查及树重命名由独立工具收集进程结果，本次同时核对其结果文件、子进程退出码和原始日志，而不是仅查找顶层日志中的 `passed` 文本。

本轮没有更改产品源码、重跑完整回归或重新打包。首次汇总的文件计数假设，以及第二次汇总的 Windows 长路径读取失败，均保留原脚本和失败日志；第三次汇总实际通过。它们是汇总工具失败，不是被改写的产品验收结果。
