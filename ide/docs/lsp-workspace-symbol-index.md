# 工作空间符号索引内核

2026-11-09，M7a2b126d。新增 `workspace_symbol_index.c/.h`，将上一阶段捕获的独立声明保存在常驻内存索引中，支持多个完整语义上下文、模糊查询、有界排序及快照内定位。实现复用 XRT 容器、内存、UTF8、原子引用和现有路径／上下文规则，没有引入额外依赖。

本阶段仅完成内存数据内核。尚未扫描工作空间、调度后台索引、公布 `workspace/symbol`／resolve 能力或新增 IDE 搜索界面，也不是磁盘持久化。默认语言服务和 IDE 未替换，交付索引未更新。

## 所有权与发布

- 一个提交所有者负责索引生命周期、Begin／Set／Remove／Commit／Acquire；已取得的不可变快照与查询结果可由多个线程保留及读取。
- Begin 仅保留当前版本及其分片指针。Set 仅重新准备变更所有者的分片；未改分片继续共享，声明及完整 `xls_context` 独立保留。不保存 AST、完整导航表或引用表，不调用编译器、磁盘及协议。
- 同一哈希桶必须再通过 `xlsContextEqual` 完整比较。相同作用域／平台词法路径／声明名／种类／完整范围及选择范围才合并；不同配置、重载、getter／setter 保留。
- 任何无效输入、内存拒绝或取消均使事务失败；Commit 无论成功与否都消费事务。构造前及发布前均核对原快照，构造期间的竞争提交、索引关闭和代次耗尽均不能被覆盖。
- 查询结果拥有快照引用，可在索引销毁后继续读取。`generation + ticket` 仅标识这一个索引快照内的记录；跨进程、索引重建后的稳定 ID 及来源／配置／覆盖文本新鲜度须由后续协议宿主管理。

分片内容有增量复用，但提交仍重新构造、排序及去重全部记录引用，不宣称完整增量索引。Begin 为 O(分片数)，查询为 O(记录数 × 匹配成本)，提交最坏包含 O(记录数 log 记录数) 排序。后台执行和任务优先级仍待接入，不能将提交放在编辑器绘制线程。

## 查询与额度

查询限制为合法 UTF8、512 字节、128 标量、16 个 ASCII 空白分隔词，所有词都须命中。ASCII 忽略大小写，非 ASCII 按精确标量匹配；依次考虑叶名称和限定名称的精确／前缀／包含匹配，再做带驼峰及分隔边界奖励的标量子序列匹配。空查询列出符号。预计算的 ASCII 字符位掩码只用于保守排除，中文查询仍会检查所有行，是后续性能优化点。

结果使用最差项为堆顶的 best-K，最后按确定顺序输出。查询固定两次堆申请，不逐行分配；完整命中数独立于返回上限。排序按最多 1,024 行分块，合并每 256 项检查取消，查询每 128 行检查取消。

默认每快照已知保留载荷 128 MiB、65,536 所有者、去重前 1,048,576 行、最多 4,096 返回项。共享上下文及声明仅按实际指针计费一次；等值但独立的分配仍分别计费。平台路径键沿用既有 malloc/free 约定，其余由 XRT 管理。额度不是进程 RSS 上限：更新中的指针数组、作用域映射、排序 scratch、分配器开销、调用者仍保留的旧快照和结果另外占用内存。合并 scratch 为 `count * sizeof(symbol_entry)`，Windows x64 默认行上限时为 24 MiB。

## 验证及失败留存

本轮核对上一阶段全部复用的生产源码、公共／私有头文件及编译器对象完全未变，只新增独立模块、独立头文件、包含实际实现的测试与构建注册。保留既有 143 项原生验证的准确产物，新增实际执行的索引用例，因此汇总为 144 项；不是重新执行全部 144 项。最终记录 1,419 输入、146 产物、147 个既有私有 AST 消费者；命令历史含之前 242 次编译及本轮新增／修正的 6 次。

新用例通过 12,321 项检查：实际原生捕获 42 条声明后销毁生产者；两配置及强制哈希碰撞、重复去重、独立 UTF8 动态规划成员对照、完整／有界结果前缀一致、快照及旧票据、65 个实际申请／容器／路径准备拒绝点、查询两次申请拒绝、全部 10 个更新取消点、额度、提交期间竞争、回调期间关闭、代次耗尽。10.5 万行检查由 42 条声明复制到 2,500 个配置作用域组成，验证单个分片变更后其余 2,499 个分片继续共享，四个读线程在新版本发布和索引销毁后仍可读取旧版本。这不是十万行源码分析验证。

五个实际 C 反例均被拒绝：遗漏发布前冲突保护、只信上下文哈希、忽略声明坐标、合并不响应取消、反转 best-K 替换条件。最初的取消断言允许合并完成后才取消；第一次补充路径比较计数也不足，因为不同作用域不必比较路径。两轮未检出记录均保留，最终通过实际 scratch 申请／释放的生命周期，确认取消发生在合并期间。生产逻辑未因此改变。

22 套既有协议、9 项真实服务 GUI 检查及 1 项受控旧能力兼容通过；113 个 GUI 对象与冻结的 180 文件 SDK 及实际运行 DLL 对齐。GUI 使用精确源码快照；后续测试修正不影响其任何消费输入。源码中 scratch 上限注释另由 16 MiB 修正为 24 MiB，两种生产／包含测试对象重编译后均逐字节相同，原协议、GUI、反例与计时二进制身份保持有效。保留最初独立上下文 fixture 无效和 SDK 冻结脚本使用旧目录名的失败记录，不将其算作通过。
