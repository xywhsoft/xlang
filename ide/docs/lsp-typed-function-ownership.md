# 原生最终函数所有权（M7a2b108）

本阶段将普通缓存检查已经产生的最终原生函数树交给独立所有者，供后续真正的局部语义／IR 生产复用。函数快照 API 直接保留这些树；不再先克隆另一份树才能建立单元。解析、语义和 IR 仍来自原编译器，节点表示没有另起一套。

这一步**尚未省去普通编辑的完整 AST 物化**。本阶段不把独立所有权、克隆次数或快照 API 的变化当作普通分析提速证明，也未完成最终 IR 局部生产。

## 正常生产与生命周期

`xlsTypedModuleTake` 在普通缓存检查已有的所有权接管处，按模块的直接子槽建立普通／异步／导出函数的独立引用。只扫描顶层声明、分配一块有界元数据并初始化一个 XRT 锁；不遍历或复制函数体，不建立逐节点查找表。原模块存活时，所有节点值、地址及子槽保持不变。

新增正常路径成本是两次顶层槽扫描、一项可观察的共享元数据分配、锁初始化和每个最终函数的引用／释放锁操作。显式捕获仍需要节点、子边、事实及来源去重遍历和相应分配，不能描述为整个 API 无分配或常量时间。

模块最后一次释放时，将这些函数子槽与模块根的释放分开。未保留的函数及其他声明正常退休；保留函数不持有模块、检查对象、报告或来源正文。共享所有者只保存函数槽元数据和 XRT 同步设施，不保存旧模块根。

不同函数可能共用原生 `XL6_AstSource` 和 XRT 池。它们的原始引用计数／池释放不是并发操作，因此最终子树释放在共同锁内进行；不可变函数读取不需要加锁。原始 AST／来源／池析构仍负责回收，不改变引擎或 XRT 的分配规则。

`ast_clone.c` 同时停止整份读取来源记录后再覆盖引用计数的写法，只复制路径及三个查询坐标字段。共享来源的兄弟函数退休时，克隆不读取正在变化的所有权计数。完整字段范围继续由已审计的原生 AST 组合限定。

所有者创建或锁初始化失败时，模块继续使用原来的完整树所有权；函数快照可回到原有独立克隆路径，不产生语言诊断。私有原生 AST 布局保持不变，新增接口使用不透明句柄。

## 函数快照消费

单函数捕获保留对应的原生函数所有者；批量捕获只在显式请求时建立一次地址到所有者的 XRT 查找表。匿名、嵌套和方法等没有独立顶层所有者的函数继续走已有完整克隆路径。节点／子边／原索引事实向量与规范字符串仍按需生成，并保留原检查前后来源验证和取消要求。

单函数的 64 MiB 本地配额计入已知原生 AST、向量、字符串和完整共享元数据；集合的 256 MiB 配额对同一所有者元数据及来源戳只计一次。共享池后备容量、保留的上下文／依赖／实体存储和临时映射仍在这些本地配额之外，不能由此推断进程峰值。池页面及地址索引的最终回收也取决于其余存活槽，不能将保留一个函数描述为只保留该函数的逻辑字节数。

这些对象保存生产时的原生类型／符号／区域 ID。独立生命周期不证明它们在下一次编译中有效。后续消费必须建立当前来源、语义读取、类型域、符号和执行区域的绑定；不能直接把旧 ID 或旧坐标当作当前结果。

## 当前验证

- `focused-v1`：四个实现与测试重新编译，在数据 ABI 不变的诊断组合下通过 176 项检查；保留原头和其余对象身份，不能代替产品完整重建。
- `focused-v2`：增加真实 C 结构体参数场景，通过 313 项检查。两类单元分别覆盖 56／52 个可观察分配拒绝点、精确单元／集合预算、原模块及未保留兄弟先退休、192 次并发独立物化，以及共享池／来源的双线程释放屏障。
- `full-v1`：补充测试故障入口时改变了正在构建的输入，因此主动中止，不用于验收；原目录、退出记录和输入历史保留。
- `full-v2`：使用固定后的源码、头和构建控制器重新构建，224 个编译单元、127 项原生、801 项输入／129 项产物闭包全部通过；生成的私有原生 AST 头与前一版本逐字节相同。
- `validation-v1`：131 个独立进程的 168 次增量／全新检查、336 项导航、26 次补全对照，以及原 56 套协议通过；构建、工具、根运行时身份前后核对。
- `omissions-v1/v2`：实际源码错误变体验证通过，最终六个案例／16 条命令。去掉函数释放锁触发并发屏障断言，强制函数树克隆触发原始地址／克隆计数断言；把有效来源引用计数字放在不可读页、其余逻辑字段放在可读页，正常克隆通过，恢复整份来源记录复制的同优化级别变体发生访问错误。该人工边界证明不读取所有权字，不替代整个堆或全部竞争条件验证。
- 追加混合路径检查通过 128 项：同一缓存检查中三个顶层函数直接保留、十个嵌套／方法函数独立克隆，单元／集合精确预算及生产者销毁后的值、物化均一致。该测试由独立验证工具用完整构建的匹配库显式编译运行。

验证目录为 `ide/build/Release/lsp-typed-function-ownership-20261102/`。九项被修改的前一构建输入，以及后续扩展的诊断测试／工具原字节另外归档到开发材料，历史报告不改写。该版本比较／故障验证目录用于保护根 `release/` 的工作版本；本阶段未部署 IDE／LS，也未更新当前交付索引。正式性能、GUI、规模与完整长期目标验收继续。
