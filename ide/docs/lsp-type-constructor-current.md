# 原生类型复制的空 token 构造优化

2026-10-31，M7a2b97。证据位于 `ide/build/lsp-m97-20261031-e87736be/`。完整 220 对象／123 原生目标／129 私有 AST 消费者、54 套协议回归通过。A/A 原 64 项全过，相同前端对照 1 项热 P95 失败、正式 0.99 对照 6 项冷 P50 失败；本轮性能未准入，候选未安装。

## 范围和原生资产

冷分析的隔离计时覆盖完整分析会话，而不只覆盖 `createBody`：入口语法构建、导入缓存捕获、原生语义检查、事实保存、最终 IR 输入证明、导航投影及响应封装均被观察。原生函数检查占主要时间。小样本计时用于定位，不能据此认定跨编译器版本的性能差异原因。

本阶段只精简固定当前前端 `xl6SemCloneTypeNode` 中的空 token 构造。原函数始终向通用 AST 构造函数传入 `NULL` token，随后由原生来源复制函数设置范围。适配器直接执行相同的 XRT 零初始化节点和文本分配，避免重复的通用构造路径；原函数的其他字段、来源引用、递归子节点复制和清理仍使用原代码。

节点继续独立拥有普通 XRT 堆存储。本项改动不增加节点共享、缓存、存储池、跨结果引用或运行时开关。省去通用文本构造中对新节点空文本的释放调用，因此 XRT 的 API 级 `FreeCalls` 统计会减少；实际块释放和生命周期保持。已核对生成运行时的空指针释放不设置错误或改变所有权。文本分配失败时保留原构造函数的返回行为；这项优化不是一般性的 OOM 语义修正。旧前端仍生成原语义代码。

原生语义文件、AST 实现及注册表仍须通过已有整文件哈希和完整前端环境审计。适配器对完整原类型复制函数及唯一构造位置再次核对，并登记原函数摘要、原始参考文件和生成器输入哈希；原生资产更新后须重新审计。

## 正确性证据

新增测试包含实际生成的语义 TU，参考函数从原始编译器源码独立提取，递归调用也指向原始参考函数。668 项检查覆盖空节点、空／非空文本、Unicode、子节点、复制和忽略的全部字段、来源身份与引用恢复、独立所有权，以及节点／文本分配每个调用位置的失败。逐次比较分配顺序和返回树，并检查释放平衡。

四种实际候选源码变体分别破坏节点种类、错误复制应忽略的符号字段、丢失来源、改变文本分配失败行为，均由原生参考对照拒绝。该失败注入不包含子节点数组扩展失败，也不能代替整个前端或服务的 OOM 验收。

旧正式 0.99 的语法、IR、语义三个对象逐字节一致，其中语义对象由本轮最终生成器重新生成后编译。完整原生和协议回归分别通过 123／54 组；新增测试在完整正常构建中仍完成 668 项检查。三轮计时前后，740 输入／125 产物／231 协议保护输入／3 项冻结源码及 8 项根发布文件均保持一致。16 个已知夹具目录、52 个文件按既有确切字节档案移入本阶段证据目录，未删除未知内容。

隔离 AST 池和最终输入证明批量写入原型只用于诊断，未采用。它们的全部结果、慢样本及失败记录保留。新增生成器输入登记后中断第一次完整构建，以最终构建代码重新执行；未将中断构建计入验收。
