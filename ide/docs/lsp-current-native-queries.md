# 当前前端的原生补全与参数提示生产

2026-10-30，M7a2b81a。接续固定提交 `9192a99f96ecd83bd57ca6e53df6dfcdda7d2f15` 的语义事实与特化声明适配，验证真实候选池、参数提示捕获、解析缓存和查询态函数复用。开发基线仍为 0.99，正常当前语义／IR／补全构建守卫保持关闭；本阶段没有发布当前服务。

## 实现

当前补全发射器增加了路径比较失败处理、选择来源编号和输出前的身份核对。独立补全组合器核对完整 Parser／AST／XRT／发射器及当前路径助手的字节，再安装已有的命名空间映射和候选池观察。其他发射器逻辑保留原文，原候选追加和池构造正文的新旧摘要相同。完整加载器／来源报告／包解析组合仍单独拒绝未经审核的当前资产。

参数提示的三处路径比较改为已有的兼容助手：当前前端只有比较结果为相等时才允许命中，错误不会当成相等。签名记录和解析缓存函数整理为 `signature_data.inc`、`signature_parse.inc`，正式 `signature.c` 和独立验证目标都包含同一份生产实现，没有第二套签名构造器。

查询目标链接真实发射器、候选池、签名追加／排序和解析缓存，不生成或链接之前事实单元目标的捕获终止护栏。语义适配仍必须显式请求私有单元入口；这个目标没有把完整服务的准入范围扩大到其他资产。
