# 排版调用内的 Emoji 匹配复用

2026-10-11，SDK47 私有实验，基于 SDK46。保持定版的 Dock 布局及 C/xlang 双语法。新增有界的调用内匹配表，并通过原生比较。长行性能尚未验收，未替换固定 SDK 或便携候选。

## 实现与边界

完整 UTF-8 校验后，单次排版为至少 256 字节、允许 Emoji 的文本建立 64 槽匹配表，表共 6144 字节，不增加堆分配或跨帧状态。每个条目保存最多 16 字节的前缀、包身份、包修订号、原始匹配结果及实际读取范围。同一次调用的 presentation 固定；表不会跨 presentation 或跨调用复用。

命中要求完整前缀与包身份、修订号一致。读到结尾的匹配还要求剩余长度相同，防止末尾追加变体选择符或更长序列时错误命中。读取超过 16 字节、修订号饱和、关闭 Emoji 或无法证明边界时继续走原匹配路径。未匹配的结果也记录实际读取依赖，检查点仍按原要求保留依赖范围。字体解析、Emoji 缩放、kerning 和浮点画笔相加继续在原位置执行；默认包激活时机保持不变。

私有观察宏只在夹具中计数，SDK 默认宏为空。没有新增公开导出，也没有更改相对 SDK46 的公开头；调用期间仍要求字体及资源稳定。该表不用于任意未校验字节串，且不提供持久的自定义包缓存。

## 实际验证

- SDK47 完整严格 O2/Werror 编译退出 0，306.703 秒。
- 完整引擎夹具冷编译退出 0，381.093 秒；原生运行退出 0，7.391 秒。包含 241 份引擎材料、116 个分编译 XUI 单元、13 份夹具及原 DPI adapter，每个可执行文件只有一个 XRT owner。
- 新增 202,402 项断言、495 组匹配比较、6 组长输入、4 组修订、1 组包身份、6 组检查点比较；观察到 142 次命中。
- 覆盖 16 字节结尾后追加 17 字节更长序列、变体选择符、ZWJ、肤色、四种 presentation、失败注册后的修订、最长前缀、超过槽数的冲突、饱和修订和长前缀后的检查点恢复。无效 UTF-8 仍在任何回调之前拒绝。
- 原 63 组检查点、52 组编辑几何、8 个真实 C/xlang 控件、3 组取消、78 组绘制像素对、39 组缓存重放、24 组水平候选及 108 对旧 GPU 像素比较继续通过。逻辑 DPI 测试不代替实体混合 DPI 和 IME 验收。
- 原 SDK 的 Unicode 和 Emoji 两项检查通过，document 在单独的补充检查中通过。六个当前应用检查通过，使用已有应用产物，没有重编译应用。
- 持久准备工具重新生成 241 份 SDK 材料及 10 份应用覆盖，与实际输入一致。持久测试工具显式复用冷编译前核对引擎、13 份夹具、DPI adapter、参数、可执行文件和日志，再运行原生比较退出 0，7.078 秒；其默认冷编译分支未再次执行。

SDK47 与 SDK46 的 5954 个导出名称及序号一致。这不代表相对固定 SDK 的完整 ABI 验收。全 SDK 许可、正式发行与独立干净 Windows 环境继续验收。
