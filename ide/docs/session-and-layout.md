# 会话、恢复正文与 Dock 布局

会话服务已接入原生启动、自动保存、正常退出、工作空间切换及工作空间另存为。它只保存本机使用状态；共享的工作空间与项目清单仍通过原来的模型服务保存。

## 存储位置

已保存工作空间和独立项目使用清单所在目录下的 .xlang-ide/workspaces/<scope>/。scope 是清单种类和文件名的稳定摘要，因此同一目录中的两个工作空间，以及同名的工作空间和项目，互不覆盖。移动整个目录时摘要不变；工作空间另存为会迁移当前会话到新的作用域，编辑标签保持打开。

未打开清单时使用 %LOCALAPPDATA%/xlang-ide/global/。全局 recent.json 只记录最后打开的清单种类与路径，window.json 独立保存主窗口位置、正常尺寸及最大化状态，启动时可重开该工作空间或独立项目。window.json 格式和错误保护见 [主窗口状态](window-state.md)。每个作用域有以下文件：

| 文件 | 内容 |
| --- | --- |
| session.json | 文件引用、活动文档和项目、语言覆盖、Unicode 选区、滚动和折叠、当前配置、主题、命令检索和所选命令，以及树、帮助与属性阅读状态 |
| layout.json | 带提交标识的逻辑 Dock 快照，包含分割树、比例、区域尺寸、活动标签、隐藏和自动隐藏、浮动位置及顺序 |
| recovery/*.text | 未保存正文，内部 UTF-8/LF |
| recovery/*.base | 原始保存基线字节，保留 BOM 和换行风格 |
| previous-session.json | 上一份完整会话，引用正文同样受到保护 |
| checkpoint.lock | 覆盖整个作用域检查点与恢复操作的独占锁 |
| archives/backup-UUID/ | 原生恢复窗口建立的原字节备份、普通恢复文件副本和版本清单，不自动删除 |
| *.json.lock | IDE 进程之间协调原子写入的锁文件，关闭句柄释放锁，空文件可保留 |

诊断参数 --session-root PATH 使用独立存储目录，按完整清单路径隔离作用域；适合测试。--no-session 关闭会话读写。普通隐藏渲染测试默认不访问真实用户会话；明确指定 --session-root 才启用，有限帧退出前记录恢复检查点。隐藏模式始终跳过主窗口状态；--size 覆盖可见窗口的启动恢复。

## 文档与恢复

每次打开的新文档分配稳定 UUID，保存与另存为保留 UUID，关闭并复用控件时分配新 UUID。会话中的文档路径相对于清单所在目录，独立于恢复文件位置。语言分别保存为 c、xlang 或 text，并记录是否为用户覆盖。

光标和选区使用一基行号与一基 Unicode 码点列。坐标适配层与 SDK UTF-8 字节偏移转换；中文、emoji 和 tab 均按一个码点计算，不把 tab 视觉宽度当作文本列。越界位置截断到实际文本范围。折叠只恢复起止行均匹配的当前语法区间，滚动由实际 CodeEdit 布局裁剪。

未命名文档及脏文档的正文放入独立、不可变的恢复快照。会话 JSON 不内嵌正文。恢复到编辑器后保留最初保存基线，因此磁盘文件被改写或删除时，后续保存仍触发冲突保护。恢复不自动覆盖源文件；恢复正文作为一次编辑进入当前撤销记录。

读取失败的文件显示错误并保留会话引用和已有恢复文件。之后保存不会因为文件暂时不可用而删除引用；手动重新打开同一文件后只保留一个打开记录。程序正常退出或界面切换前仍沿用保存/放弃/取消确认；明确放弃后，新的会话不再引用被放弃的脏正文。程序崩溃、强制结束和程序化切换使用恢复检查点。

## 保存与错误保护

文本、选区、语言、主题、配置、命令、树展开/选择/滚动、帮助章节/滚动、属性滚动及 Dock 变化经 750 ms 防抖后保存，待保存期间请求有限的后续绘制。元数据限制 8 MiB，单份恢复正文限制 16 MiB，本次检查点正文和基线合计限制 128 MiB；超过限制显示错误，保留上一个检查点。

状态文件读取校验 UTF-8、根对象、格式及当前字段类型；支持 UTF-8 BOM。未知元数据字段和保留对象的 Dock 扩展字段往返保存。损坏或不支持的文件保留原件并回到可用布局；不静默覆盖。当前作用域可通过“视图 → 会话与恢复…”先完整备份原元数据与普通恢复文件，再按当前已打开文档、Dock 与阅读状态重建。正文可先只读预览并取回为 C/xlang 未命名文档；不覆盖原源文件。布局重置只调整当前界面。独立全局 recent.json、window.json 及程序偏好的损坏修复仍待实施，不包含在该作用域重建中。

整个检查点从正文写入之前取得作用域 checkpoint.lock，持续到上一份元数据、布局、当前会话和清理完成；单个 JSON 仍取得自己的进程间锁，并核对磁盘 JSON 与加载基线；其他 IDE 保存或外部修改冲突时保留对方文件。使用同目录临时文件原子发布，发布成功前准备好新的内存基线。外部程序不参与 IDE 锁，仍依赖磁盘基线检查；不是任意编辑器间的分布式事务。

layout.json 先写入新快照及上一次已引用的快照，再由 session.json 的 layoutGeneration 发布该提交。两份文件不是一次文件系统事务，但中途失败后旧会话仍能找到匹配布局。最近工作空间索引在主检查点成功后更新；索引损坏不会阻止已经保存的工作空间会话恢复。

## 树与帮助阅读状态

session.json 新增可选 reading 对象，version 为 1，包含 workspace、commands、help 和 properties。旧 session-1 没有此字段仍可恢复文档，并在下一次成功检查点加入阅读状态；不修改工作空间或项目业务清单。

树使用稳定 JSON 元组作为不透明键。工程树按节点种类、项目 ID 和文件/分组 ID 匹配；库节点按当前引用定义匹配，定义改变则重新选择。命令树按类别、模块及稳定命令 ID 匹配，目录条目重排不依赖 SDK 编号。仅有子节点的分支保存 expanded，选择单独保存；节点数组与保留对象的未知字段往返保留。重复键、错误类型、越界或不支持的阅读版本拒绝整个会话恢复并保护原文件，不部分恢复文档。单棵树最多保存 20,000 个分支，键最多 8 KiB；仍受总元数据 8 MiB 限制。

树滚动保存顶部可见节点及行内比例，布局完成后按当前实际行高恢复。字号、节点顺序和 SDK 运行编号改变后仍尽量显示同一节点；找不到锚点时使用经当前控件裁剪的逻辑偏移。已删除的身份被忽略，新增分支使用默认展开状态。恢复选择不打开源文件，也不更改启动项目；选择工作空间级文件保留上一个有效项目属性所属者。

帮助保存所选命令、章节标题及同名序号、正文块的显示文本/类型摘要及同内容序号、块内比例、逻辑偏移和末尾标记。宽度或字体重排后匹配原内容块；块缺失时回到仍存在的章节，最后再裁剪旧偏移。位于文档末尾时恢复到新的实际末尾。正文块身份是本地阅读提示，不能用于证明语言语义或库版本一致。没有章节或正文锚点的条目仍可保存滚动；properties 保存裁剪的纵向逻辑偏移。

展开和选择先于恢复 Dock；树、帮助和属性偏移在真实布局后应用。显式启动项目、命令/搜索或 --help-chapter 优先于相应恢复位置。切换工作空间先保存当前状态，再清理浏览状态并恢复目标作用域；空查询也显式恢复，避免不同作用域之间遗留搜索和阅读位置。界面字体实时更新及失败回滚同样使用树/帮助锚点，保持当前浏览内容。

## Dock 适配

应用面板使用 commands、workspace、properties、command_help、problems、build_output、terminal、tasks 等逻辑 ID，文档使用 UUID。存储文件不依赖本次运行的 SDK 数字窗口编号。新旧运行编号不同也能正确映射。

固定 SDK 的 horizontal 分割实际形成上下区域，vertical 分割形成左右区域；适配层与应用协议明确对换。未知或已不存在的窗口从标签和浮动列表过滤，空分割折叠；已知 docked 面板失去位置时补入记录的区域。无编辑文档或可见演示页时补回编辑区。浮动窗至少保留标题栏可访问，越界尺寸按当前视口裁剪。

加载前完整转换和验证；重复窗口、非法比例、轴或矩形拒绝加载。SDK 加载失败时还原加载前快照。用户明确保存的隐藏和自动隐藏状态不会因为默认布局而被重新展开，原生“恢复默认布局”仍能显示所有基础面板。

## 原生项目迁移协调

项目清单或整个目录的迁移在物理操作前保存恢复检查点，并预分配独立项目会话路径。目录内默认 .xlang-ide 会话随目录移动，随后按新清单位置配置并保存；外置 --session-root 按新完整路径创建作用域，旧资料保留。工作空间清单位于移动目录内时更新工作空间作用域，独立项目更新 projectSessionPath。文档的会话 ID、C/xlang 覆盖、脏/未命名正文与 Dock/阅读状态保持；真实重新创建应用的验收已经执行。

自定义 --session-root 若本身位于待迁移目录内，迁移入口拒绝该组合；默认会话位于项目内已支持。项目与工作空间清单的路径修改仍需保存，工程模型的未保存属性不是文档恢复正文。协议、原生窗口与验证见 [项目清单与目录迁移](project-migration.md)。

## 旧格式会话提示

旧清单导入后端将 Open、Status 和 NewFileIndex 保存为独立 session-hints.json，以新项目和文件 ID 关联，包含未转换项目。它不是当前会话格式，不能直接替换 session.json。原生导入窗口默认在打开新工作空间后显式调用 xideSessionApplyLegacyHints；可关闭状态应用或只生成清单。服务先验证工作空间、项目和文件身份/路径及已知布尔状态，按物理路径去重后打开 C/xlang/text 标签，缺失或无法读取的文件进入既有 unavailable 集合。展开状态使用 ReadingState 的稳定键，旧编号不覆盖运行时文档 ID；完整提示保存为 legacyImportHints 扩展并随原生检查点往返。已有/受保护的会话或布局拒绝旧提示覆盖。写入失败保留已应用的当前状态与生成目录，可通过后续正常会话保存重试。重新创建应用后缺失引用、恢复出现的文件、双语法和树展开均已验收；禁用会话时只应用当前进程状态，缺失引用仍保存在工程和提示中。见 [旧格式导入](legacy-import.md)。
