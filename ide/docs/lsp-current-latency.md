## 自检工具修复

原自检工具按“普通构建目录下 EXE 路径出现在链接命令中”取配方。在增量构建已核对最终程序、但验收聚合目录保存的是相同字节副本时，这个条件不成立，计时查询通过后自检在编译前退出。

现在使用计时构建记录的实际 `check` 编译配方，核对它存在于普通构建、输出对象和原静态库成员摘要一致；按普通图像摘要以及全部真实链接对象／静态库摘要选择最终链接。保留原输入、程序、依赖和计时帧验证，不以路径放宽身份检查。六项配方检查覆盖实际最终链接及错误图像、链接对象、静态库成员、编译命令、对象摘要；修复后的 11 项计时自检通过，包括多线程嵌套、线程寿命、四个真实 C 破坏对照、取消与签名路径。
