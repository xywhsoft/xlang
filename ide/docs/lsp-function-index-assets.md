# 原生函数索引资产（M7a2b109）

普通检查现在让原编译器的索引收集器按模块直接声明分配事实缓冲区。顶层函数段与 M108 的最终原生函数所有者绑定；显式函数捕获直接保留原事实、规范字符串和函数树。保留一个函数不再要求保留整份旧索引，也不再为它扫描全局事实、复制事实向量和规范字符串。

这是后续真实局部分析需要的生产者边界。**普通编辑目前仍完整物化 AST，并执行完整最终 IR 构建及验证。** 本阶段尚未提供跨编辑的当前坐标、符号、类型域和区域绑定，也不以快照接口的变化宣称分析提速。

## 收集与所有权

`native_index_overlay.py` 继续使用原 `xl6_sem_index.c` 的遍历、选择、类型及规范化规则。根声明槽决定段编号，模块自身使用零号段；空子槽不会改变后继声明的归属。完整索引通过单独的指针目录按原先序顺序读取，各段缓冲区增长时仅更新该段在目录中的地址。没有另建解析器、语义推导或规范化器。

普通收集、实体视图和声明版本读取共用这一目录。原 JSON 路径仍使用原平面事实存储。没有可独立拥有的顶层函数、段元数据超限或可选分配失败时，类型化索引也可退回原平面方式；失败不能制造新的语言错误或发布不完整事实。

检查的原生模块接管完成后，绑定函数段与对应的原生函数所有者。只复制来源目录中的路径、原始／标准化长度、种类及两个 SHA-256，不保留报告或正文。范围是否合法仍由原报告验证，并在私有事实记录中保存三项有效位；本轮 x64 组合使用原有填充空间。段读取的范围值仍来自对应原生节点，私有收集器及其嵌入式测试全部重新生成和编译。

完整索引销毁时立即释放全局指针目录，逐段撤销自己的引用。没有外部引用的声明事实和规范字符串立即退休；保留段只继续拥有本函数的事实、规范字符串、原生函数引用，以及共同的槽元数据和来源目录。共同元数据没有旧模块根、检查结果、报告、正文、全局指针目录或其他声明的存活事实缓冲区。原生函数共享池的后备容量仍受 M108 的生命周期约束。

绑定和可选来源目录分配失败时，原索引保持可读，显式函数捕获使用原来的独立事实复制路径。嵌套函数、方法等继续使用已有完整克隆回退。保留句柄只证明生产时对象身份，不证明语义在下次编辑后仍有效。

## 成本与配额

正常路径增加每个根声明槽的有界元数据、一个全局指针目录、独立几何增长的声明缓冲区、来源目录复制、函数引用和范围有效性扫描。每段起始容量 16 项，目录起始容量 256 项，之后增长约 1.5 倍。元数据上限 8 MiB，整体仍受原 32 MiB 索引配额约束。事实缓冲区和指针目录按实际容量计费，原规范字符串预算保持。

函数单元将自己保留的事实缓冲区容量及规范字符串计入本地配额；共同槽元数据和来源目录在单元中完整计入、在集合中按同一生产者只计一次。父目录与其他声明缓冲区不属于保留资产。节点／子边向量、来源去重及取消检查仍按显式捕获生成，不能将整个捕获 API 描述为常量时间或无分配。共享 AST 池后备容量、依赖／上下文／实体存储及临时映射仍在本地配额之外。

这一步增加的冷路径分配、扫描、引用操作与碎片成本尚未取得正式性能结论。没有把它当作零开销优化，也未更改既有性能门槛。
