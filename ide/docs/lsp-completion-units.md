## 当前查询路径

正常光标查询仍使用 xlang 原解析器、导入与名称／类型规则。会话得到完整原始候选后，下一次只改变同一个标识符 token 的前缀时，尝试把候选、来源、语义 memo 和拓扑变为独立持有的数据，再由当前输入生成只读补全视图。独立单元不持有旧的完整 semantic result、checked AST、类型声明指针或 IR。

原始语法快照仍保留，用于直接比较解析器产生的每个逻辑字段。证明不建立第二套词法／语法；输入正文在 token 外必须逐字节相同，旧／新快照也必须绑定到各自真实 batch。batch 之间的路径拼写、身份、context、入口与其他正文必须精确匹配；语法路径通过原 `xrtPathAbs` 与真实 batch 绑定，视图及来源沿用原规范化查询路径。语法节点的类型、flags、文档、字面量、未知范围及映射后坐标均检查。新前缀只能落在原候选前缀覆盖的集合里。关键字、超出原集合、字段无法证明、资源或取消失败都回到原分析。

来源数据复制磁盘／覆盖文本、原始与解码散列、文件信息、缺失路径探测和包环境。发布之前与之后使用原来源验证，并通过原协议当前版本／输入守卫。候选定位仅复制必需的最小节点；位于查询文件 token 之后的选择范围按证明映射，重叠查询 token 的候选拒绝复用。显式请求完整 AST 时重新执行当前原查询，再执行原最终阶段；不会返回旧 AST。并发首次 demand 用原结果锁保护。

已有语义 memo 独立引用计数；只保留既有 facts、read sets、只读类型与坐标记录。拓扑副本独立复制原已准备键；overlay 只复制路径并借用固定 batch 中的正文。对当前 batch 顺序重新映射原输入使用掩码，保留无关正文／成员变化的既有缓存命中；后续普通编辑继续通过原拓扑兼容判断使用 memo。当前严格的 word-view 构造允许保守拒绝无关正文变化加前缀变化的组合。

## 接口和所有权

`analysis/completion_unit.h` 提供工作计数、同线程预算控制和会话内部入口。旧生产者、batch、syntax 在首次用户取消回调之前取得引用；回调可以验证生产者，或释放调用方输入引用。独立单元／视图销毁按原 XRT 所有权释放各自数据，不将借用正文或候选文本交给释放函数。

`builds` 记录完整语义构建；`wordViews` 和 `wordProofNodes` 单独记录新路径。`lastBuildWordView` 暴露 projected、proofNodes、candidates、knownBytes、astMaterialized、astFailures，补全视图本身要求 checked/reused 均为零。精确命中继续保留构造时统计，不能把它误读为这次请求重新构造了同样的数据。

## 边界

最多证明 262144 个原语法节点、递归深度 512，取消检查间隔最多 64 节点。known retained payload 的局部上限为 256 MiB，拓扑复制上限 8 MiB；零预算或失败使用完整原路径。既有容器／分配器开销、克隆临时数据、已有语法以后形成的只读 AST 视图和显式 demand 的完整分析不在这个局部计数内，它不等于进程 RSS 或峰值预算。旧文本和原始语法用于证明而继续保留，不声称不存在历史正文。

这次实际让补全消费者跳过完整导入、语义与 AST 物化；它仍需得到当前原解析器快照、比较原语法字段、验证来源和生成当前响应，不是常量时间查询。零长度点成员 token 首次输入保守回退，之后的合法前缀才可能复用。函数正文／结构修改、完整类型／模块／最终 IR 的持久生产和部分重建仍未交付。
