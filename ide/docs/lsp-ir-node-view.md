# 不可变最终 IR 节点视图

2026-11-16，M7b6u，外部服务 0.107。本阶段让完全未变的最终 IR 图共享节点存储和原有验证证书，减少相同坐标下的节点数组分配、复制及重复验证。实现复用现有 C 前端、XRT 原子引用和分配器，不增加运行库依赖，也不保留前一结果、检查对象或 AST。

## 复用边界

沿用最终 IR 的完整原生输入键：模块包络及每个声明的全部非坐标输入必须一致，原生类型／符号／区域等 ID 保持精确。随后逐节点核对当前 AST 的种类、行列及最终节点数，只有全部坐标也相同时才共享已经完整验证的不可变节点数组。节点拥有者单独保留认证状态、数组及容量；每个结果分别持有节点拥有者和已有表／文本拥有者。

这条路径复用同一份不可变 IR 值的有效证书。首份结果仍执行完整原生构建和验证；坐标变化会分配独立数组、应用当前坐标并重新执行完整原验证器；非坐标输入、原生 ID 或其他键变化仍走原构建路径。原有 C 互操作捕获限制及失败回退保持。普通可变编译器模块不使用这些共享节点，结果 API 返回的模块只供只读访问。

数据生命周期不依赖前一结果：创建者和 AST 退休后，后继视图继续持有节点及对应表／文本；最后一个视图退出时各自释放一次。引用仅指向独立拥有者，不形成历代结果链。共享节点不经过旧数组的复制或修改；变更坐标的结果也不会改写旧视图。

32 MiB 的现有持久元数据上限继续生效，并计入新增节点拥有者的实际大小。该额度仍只约束键及拥有关系元数据，不是节点模型、瞬态分配或整个进程 RSS 的上限。整体内存预算仍需后续验收。

## 工作计数与构建

`lastBuildPersistentIr` 将本轮工作分开报告：`verified` 是本轮完整原生验证，`certificatesReused` 是同一不可变图的证书复用；`nodesCopied` 与 `nodesShared` 分别报告复制和共享的节点数。没有用旧的验证计数冒充一次新的原生验证。`tablesShared`、`keyBytes`、`metadataBytes`、`prepared` 等既有边界继续保留。

这次调整了分析统计结构，因此核心和所有公共头消费者完整重编译，IDE 也用匹配 SDK 完整重编译。后续只修正一份旧夹具的 C 断言，其公共头与原完整构建逐字节一致，单独重编该夹具；不把旧断言失败记作通过，也不混入旧 ABI 对象。

## 正确性验收

完整 221 个原生程序、21 组既有协议回归、55 组 IDE 配对及 47 个真实编辑器模式通过。新 stdio 对照在 32／512 辅助函数、单文件／导入、打开／关闭工程入口下共执行 156 次检查、12 个进程；与 0.106 比较完整标准结果，覆盖同坐标注释／尾部空行、坐标移动、字面量／声明变化、精确重复、错误输入及恢复，并核对实际工作计数。关闭工程入口通过当前打开的成员发起检查，遵守既有接口要求。

新增节点视图夹具用完整原构建器生成独立 IR 对照，验证原结果和 AST 退休、连续十六代、坐标变化后的新节点拥有者、零预算回退及四个并发读取／退休视图。故障夹具覆盖 515 个移动视图和 265 个同坐标视图的真实分配失败点，并追踪首份节点到最后引用的全部释放。三种实际 C 破坏分别省略当前坐标检查、泄漏节点引用和忽略完整输入键，均被原检查拒绝。

另执行当前所有权 19 项、旧持久 IR 的 72 次标准结果对照、自动工作区发现 26 项，以及真实目录门闩的 6 项物理源码租约／取消检查。保留初次夹具链接、BOM 放置、关闭入口查询及旧统计断言的失败原件，修正对应夹具后重新核验。

## 性能与后续

原型先在未改变公共头的独立变体上验证机制。固定 2,304 请求／32 进程的原型 A/A 有 1／40 项尾延迟门槛失败；随后同规模 A/B 的 40 项门槛通过，观察到 512 函数尾部注释编辑热 P50 约 403→369 ms、508→482 ms。原型沿用旧统计结构，生产实现新增独立证书计数；这些原型值不能替代生产图像的测量或完整性能准入。
