# LSP 0.108 发布构建

本版本为 Windows x64 的保守运行配置。声明节点和表记录的直接捕获接口已经完成，但尚未接入普通检查中的选择性最终 IR 生产。

## 运行配置

`analysis/ir_profile.h` 默认设置 `XLS_EXPERIMENTAL_IR_NODE_VIEWS=0`，恢复 0.106 的独立节点所有权、原有分配布局、当前位置重建和完整原生验证。0.107 的已验证节点共享实现保留在编译期开关后；它此前未通过完整性能矩阵的一项尾延迟限制，不能作为默认发布配置。

对真实编译器命令执行预处理后，IR、检查、快照编码和服务入口四个编译单元分别与 0.106、0.107 的历史源码比较：默认配置与 0.106 相同，实验配置与 0.107 相同，仅服务版本字符串归一化。默认运行路径不增加开关判断。覆盖配置时必须重新编译全部消费者，不能混用不同布局。

## 验收和交付

本轮全量构建 368 个原生对象，产生 226 个原生测试程序和独立服务；IDE 全量重编 140 个对象及入口、资源，保持 C LSP 默认关闭。具体执行结果、配对 SDK、编译输入、程序摘要、原始日志和交付记录以 `dev/release-materials/provenance/lsp-stable-package-20261116.json` 为准。

226 项原生测试、33 组协议、55 组配对 GUI 检查和 47 个编辑器事务模式通过。覆盖 C／xlang 点击恢复焦点、输入、删除、撤销、Unicode／IME，以及补全、导航、语义着色、重命名和异步写入。协议验收补齐解码器参数，并把两份旧测试写死的 0.101 改为可显式指定服务版本，本轮指定 0.108，保留原功能断言。历史旧能力夹具的构建路径已缺失；保留原始失败，依据归档配方重建当前匹配的受控服务，补完兼容检查。

固定同图像计时校准实际运行 64 个进程、4,608 次查询，78／80 项通过。32 函数单文件声明改动的热 P95 为两组 14.3881／16.6324 ms，后一组超出 15.107505 ms 门槛；整条交互链每次改动 CPU 中位数为 10.5807／11.3189 ms，后一组超出 11.109744 ms 门槛。因此未继续版本间 A/B，没有性能准入或提速结论，也不以重跑替换失败记录。本次保守交付的依据是完整功能验收和普通生产代码与 0.106 的等价核对；完整性能目标保持未完成。

服务和 IDE 在仓库的真实 `release/win_x64` 中验证。构建对象、测试输出和回退副本位于开发材料目录；发布目录仅替换经过配对验证的 `xlang-ls.exe` 和 `xlang_ide.exe`，保留 `xlang_ide_xge.dll`、公共引擎 DLL、更新器及用户数据。

当前服务继续使用已验收的原生前端输入批次，并对实际发布引擎进行 IDE 联调；本轮不将它描述成对所有并行引擎源码变化的重新同步。Windows 7 物理显卡和 Linux 平台未在本轮验证。完整 LSP 目标中的选择性生产、大型工程、长期运行和整体验收仍需继续，DAP 和调试补全不在当前范围。

本地版本替换与更新通道发布是两项操作，本轮不会推送线上更新。
