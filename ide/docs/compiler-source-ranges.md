# 编译器源码范围

此增量实现真实 xlang AST 的位置基础，合同、调用方法、坐标与限制见 [DEMO6 源码范围接口](../../docs/IDE源码范围接口.md)。实现仍使用 C，生成后处理使用既有 PowerShell 工具链，测试驱动使用 Python。

新 xlcEmitAstWithRanges 和 parse --json --source-ranges 返回入口语法树的完整语法范围、构造 token 范围和来源路径，保留旧 AST 输出。覆盖表可提供未保存的入口。双语法编辑器及既定原生布局保持。

这次位置基础尚未接入 GUI 大纲、悬停、语义补全或定义跳转。新输出是入口语法结果，没有依赖摘要与语义符号；不能独立替代当前完整检查批次。下一步将真实语义 Symbol/Type ID、声明名称和引用位置关联到已复核的源码/覆盖批次，保留版本与发布后输入失效守护，再接 stdio 查询和原生视图。C 语义服务继续是首版待完成项。

实现与验收记录见 [实施进度](progress.md)。首版范围继续遵循 [实施计划](implementation-plan.md) 第六阶段。
