# 工具链查询的源码读取暂停

M7b5k，2026-11-12。独立工具链信息查询增加源码事务参与接口，补充[任务调度](lsp-edit-task-lease.md)、[文件监视](lsp-edit-file-sync-lease.md)和[IDE 语言功能](lsp-ide-analysis-lease.md)的暂停机制。完整事务宿主仍需组合这些参与者以及文档打开、缓存来源、物理别名、请求/配置时效、用户确认和恢复策略；标准重命名与 `workspace/applyEdit` 尚未启用。

工具链查询会读取编译器及 `xlc.dll`、`xl.dll` 的指纹，实际执行编译器 `--help`，然后再次校验文件。它没有项目源码参数，但仍可能持有文件读取、子进程和清理工作，因此不能把界面上的“查询完成”视为这些工作已经退出。

## 所有者接口

`xideToolchainsSuspend(cache, error)` 返回非零令牌后立即关闭新查询准入，不取消已有查询，不清空缓存，也不等待工作线程。请求前的路径解析、分配和线程创建均在暂停准入检查之后。令牌属于同一个存活 cache 实例；不支持嵌套，序号耗尽时拒绝新暂停。

`xideToolchainsSuspended(cache, token)` 需要准确的当前令牌，并逐一检查所有已登记请求的真实 worker HANDLE。READY、FAILED、CANCELLED 只是结果发布状态，不能替代线程退出。调用方尚未销毁的已完成请求仍保留原有所有权，已经退出的句柄不妨碍确认静默。

`xideToolchainsResume(cache, token, error)` 仅释放准确令牌，可以提前放弃尚未确认的等待。已经开始源码写入的宿主必须先完成提交、回滚或明确恢复协调；Resume 不自动执行请求、不清缓存、不重新授权旧编辑计划。

Request、Destroy 和暂停接口由同一个所有者串行调用，cache 存储必须活过每个请求。注册表由所有者维护，后台线程仅使用原有互斥锁保护的 profile 缓存。失败的路径准备、调用者分配和线程创建均撤销注册前缀。请求可以不按创建顺序销毁。

这些接口只覆盖 `xideToolchainRequest` 创建的查询。任务工作线程直接调用的 Capture、Validate、Observe 需要同时持有任务服务的暂停；其他独立调用者仍由完整宿主纳入。不能只凭工具链查询静默就写源码。

## 窗口和性能边界

工具链窗口在暂停时拒绝打开新查询，并禁用刷新；取消和关闭仍可使用。已经显示的结果保持。Poll 除检查结果状态外，还要求 `xideToolchainRequestStopped` 确认线程真实退出，随后才销毁请求。因此普通 UI 轮询不会因为工作线程已发布结果、尚未完成清理而阻塞 join。显式 Destroy、Stop 和应用关闭保留原有取消并等待的生命周期约定，不能把它们用于未协调的活动源码事务。

暂停请求和被拒绝查询的探针观察到零次直接所有者 malloc/calloc/free，不覆盖 DLL 内部分配。静默查询会遍历所有已登记请求并执行非阻塞内核探测；普通查询增加固定的注册/撤销元数据，窗口 Poll 增加实际退出检查。这些成本均不属于硬实时或整体 RSS/输入延迟保证，也没有向普通键入路径加入正文扫描或哈希。

## 验证

`ide/tools/build.ps1 -Tests` 注册 `toolchain_lease_test`，参数为 `<夹具目录> <匹配的 xl.exe>`。夹具以自身充当受控 `--help` 程序，并在真实已打开文件的 ReadFile 位置和真实 queryWorker 返回后的线程尾部设置门控；产品没有测试钩子。验证被动等待、暂停中取消、缓存命中保留、多请求乱序销毁、直接分配失败、真实 CreateThread 失败、准确/过期/耗尽令牌以及终结状态不能提前解锁。

窗口测试使用真实 XUI、工具链控制器和 Document，在线程尾部被持有时调用 Poll，并操作 C/xlang 输入、删除、撤销、IME 与聚焦。键盘文本测试发送完整的按键/文本/抬键序列，避免把快捷键之后的独立文本事件误当成实际本机键入。独立桌面在 Win32 返回 ERROR_BUSY 时由测试进程退出释放，不把该测试辅助对象算作句柄平衡证明。

编译与验收绑定完整匹配的 SDK 和原生服务，使用根 `release/win_x64` 下的私有测试入口保护当前工作程序；对象、截图和原始失败记录保存在开发构建目录。具体断言、回归、变异和精确构建摘要见 `dev/release-materials/provenance/lsp-toolchain-lease-20261112.json`。本阶段不替换正式运行程序，不构成全目标性能或最终交付验收。
