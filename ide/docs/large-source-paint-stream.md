# 完整度量后的流式绘制

2026-10-11，SDK43v2 私有实验，基于 SDK41。保留既定 Dock 布局和 C/xlang 双语法。完整排版数组已从长段绘制缓存失效路径移除；本轮正确性检查通过，但延迟未达标，未替换固定 SDK 或便携候选。

## 实现

第一遍按原顺序完成整段排版度量和普通字形图集准备；取得最终字体基线、行高及 Emoji 包后，第二遍使用原绘制函数和浮点相加顺序绘制。只保留最多 4096 个实际可见字形及其画笔位置。可见记录过多或分配失败时放弃缓存并继续绘制。最终度量必须先完成，因为行尾的大号回退字体或 LINE_EXPAND Emoji 会改变前面文本的基线。

第二遍保持第一遍默认 Emoji 包的引用，同时保留原有自动激活时机。若默认包注册了 ASCII `A`，`A😀A` 的第一个 `A` 仍是普通字形，后一个才可能使用已激活的 Emoji 包；不能把默认包直接改成显式包。原来的完整排版和检查点接口保持其调用方式。

公开头未改变，SDK41 的 5954 个导出名称和序号全部保留。此结论仅针对 SDK41 → SDK43v2；早期提供器扩展相对固定 SDK 的完整 ABI、全 SDK 许可、物理混合 DPI 与实体 IME 验收继续。

## 实际验证

- SDK43v2 完整严格 O2/Werror 编译退出 0，306.156 秒。
- 新完整引擎夹具冷编译退出 0，292.250 秒；原生运行退出 0，6.969 秒。78 组新旧绘制像素对、39 组缓存重放、可见记录上限及默认 Emoji 包替换检查通过，共 1975 项新断言。
- 覆盖不同字号、行尾大号 CJK 回退字体、LINE_EXPAND、分数与负坐标、CRLF/多行、嵌入 NUL、无效 UTF-8、重叠颜色覆盖、SVG 根变换溢出及加载失败、无裁剪缓存、2 MiB 浮点累计和 5000 个几乎重叠的 Emoji。
- 原 63 组检查点、52 组编辑几何、8 个真实 C/xlang 控件、3 组恢复后取消、2822 组完整排版、585 组布局和 108 对旧 GPU 像素检查继续通过。四档 DPI 是逻辑层测试。
- 原 SDK 的 Unicode、Emoji、document 三项及六个当前应用检查通过。应用没有重编译。
- 持久准备工具重新生成 241 份 SDK 材料和 10 份应用覆盖，与实际材料一致。持久测试工具显式复用上述冷编译产物前，逐一核对引擎、11 份夹具、DPI adapter、参数、产物与日志，重新执行原生测试退出 0；持久工具的默认冷编译分支未再次执行。

源准备首轮因源码同时存在真实和 NO_TEXT 两个 `xgeGlyphRunDraw` 定义而停止，未开始 SDK 编译；修正定位后在新树准备成功。夹具语法检查首轮使用了错误的覆盖头路径，并漏掉 paint span 的结构大小字段；保留失败材料后，在新夹具树修正，通过语法、冷编译与原生比较。SDK 实现未因该夹具修正而改变。

阶段归档检查首轮读取了不存在的编译复用字段而退出 1，尚未生成快照或归档；保留该检查器后，新版本改为读取实际的 `wholeEngineCompileReused` 字段。源实现和原生结果未因这次检查器修正而改变。

## 实际 IDE 窗口与性能

两版共享相同 83 个应用对象及同一探针源码，分别运行 C/xlang、2/16 MiB、多行/单行，共 16 个私有桌面原生窗口，每个通过 45 条检查。8 对 1600×1000 完整截图逐像素一致。实际显示 DPI 为 125%；没有切换用户桌面，截图比较关闭 caret blink。
