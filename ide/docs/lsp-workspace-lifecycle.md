# 工作空间主动分析与磁盘变化接入

阶段：M7a2b126j，2026-11-09。

IDE 主语言连接现在可以在没有打开编辑文档时，使用已配置的可用 xlang 工程启动服务。工程入口和配置仍由现有分析配置协议传入；服务沿用上一阶段的空闲索引刷新。空工作空间和只有 C 文件的工作空间不会因此启动 xlang 主连接。补全连接继续显式关闭重复的工作空间后台索引。

## 文件监视与同步

工程入口即使没有出现在工程文件清单里，也会加入现有文件监视订阅。已订阅文件的创建、删除和内容变化，经监视线程的稳定快照确认后，传给主连接，并撤销补全和参数提示的旧意图。已保存的已知内容沿用原来的去重处理；本地未保存文本、撤销记录和外部冲突处理继续由文档模型负责。

`workspace/didChangeWatchedFiles` 的 JSON 和完整传输帧改由现有 XRT 同步规划线程生成。没有新增线程。UI 线程复制有界路径元数据，复用同一个待处理、结果和退休槽；每批最多 128 个 URI，单个 URI 最多 256 KiB，总 URI 数据最多 1 MiB。准备结果带有同步代次、连接代次和逐路径修订号。发送前再次核对当前输入及监视修订号，整个编码批次被传输队列接纳后才确认相应路径，过期结果不能确认后续变化。

监视通知先于依赖其输入的收据和搜索请求。队列忙时定时重试，不在每帧自旋。监视历史或队列超过上限时，合并为一次完整重连；等待 150 ms 防抖及监视队列稳定，突发中的后续事件只延长等待。连接初始化或同步失败会暂停自动重试，配置变化或后续用户操作可恢复，避免反复启动服务。

磁盘变化撤销旧收据、定义、悬浮、大纲、高亮、引用和工作空间搜索结果，但保留已协商能力。引用列表清除后需要重新查询；未监视依赖的导航仍由实际服务的来源证明重新验证。诊断按已有依赖键失效，保持无关组的缓存。

## 回归中修复的外部重载问题

前一版本的整篇文本替换会先丢失折叠状态。外部重载现在在替换前保存折叠范围，语法重建后恢复起止行和层级均未变化的折叠。边界移动的块保持展开。分配保存数据失败发生在文本修改之前；选择、BOM、换行和本地冲突继续沿用原规则。

## 验收范围

- 全量重编译当前 115 个 GUI 对象，匹配同一份 180 文件的 XGE SDK 和实际运行库，默认关闭 C LSP。所有测试程序在根发布运行目录运行；日志、对象和夹具留在构建目录。
- 新生命周期夹具使用真实 IDE、文件监视和语言服务：零文档双工程启动、空闲预建、等长磁盘修改、模态搜索、删除／重建、未保存覆盖和撤销、旧准备批次拒绝、132 路径突发合并及 C／空工作空间隔离。
- 同步规划器验证真实编码帧、非 UI 线程编码、发送时禁止 UI 分配／编码、输入不可变、取消、队列上限、错误输入和分配失败恢复。编辑回归保留 C／xlang 输入、删除、撤销、Unicode／IME 和点击聚焦。
- 原生服务没有修改或重新构建。核对上一阶段合格构建的全部 1,457 输入、152 产物及 147 个私有 AST 消费者，保留 150 项原生测试记录，不将其计为本阶段重新执行。
- 早期折叠失败、完整前驱文件同步夹具的超时、测试驱动参数错误及模态窗口目标错误全部保留。最小前驱折叠复现确认丢失折叠；完整夹具超时本身不作为该问题的证明。

精确测试结果、源码和产物摘要见仓库的 `dev/release-materials/provenance/lsp-workspace-lifecycle-20261109.json`。本阶段不重跑或放宽既有性能矩阵，不将功能通过解释为整体性能准入。默认发行程序与活动交付索引不替换；候选程序不推送更新通道。

后续继续工程目录成员发现、错误／未完成代码的保守声明、适用 LSP 与静态检查／编辑态补全、实际局部语义及最终 IR 生产，以及真实规模、并发、耐久和端到端性能验收。DAP 和运行／调试态补全不在当前范围内。
