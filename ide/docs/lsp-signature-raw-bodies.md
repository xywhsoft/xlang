# 参数提示的原始函数体增量生产

2026-10-29，M7a2b69a，开发服务 0.98。本切片将已有 raw 函数体生产机制接入参数提示，继续使用外部 xlang-ls.exe、原编译器及 XRT。完整 LSP、持久 checked 模块／类型／最终 IR 与整体性能目标仍为 active；不包含 DAP、调试／运行态补全或合并 xlc.dll。

## 实现与所有权

签名帮助在原签名投影的 mode、路径、偏移和 LPAREN 位置全部匹配后，复用未改函数的独立不可变语法单元；当前调用所在函数仍完整解析。普通补全和完整解析保留各自准入。冷查询继续原完整复制，再登记原完整来源；资源／预处理／语义或证明不匹配时沿用一次干净全量重试，没有另建语法、类型规则或容错语言。

原整棵类型、符号、来源、坐标及分配区间证明继续执行。raw scope／memo 各 32 MiB、环境 8 MiB、语义 memo 64 MiB 等原有边界不变，不等于全进程峰值。签名的公开完整 AST 请求独立执行原签名投影并保留原 batch／查询 key，不能用标识符补全投影代替它；已保留旧结果可以比会话及调用方 batch 活得更久。

nativeSignatureRun 新增与补全同字段的 lastBuildRawBodies 观测；公共 UI 结果布局和既有协议字段不变。新私有 C 声明只使用 opaque 签名句柄，没有引入 XUI 或原生 AST 布局到公共边界，也没有宣布尚未实现的 LSP provider。
