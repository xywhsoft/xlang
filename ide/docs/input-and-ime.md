# 原生输入与 IME

2026-10-06 输入增量。首个验收平台为 Windows；字体配置、完整 DPI 和跨平台输入继续实施。

## 有序输入

platform/xide_input.c 只调用固定 SDK 的 xuiProxyXgePumpInput。键盘、文本、鼠标、滚轮、触摸和 IME 采用同一条有序队列，逐事件派发后再处理下一条。鼠标点击、焦点变化与后续文本能在同一帧正确排序。修饰键使用事件到达时的快照，原生重复按键保留；不再按本帧的最终状态合成输入。

不能再同时消费 xgeTextGet、旧按键状态或自行合成鼠标按下/释放，否则会重复投递或丢失原始顺序。窗口尺寸仍由主循环先更新渲染目标和 XUI 视口。输入桥负责指针光标、离开、触摸取消和窗口失焦后的捕获释放。

文件、工程和构建快捷键注册为 XUI HotKey，继续调用统一的 IDE 动作入口。编辑器保留原生撤销、重做、查找、剪贴板、选择和移动行为；焦点控件先处理键盘。配置模态页阻止新建、保存、关闭和构建等 IDE 动作，停止任务入口保留。

Ctrl+Space 仅在可编辑文档拥有焦点时显式打开补全。CodeEdit 默认的对应命令映射在绑定编辑器时解除；重复绑定允许键已解除的状态。SDK 的候选过滤、键盘选择、确认和一次撤销继续使用原生实现。

## 组合与提交

启动请求 XGE_IME_MODE_COMPOSITION：组合串在编辑控件内显示，候选列表使用操作系统原生界面。后端不支持该模式时恢复 NATIVE；其他初始化错误正常返回失败，不把未初始化当作成功。

XUI 输入桥绑定 Windows TSF 文本客户端，并从当前获得焦点的 CodeEdit、Input 或 TextEdit 提供 UTF-8 文本和选区快照。组合与替换范围使用 UTF-8 字节偏移，候选锚点按控件世界坐标转换至窗口像素。上下文销毁时由匹配 SDK 解除文本客户端和缓存引用。

组合更新不写入文档，不改变保存基线或脏状态。提交通过 CodeEdit 的正式文本输入事务进入正文；中文和非 BMP 字符可以整体撤销。结束或失去控件焦点会取消未提交组合；只读代码块不接受 IME 提交。输入框、停靠和浮动编辑器都使用同一输入桥。

## 固定 SDK 兼容

参考使用 AutoTestIDE 的 theme-20260916 固定 SDK 配套源快照，核对输入和代理源指纹；不使用另一个仓库的当前源码推断这个 DLL 的行为。所有修正在 IDE 应用层，SDK 文件保持原样。

- CodeEdit 的映射补全命令会在打开候选后执行通用取消逻辑。IDE 解除该键映射，通过 HotKey 调用显式 ShowCompletion，避免重复触发或立即关闭。
- Dock 对捕获阶段的子控件 Focus/Blur 返回停止传播，阻止 CodeEdit 取消组合。IDE 保存并调用原处理器以保留重绘，随后只解除子控件捕获阶段的停止标志；目标和冒泡处理仍保留原行为。

现有公共动作已经接入 [ActionRegistry](actions.md)。注册的编辑快捷键在 CodeEdit 目标 KEY_DOWN 阶段先核对状态，保存并转交其余原处理器；这样只读撤销不会先被固定 SDK 执行。普通 Edit/TextEdit 保持自身快捷键，核心右键命令按实际目标文档路由。底层编辑直接派发 COMMAND，不再注入一轮键盘；未知命令与其余 IME、文本和补全仍使用原生处理。

## 验收与边界

input_test 在真实 XGE 原生窗口运行循环内执行，隐藏本程序自己的窗口；不能只初始化 XGE 描述后就当作原生绘制。断言结果和实际执行标志独立决定进程退出码，不依赖主循环单独返回成功。

测试覆盖同帧文本/删除/文本顺序、事件修饰键、重复删除、撤销重做、Ctrl+N 后的焦点输入、C 补全确认及重复打开、C/xlang 中文与非 BMP 组合提交、载荷复制、取消、替换范围、只读保护、失焦取消后的普通输入、浮动编辑器及候选锚点。模态配置字段使用同帧鼠标点击和 IME 输入，确保新焦点先收到文本；模态期间新建/关闭/构建不穿透。中键完整点击、触摸取消、Win32 失焦捕获释放和有序编辑/保存/关闭也已验证。

原生组合截图位于 build/tests/input/中文 输入/native-ime-preedit.png，已执行更新、布局和渲染，确认组合串显示但文档及标签未变脏。

上述组合流程主要通过真实 XGE 事件队列注入进行自动验收；窗口焦点走真实 Win32 消息。不同实体输入法的候选翻页、选择、重转换、系统快捷键以及硬件触摸仍需人工设备验收。代码字体设置已接入；逻辑视口和物理输入的 DPI 映射现已接入，100%–200% 原生注入比例的鼠标命中与候选反向定位见 [DPI 与界面字体](dpi-and-ui-fonts.md)。界面字体配置及实体跨显示器候选定位仍需继续验收。
