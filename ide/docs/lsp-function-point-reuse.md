# 不可变函数的点位导航复用

M7a2b126t，2026-11-10。本阶段合入已验证的增量导航源码和测试。最终组件筛选 **41/41 通过**；完整 LSP／性能目标继续，默认发行程序、在线通道与交付索引保持。

## 复用与边界

新视图短暂借用上一轮同源路径、种类、BOM 和点位域的投影。只复用当前已完成检查中身份完全相同的不可变函数；原始语义、类型、来源、编号和完整 IR 验证均继续运行。核心以 `index_segments.h` 提供原有索引分段、借用身份及范围概要，不暴露 AST 或新增全局序号库。

构造同时持有两个检查，核对分段、父形状、当前规范类型文本的原额度，以及从函数首个范围所在行起点到最后端点的字节和 UTF-16 坐标。证明工作总额最多 8 MiB；失败尝试也在扫描前计费。通过后复制形状、声明和光标记录，并重定位节点序号。当前类型文本仍读取当前索引。所有新数组独立所有，原投影的构造借用在返回前释放，不将旧检查／AST／工作器加入长期缓存。

缓存仍服从原容量边界，分配失败、跨源或未知身份使用原完整路径。没有任何可匹配的旧函数时，本轮直接放弃额外缓存和分段排序，避免声明重编号后的无效工作；以后可以重新播种。临时后台视图保持原来的不发布语义。仅身份相同不代表输入新鲜；当前检查仍需通过原有完整验证。新增统计位于 `analysis.navigation.points`：`functionsReused`、`factsReused`、`cursorRowsReused`、`proofBytesCompared`。

## 正确性与 IDE

核对 259 个实际编译闭包，重编受新增公开头／私有布局影响的消费者后，157 项原有原生夹具全部重新链接执行。后续两次仅改变私有缓存实现，各重编四个消费者、重链完整组合并实际重跑 35 项受影响宿主夹具；原核心库及其通过的测试保持。最终两个新增夹具也从仓库实际源码、匹配头和对象重新编译执行，分别通过 **218,595** 与 **281** 项检查。

检查包括所有有效 UTF-8 位置的完整定义／悬停参考对照、真正的节点序号移动、重载／别名／类型／遮蔽、导入内部函数、保守导出包装回退、BOM、CRLF、等字节不同 UTF-16 前缀、34 个实际分配拒绝位置、独立数组计数、已失效旧检查的受限借用、退休后借用生存期和析构重入。扫描预算与无交集回退的两个实际 C 破坏对照分别由明确 CHECK／exit 1 检出，不把编译失败或崩溃算通过。早期小函数未进入已有语义缓存、导出包装未获得可复用身份导致的过强测试断言、构建配置修正及所有日志均保留。

最终八套协议通过。GUI 全量重编 115 个普通对象、入口和资源；私有 LS 实现随后调整时，公开头和 GUI 有效布局不变，复用这套匹配对象，对每份最终服务重新执行 26 项联调。最终 C／xlang 输入、删除、撤销、Unicode／IME、焦点、补全、导航、自动诊断与工作空间功能通过，三张最终截图已检查。临时程序均在根 `release/win_x64` 运行并清理，旧的六个默认程序／库摘要不变。

归因工具适配分段构造，较早的有界候选十个插桩单元、四项原生及 16 进程／240 请求／360 帧对照通过，实际协议中可观察到约 9.8 万个事实被复用。这些插桩数据只用于定位工作，未作为最终无交集候选的性能结论。本阶段验证的是匹配的冻结前端组合，没有重新准入并行修改的当前引擎工作树。

## 固定组件筛选

两份不同候选各只运行一次固定屏：512 函数，单文件／导入、字面量／局部声明四类，四对进程、14 次变化及一次精确重复，共 32 进程／480 请求。默认后台开启，一次运行一个服务链；启动／运行可用物理内存与提交额度至少 5／3 GiB。计时期间本任务停止构建及其他 QA，宿主并非独占。

首份有界候选的整链 CPU 比值几何平均为 0.9407561085，但导入／声明首次改动 P50 为 483.8456 ms，超过 483.764505 ms 上限，故 40/41，未准入。该结果保持，没有重跑同一图像或调整门槛。分析到声明变化后没有旧函数可复用却仍创建缓存，实施无交集快速回退，经过上述回归后才测试新图像。

最终原有 40 项不回退／精度／内存／精确命中条件及额外 CPU 收益条件全部通过；四类整链 CPU 中位数比值的等权几何平均为 **0.9440228023**，改善约 **5.6%**，满足不大于 0.98 的预登记要求。
