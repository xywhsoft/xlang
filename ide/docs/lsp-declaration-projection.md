# 轻量声明投影与完整大纲声明

本阶段把文档大纲从完整导航表中分离。已有准确来源的点查询结果作为验证证书，声明投影读取原生检查结果中的事实，只保存声明需要的名称、标题、路径、范围与父子关系。其结果独立拥有数据，分析结果、来源、导航证书及缓存释放后仍可使用，供后续工作空间索引复用。

## 原生声明事实

`analysis/declaration.h` 定义声明角色、名称来源和可调用作用域，原生枚举与兼容字符串分类共用一张表。新增门面保留原始索引事实，按已检查语法结构确定实际名称 token；不扫描源码猜名称，不更改编译器 AST 布局，不创造符号身份。

覆盖函数、类、协议、枚举及成员、记录／联合、别名、普通／导入／导出变量和常量、字段、属性、构造／析构、原生成员、泛型参数及多变量绑定。多变量的完整范围共享原声明语句，名称范围各自独立。匿名函数、属性、构造／析构及其他可调用节点均形成局部作用域，即使它们没有可显示名称，也排除其内部变量。声明按实际源码位置排序，再重映射父关系，解决泛型参数在原生树中晚于函数体出现的问题。

字段当前没有可执行的 SymbolId。本阶段提供准确的大纲与名称跳转，不凭同名关系伪造字段引用。属性和特殊成员已有的真实声明身份保持，补齐缺少的源名称选择范围；点查询与后来生成的完整导航目标必须一致。

## 内存、位置与后台调度

主路径复用同一份不可变、已完整验证的点查询证书，不再为大纲复制全部节点、类型和引用表。证书通过明确引用计数共享，后台工作线程在请求时构造声明结果；声明和完整导航的需求仍使用原事件，合并唤醒时依次处理两个需求。版本、来源、配置、取消和发布前输入检查保持，失败请求明确结束。

声明端点一次批量转换为 UTF-16 位置。默认桶转换按源码遍历，临时存储不足或可选分配失败时退回原始排序转换，避免每个声明重复扫描长行的行首。这里改善的是声明坐标转换；完整验证、行表和其他导航路径仍有各自开销。

声明构造额度为 64 MiB，其中保守预留 4 MiB 文本；额外坐标临时额度最多 8 MiB，并纳入构造总额度。保存后的有效数据字节及借用证书的字节分别报告，XRT 数组增长按固定版本的保守容量上界预先计费。序列化仍使用已有层级／扁平协议、4,096 个可见符号和最坏转义响应预算。仍沿用原有完整导航准入，未声称大文件各功能已经独立准入。

## 验证边界

原生回归覆盖真实编译器、原始事实稳定性、34 项声明／13 个根节点、BOM／CRLF／中文／emoji、父范围、属性与特殊成员、泛型排序、匿名局部排除、多变量、每个实际分配／数组拒绝点、可选坐标回退、协作取消、证书共享及独立生命周期。另将 513 个函数放在同一行，检查全部位置及构造期间没有逐端点行首扫描；实际插入冗余扫描的生产代码控制必须被拒绝。

标准 stdio 同时验证层级／扁平结果、冷查询、改名、字段名称，以及按需点查询转完整导航后属性／特殊成员定义的一致性。旧已验证服务作为反例，复现声明遗漏和局部泄漏。完整协议与匹配 SDK／真实发布 DLL 的 IDE 配对回归还需通过 C、xlang 输入与受影响的大纲跳转。

第一次完整构建的既有 141 项原生测试通过，新增故障注入揭示首次 XRT 分配失败时返回 NULL 却没有填写错误码。已设置 `XIDE_MODEL_IO` 并完整重编全部消费者；原失败回执及其精确源码保留，状态仍为失败。

首次 IDE 回归的八项检查以及新增的 34 项声明／字段跳转已通过；随后测试错误地用这份大纲校验前一段异步用例，暴露了新增测试插入位置错误。将新增段落移到异步用例的全部断言之后，保留所有原断言和失败字节，重新冻结源码并重编配对 IDE；这次修正仅改变测试顺序，原生及协议产物未改动。

固定前一服务与新服务、32／512 函数、正常换行／单长行、三对交错进程及每进程十次缓存查询，只作为符号路径的时延观察，并核对完整返回相同。它不替代全目标性能验收，也不覆盖原始分析、并发和耐久性。前阶段校准与尾延迟失败保持，原矩阵不重跑取优，不调整门槛。

下一步仍包括各功能的大文件独立准入、编译器字段引用事实、工作空间符号、其余适用协议／IDE 能力，以及完整性能、规模、并发和耐久性验收。DAP 与调试／运行态补全继续排除。

最终验证：完整 240 个编译单元、142 项原生测试、146 个私有 AST 消费者，1,410 个输入／144 个产物身份一致。新声明夹具 4,355 项检查，115 个分配／数组操作拒绝点；单长行 513 项声明、2,052 个批量端点、零逐偏移行首扫描，保存的有效数据 118,470 字节。22 组协议、9 项真实服务 GUI 及 1 项旧能力兼容检查通过；113 个 GUI 对象使用冻结的 180 文件 SDK，与真实发布 DLL 匹配。

符号路径观察完成 24 个进程、264 次响应，全部返回值一致且进程退出正常。512 函数首次大纲中位数约 11.11→10.28ms（换行）、11.14→10.29ms（单长行）。缓存 P95 仍有退化，例如 32 函数单长行约 0.660→0.758ms、512 函数换行约 9.635→9.688ms。完整分布与初始失败一并保留，不作为全目标性能准入。默认 IDE、服务、引擎及交付索引未替换，也未推送线上。证据见 `dev/release-materials/provenance/lsp-declarations-20261109.json`。
