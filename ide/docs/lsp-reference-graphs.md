# 可复用的源码声明图

后续跨工作空间符号族闭包需要对同一成功检查查询多个新发现的声明。原有按目标构造器每次重新枚举原生关系、构建临时图并复制贡献源码；只保存引用分片则会在原检查销毁后丢失这些关系。本阶段增加显式、按需的不可变声明图，及分析工作线程的捕获入口。项目引用缓存尚未存储该图，跨项目固定点闭包仍待接入。

图使用与既有构造器相同的原生派发、重载和属性关系，记录当前导航中已注册的符号/类型声明区间，包括没有关系边的局部变量与类型。精确相同的源码声明区间合并为同一节点，不把编译内数字 ID 当作跨检查身份。未映射的原生端点仍参与连通性；缺少来源、非源码、非 IDENT 或拼写不一致会将整个相连分量标为不支持，不能通过省略节点得到看似完整的可编辑结果。没有源码节点的生成分量也保留不可用标记。

源码及引用只捕获一次：声明图持有一个既有引用分片，图与外部引用消费者共享这一份不可变源码库。新增图载荷只包含声明区间、分量、关系统计和已验证的标识符宽度，不保留 AST、IR、索引、检查、导航缓存或工作线程。图及其成员租约可在原检查、会话和分析工作线程销毁后继续读取。

`xideSemanticReferenceGraphFamily` 先验证外部键的完整源码、类型和精确区间，再按排序声明表查找分量；来自同一源码库的键跳过整文件比较。标识符合法性、宽度和分量内拼写在图捕获时验证一次。查询只分配一个族头和紧凑成员数组，不复制源码；成员键继续保留该族。原有按目标构造器仍保留，作为只复制贡献源码的独立路径及对照。新增流式遍历接口按源码序号、字节区间输出全部注册声明，并输出各分量的成员数、关系类别和不可用状态，无分配、扫描或分析工作。

图默认及最大 64 MiB 的预算计入源码/引用分片、关系捕获的临时峰值、图临时数组和完成载荷。图的 `ownedBytes` 只计图头与拓扑载荷，`bytes` 另外保守计入整份引用分片；已经持有该确切分片的缓存只需再计 `ownedBytes`。族租约的默认 32 MiB、最大 64 MiB 构造预算只计新增头与成员数组，`FamilyInfo.bytes` 和成员 `KeyBytes` 仍保守报告整份被保留的图与分片。借用的分析/导航、分配器、路径转换和排序实现内部成本另计，这些预算不是进程 RSS 上限。常规导航、诊断、补全及引用捕获不会构造该图。

捕获在图循环中定期检查取消；原有导航获取、引用分片捕获和库排序不可中途抢占。预算验证对照实际分配与释放序列的同时在用字节峰值，检查最小成功额度及少一字节拒绝；五处真实构造分配、成员租约分配拒绝，以及所有观测取消位置均验证回滚。

`xideLanguageCheckStartFamilyCapture` 复用既有原生分析工作线程与完整输入防护，显式捕获图和共享引用分片；只在成功、未取消且仍受防护时提供独立引用。它保留引用模式的精简报告，不为无关大编辑器快照生成诊断文档或散列。工作线程测试先完成普通引用捕获，再两次捕获图，验证分析构建数不增加、分析与导航缓存均实际命中；图被捕获两次，不据此宣称已经存在项目级图缓存。

图是已验证输入的一次快照。输入失效后原图仍可用于读取旧结果，不能证明当前文件、配置或可写性；已知失效的检查不能再创建新图。发布任何完整操作仍须验证对应的独立输入防护和编辑器/目录配置代次。未展开模板、所有泛型来源、外部符号策略、物理别名及可写性、重命名冲突和改名后绑定证明均未据此完成，`renameProvider` 继续关闭。

下一阶段应流式合并每个已检查所有者的图：逐文件验证完整源码与输入证明，按实际源码声明身份合并局部分量，传播不可用状态，得到所有配置项目与独立文件共同作用后的闭包。不能按新成员反复调用完整分析或重新构造同一分量。最终仍需覆盖没有原始目标引用的作用域，并在最后一次合并后复核所有输入防护；这部分尚未实现。

本阶段验收通过 176 个原生测试程序、12 组协议测试与 29 项 GUI 检查；287 个实际原生编译消费者、177 个链接程序及重新编译的 116 个 GUI 对象均核对当前源码与依赖身份。声明图专项 1,653 项检查、工作线程专项 33 项检查，并拒绝四个实际实现变异：遗漏独立声明、丢失未知来源标记、漏计关系载荷峰值、接受同路径同长度但内容不同的源码键。亮／暗主题语义着色及属性引用窗口完成图像复核。此前失败尝试与对应源码保留在独立验收材料中；默认发布程序未替换，也未据此宣称通过全目标性能验收。
