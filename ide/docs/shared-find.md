# 原生共享查找与替换

IDE 使用 XGE 内建查找／替换窗口，不再创建窗口、输入框、选项、结果表或搜索会话。`ui/find_view.c` 仅将 IDE 活动文档映射到原生查找域，并连接菜单／快捷键与界面字体。

- Ctrl+F／Ctrl+H、编辑菜单及编辑器右键菜单调用 `xuiCodeEditOpenFind`／`OpenReplace`。同一域内所有编辑器返回同一个内建窗口。
- Dock、程序打开文档、浮动编辑器焦点变化通过 `xuiCodeFindScopeSetActiveEditor` 通知 XGE；切换保留查询、替换和选项，不抢焦点、不重新打开已关闭窗口。
- 勾选 Scope 搜索所有已打开的 C、xlang、普通文本及未命名草稿，包含只读文档；不搜索未打开的磁盘文件或帮助示例。没有活动编辑器仍可搜索全域。
- F3／Shift+F3、原生上一个／下一个和结果表负责导航，已有激活回调打开对应 IDE 标签。
- **替换当前匹配及全部替换只作用于活动文档。** Scope 只改变查找范围，不提供跨文档批量替换；只读或无目标时禁用替换。一轮全部替换保留原生单次撤销。
- XGE 管理窗口生命周期、80ms 输入合并、选区及过期结果、表达式错误和转义预检。编辑器销毁或槽复用不会保留旧目标。宿主仍同步域成员、文件名和文档版本。
- 原生窗口使用 XUI 布局、可用视口内的最小尺寸、内容滚动、分隔线及固定操作区。IDE 显式登记原生窗口以维护界面字体和滚动位置。

验收包含 XGE 原生生命周期专项、IDE 原生窗口身份检查，以及真实菜单／键盘／Dock／浮动编辑器、Unicode、只读、撤销、正则错误、关闭复用、DPI 和界面字体回归。
