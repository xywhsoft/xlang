# 共享查找与替换

Ctrl+F / Ctrl+H、编辑菜单及文档编辑器的右键菜单打开同一个非模态窗口。它属于 IDE 会话，不属于单个文档。切换 Dock 标签、程序打开文档、点击浮动编辑器时，当前目标自动更新，保留查询、替换文本和匹配选项，不抢回编辑焦点。

- 默认查找当前文档；勾选“所有已打开编辑器”后搜索全部已打开的 C、xlang、普通文本和未命名草稿，包括只读文档。关闭的文档、磁盘上未打开的文件、帮助内嵌示例不进入该域。
- 结果按文档、行、列、预览显示。点击结果打开对应编辑器；上一个/下一个、F3/Shift+F3 在结果中循环。查找输入框中的 Enter/Shift+Enter 同样导航；Ctrl+F/H 切换模式，Escape 关闭并回到当前编辑器。
- **替换当前匹配和全部替换都作用于当前文档。** 全域勾选框改变查找域，不改变替换目标；界面标注“全部替换（当前文档）”，并显示目标文档及只读状态。一次全部替换保留 XGE 原有的单次撤销语义。此轮没有增加跨文档批量替换。
- “仅选区”捕获当前文档选区；切换文档重新捕获。文本修改后旧范围失效，自动取消选区限制；全域模式关闭选区限制。非法表达式/转义不进入替换操作，错误不会污染后续原生 UI 回调。
- 关闭窗口保留本次 IDE 会话的查询/选项；切换编辑器不会把已关闭的窗口重新打开。显式打开时仍可用当前短选区作为查找词。

IDE 仅组合原生控件和维护会话、目标、有效性，不实现另一套搜索算法。查找调用 `xuiCodeEditFindAll` / `xuiCodeFindScopeFindAll`，替换调用 `xuiCodeEditReplaceCurrent` / `xuiCodeEditReplaceAll`。现有域负责成员和名称；编辑、关闭、另存为及复用文档槽时同步登记并使旧结果失效。结果表使用 XGE 虚拟适配器，不为每条匹配创建控件。

查询变化采用 80 ms 合并等待；显式按钮立即处理最新查询。空闲轮询不重新搜索，不重新创建窗口，不重设表格列；布局尺寸或模式变化时才更新几何。浮层窗口显式登记到界面字体替换和滚动状态维护中，避免脱离根控件树后仍引用旧字体。窗口使用 XUI 行/列布局，内容滚动，分隔线和操作按钮固定在底部；最小尺寸受可用视口约束。

固定 SDK 已有跨编辑器查找能力，但没有共享查找 UI 的公开重定向接口，所以本次接线在 IDE 层实现，不升级或修改 XGE。原生高级匹配边界测试继续直接测试 SDK；共享 UI 与菜单/快捷键、切换、只读、Unicode、撤销、旧范围和高 DPI 另由 `find_follow_view_test` 验证。固定引擎已有的无匹配/非法转义边界失败单列在交付报告，共享 UI 在调用前预检 NUL、截断及非法代理项转义。
