# 查找与替换

在代码编辑器内使用 `Ctrl+F` 打开查找、`Ctrl+H` 打开替换，也可使用编辑菜单。打开 C、xlang、纯文本或未命名文档后，查找窗格直接复用与 AutoTestIDE 相同的 XUI CodeEdit 窗口。只读文档可以查找，替换动作禁用。

## 查找范围

默认查找当前文档。勾选“范围”后，“查找全部”汇总所有已打开的编辑文档，包括其他标签和暂时隐藏但仍可恢复的文档；不扫描未打开的磁盘文件，不包含只读的语法示例页。结果显示文件、位置和匹配行。文件列使用完整路径，未命名文档使用标题；长路径可拖动列边界查看。

点击结果会激活对应标签、选择匹配范围并显示光标。查找操作不改变正文或脏标记。关闭查找窗口时使用窗口关闭按钮，或者在查找输入框获得焦点时按 `Escape`。

## 替换和撤销

“替换”和“全部替换”仅作用于当前文档，即使“范围”已勾选。跨文档批量替换尚未开放。中文和非 BMP 字符可参与匹配及替换；一次“全部替换”使用编辑器的一次撤销/重做事务，其他文档和磁盘文件保持原样，保存仍需显式操作。

大小写、全字匹配、正则、转义和选区选项已在实际 C／xlang 编辑窗口中验收。勾选“选区”时，查找和替换限制在当前选区；“范围”勾选后的跨标签查找以全部已打开文档为范围。SDK67 进一步统一空匹配的 Unicode 标量推进，并拒绝非法 UTF-8 字节转义；非法输入不改正文或历史。详情见[查找选项](find-options.md)与[正则边界](find-boundaries.md)。

## 文档生命周期

SDK 的共享结果保存字符偏移，不携带文档版本。IDE 在成员文档正文变化后清空整个共享结果集，要求重新查找，避免旧范围被再次激活。关闭文档会移除范围成员并隐藏该文档的查找窗口；取消关闭不会移除成员。另存为后结果更新为新路径。切换标签、显式切换语法或恢复布局不会改写正文。

关闭活动文档时，IDE 在刷新动作状态前清除活动指针，再由正常关闭流程选择下一文档。直接调用文档层关闭也遵守此规则；复用文档槽位不会继承旧查找结果。
