# IDE 原生编辑的异步协调

M7b6d，2026-11-14。`editor/native_edit_async` 复用既有原生候选、混合事务、恢复包和日志，以单个常驻 XRT 线程串行执行 Prepare、Stage、Apply、Finish、资源关闭和大对象退役。`ui/native_edit_view` 已进入实际语言视图的正常轮询，并在应用销毁前收尾。当前是内部接入 API；完整宿主保护集合、用户确认/恢复窗口及标准 rename/applyEdit 的公开入口仍待完成。

Begin 只复制有界元数据并保留实际候选，进入 CONFIRM，不读写源码、不取得读取屏障，也不锁文件。预览只是借用数据。Confirm 要求同一个操作令牌和候选，重复完整 Current，然后取得真实的六参与者源码屏障。所有参与者物理静止后，才允许协调器读取、准备和应用。工作线程首次使用时创建，后续操作复用；没有给普通启动新增事务线程。

工作线程的 job 不保存 app、GUI、store 或 ticket 指针。owner 捕获和提交编辑器状态，ticket 只在 owner 一侧访问；后台只使用不可变候选、复制的路径、原有 NativeWork、缓存结果和原子许可。状态查询只复制小型缓存，不进入仍在运行的 Work。构造、阶段调度、借用、资源关闭和退役有明确状态门槛；不能以发布了结果代替工作线程真实离开该步骤。

APPLY 与 RESTORE 分开授权。前者要求明确确认、仍有效的原始请求和屏障；组边界还比较当前进程包路径与捕获环境。后者保留已经取得的屏障下恢复本次写入的许可，不能要求被取消或因本次界面提交而失效的请求重新有效。界面已经提交的 outcome 仍优先；提交后取消只影响后续操作，不能撤销已经发布的编辑。

协调器持有屏障时，保留原候选生产者的 READY 状态，避免普通轮询把它改为后台退役并破坏同一屏障的静止证明。失败或取消后，先处理明确的未发布结果与回滚，再关闭源文件资源。随后使受影响的任务输入失效，异步恢复监控和语言服务。最后一个屏障请求引用释放时，协调器仍持有候选；全部屏障释放后才把元数据与潜在大快照的最后释放交给工作线程。

IN_DOUBT 保留句柄、屏障和恢复资料，不自动恢复读者。失效或被替换的参与者令牌也进入显式恢复状态，不能一直停在“处理中”，不能释放另一个持有者的令牌。正常监控恢复的暂时失败保留前缀，按原接口重试。最终关闭会取消并等待正在执行的步骤，在 owner 拆除 ticket，再在后台结算未发布写入或已提交结果，保留不确定日志。`xideSourceBarrierAbandonFinal` 只退役最后的请求引用与调用方存储，不恢复任何参与者；之后销毁整个参与者图。

路径扫描有 64 KiB 上限，最多 255 个额外保护路径、合计 1 MiB 复制文本；校验时记录长度，复制时不重复扫描。候选正文保持共享。NativeWork 的原有已知预算另计，线程栈、XRT/OS、SDK、配置准备及分配器并不是这些数字的总内存上限。完整 Current 仍有既有配置与路径元数据准备成本，XUI 捕获/提交仍在 owner。测试计数针对项目调用的 ReadFull 和条件等待入口，不能据此声称所有系统或 SDK 调用都没有 I/O/等待，也没有整体时延或 RSS 资格声明。

验收覆盖真实 RPC、五目标编辑及真实 XUI 文档；受控阻塞发生在实际正字节读取、文件写入和资源销毁之后。检查取消与回滚、后台物理活动、外线程拒绝、路径/容量门槛、原始环境变化、提交后取消、最终关闭、冻结日志和后台退役。真实 IDE 的九个场景还覆盖确认前无写入、两个连续操作的线程/屏障代次复用、修改后重新获得语义候选、写入期间 C 输入/删除/撤销/IME/焦点、关闭时恢复、失败前缀、监控恢复重试、候选跨屏障释放保留和令牌丢失。C/xlang 两种编辑器均保留输入回归，另执行完整配对 GUI 回归和错误实现检查。

原服务及协议工具未改变，本轮使用上一阶段同一 SHA-256 的已验收 `xlang-ls.exe`，并核对它实际使用的原生源码/头文件闭包。不能把上轮 85 个协议场景称为本轮重新运行。实际构建、夹具、失败历史、测试入口清理、截图及依赖身份见 `dev/release-materials/provenance/lsp-native-edit-async-20261114.json`。现用发行程序、开发 SDK 和 active delivery 不替换。

下一阶段需要完成宿主保护路径构建、确认/应用/恢复窗口、交互关闭与保存流程及公开操作激活。引擎资产对齐、泛型/外部来源资格、其他同步读取点、整体性能/资源、Linux 和 sanitizer 验收继续开放。C LSP 仍默认关闭，不包含 DAP、运行态或调试态补全。
