## 交付边界

第一可用版本完成阶段一至五：真实原生工作台、三层工程管理、多文档编辑、命令帮助和构建运行闭环。正式首版完成阶段六的能力核对与发布验收；语义功能按实际编译器接口宣告，不以占位响应验收。

完整 xlang 调试器是后续独立阶段，依赖 DEMO6 的真实调试能力。AI 与自动化脚本业务不进入本计划。

## 阶段零 依赖与模块准备

- 确定已验证的 XGE IDE 配置 SDK，记录 DLL、导入库、公开头、XRT 声明头、配置和来源指纹。
- 从 AutoTestIDE 抽取通用初始化、主题和 SDK 校验经验，去除 AI、Python、ADB、scrcpy、cyou、图像与设备运行时。
- 建立独立 C 模块的最小编译清单、GUI 与诊断构建模式、产物目录和依赖说明。
- 核对 XUI Dock 嵌套、CodeEdit、文档、树、表格、只读示例与滚动控件的真实 API。

验收：新 IDE 构建不依赖 AutoTestIDE 的业务目录；SDK 校验能识别混用头库；GUI 中只使用 XGE 提供的一份 XRT。此阶段不能直接照抄 AutoTestIDE 的完整 build.bat。

## 阶段一 原生工作台

实现窗口、菜单、工具栏、状态栏和定版 Dock 树。左侧命令列表，中央编辑器与其下底栏，右侧上下工作空间与属性。命令帮助为默认活动页。

实现主题、字体、DPI、面板显示隐藏、尺寸调整和恢复默认。菜单动作先注册服务入口，尚未实现的动作保持不可用。

验收：底栏的左右边界与编辑区一致；左右 Dock 延伸到底栏下沿；工作空间和属性同时可见。启动、调整、隐藏恢复、重启和恢复默认都保持正确树结构。真实 XUI 控件做布局断言与截图核对，不只验证网页样例。

## 阶段二 工程模型与持久化

实现 Workspace、Project、FileEntry、路径服务与 JSON 序列化，再接工程树和属性。支持创建打开保存工作空间、添加移除项目、启动项目、文件分组和最小 DEMO6 项目。

随后接会话恢复、未知字段保留、缺失文件状态和旧格式导入。模型独立于 XUI，可用无窗口测试验证。

验收：工作空间到项目到文件操作闭环；查看另一个项目不改变启动项目；中文空格路径、相对路径、另存为与共享文件正确；保存失败不损坏原清单；超过旧固定容量仍工作。

## 阶段三 文档与编辑器

实现 DocumentService 和 EditorService，接 XUI CodeEdit。支持多标签、未命名文档、打开保存、另存为、全部保存、撤销、缩进、查找替换、跳转行、高亮与折叠。

2026-10-08 行列定位增量接入编辑菜单、原生右键菜单和 Ctrl+G，同一动作支持 C/xlang/纯文本、未命名与只读文档。行列沿用编辑器状态栏坐标，处理 Unicode 字素簇、文档身份/版本、模态与 IME、折叠目标展开以及大字号滚动。原生与完整回归证据记录于 [行列定位](goto-line.md) 和 [实施进度](progress.md)；此项不代表阶段 3 或整个首版已全部验收。

加入外部变化、脏状态、关闭确认、会话光标和文档去重。C 与 xlang 同属首版编辑器支持范围：`.c` / `.h` 使用 C 语法，`.xl` 使用 xlang 语法；未知类型为纯文本，可逐文档手动覆盖。覆盖影响高亮、折叠和注释操作，不改变文件名。完整 C 语义另行接入。

验收：C / xlang / 纯文本切换后保留文本、撤销和光标，词法缓存确实随语言与文档版本更新；C 预处理器和注释、xlang 文档块、嵌套注释、原始与插值字符串及中文标识符得到正确显示。同一文件从不同项目或入口打开不产生文本分叉；编辑后切换标签不丢失文本与撤销历史；重新载入或关闭不会静默丢弃修改；清单文本与属性编辑不会互相覆盖。

2026-10-10 常用编辑命令增量补齐剪贴板、全选、缩进／反缩进及行注释的统一菜单与快捷键。C／xlang 当前语法覆盖决定注释能力，纯文本和只读修改受保护；Tab 补全与普通字段输入保留。51 项新增原生检查、12 项邻近及标准全量回归和便携专项验收通过，见[动作注册](actions.md)和[实施进度](progress.md)。该增量不代表实体 IME、混合 DPI 或整个首版已验收。

## 阶段四 命令目录与集成帮助

实现 CommandCatalog、分类检索、单击联动、单栏文档渲染、参数返回值和只读范例。先维护一批经过核对的语言与基础库条目，再逐步导入标准库和扩展库文档。

目录补全、帮助和显式示例插入共用数据；补全弹窗的过滤、确认和插入可参考 AutoTestIDE 的原生实现。

验收：长文档在整个中央帮助宽度内纵向阅读；说明与范例没有左右分栏；切换条目不会修改代码；显式插入可以完整撤销；真实签名与范例来源可追踪。文档加载错误显示真实状态，不使用静默占位内容。

## 阶段五 构建运行闭环

实现 ToolchainProfile、BuildRequest、进程适配、TaskService、构建输出、问题页、运行会话和停止。配置当前 DEMO6 编译器，先接现有 `.xlp` 构建及可执行产物运行。

支持构建前保存策略、退出码、日志定位、运行参数、工作目录、环境变量和输入输出。测试任务仅运行项目明确配置的测试命令。任务与 UI 线程隔离，取消和退出清理相关进程。

验收：编辑保存、构建、诊断跳转、运行输入输出、停止形成真实闭环。构建失败不能运行旧产物；DLL 无宿主时不直接运行；中文空格路径正确；重复任务不覆盖产物；异常退出或服务不可用不会阻塞界面。

此时形成第一可用版本，可以验证用户日常 xlang 开发流程。

## 阶段六 语义能力与首版发布

先审计编译器查询接口，补齐源码范围、符号与定义位置、类型查询和依赖模块的内存覆盖层。相关编译器改动进入 DEMO6 源码与文档，不能仅在 IDE 中用字符串猜测语义。

实现 C 语言服务和 stdio LSP，接文档版本、诊断、大纲、悬停、补全、定义跳转和能力协商。初始保存后检查与编辑中语义诊断须区分；不把单入口 `check` 当成多输入项目检查。

验收：诊断与定义位置来自真实源码；未保存依赖模块也参与分析；中文和非 BMP 字符位置正确；过期结果不覆盖新版本；断开重启能恢复文档同步。未实现能力不宣告支持。

完成干净环境安装、成套 SDK 与程序打包、字体和资源路径、主题持久化、错误恢复和发布清单。正式首版说明实际支持范围，调试入口按真实能力处理。
