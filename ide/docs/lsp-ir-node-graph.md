# 最终 IR 节点的独立所有权

这是最终 IR 按声明增量生产的基础组件。它将原生节点及其载荷分成独立拥有的声明单元，解决保留一个函数时连带保留旧模块全部节点的问题。目前不接入普通检查路径，不替换最终 IR 构建器，不宣称编辑速度改善。默认发布程序仍为 0.106。

## 数据边界

`ir_node_graph` 使用实际编译器的 `XL6_IrNode`，完整保留节点标量、来源坐标、整数引用及子列表。第零单元拥有模块根，每个根级声明拥有其完整子树，包括嵌套可调用体。物理节点不必连续，模块根也不必是第一个节点。单元内保留原生 ID，不提前假设它们可以直接拼入另一个模块。

每个单元用一块 XRT 分配拥有节点、原生 ID、局部子列表索引、子节点列表及文本／二进制载荷。字符串、带内嵌 NUL 的字面量和可选编译包链接均复制到本单元；引用计数使用 XRT 原子操作。独立保留单元只保留这一块分配和一个很小的来源标记，不保留父图、相邻单元、AST、检查结果或上一代图。

来源标记仅标识同一次捕获。它不是语义、输入新鲜度或跨模块 ID 兼容的证书。组件不拥有类型、符号、区域及其他非节点表；仅持有一个单元不能据此访问原模块的表。后续链接器仍须建立精确依赖证明、表所有权及原生 ID 重定位。

图另外拥有稠密 ID 到单元／局部位置的索引，以及完整原生子数组。后者保留原数组中未被引用的槽，便于与独立完整构建逐字节比较。显式平面适配器拥有新的节点／子数组并保留图，其载荷指针只读借用；不能把这些数组交给原生模块析构器。需要原生完整模块的消费者须另外提供并验证对应非节点表。

## 资源和准入

调用者在捕获期间持有不可变、已验证的原生模块。组件迭代验证树的根、节点／子跨度、父关系、重复、环和孤立节点，不使用递归。它不会重新证明节点的类型语义。零预算明确拒绝；分配前检查乘法、对齐和加法溢出，预算覆盖图、全部单元、来源标记和临时栈／计数块的申请字节峰值。该值不包含已有输入、分配器开销或整个进程 RSS；分开分配的 scratch 对齐按保守上界计费。

构造阶段不发布部分结果。预算、分配和取消失败均释放已拥有的块；图的原子引用仅在成功物化后交给平面适配器。遍历和复制按节点轮询取消，宽节点的子边遍历也周期轮询。单次载荷复制和已有数组的 `memcpy` 不提供字节级抢占。

标准构建从实际 GCC 依赖中读取选中的原生头，拒绝新增未拥有指针、指针数组、回调、未知值记录和嵌套记录中的指针。实际原生整数别名另由 C11 类型断言检查，防止别名藏指针；复制新增标量时不需维护另一份节点声明。原生源文件仍由既有固定前端契约准入，守卫不替代编译器 ABI 审核。

## 验证

新增夹具按原生完整节点字节（归一化指针地址）及所有载荷内容建立独立对照，并比较物化后的完整原生 IR JSON。369 项检查覆盖物理顺序不连续的单元、原生引用及未使用子槽、生产者退休、四读线程、32 代独立单元、根节点空模块、2,049 节点宽树和 16,385 节点深树。申请字节追踪核对保留量／峰值和单单元保留的两块分配；小夹具七个实际分配点、九个取消点逐一拒绝，并抽查深宽树取消。

十四组实际头文件模式检查通过。三种独立 C 变体分别借用旧文本、清除父节点和遗漏来源标记释放，均被原夹具拒绝；将原生节点 ID 别名改成指针也触发编译期类型断言。它们只用于测试，不进入产品源码。

标准构建从冻结源码重编 361 个目标文件，核对 1,650 项输入、73 个 core 成员及 224 项输出。构建器登记的 360 个对象与另行编译的 1 KiB 索引边界夹具分别核对；静态库通过原始文件提取核对新成员，避免 Windows `ar p` 标准输出换行变换。服务符号表确认新组件没有链接进普通服务，既有 584 个生产文件／公共头与上一完整构建逐字节一致。完整 222 个原生程序及 21 组协议回归通过；实际程序均在根发布目录以受控别名执行，夹具和日志位于构建目录。初次冻结快照遗漏补丁目录的构建失败原件保留，补齐匹配补丁后在全新输出目录完整重编。

发布目录中默认程序、引擎、匹配 SDK 和交付索引保持原值；本阶段未替换服务，也未重新计入之前的 GUI 或性能验收。0.107 先前的尾延迟失败没有因此关闭。

## 后续

下一步把类型、符号及派生交叉表纳入明确的单元所有权和重定位规则，再接入改变声明的最终 IR 生产。仍保留独立完整构建／验证作为正确性对照，并要求代表性普通编辑链减少实际工作后再做端到端性能准入。当前组件每次捕获仍复制全部节点；提前在普通检查后追加捕获只会增加工作，因此尚未启用。

验收资料与实际构建身份见 `dev/release-materials/provenance/lsp-ir-node-graph-20261116.json`。最终 IR 局部生产、全局内存／长稳、完整 IDE 性能及跨平台仍属于长期任务；不包含 DAP、运行或调试补全。
