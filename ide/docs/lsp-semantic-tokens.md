# 语义高亮：已检查索引的符号分类基础

日期：2026-11-10。阶段 M7b1。本阶段实现可独立验收的分析核心生产器，尚未提供 LSP semanticTokens 端点，也未改变 IDE 着色。默认发行程序和线上通道均未替换。

## 实现与边界

`analysis/semantic_tokens.h/.c` 从成功检查的原生索引产生不可变符号分类。复用声明角色、符号身份、类型身份及 ABI、调用目标与原 token 范围，不另建解析器或按名字猜测绑定。支持类型、类、接口、枚举、记录、类型参数、参数、变量、属性、枚举成员、函数、方法；只输出实际有依据的 declaration / readonly / async 修饰。

声明和引用各遍历一次索引。声明前序遍历同时计算父作用域，函数子节点重置类作用域，不再逐声明回溯祖先。身份表排序后查找；同身份但角色有冲突时保守放弃。字段缺少 ID 时仅使用已检查 MEMBER / SAFE_MEMBER 语法角色。无法判定的普通名字留给词法高亮。符号范围排序、去重并移除重叠后，使用编译器原始 `xl6LiteralIdentByte` 检查原文本原子范围，排除省略号等非名字参数。

输出保留编译器的 UTF-8（去 BOM、保留原 CR/LF）字节偏移和一基 Unicode 标量坐标。它们不是 LSP UTF-16 坐标、协议图例下标或编辑器样式。协议接入仍须复用批量坐标验证，按客户端能力协商图例，并在既有后台检查/发布守卫下工作；不能逐 token 从长行开头重新扫描 Unicode，也不能用这些行号直接发布。

对象和数组均由 XRT 管理。16 MiB 上限覆盖已知对象及实际数组容量，包括临时身份表、作用域表；不含分配器内部开销、排序栈或既存检查/文本。失败不返回部分结果。返回值不保留检查、AST、源文本、上下文或 JSON，原检查销毁或失效后，已取得的值仍可安全读取，但不证明输入仍然新鲜。已失效/被拒绝且没有完整索引的检查拒绝新建分类。取消在事实遍历及最多 4 KiB 的原子扫描间隔轮询；库排序调用不支持抢占。
