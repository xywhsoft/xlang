# 工作空间符号协议

2026-11-09，M7a2b126f。原生后端接通标准 `workspace/symbol`，复用已有项目目录、后台声明服务、保留索引及 XRT。未打开任何文件也能查询已经配置的项目；未归属项目的已打开 xlang 文件作为独立作用域参与，关闭后移除。项目成员来自完整分析上下文，不递归猜测目录内容。

这是协议功能及既有 IDE 接入的回归阶段。IDE 的工作空间符号搜索窗口、结果跳转时的新鲜度证明、主动索引调度及错误源码下的声明恢复仍未完成。候选不替换默认发布程序，也不推送更新频道。

## 请求与结果

原生后端声明 `workspaceSymbolProvider: true`；CLI 兼容后端不声明，并明确拒绝该方法。查询使用既有 UTF-8 模糊匹配和排序，最多 512 字节、128 个非空白 Unicode 字符、16 个词项。默认返回前 200 项；扩展参数 `xlangLimit` 可设为 1–4096。无效查询在启动后台分析前拒绝。

结果为标准 `SymbolInformation[]`：名称、协商后的符号种类、完整 URI 和 UTF-16 声明选择范围，以及可用的限定父名称。客户端未提供种类集合时使用旧版 1–18 集合；提供时保持受支持种类并选取集合内回退值，重复集合项不会触发错误回退。即使客户端支持 resolve，本阶段也直接返回完整位置，不公布尚未实现的 resolve 能力。

作用域使用全部已配置项目及其配置身份，不受当前活动编辑器或启动项目限制；相同来源在不同配置中仍有独立语义身份。覆盖文本、真实导入、磁盘输入、负候选、BOM、上下文和版本历史继续由已有原生守卫核对。文档版本完整支持 LSP 的 int32 范围，最小值映射为原生 revision 0；不添加底层接口没有的正数限制。

## 线程、取消与边界

最多同时保留 8 个请求。后台协调器完成声明收集、查询、结果对象构造和精确转义字节计数，然后再次核验输入。宿主依据覆盖／文件监视输入代次及配置代次核对发布，存在排队输入时延后处理结果；显式取消、关闭和过期请求都不会晚发成功结果。队列满、配置／输入额度超限或查询失败均返回错误，后续有效请求可继续。

结果 JSON 上限为 7 MiB，为现有 8 MiB 帧保留请求 ID 和封装空间；字符串 ID 额外限制为 65,535 字节。额度按所有结果的实际 JSON 转义总量计算，不按原始名称长度猜测。计数字节回调和每条结果均检查取消。原有索引、输入、记录及任务队列额度保持。

最后的通用 JSON-RPC 封装、帧序列化与管道写入仍由现有 stdio 宿主负责。本阶段不声称大响应发送不会占用该线程，也未完成分块／流式结果或优先级输出调度。每次查询仍遍历成员并核对实际输入，主动增量刷新和大工作空间尾延迟需要继续推进。
