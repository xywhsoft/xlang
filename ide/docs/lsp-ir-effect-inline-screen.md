# IR 效果分类内联实验

2026-11-11，M7b4s。该实验未通过原有性能门槛，原型不进入产品构建。已提交的投影字段补全和原生检查保持；本阶段没有替换默认语言服务、IDE 或 DLL。

细化的生命周期诊断在八种输入组合、80 次检查中保持标准结果和原生工作量一致。512 函数热编辑中，原生 `xl6IrVerifyOwnedReadResults` 约占 4–6 ms。实验只在原生构建和验证的两个完整循环中，强制内联四个完整效果分类函数；未缓存结果、缩短规则或删除验证。原函数保留为独立对照。

机械检查确认四份函数体和两份消费循环与原生实现逐字节一致，14 种来源漂移或重复派生被拒绝。控制版本从同一次完整构建中只逆转内联；静态库的 72 个成员中只有 `xl6_ir.o` 不同。候选程序增加 8,884 字节。

候选通过 189 个原生程序、13 套协议检查、全部 116 个 GUI 对象重编译后的 29 项 GUI 检查。新增专项有 5,527 项断言，覆盖实际非默认效果、独立完整 IR、元数据破坏、错误诊断和嵌套原始路径。三个实际实现变异均被拒绝。这些正确性结果不能代替性能准入。

预先固定原有八场景、14 个版本、64 项门槛、完整隔离进程链和反转顺序。计时期间不编译或运行 GUI 验证；开始要求 5 GiB、运行中要求 3 GiB 可用物理内存和提交额度。全部样本、过程日志和失败结果保留，没有重跑取优。
