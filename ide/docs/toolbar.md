# 主工具栏

主流程为：文件操作 → 执行目标与配置 → 构建／运行／测试／停止 → 任务与输出。

- 新建、打开、保存分别使用主按钮和下拉菜单；打开菜单包含最多 12 条最近记录。
- 执行目标支持启动项目、指定项目、当前文件。项目树选择不改变执行目标。没有工作空间时默认使用当前文件；有项目时默认使用启动项目，缺失时明确禁用执行。
- 构建、运行、测试及 F7／F5 使用同一执行上下文。运行始终先构建。库目标不能直接运行，没有测试程序的配置不能执行测试。
- 配置优先级为：用户明确选择 → 命令行覆盖 → 项目默认配置。失效的明确选择返回不可用状态，不悄悄回退。切换目标后使用该项目自己的配置。
- 工具栏配置选择保存在工作空间会话中，不修改项目清单或使正在运行的任务失效。C 与 xlang 分析使用同一有效配置。项目属性面板对默认配置的显式修改仍遵守原有清单保存规则。
- 提交前复制项目和配置身份；保存清单后重新核验，再交给原任务引擎冻结完整输入。后续切换编辑标签、目标、配置或项目树选择，不会重定向已提交任务。
- Shift+F5 与停止主按钮只停止当前任务选择器中的任务；停止全部是独立命令。任务菜单通过稳定任务 ID 选择，历史裁剪后不解引用旧指针。任务状态与执行目标独立，失败保持可见。
- 语法演示位于帮助菜单，恢复布局位于视图菜单，工具链设置位于工具菜单。状态栏中的当前文件语言可点击切换。

工具栏保持单行，默认高度 40 DIP，随界面字体增长。宽布局展示文件分组、目标和配置、三个执行按钮；中等布局压缩次要操作；窄布局合并目标与配置，将隐藏操作移入更多菜单。运行、停止及任务入口始终保留。文字按实际字体测量并在 UTF-8 字符边界省略，完整目标路径和快捷键可从提示中读取。

所有交互使用 XUI 原生 Button、Menu、Toolbar 和 Popup。图标通过原生 SVG path 绘制并按 DPI 缓存，颜色跟随主题及启用状态；没有新增自绘输入、菜单或滚动系统，也没有新增编译线程。

实现入口：`ui/main_toolbar.c` 管理界面与布局，`services/execution_target.c` 解析统一上下文，`app/actions.c` 共享启用规则，`ui/task_view.c` 提交任务。每个控件的提示和可访问名称与实际动作对应。

验收包括 `toolbar_test` 的真实任务排队、单任务／全部取消、配置优先级、失效目标、失败状态、会话和最近记录、四种主题、100/125/200% DPI、24 DIP 字体、六档宽度及窄布局菜单；并回归动作、任务、配置、阅读状态、设置、编辑器、字体、输入、帮助和后台编译响应。最终在根目录 `release/` 验证相同的 IDE、语言服务、编译器与 XGE 组合，测试输出位于 `release/tmp/toolbar-20261031/`。
