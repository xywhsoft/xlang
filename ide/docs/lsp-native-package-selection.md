# 原生包选择进入分析上下文

2026-11-08，补齐 `.xlp` 的 `nativeLinkage` 从 IDE 模型到原生检查／补全的传递。此前项目保存和构建保留该字段，分析上下文却没有表达它，导入器一直使用普通 JIT 默认选择。本阶段使用编译器已有的 `XL6_ImportDeps.nativeSelection` 和包选择器，不另写选择规则。

## 行为与身份

项目顶层 `nativeLinkage` 支持 `auto`、`static`、`dynamic`，缺失或 `auto` 继续遵循普通 `check` 的 JIT 自动策略。静态和动态选择与实际编译器项目检查一致。分析目标类型 `exe`／`dll`／`shared` 不隐含 AOT 策略；需要 AOT 自动策略的客户端可以显式指定 `auto-aot`。

不可变上下文保存选择值，规范身份包含该值，强制哈希碰撞仍逐字节区分。继续使用一次 XRT 分配，规范头增加一个 64 位字段。IDE 直接读取已有模型保留的项目快照；上下文创建完成后不依赖该 DOM 的生命周期，也不读取运行环境覆盖或修改进程工作目录。

默认上下文继续写原有 schema 1。显式选择使用严格 schema 2，新增 `nativeSelection`：`auto-jit`、`static`、`dynamic`、`auto-aot`。非法值、类型、字段数量及混合格式拒绝，配置更新失败保留旧配置。`auto-jit` 和默认上下文具有相同规范身份。初始化能力增加 `experimental.nativePackageSelection`。

支持依据来自经过审查的导入源／头、包头和变体实现四项身份；四项枚举通过编译期断言对应原生 ABI。选择值从既有请求 TLS 域进入原生依赖初始化，涵盖检查、光标补全、依赖收集和嵌套／并发调用。旧资产保持原初始化并报告不支持显式选择，后端验证拒绝未支持的选项。没有新增进程全局选择状态或 TLS 域。

其他尚未支持的 C／资源／包含／链接项目选项继续按既有约定拒绝。本阶段不等同于完整工程选项支持。

## 缺失所选清单

真实协议检查发现，声明但缺失的原生变体会使源报告不完整，最终表现为内部错误。对固定当前版本的选择器增加已有的 `xl6SourceReportExists` 观察，再调用原加载入口；选择、身份一致性及相对路径规则保持。缺失文件成为受验证的负依赖，因此可发布原生导入诊断；补齐、删除或替换后，旧结果失效并重新检查。完整性、分配失败和读文件失败的原有拒绝路径保留。

显式静态选择不读取损坏的动态替代清单。已选中的本体不会跟随另一种变体；无 linkage 声明的旧包保持原实现。自动诊断覆盖缺失、补齐、删除及不编辑文件而切换选择，补全也验证相同输入身份。
