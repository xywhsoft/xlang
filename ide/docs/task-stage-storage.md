# 任务阶段目录保留

实现状态：开发候选，2026-10-09。每次构建、运行或项目测试在输出目录的 `.xlang-ide-build/<GUID>` 中保存请求、实际调用、输入收据、原始日志与阶段产物。任务历史裁剪只释放内存，目录清理由工作线程独立执行。

## 默认策略

- 同一缓存根按一小时冷却维护，在任务结束全部磁盘与进程 I/O 后执行。记账表最多保存 64 个根；超出后按较早维护时间替换，已被替换的根再次使用时可能提前维护，故不是任意数量工程的全局硬限。
- 保留最新 64 个具有有效完成记录的阶段；其他阶段也必须超过七天宽限才可删除。阶段完成时间、标记及每个文件的创建/修改时间都必须满足宽限。
- 活动请求、仍在任务历史中的请求、引用缓存的任务以及打开/恢复的编辑文档持有共享租约。关闭、另存为或历史销毁按各自生命周期释放；当前工作目录、直接输入、资源输入、编译器报告的实际输入与候选、待保存路径和工具程序也进入保护范围。
- 维护在后台运行，取消和约五秒的检查预算保留未处理数据。原生 I/O 的一次调用无法强制中断，这不是任意设备延迟的上限。
- 不扫描或删除输出目录以外的缓存，也不删除正式输出程序。未标记的旧目录、未知格式、活动/未完成记录、未知文件、用户修改、只读项、链接和占用均保留。
- UNC 与映射网络驱动器的自动删除禁用：本机内核租约无法协调另一台机器上的读者。正常任务可继续保存日志；真实 UNC 工具链与任意深工作目录仍需单独验收。

## 所有权与删除边界

新阶段必须是本次创建的空 GUID 目录，已有目录从不复用或接管。隐藏 `.xide-stage` 是固定 848 字节、版本 1 的记录，包含缓存根和阶段目录的卷/文件身份、GUID、完成状态与时间。完成时对允许的十种文件保存身份、长度、创建/修改时间和 SHA256。

允许文件为 `request.xlp`、`compiler-help.log`、`build.log`、`run.log`、`test.log`、`program.exe`、`module.dll`、`publish.tmp`、`inputs.json`、`build-invocation.json`。遇到任何其他名称或子目录，整个阶段保留。用户修改已知日志或产物，即便长度和时间不变，也会因摘要不同而保留。所有权标记不是抵御恶意进程伪造的安全边界。

活动任务短暂保留标记及目录句柄；完成后仅保留按物理目录身份命名的 Windows 内核事件。事件在最后一个进程句柄关闭时消失，进程退出也会释放它。命名互斥量协调读者加入与清理检查；清理持有互斥量并确认没有存活租约后才检查文件。完成请求不长期打开磁盘标记，避免 Windows 拒绝父目录移动。

先完整枚举缓存根，最多检查 20000 个条目，未完整枚举时不开始删除。候选目录、标记和所有文件均通过句柄重新核对身份、属性、硬链接数、原记录及内容摘要；全部通过后才按持有的文件句柄删除，标记最后删除。祖先和目录句柄防止操作期间路径被迁移；重解析点不跟随。对输入的物理别名也作身份核对。

清理不是文件系统事务。取消或设备错误可能留下部分清理的旧目录；剩余文件保留，后续检查不会接管缺失清单的目录。当前没有崩溃重放、自动修复或按总磁盘大小淘汰；计数是已发起删除的文件长度，不代表设备即时可用空间。

## 当前待补齐边界

普通相对 `XLANG_PACKAGE_PATH` 的预先租约已改为以实际编译器工作目录解析，并以同一原生测试核对原版失败与修复后行为。提交时捕获的原始环境仍直接传给编译器，实际输入收据继续校验和保护绝对路径。Windows 其他路径形式、工程规模、总大小配额和清理崩溃重放继续推进，详见 [包搜索目录](package-search-paths.md)。

## 原生验证入口

`task_stage_test` 纳入严格构建与默认回归，检查新建/拒绝接管、身份记录、宽限与最近记录、共享/跨进程占用及进程退出释放、完成项目父目录移动、Unicode 深路径、用户同长度同时间修改、未知/旧文件、只读、锁定、硬链接和取消。

`document_test` 验证实际编辑文档打开、恢复、另存为与关闭时的租约行为；`task_test` 验证成功/失败请求的完成记录、历史保护及销毁后清理。完整回归还验证双语法编辑、项目管理、构建运行和既定 dock 布局。本文描述实现合同；本轮实际运行结果与候选回执记录在 `progress.md`。
