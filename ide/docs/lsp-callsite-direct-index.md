## 测量与实现

在原调用边界增加私有计时，512 函数样例的成员 ABI 阶段约 10.7～11.8 ms，循环 ABI 约 9.4～9.7 ms，验证约 43.3～46.7 ms。既有有序索引避免了全表扫描，但对大量节点仍反复执行二分查询。

当前前端的短作用域索引增加一个可选 XRT 数组，按调用表实际最大来源编号建立“首条物理记录序号加一”的直接映射。它不按节点数量过滤来源，不复制 ABI、实参或构造效果；后续查询继续读取实际调用表。逆序写入保证重复来源保留原来的首条记录，零值和异常的大编号仍交给原语言验证器判断。

直接数组与原有序候选、后继位置数组共用 **8 MiB 总预算**，同时检查保守增长预估和 XRT 实际容量。编号稀疏、预算不足或直接数组分配失败时继续使用已经构建好的有序索引；原有索引本身不可用时仍执行原扫描。结束时释放三个数组并恢复之前的线程局部作用域。旧前端不启用新增数组和统计字段。

私有原型的对应三个版本中，成员约 5.3～5.6 ms、循环约 4.3～5.6 ms、验证约 28.4～35.8 ms。标准结果在仅映射明确的样例目录前缀后完全一致。这些是热点定位数据，不是配对性能准入或 IDE 交互延迟。
