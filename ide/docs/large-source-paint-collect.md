# 完整度量时收集水平可见候选

2026-10-11，SDK46 私有实验，基于 SDK43v2。保持既定 Dock 布局及 C/xlang 双语法。本轮减少长段绘制的第二次整段排版，正确性检查通过；长行延迟仍未达标，未替换固定 SDK 或便携候选。

## 实现与边界

第一遍按原画笔相加顺序完成整段度量、普通字形图集准备，同时保留水平可能可见的候选。取得最终全局字体基线后，用原绘制函数处理候选并就地压缩为实际可见缓存。普通字形仍全部按原顺序准备，不能提前只准备可见字形，否则会改变图集状态。垂直裁剪必须等最终基线，行尾的大号 CJK 回退字体和 LINE_EXPAND Emoji 会改变此前文本的位置。

候选最多 4096 条。多行、未知 SVG 边界、包含 Y-to-X 分量的运行时变换、分配失败或候选溢出时，继续采用 SDK43v2 已验证的两遍路径。SVG 水平边界包括 picture 层级运行时变换，不能只读源文件中的 transform。SVG 被裁掉时仍检查潜在备用字形的墨迹范围，以保持缓存重放遇到 SVG 加载失败时的行为。

内部观察宏仅在夹具中记录快速路径、回退与候选数量；SDK 默认宏不产生观察状态，也不增加公开导出。调用期间字体及资源保持稳定。GUI 继续只为不可注册的内建 Emoji 包保留跨帧缓存；直接夹具的自定义包重放测试不等同于 GUI 自定义包缓存支持。

## 失败与修正

SDK45 完整严格编译成功，但原生比较第 47 组失败：新旧像素当时一致，缓存却为 2 条和 3 条。两次独立私有桌面 GDB 诊断确认漏掉了 SVG 不可见时潜在的备用 Emoji 字形。调试器退出 0 表示诊断执行成功，不能作为该原生用例通过的证据。失败源码、冷编译、原生日志及诊断材料均保留。

SDK46 在新源码树修正该边界，并增加 SVG 源失效后的缓存重放比较；未修改 SDK45 或此前阶段的材料。

## 实际验证

- SDK46 完整严格 O2/Werror 编译退出 0，298.594 秒。
- 完整引擎夹具冷编译退出 0，386.609 秒；原生运行退出 0，8.922 秒。使用 241 份引擎材料、116 个分编译 XUI 单元、12 份夹具及原 DPI adapter，每个可执行文件只有一个 XRT owner。
- 新增 2399 项断言、24 组用例：19 组快速路径、4 组回退、1 组无效输入；候选上限为 4096，包含 1 组 SVG 失效后的缓存重放。
- 覆盖四种字号、分数与负坐标、长段尾部大号 CJK、LINE_EXPAND、运行时 SVG 平移及 Y-to-X 剪切、无裁剪、多行 CRLF、无效 UTF-8 和 5000 个几乎重叠的 Emoji。
- 原 78 组绘制像素对、39 组缓存重放、63 组检查点、52 组编辑几何、8 个真实 C/xlang 控件、3 组取消及 108 对旧 GPU 像素检查继续通过。四档 DPI 是逻辑层测试；实体混合 DPI 和 IME 继续验收。
- 原 SDK 的 Unicode、Emoji、document 三项及六个当前应用检查通过。当前应用检查使用已有产物，没有重新编译应用。
- 持久准备工具重新生成 241 份 SDK 材料和 10 份应用覆盖，与实际材料一致。持久测试工具显式复用上述冷编译前核对全部引擎、12 份夹具、DPI adapter、参数、可执行文件及日志，重新执行原生比较退出 0。其默认冷编译分支未再次执行。

公开头未改变，SDK46 与 SDK43v2 的 5954 个导出名称和序号一致。该比较不代表相对固定 SDK 的完整 ABI 验收。全 SDK 许可、正式发行及独立干净 Windows 环境验收继续。

## 实际 IDE 窗口与性能

SDK43v2 与 SDK46 共用相同 83 个应用对象及同一探针源码，分别运行 C/xlang、2/16 MiB、多行/单行，共 16 个私有桌面原生窗口，每个通过 45 条检查。8 对 1600×1000 完整截图逐像素一致。实际显示 DPI 为 125%，没有切换用户桌面，截图比较关闭 caret blink。已人工查看 C 和 xlang 的 16 MiB 单行截图，布局及文本显示一致。
