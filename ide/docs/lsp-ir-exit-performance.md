# 热路径隔离候选的完整性能结果

本轮显式开启退出计划缓存的全量图像未通过性能准入，不能替换默认发布程序。继续使用已验收的保守 0.109 配对，退出计划缓存及节点共享均默认关闭。

测试在运行前固定：四对独立进程，32／512 函数、单文件／导入结构、字面量／声明编辑八个场景；小文件 128 代、其他场景 14 代，保留 500 ms 编辑间隔，并在小文件精确重复后追加 384 次连续编辑。后台索引使用服务默认设置。驱动与服务采用前次校准的进程亲和性，结束后恢复驱动原值；没有修改系统电源或优先级，宿主仍非独占。

全部 64 个进程、4,608 次延迟查询和 12,288 次连续编辑查询完成。功能结果、输入摘要、发布目录八个关键程序／DLL 摘要与清理检查通过。原 96 项门槛通过 93 项，三项失败如下：

| 失败项 | 保守程序 | 候选 | 预设上限 |
| --- | ---: | ---: | ---: |
| 32／单文件／字面量，热查询 P95 | 10.3657 ms | 11.1257 ms | 10.883985 ms |
| 同场景，原编辑节奏 CPU／改动 P50 | 4.798228 ms | 6.274606 ms | 5.038140 ms |
| 32／导入／字面量，冷查询 P50 | 49.8798 ms | 52.4050 ms | 52.373790 ms |
