# SVG 外层裁剪与大文件编辑

2026-10-10，独立 SDK15 减少屏幕外 Emoji 的 SVG 递归边界遍历。整套 SDK 严格冷构建、实际几何与像素比较、C／xlang 原生文件矩阵和相关应用回归通过。16 MiB 超长单行仍有数秒响应延迟，性能未验收，长期任务继续。当前应用、固定 SDK、编译器与便携候选保持原样。

前一阶段见[文档坐标缓存](large-source-position-cache.md)。本轮使用当前 83 个实际应用对象分别链接 SDK13 与 SDK15，两边的对象、公开头、夹具和编译器相同。237 个 SDK 材料中，仅 `src/xge_emoji.c` 和 `src/xge_svg.c` 相对 SDK13 改变。

## 修改依据与规则

在由本轮控制器创建并持有句柄的 SDK13 进程上采集两次真实 GDB 栈；每次附加前核对句柄的 PID、创建时刻与可执行路径，采样后实际分离，最终原生进程完成 43 项检查且退出 0。第一次栈位于 SVG 子图形边界遍历，经 Emoji／文本绘制进入编辑器；第二次位于字体查找与整行整形，经行布局进入输入处理。调试暂停影响运行时间，所以该次运行不作为性能基准。

屏幕外 Emoji 原本仍需递归求 SVG 绘制边界，以防自定义图形超出名义目标框。新路径先计算 SVG 渲染器实际使用的外层根裁剪框，包括四层可变画笔的运行时矩阵。只有名义框及该保守裁剪框都确定处于像素裁剪范围外，才跳过子图形遍历；否则继续原有完整边界计算与绘制。保留原有两像素余量和引用释放，不改变世界坐标绘制。

不能单独依据名义目标框提前返回：根变换可能把它移入视口。新 helper 使用真实渲染器的矩阵和合法性检查；没有缓存可变画笔状态、加入文本或字形数组，也没有改公开 API。非有限边界及关闭／无效像素裁剪仍由原有保守判定处理。

## 实际验证

实际引擎比较夹具在一个翻译单元中运行 SDK15 和 SDK13 的真实 Emoji 绘制路径，可执行文件是唯一 XRT 所有者，没有链接 SDK DLL，也没有在 SDK 中加入诊断钩子。原始成功运行完成 35,263 项断言，其中包括 17,274 项几何提前裁剪证明和 768 组新旧像素对照。第一次夹具严格编译因两处测试语句缩进警告退出 1；仅拆开语句后第二版通过，SDK 源码不变，失败日志保留。

几何检查采用六类实际 SVG：普通矩形、超范围图形与描边、组旋转、渐变、偏移 viewBox 和 clipPath；覆盖八类根矩阵、四层画笔组合、64 个目标位置、八种像素裁剪，以及极端坐标、无效参数和非有限判定。实际完整边界受外层框约束，新提前裁剪对应的完整边界也不可见或为空。

像素检查使用真实渲染目标，覆盖屏幕与世界坐标的 768 组对照，返回值、裁剪状态和像素一致。控制用例将名义位置 `(-160, 32, 32, 32)` 经根平移 `+200` 移入视口，新旧都渲染出非空图形。人工查看了该控制截图。未覆盖所有滤镜、内嵌图像、SVG 文本、透明度、GPU 故障或恶意分配失败情形，不能据此宣称完整绘制验收。

SDK15 整套冷构建以 `-O2 -Wall -Wextra -Werror` 和既有三项警告排除实际完成，退出 0，耗时 148.344 秒。原始 `build_dll.bat` 不变，严格构建脚本独立保存在实验根目录；237 个输入前后相同。DLL、导入库和资源对象成套保存，公开头未改变，5,949 个导出名称及序号与 SDK13 一致；导出表一致不等于完整 ABI 验收。

原始 Unicode、Emoji、文档三项 SDK 测试退出 0。现有 `document`、`editor_view`、`goto_view`、`find_view`、`input`、`reading` 六项 IDE 测试在新独立目录使用 SDK15 DLL 全部退出 0。它们复用当前程序，未重新编译应用，不代表完整标准回归、便携包或实体键盘／IME 验收。

原生矩阵是新旧 SDK × C／xlang × 2／16 MiB × 多行／单行，共 16 次独立运行。每例完成 43 项检查，总计 688 项，覆盖打开、定位、插入、撤销、绘制、空闲帧与截图。使用私有 Windows 桌面、1600 × 1000 窗口、1.25 DPI 覆盖和 2 GiB 私有提交限制；桌面未切换到前台，语言服务未配置。
