# 空闲工作空间索引刷新

2026-11-09，M7a2b126i。在已初始化的原生语言服务中，配置、打开／修改／关闭／保存文档及有效文件监视通知改变输入代次后，等待 500 ms 再刷新工作空间索引。默认启用，客户端可用初始化选项 `backgroundWorkspaceSymbols: false` 关闭。必须收到合法的 `initialized` 通知才开始；CLI 后端不支持开启该选项。`experimental.workspaceSymbolBackgroundIndex` 声明此能力。

维护任务复用现有工作空间协调器、语义 worker、输入版本历史、真实成员覆盖、独立声明及事务索引。新增 `xideWorkspaceSymbolsRefresh`，完成原有完整覆盖和前后来源核对，但不遍历／排序查询命中、不创建结果列表或 JSON。其 `Result` 可返回 READY 和工作统计，`Take`／`TakeLsp` 返回 NULL。源码错误、基础设施错误、取消或覆盖不完整都不能成为成功的旧索引结果。

宿主只保留一个维护任务和一个最新待刷新代次；输入变化合并到最新不可变上下文与编辑覆盖。输入队列、语法／语义查询、补全／签名、引用、搜索和诊断工作优先。前台请求先请求取消维护任务，输入与配置代次在维护结束时再次核对。成功的前台符号查询已经刷新当前索引，会撤销多余的空闲刷新。错误后每个已接受输入代次只尝试一次，等待下一次输入／配置／文件通知或手动搜索，不进行定时失败重试。取消为 XRT 的协作取消，不能将请求取消描述为已立即终止编译。

协调器仍只有一个线程和一个语义 actor。任务池等待上限由 8 调整为 9，容纳一个已取消／待执行维护任务及协议已有的 8 个前台请求；会话数、源输入、索引、紧凑守卫和输入历史额度保持。引用、老结果、活动编译对象及分配器开销另计；本阶段没有全进程 RSS 上限或大型工作空间资源准入声明。

IDE 的主语言连接使用服务默认行为；专门处理补全／签名的独立连接显式关闭空闲索引，避免同一 IDE 重复扫描工作空间。该选项无法分配时初始化失败，不退回会启用重复索引的缺省行为。实际 GUI 测试在发送初始化消息的边界观察这一标记，并继续运行真实服务的补全回归。IDE 主连接目前仍由打开 xlang 文件或符号搜索等现有入口启动；零打开文件时随工作空间主动建立连接，以及工程文件监视的完整宿主接入，继续列为后续工作，不能将服务层的零文档刷新测试视为这些生命周期能力已经完成。

`xlang/workspaceSymbolStats` 新增 `background` 对象，包含 enabled／pending／running、调度／开始／完成／取消／失败计数、最近完成工作的覆盖／复用／声明数量、输入代次及最近错误。原前台工作统计保持；serial／epoch 属于最近启动的维护任务，覆盖／索引 work 属于最近成功完成的维护任务，失败时不覆盖这份成功 work；不能拼合它们来代替当前源码证明。查询和 IDE 导航继续执行原有新鲜度检查。

本阶段审计 252 个既有 GCC 依赖闭包，重编译 6 个受影响消费者，新增一个包含生产实现的刷新夹具。首次夹具错误地假定 XRT 取消会立即改变 future 状态；保留其源码／失败，改为在真实提交屏障解除后等待终态，仅该夹具补编。实际执行 33 项原生测试，保留 117 项未受影响测试，共 150 项；1,457 个输入、152 个产物、147 个私有 AST 消费者身份核对。刷新夹具的 25 项检查覆盖完整原生成员、无查询构造、覆盖撤销、错误恢复、确定性提交前取消与空目录清理；额外真实 C 遗漏对照确认去掉刷新路径的查询省略会被检测。

6 套相关协议检查通过，其中新增 11 个场景包含合法 initialized、零文档、19 次编辑合并、磁盘等长变化、项目移除、一次性错误处理与修复、显式关闭、真实 512 函数任务抢占、诊断优先及退出取消。115 个 GUI 对象以当前源码和匹配的 180 文件 SDK 全量重建，12 项真实服务及 1 项受控旧能力 GUI 回归通过，包含 C／xlang 输入、IME／撤销／焦点及新增初始化标记观察。此前重链接辅助脚本对双向 LF／CRLF 还原的误判，以及遗漏主入口的链接失败均保留；这些尝试没有产生合格候选，最终使用完整 GUI 构建。

固定 6 对交替顺序、12 个独立进程的同一服务对比中，512 个真实函数的完整 513 行搜索结果一致；未预建／已在空闲预建的查询中位数分别为 40.4033／9.73485 ms，原始范围 38.7541–43.4535／9.4731–10.6231 ms。未预建每次捕获 1 个入口，已预建查询复用 1 个入口、无新分析。预建仍花费后台分析与 500 ms 等待，这不是启动时间、编辑链路、跨版本全量性能或 RSS 准入；所有样本保留，没有重跑取更佳结果。原正式 A/A 4／64、阶段 A/B 1／64、累计 A/B 0／64 记录、阈值和未准入结论保持。
