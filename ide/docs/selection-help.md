# 集成帮助跟随编辑器选择

在设置 → 文档与帮助设置中开启“集成帮助跟随编辑器选择”（默认开启）。在代码编辑器中选中完整名称后，约 80 ms 后更新当前已显示的集成帮助。帮助中的“固定当前条目”暂停自动跟随；F1 主动查询选区或光标所在名称，并可打开已关闭的帮助窗格。固定状态仅保留在当前 IDE 会话中。跟随提示、固定选项和候选框位于帮助滚动内容顶部，以免在高 DPI、矮 Dock 面板中挤掉正文空间。

## 名称匹配合同

- 支持完整标识符、关键字和连续的限定名称，包括 Unicode 名称。选择 `math.sin` 中的 `sin`，会用附近的 `math.` 补全查询。
- 按编辑器语言隔离 C 与 xlang。完整名称优先；没有完整匹配时提供短名称候选。候选框显示签名，同一组候选中保留用户选择的重载。最多显示 64 个候选，同时显示真实候选总数。
- 这是静态目录的**名称匹配**。界面明确标注“未作语义确认”。当前语言服务没有经过验证的 SymbolId → 目录条目 ID 映射，不能声称已确定变量接收者类型或实际调用重载。例如 `obj.append` 会提供同名候选。普通未知变量、部分单词、多词选择、字符串及注释保持当前帮助。
- 选词不会请求编译分析、等待语言服务器或重建命令树。隐藏帮助、切换到其他工具标签和打开模态弹窗时不自动跟随；跟随保持编辑器焦点。帮助内部的范例编辑器不参与跟随，避免循环。
- 鼠标捕获期间不发布选择，释放后重新防抖。IME 组合输入期间暂停；通过链式事件处理保留原编辑器输入处理。

## 热路径与索引

复用编辑器状态轮询，比较文档身份、核心对象、版本、选区及语言。没有变化立即返回；连续变化只保留最后选择。有效选区最多 512 UTF-8 字节，区间复制最多 1,538 字节，不复制整个文档。使用当前版本的语法 token 排除字符串、字符和注释。

目录加载时建立完整名称、短名称和稳定 ID 三份 32 位排序下标，查询二分边界并只复制有限候选。17,598 条目录的下标主体为 211,176 字节（约 206 KiB），不复制签名或文档文本。同一条目不重新设置控件、范例或阅读位置；同一文档集合不重新解析。

## 后台正文与生命周期

自动跟随的 Markdown 正文由一个按需创建的工作线程解析成不可变块模型。工作线程不访问 GUI 控件；目录 lease 保留其引用的文档，目录重载不会产生悬空指针。每次提交有代数，过期结果丢弃；只保留一个等待请求及一个待发布结果，垃圾队列设置反压。关闭 IDE 时停止并加入线程。

工作线程维护最多 8 个、合计最多 16 MiB 的正文模型缓存；切换目录拥有者时清除旧缓存。缓存限额针对解析后的模型，不包含目录本身的拥有快照。单次正文总输入上限为 16 MiB、4,096 块；超限显示说明并保留原文来源入口。目录现有的单份 Markdown 4 MiB、目录文件 64 MiB 校验仍生效。

UI 线程发布元数据、布局和原生控件。自动正文仅在可见区域创建控件，每帧最多创建两个，完成一个后检查约 0.5 ms 的准备预算；一个原生控件的创建无法中断，因此该预算不是硬实时保证。未创建的段落先估算高度，显示后用实际测量修正。离屏绘制缓存按原有机制释放。退役页面按帧释放原生控件，最多保留两个，避免切换时一次销毁整篇文档。

手动选择命令目录保留原有同步正文入口；它也会取消旧后台结果。手动回到仍在显示的文档时恢复其可见性，避免被已取消任务留下隐藏正文。

## 验证

`catalog_follow_test` 使用真实发布目录、原生命令目录与隔离桌面，覆盖防抖、候选、固定、开关、隐藏/非活动帮助、F1、部分名称/注释/字符串排除、鼠标捕获、IME、Unicode、缓存和目录重载拥有权。它记录 1 MiB 文件的检测与选择发布耗时，并对比开关前后的原生输入和滚动派发加布局耗时。后者不包含 GPU 绘制或显示呈现，不能称为整帧延迟。

配合设置持久化、C/xlang 输入（删除、撤销、Unicode/IME、点击聚焦）、帮助视口/字体/长代码块、目录来源、Dock 和快捷键回归。实际发布数据见同批 `dev/release-materials/provenance/` 中的验收报告。
