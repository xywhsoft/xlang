# 声明族的精确引用收集

工作空间关联查询得到全部已观察原生分量后，可以通过 `xideProjectReferencesSubmitFamilyReferences` 收集整个声明族的 IDENT 引用和声明。它沿用同一工程引用 actor、图缓存、完整范围遍历和输入防护；普通引用查询的行为保持。成功结果同时提供带完整来源证明的 Location 数组及独立的声明族对象，尚不开放标准重命名。

新增分片批量入口按既有原生路径规则对分片来源与声明族来源排序。同一路径的类别、BOM 转换约定、完整正文必须一致；每个存在的声明文件只证明一次，随后将族成员映射到该分片的原生声明区间。扫描已捕获引用表时按已绑定目标查找成员，复用原有 `xideSemanticReferenceShardIdentifierAt`，没有名称推断、重新解析或语义分析，也不为每个成员重新比较整份源码。计数与填充两遍扫描，结果工作统计报告两遍访问数及实际正文比较次数/字节。

单分片结果持有一份原引用分片，保存已投影的精确位置，不持有声明族、检查、缓存或工作线程，支持原所有者退出后的只读并发访问。缺少目标来源时返回成功的空结果；任何相连成员的已有引用无法投影时，拒绝整个捕获，不能静默省略。默认 32 MiB、最大 64 MiB 的构造预算同时计入排序/成员数组、保留的原生路径键与结果。借用输入、路径转换、分配器和排序内部成本额外；结果字节报告保守计入整份所持分片。

工作空间在合并完声明族后遍历已有提供者分片，不再启动成员分析。每个提供者使用与它匹配的输入防护生成文件证明，并要求每条引用都属于明确登记的 `.xl` 成员。全体行只排序一次，按文件核验完整证明，归并到同一证明并去重；不会按族成员或提供者反复合并增长的行数组。输出还逐一确认所有族成员的声明 IDENT 均在结果中，防止仅有使用位置而遗漏声明。

位置路径、行容量和完成后的每文件证明已知合计限制为 32 MiB，构造期间各提供者证明的累计序列化额度为 128 MiB，最终 JSON 仍限制为 7 MiB。DOM/分配器内部开销、提供者图、当前分片捕获与原生分析成本额外，均不能解释成进程 RSS 限额。完成行归并及输出 JSON 后，再核验所有范围的防护，包含没有返回引用的范围；失败、失效和取消不发布任何前缀。

这提供当前原生声明关系闭包内的精确引用集合。完整泛型来源、物理别名和可写性、外部符号策略、配置间绑定冲突、改名冲突及改名后绑定保持、版本化编辑和 IDE 原子应用仍待完成。宽工作空间中跨提供者源码银行共享、当前引擎一致性和全目标性能/内存/长期稳定性准入继续保留。

后续的[版本化候选计划](lsp-rename-plans.md)复用这些位置与来源证明，生成精确 before/after 字节及用于重新分析的偏移映射；尚不授权应用编辑。

本阶段通过 180 个原生测试程序、12 组协议测试和 29 项 GUI 检查。新增分片专项 425 项检查，以逐声明旧查询为差分对照，验证普通、索引与复合属性的原生 IDENT 行、按文件正文比较、空来源零引用扫描、声明过滤、Unicode/BOM/CRLF、最小成功额度及少一字节拒绝、两处真实分配拒绝、全部观测取消位置和脱离原所有者后的四读者访问。工作空间专项 293 项检查覆盖所有范围、未打开与独立文件、不同签名同名方法的排除、温热零捕获/零成员任务、未登记导入文件中的引用、声明遗漏、最终输入变化、取消和独立结果。

仅保留首个族目标、忽略完整来源变化、放行未登记引用、跳过最终防护、跳过声明覆盖这五个实际实现变异均被拒绝。资格检查绑定 291 个实际编译消费者、181 个程序及 core 的所有成员；配对同一语言服务和匹配 SDK 重编译全部 116 个 GUI 对象，完成 C/xlang 输入、删除、撤销、Unicode/IME、焦点及现有语言功能回归，浅色、深色与属性引用窗格已复核。材料索引为 `dev/release-materials/provenance/lsp-family-references-20261111.json`，保留首次路径表示测试失配及原始构建/运行材料。没有替换默认发布程序、推送线上或声明通过全目标性能准入。
