# 退出计划缓存的原生热路径隔离

本轮缩减显式开启退出计划缓存时的接入成本。优化仍默认关闭，已交付的保守 0.109 程序保持原样；本轮不构成正式性能或完整发布验收。

## 改动

缓存资产指针和结果统计移到 `xls_ir_memo` 末尾，保留上下文、片段列表、实体映射、输入证明和派生记录等原有字段的偏移。与旧启用配置相比，头部的分配大小保持不变。检查夹具用独立的旧字段布局及旧前缀布局作编译期对照；重新引入前缀的实际 C 变体必须失败。

无退出计划缓存预算时，在初始化临时键状态之前进入原生刷新分支。需要缓存的路径放入单独函数，受支持编译器上禁止把它重新内联到入口；原生扫描、初始化器作用域、原始生产者和清理流程保留。预算、完整验证、取消检查、资产所有权和失败回退规则不变。

启用配置只有发生过退出计划查询或仍持有资产时才构造 `analysis.irExit`。没有查询、没有资产时省去这组可选统计；调用者可将缺失视作没有相关活动。持有资产的整结果复用仍可显示统计，创建时的统计不代表每次精确命中都重新执行了生产者。

启用配置仍有缓存字段、作用域和观测计数，其实际 CPU／内存成本必须继续测量，不能据此宣称零开销。

## 组件验收

- 八个定向原生程序通过，覆盖完整新旧 IR 对照、输入键、持久化、派生阶段、预算、并发、取消和生命周期。
- 退出计划普通检查 2,523 项断言，以及包含它们的分配／取消检查共 2,556 项断言通过。
- 当前审核批次的十个布局断言通过；实际恢复旧前缀的 C 变体被明确的字段偏移断言拒绝。
- 32 进程／160 次 stdio 功能矩阵通过：40 条小输入结果省去未使用统计，16 条大输入热结果证明实际复用且没有执行原生退出计划生产者。
- 七组协议回归通过：原生补全、取消、签名、导入错误下补全、持久化 IR、节点视图和自动诊断。

这是一份显式开启的私有组件构建，复用同批次其他不透明 ABI 的已验证对象。没有完成该配置的全量原生／配对 GUI 发布重建，也未做新的整套端到端性能准入。后续必须继续验证原编辑节奏下的计时可靠性及全部目标，不能把代码段缩小或单组校准通过当作整体提速证明。
