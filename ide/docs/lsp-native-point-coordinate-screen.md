# 原生点位坐标复用的筛选

M7a2b126s，2026-11-10。本阶段提交已验证的点位生产归因工具及材料索引。坐标复用原型没有达到预先登记的 CPU 收益门槛，保留在开发材料包，**不合入生产源码、不替换默认程序**。完整 LSP 和性能目标继续。

## 归因与原型

归因工具在实际 `nativePointsCreate` 中增加构造、事实／范围、批量坐标、游标和排序阶段计时。十个插桩对象重编，四项原生回归及正常／探针 16 进程、240 请求稳定事实对照通过，360 帧保留。新增阶段各有 112 个实际构造样本；跨四类案例的中位数分别约为 1.286、17.176、4.134、5.180、8.590 ms。它们包含冷启动、首次和热修改，不能将中位数相加作为 CPU、请求延迟或提速结论。落盘工具与执行过的私有工具字节一致。

原型在已有不可变 `xls_text` 的 XRT 行数组中记录 ASCII 前缀终点。新增的三态入口只直接核验 ASCII 前缀；Unicode 后缀仍进入原有 dense／有序批量转换。每个端点仍验证原编译器行列、UTF-8 标量与 CRLF 边界；BOM、源身份、类型和完整原生校验保持。未知端点需要时才分配原容量的临时表，原保守额度不扩大。最终实现只在原边界检查之后直接读取已完成构造的私有 XRT 数组；汇编确认该入口没有外部调用，不代表整个桥接零开销。

早先逐端点解码的原型已停止。实际包装原解码器证明：512 个 Unicode 端点触发 131,328 次解码，1,024 个触发 524,800 次，存在三角增长。该版本、终止记录和未完成构建日志保留；没有将它计为完整构建或性能验收。

## 正确性与接入

最终候选核对 259 个实际依赖闭包，沿用已重编的 177 个公共头消费者，再重编一个私有实现；公开头不再次改变。157 项原有原生夹具全部重新链接运行。新增文本夹具使用独立逐字节参考实现，覆盖 500 轮改动、保留旧快照、UTF-16／BOM／CRLF、失败输出及真实分配拒绝：Release 为 1,318,053 项检查，单独匹配 Debug-memory 为 1,317,875 项。长 Unicode 单行的 4,096 次快速入口调用确认不进行标量解码。

导航扩展夹具为 139,663 项检查，包含原点位／分配失败／缓存／生存期回归，以及 64／256 个 Unicode 参数同处一行的真实程序、BOM／CRLF 和逐位置导航参考对照。两类运行配置的包装调用可见范围不同，实际创建／编辑故障位置分别为 7／7 和 6／6，不将它们混为一个分配计数或内存证明。

最终实现的四个文本 C 破坏对照和两个导航 C 反例均实际编译、链接并由明确 CHECK／exit 1 检出；没有将编译失败或崩溃作为检出。八套协议通过。IDE 使用相同服务和匹配 SDK／DLL，全量重编 115 个普通对象、入口及资源，26 项联调通过，覆盖 C／xlang 输入、删除、撤销、Unicode／IME、焦点和相关语言功能；三张补全、输入法、深色搜索截图已检查。这里验证的是匹配的冻结前端组合，没有重新准入并行修改的当前引擎工作树。

## 首次固定性能筛选

预先登记 512 函数、单文件／导入、字面量／局部声明四类案例；四对进程、14 个版本及一次完全相同请求，共 32 个进程、480 请求。默认后台开启，一次只运行一个服务链，统计完整交互链 CPU。启动／运行可用提交额度门槛为 5／3 GiB，计时期间本任务停止构建及其他 QA，宿主非独占。

原有 40 项不回退、精度、内存和精确命中限制全部通过；额外要求四类整链每改动 CPU 中位数比值的等权几何平均不大于 0.98。实测为 **0.9903228777**，改善约 **0.97%**，低于 2% 要求。因此 41 项中 40 项通过，最终拒绝合入原型。
