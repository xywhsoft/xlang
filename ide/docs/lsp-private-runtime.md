# IDE 与语言服务的本地运行包

本阶段将已验收的原生语言服务 0.105 接入本地默认 IDE，同时明确界面库与引擎库的归属。产品显示版本和更新迭代号不在此阶段变更，线上更新通道不发布。

## 运行库边界

公共 `release/win_x64/xge.dll` 与当前 IDE SDK 的 DLL 都显示 3.0.0，但 ABI 分别为 `0x9e6e84f348182bf8` 和 `0xcb44b468900ed7c0`。真实的 `xgeGetBuildInfo` 与 `xgeCheckBuildCompatibility` 已证实两者不兼容。

IDE 使用 `xlang_ide_xge.dll`，字节与选定 SDK 的 `xge.dll` 一致。公共 `xge.dll` 继续由引擎及扩展依赖维护。IDE 通过独立进程调用编译器和语言服务，没有在界面进程加载 `xl.dll`、`xlc.dll` 或引擎的 XGE，因此不会混用两个 XRT 分配器。

| 文件 | 归属 |
| --- | --- |
| `xlang_ide.exe`、`xlang_ide_xge.dll` | 完整重编译的 IDE 与匹配框架 |
| `xlang-ls.exe` | 已验收当前前端规则的独立原生服务 0.105 |
| `update.exe` | 不依赖 XGE 的独立更新器 |
| `xl.exe`、`xl.dll`、`xlc.dll`、`xge.dll` | 保留现有引擎运行包 |

`src/platform/runtime_library.h` 定义 IDE 运行库文件名。`tools/ide_runtime_library.py` 从 SDK 的 GNU 导入库生成派生库，只修改一个对象的 `.idata$7` DLL 名称段，验证其余 7069 个对象逐字节不变，并检查 `dlltool -I` 的结果。SDK 本身及元数据保持不变，函数、数据导入和调用方式沿用原库。

## 构建、启动和交付

`tools/build.ps1` 使用派生导入库，完整重编译所有 GUI 单元，记录名称、SDK DLL 和原始/派生导入库摘要。`tools/publish_ide_runtime.py` 验证实际 GUI 导入、SDK DLL 摘要和文件占用，准备所有文件及备份后，按运行库、可选更新器、语言服务、GUI 的顺序替换；失败时仅回退本次安装且字节仍匹配的文件。

长路径启动暂存同步使用专用运行库，记录格式、魔数和目录前缀升为 v3。仍校验源程序、DLL、身份、所有者和摘要，持有父/子租约，按原有期限与扫描预算回收。旧 v2 目录保持原状，不推断删除权限。缺少专用 DLL 时，不回退到公共 DLL。

原生重命名保护加入新 DLL，并保留公共 DLL 保护。更新管理器、独立更新器、发布清理和便携打包将两个 DLL 作为独立文件处理，扩展包和用户配置的所有权规则不变。更新器构建增加候选输出选项，可验收后随 IDE 安装。

## 验收与记录

完整 GUI 构建、配对服务回归、真实渲染、原生启动及缓存租约、签名更新和安装回退结果见：`dev/release-materials/provenance/lsp-private-runtime-20261116.json`。缺失测试代理造成的首次验收中止也保留在原始记录中。对象、截图和日志存入外部开发材料，运行目录不保留测试程序。

原生 0.105 的完整前端资格来自[当前编译器前端对齐](lsp-current-ownership.md)。本阶段单独复核安装后的协议与 IDE 行为，历史执行次数不算作新执行次数。

本轮通过 140 单元 GUI 重建、55 项配对 GUI、47 个实际编辑/重命名场景、45 项签名更新回归、19 项安装后前端协议检查、4 种缺省/损坏配置启动，以及原生和真实 GUI 的长路径、父进程中断与缓存回收检查。安装器的 8 个成功/中断用例覆盖已有和缺失专用 DLL 两种状态。7090 个既有非安装文件逐字节保持不变，用户已有临时目录保留。

打包检查最初遗漏系统 DirectWrite 依赖，实际安装完整回退后补齐分类并重新通过。旧启动夹具还假定缺失的 Noto 字体、精确的最少帧数以及设置文件完全不写历史；修正为选择实际发布字体、验证任务安定后的最终帧回执、保持全部非历史偏好相同且仅允许夹具输入进入历史。缓存目录比较使用物理路径，支持开发材料目录的联接。原失败记录均保留，没有据此降低源/DLL 身份、摘要、租约、父子进程、退出状态或截图检查。

本地安装不代表完整 LSP、整体性能目标或物理 Windows 7 设备兼容性已经完成，现有引擎运行字节也未升级。自动工作区发现接入、剩余协议能力、补全尾部延迟、长期资源预算和跨平台验收继续推进；不包含 DAP 或运行/调试态补全。
