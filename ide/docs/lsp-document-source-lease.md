# 文档源码准入与准备结果代次

M7b5m，2026-11-12。`editor/documents` 为完整 WorkspaceEdit 宿主补充文档模型参与者。与语言功能、文件监视、任务和工具链的暂停接口组合后，宿主仍需完成来源、物理别名、请求/配置/项目、用户确认、其他独立读者与恢复策略；本阶段不启用标准 rename 或 `workspace/applyEdit`。

## 所有者与代次

`xideDocumentsSuspendSources` 由文档 store 的 UI 所有者调用，不等待或分配。已有同步模型操作及其回调尚未返回时拒绝暂停，避免在打开、保存、重载或迁移的半途中授权静默。成功推进非回绕的 `sourceEpoch` 并返回准确令牌。`SourcesSuspended` 只证明本 store 的同步模型入口已静默，不能证明后台线程退出、缓存读者静默或允许源码写入。

持有期间，普通打开（含已打开路径）、预准备打开、会话恢复、创建模型、保存、重载、外部快照接收、源文件重命名、关闭、语言切换和旧元数据迁移均在路径工作、直接分配、回调和源码 I/O 之前拒绝。`CheckExternal` 无法读盘时返回保守的“有变化”。已有元数据查询、不可变基线租约、真实编辑器的输入/删除/撤销/IME/聚焦以及显式批量发布助手仍可用，没有切换控件只读或给每次键入增加正文扫描。已有路径相等查询仍可能打开文件属性句柄；不把这些查询说成纯内存或零 I/O。

`xideDocumentsResumeSources` 只释放准确的当前令牌。宿主必须先完成写入、回滚或恢复协调；没有超时自动解锁。序号耗尽时拒绝新暂停。令牌和代次属于同一个已初始化 store 生命周期，不能跨 `Init/Clear`、不同 store 或借用已释放的 store 地址；Clear 终止该生命周期。store 地址须活过其同步调用及回调，操作不可跨线程并发。

`sourceEpoch` 是来源代次，不是新的请求身份，也不是读盘许可。准备快照前捕获，交付时原样携带；不能在接收旧结果时重新取当前代次。`OpenPrepared`、`AcceptExternal` 和 `Recover` 要求显式代次，拒绝零值、过期输入及暂停中的接收，失败保留调用方快照所有权。普通同步 Reload 的整个读取和接收都位于同一个活动模型操作内，因此其代次在这段期间不能被暂停推进。

Resume 不把代次退回。即使文件和正文完全未变，暂停前的快照及元数据迁移计划仍必须重新准备。迁移 Validate 和 Apply 都先检查代次；后者对暂停/过期计划不执行元数据发布。既有迁移调用者仍必须在物理移动前完成 Validate，且在移动与 Apply 之间不派发事件；没有新增正文比较或把 Apply 当作完整验证器。

## 实际消费链

工作空间符号搜索在请求捕获时保存代次，排队结果、导航和缓存文档打开重复检查同一代次。监视器在订阅建立时保存代次；指纹包含该元数据，跨代次重新订阅时不继承旧观察基线，也不为旧待处理快照换发新代次。模型持有期间不消费监视器 UI 事件；显式 monitor Resume 可在宿主已经完成写入后重建新订阅，准备的新事件等到文档准入释放后再发布。监视器仍须单独暂停并确认实际 worker 静默。

会话恢复在读取恢复缓存前捕获代次；持有期间 SessionPoll 不消费恢复工作。相关直接调用和测试均改为显式传入准备代次，没有保留绕过检查的无代次快照入口。

## 验证与边界

`document_source_lease_test` 以真实 GPU/XUI、C/xlang Document 和实际文件验证入口拒绝、准确/耗尽令牌、同步回调中拒绝暂停、失败前缀退役、过期 prepared/external/recovery/relocation、空 store 与 held Clear，以及暂停中的点击聚焦、输入、删除、撤销和 Unicode/IME。直接 CRT 分配、路径解析、模型文本读取及 DLL 读写导入槽的拒绝路径探针均为零；这不覆盖 DLL 内部分配、系统缓存或整个 IDE。

`file_sync_lease_test` 组合真实 IOCP 监视器和文档准入，阻塞新订阅的实际 ReadFile，确认旧缓存不获得新代次。新数据尚未读到时，模型仍保留原文本；解除门控后才接收新内容。符号搜索夹具在监视修订和磁盘未变化时推进文档代次，确认旧准备导航在暂停中及恢复后均不能打开目标。

新 store 字段改变 app 布局，因此重编完整 IDE 消费者，并绑定同一 SDK、原生服务与根目录编译器；正常运行目录保持原交付，验证通过精确私有别名在根 release 中执行。阶段材料索引为 `dev/release-materials/provenance/lsp-document-source-lease-20261112.json`。

本模块没有拥有或枚举后台 prepared-open 工作线程，没有批准完整来源集合、后台应用器、恢复写回或用户确认，也不是全局读写锁。普通打开、保存及重载增加固定的所有者准入/活动计数；监视器已有指纹增加一个代次字段，没有增加每键正文扫描。全局宿主组合、完整 LSP 与端到端性能/交付资格仍待继续完成。
