# 完整原生候选池与前缀替换补全

M7a2b67a / 开发服务 0.96。对比已验收的 M7a2b65a / 0.95；M66 的坐标实验仍未合入。本切片通过限定路径验收，长期目标 active，发布目录不变。

## 查询路径和所有权

原光标补全消费独立候选、来源、memo 和拓扑单元。0.95 只允许原前缀的子集；0.96 在可选生产者完整成功时保存原生发射器的全部可见候选，允许同一非零 token 的前缀扩大、换词、退格和光标移动。原解析器的 AST 逐字段证明、全部输入身份／正文／配置／路径及磁盘／探测／包环境守卫保留；未知、取消、预算或分配失败仍回退原路径。

候选观察点组合在已有命名空间适配器之后、原私有名称过滤之后。原过滤查询的 appender 逐字节保留，源文件和已有命名空间生成文件均钉住 SHA256。独立池的 builder 保留原 item/text 限制、增长和字段规则，只把字符串改为 XRT `xstrbuf` 中的偏移记录；缓冲区增长时没有悬空指针，End 固定缓冲区地址后才生成原生 item 指针。原前缀过滤本应释放的 canonical 缓冲区及时释放，匹配候选的原缓冲区继续归原查询。

builder 使用 XRT 的字符串缓冲区与分配器，复用已有前端上下文的 scope slot，不新增 TLS 域。池只在当前结果内暂借原 selection；独立补全单元随后复制最小位置事实和字符串，不持有旧完整 semantic result／checked AST／IR。按需完整 AST getter 仍运行当前原始分析，不用残缺节点对外冒充完整 AST。

原生上限仍为 4096 items、4 MiB 文本。局部池准入上限来自既有 256 MiB 控制，计入 record-array 容量、XRT buffer 容量及 NUL，以及交接时共存的最终 item array。独立 word unit 继续使用原 known-payload 预算。容器／分配器头、realloc 瞬时副本、原完整分析和其他会话不属于这个局部计数，不能把它当作全局内存峰值。零预算、LIFO 拒绝、嵌套零 scope、上下文异常退出均不改变原查询所有权或错误。

## 正确性和实际生产者

4239 项候选池检查包括四个可选分配 API 边界的逐项失败、原查询自身的失败、精确／短一字节／零／微小预算、长字符串、多次 buffer 增长、4096 item 和长名称拒绝、嵌套／回滚／异常退出。它不是 XRT 内部每个底层分配指令的任意 OOM 穷举。4300 项补全单元、481 项回滚（231 个构造拒绝位置）、34 项拓扑与其余原生用例保留。

真实 stdio 的 56 个场景使用 116 个进程，每份响应同时与当前独立新进程和已验收 0.95 比较，并有预期候选标签断言；只排除 analysis 与已验证为非负整数的 durationMs，候选、类型、位置、来源和其余字段完整比较。覆盖命名空间／成员、Unicode／BOM／CRLF、换词／退格／关键字、其他输入变化及磁盘失效。

最终 `native-v5` 这次新编译 7 个实际受影响对象，183 个按实际 GCC 闭包与当前源码验证复用；归档 62 成员，重新链接并运行全部 102 个夹具，核验服务在内的 103 个 PE／104 项输出。103 个实际私有 AST 对象、102 个不同 C 源文件共享同一已验证 AST 头。较早的私有 context scope 从 32 增至 40 字节时，`native-v3` 已按真实闭包重编全部 28 个受影响消费者；不能将最终修订写成 190 个全新编译。

GUI 在本阶段最初重编 1 个 snapshot 对象，核验复用 106 个并链接 42 个程序；最终修订的 107 个对象和 42 个程序依赖／字节均相同，复用后重新运行 28 组 IDE。48 组协议、四组原始 fresh AST／类型／索引／来源／报告／IR、包上下文和查询体对照全部通过。56 场景的同一最终服务字节证明在协议总验收中显式引用，没有重复计作新执行。

body-boundary reference 只是隐藏／恢复已经物化的函数体，8 个 fixture 通过也不代表减少实际 AST 分配。完整持久 typed function／type／module／最终 IR 生产者、真正部分重建、未列出导入和多项目 catalog／歧义／零打开边界、剩余适用 LSP、100k／并发／长稳与全局预算、编译器／SDK／发布对齐仍未完成。不包含 DAP、运行／调试期间补全。
