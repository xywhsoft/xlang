# 两个原生句柄阶段共用输入证明

实验组件将相邻的原生句柄绑定（阶段 28）与原生句柄投影（阶段 29）组成一个复用单元。每个根声明区间只验证一次输入；命中后分别恢复两个原生结果表。仍先执行全部绑定区间，再执行全部投影区间，保留原生全局顺序。没有先生成完整新结果，再用新结果决定是否命中。

## 原生依赖和适用边界

生成器审核 14 个原生／资源函数的完整正文。两个生产者只追加自己的结果表；节点、类型、符号映射、类布局等输入在两个阶段之间保持不变，投影不读取绑定表。两个结果结构都必须保持独立标量记录。原生必需分配继续经过既有资源失败保护。

共享输入包含实际读取的节点和类型，采用与名称组件共用的有界编号记录器。节点采用保守的 13 字段投影、完整文本及有序子节点；类型包含存在性、种类、C ABI、所有者 ABI、名义符号及参数向量。有效编号去重，入口记录可升级为完整记录；无效类型查询没有索引槽，继续保留存在性读取。

公共输入还覆盖符号映射、泛型实例、类布局／字段和原有结果表。析构查找中的原生整表扫描没有改成另一套算法：公共证明保存有序的全部原生特殊函数候选、其首子节点及名称事实，覆盖候选新增和删除；原生辅助函数真正访问的祖先、节点与类型仍独立记录。

所有命中均要求精确的当前原生编号。类型／节点重定位、归一化语义函数输入、其他阶段及全局最终化器的选择性生产仍未完成。这一组接口也尚未与名称、调用等组件组成普通服务请求的统一缓存。

## 两阶段暂存和失败处理

绑定阶段记录依赖编号及各区间新增绑定表的下标范围。投影阶段合并该区间的编号，运行真正的原生生产者，再保存共享输入及两个结果切片；不长期借用可能重新分配的结果表指针。

命中时在绑定阶段预留整个旧单元的保留额度，防止多个区间在投影阶段才计费而突破上限。旧缓存仅借用到公开接口返回；新缓存按单元原子引用计数共享自有字节，不保留 AST、语义检查对象或原生模块。

保留缓存最多 16 MiB，暂存数组、两个阶段之间的编号副本及工作缓冲合计最多 16 MiB。它们不是整个分析或进程内存的上限。可选元数据分配失败时继续原生生产；原生结果分配失败或取消时退休整个部分模块和候选缓存。只有完整原生验证通过后才能公开新缓存。

## 验证与交付范围

正向语料包含托管类的句柄绑定与 `@lifetime("caller")` 外部类的句柄投影，明确要求两表非空。基础 49 个完整语义输入另外做冷／热结果对比，包含没有句柄结果的输入；不将这些输入称为 49 个正向句柄用例。

最终普通夹具通过 8,745 项检查，契约夹具包含普通检查共 8,976 项，并覆盖 2,450 次退休单元清零、四线程各三代读取。冷／热路径分别枚举 223／203 个外部 XRT 分配或 API 拒绝点、128／120 个取消点。名称和调用缓存原有四个程序继续通过；普通构建入口及相关原生回归另有记录。

合法调用目标编辑保留原生编号，复用 9／10 个区间，仅重产 23／385 个节点（每个阶段）。只移动源码坐标复用全部 10 个区间，两阶段均不扫描节点。新增函数改变结构后完整原生回退，比较完整 JSON 和原生验证结果。

最初的普通类用例只有绑定结果，没有外部类投影，已保留其失败记录。另一个用例试图重命名保留的 `native point handle` 字段，被当前语义规则拒绝；它不计入正向覆盖。编号记录器也明确允许重复的无效类型查询，最初过严的去重断言保留在历史记录中，后续检查只允许这一类重复，仍拒绝有效节点／类型重复。

实际编译的一个错误版本删去了命中单元的预算预留，最初仍通过旧测试：较小暂存先导致了未命中，掩盖计费错误。该通过的错误程序、摘要和日志保留，不计作被拒绝的缺陷。加强后的契约独立汇总当前缓存真正保留的对象，检查冷、混合、限额和四线程热结果；没有改动原本正确的生产计费。相同漏计错误现已被加强后的测试拒绝。

该功能由 `XLS_NATIVE_IR_PIPELINE_COMPONENT=1` 显式启用。普通服务仍走原来的生产流程；组件正确性、复用计数及 IR 构造筛查不构成普通 LSP、IDE、跨平台或端到端性能放行。发布版本状态以交付索引为准。

## 构造耗时筛查

新组件按既定的 24 轮交替顺序运行原生、首次捕获、跨代复用三种模式，每次都比较完整原生 JSON。句柄输入包含 32 个实际绑定和 32 个投影，仅切换一个同形调用目标；普通输入沿用 32 函数重复调用对照。两个输入共 144 次比较，无故障注入链接包装，构造计时不含解析、语义检查或清理，也不含 LSP／IDE。

| 输入 | 原生中位数／P95 | 首次路径中位数／P95 | 跨代路径中位数／P95 |
| --- | ---: | ---: | ---: |
| 原生句柄 | 1.80290／2.76430 ms | 1.82605／2.44200 ms | 1.81215／2.95170 ms |
| 普通函数对照 | 4.73800／6.29460 ms | 5.02825／6.33980 ms | 4.96490／6.10630 ms |

句柄输入首次比值 1.01284 通过 1.15 上限，跨代比值 1.00513 未达到原定 0.98 上限；普通函数首次 1.06126、跨代 1.04789 均未通过 1.02 上限。两个筛查均失败，未重跑同一图像、修改门槛或解释成已排除的噪声。减少两个原生扫描仍没有转化成构造收益，普通函数还承担了可选元数据成本，继续默认关闭。

最后的构建只加强了私有预算断言，生产核心的全部归档成员内容与计时使用的核心相同；归档文件本身有一个符号目录时间戳不同，不能将两者称为整文件字节相同。80 个核心对象逐依赖验证复用，当前契约程序新编译，其余五个同图像程序的通过记录按实际依赖保留。此前第一次完整通过的构建新编译了原生 IR 成员。
