# 退出计划缓存的原编辑节奏筛查

本轮仅检查热路径隔离候选在一个小文件场景下的回归情况。默认关闭的 0.109 发布程序保持不变；本结果不是整套性能准入或发布验收。

在第一次运行前固定两阶段：先比较字节完全相同的保守程序，再比较保守程序与热路径隔离候选。两阶段均运行四对独立进程，采用 32 函数、单文件、声明编辑、128 代主序列、500 ms 编辑间隔；精确重复后再执行 384 次连续编辑。后台工作空间索引使用服务默认值，没有关闭。

本机按物理核心拓扑为被测子进程与驱动设置互不重叠的亲和性，运行后恢复驱动原值。它是测量条件，不是服务运行要求或跨机器常量。没有修改系统电源或进程优先级。宿主仍不是独占环境。

原有相对延迟／CPU、精度下限、精确命中绝对延迟和额外私有内存限制均保留。没有删减慢样本或放宽门槛。输入与发布目录关键程序／DLL 的结束摘要校验通过，测试别名按持有摘要清理。
