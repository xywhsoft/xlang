本阶段对显式开启退出计划缓存的源码全量重建并完成原生、协议及配对 IDE 验收。优化仍默认关闭，发布目录继续使用已验收的保守 0.109 程序；本阶段没有替换程序或推送更新通道。

新全量服务摘要为 `bfb13766f8db6779f8d347b3f26b6aec00ecba41c4a9dd8d9f854d2030f4b043`。它与先前通过单场景计时筛查的组件图像不同，因此不能沿用组件图像的性能准入结论。

55 组 GUI 检查包括 54 组当前服务检查和一组受控的旧能力兼容夹具。协议颜色解码复用已校验摘要的既有独立解码器，记录其来源和身份。没有将这些控制程序说成新服务或全部新编译的依赖。

原生、协议和 GUI 测试均通过临时程序别名使用真实 `release/win_x64` 运行目录。GUI 与同一份全量服务、匹配的私有 XGE SDK／DLL 配对；输入、删除、撤销、Unicode／IME 和焦点处理沿用既有检查。服务、IDE、私有与公共 XGE、引擎和更新器的八个结束摘要全部保持原值。

第一批 GUI 验收因新目录漏带 `fixed-xui-proxy/xui_test_proxy.c` 而中断，没有发生产品断言失败。补齐三个经过摘要校验的既有代理文件后，以新批次重新执行完整 GUI 和编辑事务检查，未修改产品或测试断言。第一批原始日志、非零退出及尚未开始额外检查的排队进程终止记录均保留；原外层记录在异常时仍留下 `running` 字段，另附说明明确它已退出，不能将该字段视为仍在运行或验收通过。

这是全量正确性验收，不是完整发布或整套性能准入。原 500 ms 节奏的全部场景、大型真实工程、长时间运行及其他平台仍需继续验证。节点共享与退出计划复用均保持默认关闭，不以功能通过替代性能放行。
