# 工作区根身份与事务变更

M7b6l，2026-11-15。为后续后台发现 `.xlw/.xlp` 和闭合源文件提供实际的不可变根目录集合，替代原先只记录“有工作区”的布尔标记。本阶段完成标准根元数据与生命周期，尚未自动读取清单或扫描目录，不将这项前置工作称为开箱即用的工作区自动加载。

初始化采用优先级 `workspaceFolders`、`rootUri`、`rootPath`。存在的 `workspaceFolders: null` 或空数组明确表示没有根；存在的 `rootUri: null` 覆盖旧 `rootPath`。较低优先级字段不参与解析或范围推断。每个 folder 需要文件 URI 和 UTF-8 名称，验证绝对路径、转义、NUL、UTF-8 及规范化后的重复路径；不访问目录或清单，不改变进程工作目录。依据：[LSP 初始化定义](https://github.com/microsoft/language-server-protocol/blob/gh-pages/_specifications/lsp/3.17/general/initialize.md)。

`workspace/didChangeWorkspaceFolders` 先完整验证 `removed` 和 `added`，然后生成新快照，按先移除后添加应用。任意一项错误都保留旧集合；数组内部重复路径拒绝，移除未知根及添加已有根幂等。URI 转义、大小写、末尾分隔符和显示名称变化不改变编译器采用的原生词法路径集合。空事件直接保留旧快照，不重新解码全部旧路径。名称叶子与根集合使用 XRT 引用计数，未来后台任务可以保留快照，不借用协议消息或可变 owner 数据。

根集合变化才递增工作区修订、输入代次和 input serial。取消旧检查、补全、签名、语义查询、引用、重命名和工作区符号请求；暂停旧范围的后台符号维护。全局操作在新完整配置到来前拒绝执行，防止仅取消重命名却仍返回旧工程的引用或符号。无配置且最后一个根被移除时，标准独立文件重命名恢复可用；仍有显式 catalog 时保持配置失效，必须刷新。请求形式的 folder 通知返回错误；分析租约期间继续保留输入通知并在释放后按顺序重放。通知格式依据：[LSP 文件夹变更定义](https://github.com/microsoft/language-server-protocol/blob/gh-pages/_specifications/lsp/3.17/workspace/didChangeWorkspaceFolders.md)。

元数据限制为 64 个根，单个路径 32768 字节、URI 262144 字节、名称 65535 字节，已知保留的结构、路径、原生键和标签合计 2 MiB。超过容量明确失败，不截断列表；DOM 对象、分配器开销和事务中的多个快照另计。本阶段不做源正文、文件身份或目录形状验证；根路径集合也不等于完整可编辑成员清单。

新专项协议验收覆盖 28 个场景：空根及旧字段优先级、失败初始化重试、最后一个根移除、实际变更取消四种待完成全局请求、空通知保留待完成重命名、无效事件事务回滚、租约重放及完整配置恢复。原有标准 rename/prepareRename 失效用例改为实际添加根，而不是把空事件误作变更；原始取消和刷新断言继续保留。全部 237 个协议用例、661 项根元数据检查、55 项 GUI 回归、47 个实际 IDE 场景及 C/xlang 程序渲染通过。8 个编译后的反例必须被测试拒绝。绑定重新构建的 119 个原生单元和 139 个 GUI 单元，不把上阶段的原生专项套件说成本轮执行。
