已知数据类型定义（和C一样）：
	bool xxx = true
	->
	bool xxx = true

Variant数据类型定义：
	var xxx = 0
	->
	variant xxx = Variant_New()
	Var_SetInt(xxx, 0)

设置变量数值：
	xxx = x
	Var_Set*(xxx, x)

获取变量数值：
	x = xxx
	x = Var_Get*(xxx)

结构体定义（X Lang的结构体也是普通类型）：
	struct xxx{
		...
	}
	->
	struct xxx{
		...
	}
	typedef struct xxx XLANG_Struct_xxx
	同时加入映射表，结构体一律以指针形式存在
